## Почему это важно

Как найти «Рахимова» в телефонной книге? Вы не читаете каждое имя с первой страницы: открываете книгу посередине, смотрите, впереди буква «Р» или позади, и сокращаете поиск вдвое. Это возможно только потому, что имена стоят **по алфавиту**.

Сортировка и поиск — самые используемые операции в программировании: упорядочить товары по цене в интернет-магазине, определить место в рейтинге, найти студента в базе. На этом практическом занятии мы вручную напишем самые простые и самые важные из этих методов.

:::note
**После этого занятия вы сможете:**

## Статический массив (C++)

**Статический массив** — массив, размер которого известен при компиляции и не меняется во время работы программы:

| Запись | Смысл |
|---|---|
| `int a[100];` | место для 100 `int`; значения не определены («мусор») |
| `int a[5] = {3, 1, 4, 1, 5};` | со значениями |
| `int a[100] = {};` | 100 нулей |
| `const int MAX = 1000;` `int a[MAX];` | размер через константу |

Если в задаче сказано «*n* ≤ 1000», массив объявляют для наибольшего случая (`MAX = 1000`) и используют только первые *n* элементов. Статический массив «не знает» своей длины — *n* нужно хранить в отдельной переменной.

В Java и Python статических массивов нет: массив Java создаётся во время работы через `new int[n]` (его длина потом не меняется), а список Python может менять размер.

## Линейный поиск

**Линейный поиск** — проверка элементов по одному с начала, пока не найдётся нужный. Если не найден, обычно возвращают −1.

- Массив не обязан быть отсортирован.
- В худшем случае проверяются все *n* элементов.

## Сортировка пузырьком

**Сортировка пузырьком (bubble sort)** — сравнение соседних элементов и обмен стоящих в неправильном порядке. За каждый проход наибольший элемент «всплывает» в конец, как пузырёк.

1. На *i*-м проходе сравниваются соседние пары `a[j]` и `a[j + 1]` (*j* = 0 … *n* − 2 − *i*).
2. Если `a[j] > a[j + 1]` — они меняются местами.
3. Если за проход не было ни одного обмена, массив отсортирован — можно остановиться.

После каждого прохода последний элемент на своём месте, поэтому следующий проход на один короче. В худшем случае выполняется около *n*²/2 сравнений.

Другие простые методы — **сортировка выбором (selection sort)**: найти наименьший и поставить в начало; **сортировка вставками (insertion sort)**: вставлять каждый элемент на своё место в отсортированную часть. На практике же используют стандартные функции: Python `a.sort()`, Java `Arrays.sort(a)`, C++ `sort(a, a + n)` — они работают за ~*n* log *n*.

## Двоичный поиск

**Двоичный (бинарный) поиск** работает только в **отсортированном** массиве:

1. Интервал поиска [*chap*, *ong*] — вначале весь массив.
2. Берётся средний элемент: *orta* = (*chap* + *ong*) / 2.
3. Если `a[orta]` — искомое число, найдено. Если меньше — поиск в правой половине (*chap* = *orta* + 1), если больше — в левой (*ong* = *orta* − 1).
4. Повторяется, пока интервал не станет пустым (*chap* > *ong*).

На каждом шаге интервал сокращается вдвое:

| Число элементов | Линейный поиск (не больше) | Двоичный поиск (не больше) |
|---|---|---|
| 1 000 | 1 000 | 10 |
| 1 000 000 | 1 000 000 | 20 |
| 1 000 000 000 | 1 000 000 000 | 30 |

## Разобранный пример 1: линейный поиск

В первой строке *n* (*n* ≤ 1000), во второй — *n* чисел, в третьей — искомое число *x*. Выведите позицию (с 1), где *x* встречается впервые; если не найдено — `-1`.

```python
n = int(input())
a = list(map(int, input().split()))
x = int(input())

orin = -1
for i in range(n):
    if a[i] == x:
        orin = i + 1
        break

print(orin)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = in.nextInt();
        }
        int x = in.nextInt();

        int orin = -1;
        for (int i = 0; i < n; i++) {
            if (a[i] == x) {
                orin = i + 1;
                break;
            }
        }

        System.out.println(orin);
    }
}
```
```cpp
#include <iostream>
using namespace std;

const int MAX = 1000;
int a[MAX];                    // статический массив: место для наибольшего случая

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    int x;
    cin >> x;

    int orin = -1;
    for (int i = 0; i < n; i++) {
        if (a[i] == x) {
            orin = i + 1;
            break;
        }
    }

    cout << orin << endl;
    return 0;
}
```

При вводе `6`, `4 8 15 16 23 42`, `16`: проверяются 4, 8, 15, 4-й элемент — 16, `orin = 4`, `break`. Выводится: `4`. При *x* = 7 проверяются все 6 элементов и выводится `-1`.

В версии на C++ массив объявлен вне `main` — **глобально**: глобальные массивы автоматически заполняются нулями и даже при большом размере не переполняют стек.

## Разобранный пример 2: сортировка пузырьком

В первой строке *n*, во второй — *n* чисел. Отсортируйте массив по возрастанию и выведите его.

```python
n = int(input())
a = list(map(int, input().split()))

for i in range(n - 1):
    almashdi = False
    for j in range(n - 1 - i):
        if a[j] > a[j + 1]:
            a[j], a[j + 1] = a[j + 1], a[j]
            almashdi = True
    if not almashdi:
        break

print(*a)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = in.nextInt();
        }

        for (int i = 0; i < n - 1; i++) {
            boolean almashdi = false;
            for (int j = 0; j < n - 1 - i; j++) {
                if (a[j] > a[j + 1]) {
                    int t = a[j];
                    a[j] = a[j + 1];
                    a[j + 1] = t;
                    almashdi = true;
                }
            }
            if (!almashdi) {
                break;
            }
        }

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) sb.append(' ');
            sb.append(a[i]);
        }
        System.out.println(sb);
    }
}
```
```cpp
#include <iostream>
using namespace std;

const int MAX = 1000;
int a[MAX];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    for (int i = 0; i < n - 1; i++) {
        bool almashdi = false;
        for (int j = 0; j < n - 1 - i; j++) {
            if (a[j] > a[j + 1]) {
                int t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
                almashdi = true;
            }
        }
        if (!almashdi) {
            break;
        }
    }

    for (int i = 0; i < n; i++) {
        if (i > 0) cout << ' ';
        cout << a[i];
    }
    cout << endl;
    return 0;
}
```

При вводе `5` и `5 1 4 2 8`:

| Проход | Массив после прохода | Встал на место |
|---|---|---|
| 1 | 1 4 2 5 8 | 8 |
| 2 | 1 2 4 5 8 | 5 |
| 3 | 1 2 4 5 8 (обменов нет) | — остановка |

Выводится: `1 2 4 5 8`. На 3-м проходе не было ни одного обмена, поэтому флаг `almashdi` («был обмен») остался ложным, и сортировка завершилась досрочно. Уже отсортированный массив проверяется за один проход.

## Разобранный пример 3: двоичный поиск

В первой строке *n*, во второй — *n* чисел, отсортированных по возрастанию, в третьей — *x*. Выведите позицию *x* (с 1) и число шагов, за которое он найден; если не найден — `-1` и число шагов.

```python
n = int(input())
a = list(map(int, input().split()))
x = int(input())

chap, ong = 0, n - 1
orin = -1
qadam = 0
while chap <= ong:
    qadam += 1
    orta = (chap + ong) // 2
    if a[orta] == x:
        orin = orta + 1
        break
    elif a[orta] < x:
        chap = orta + 1
    else:
        ong = orta - 1

print(orin, qadam)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = in.nextInt();
        }
        int x = in.nextInt();

        int chap = 0, ong = n - 1;
        int orin = -1;
        int qadam = 0;
        while (chap <= ong) {
            qadam++;
            int orta = (chap + ong) / 2;
            if (a[orta] == x) {
                orin = orta + 1;
                break;
            } else if (a[orta] < x) {
                chap = orta + 1;
            } else {
                ong = orta - 1;
            }
        }

        System.out.println(orin + " " + qadam);
    }
}
```
```cpp
#include <iostream>
using namespace std;

const int MAX = 1000;
int a[MAX];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    int x;
    cin >> x;

    int chap = 0, ong = n - 1;
    int orin = -1;
    int qadam = 0;
    while (chap <= ong) {
        qadam++;
        int orta = (chap + ong) / 2;
        if (a[orta] == x) {
            orin = orta + 1;
            break;
        } else if (a[orta] < x) {
            chap = orta + 1;
        } else {
            ong = orta - 1;
        }
    }

    cout << orin << " " << qadam << endl;
    return 0;
}
```

При вводе `10`, `3 7 11 15 19 23 27 31 35 39`, `27` (*chap* — левая граница, *ong* — правая, *orta* — середина):

| Шаг | *chap* | *ong* | *orta* | `a[orta]` | Решение |
|---|---|---|---|---|---|
| 1 | 0 | 9 | 4 | 19 | 19 < 27 → вправо |
| 2 | 5 | 9 | 7 | 31 | 31 > 27 → влево |
| 3 | 5 | 6 | 5 | 23 | 23 < 27 → вправо |
| 4 | 6 | 6 | 6 | 27 | найдено |

Выводится: `7 4` — на 7-й позиции, за 4 шага. Линейный поиск сделал бы 7 шагов; для 1 000 000 элементов разница — 20 против миллиона. При *x* = 20 интервал становится пустым и выводится `-1 3`.

:::warning
**Частые ошибки**

- **Двоичный поиск в неотсортированном массиве.** Результат будет неверным — без всякого сообщения об ошибке.
- **`while chap < ong`.** Когда в интервале остаётся один элемент, он не проверяется; условие должно быть `<=`.
- **`chap = orta` или `ong = orta`.** Интервал может перестать сокращаться — бесконечный цикл. Пишите `orta + 1` и `orta - 1`.
- **Внутренний цикл пузырька `j < n - i`.** На последней итерации `a[j + 1]` выходит за границу; правильно `j < n - 1 - i`.
- **Считать, что локальный статический массив в C++ заполнен нулями.** `int a[100];` внутри `main` полон «мусора»; обнулите `= {}` или объявите глобально.
:::

:::tip
Сначала выполните сортировку и поиск вручную на бумажном примере из 5–6 чисел, записывая на каждом шаге *chap*, *ong*, *orta* в таблицу. Если результат программы совпадает с таблицей, алгоритм понят верно.
:::

## Итоги

- Статический массив C++ `int a[MAX];` — размер заранее, для наибольшего случая; *n* хранится отдельно.
- Линейный поиск работает в любом массиве, не более *n* шагов.
- Сортировка пузырьком меняет соседей; если обменов нет, останавливается досрочно; ~*n*²/2 сравнений.
- Двоичный поиск — только в отсортированном массиве, на каждом шаге делит интервал пополам: ~log₂ *n* шагов.
- На практике используют стандартные функции `sort`; ручная реализация — чтобы понять алгоритм.

## Проверьте себя

:::check
Q: Нужно ли, чтобы массив был отсортирован, для линейного поиска? А для двоичного?
A: Для линейного не нужно; для двоичного — обязательно.
Q: Как будет выглядеть массив `3 1 2` после первого прохода сортировки пузырьком?
A: `1 2 3`: 3 ↔ 1, затем 3 ↔ 2.
Q: Сколько шагов не более сделает двоичный поиск в отсортированном массиве из 1024 элементов?
A: 11 (2¹⁰ = 1024; каждый шаг делит интервал пополам, а в конце проверяется и один оставшийся элемент).
Q: Что даёт флаг `almashdi` в сортировке пузырьком?
A: Если за проход не было обменов, массив отсортирован — остальные проходы не выполняются; отсортированный массив проверяется за один проход.
Q: Чему равно `a[0]`, если в C++ `int a[5];` объявлен внутри `main`?
A: Не определено: случайное значение из памяти. Глобальный массив или `int a[5] = {};` начинаются с нулей.
