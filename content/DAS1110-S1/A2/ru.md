## Почему это важно

Если банковское приложение при расчёте процентов отбрасывает дробную часть, клиент теряет деньги. Программа, считающая средний балл студентов в целых числах, выдаст 4 вместо 4,67, и студент получит «удовлетворительно» вместо «хорошо». Это не синтаксические ошибки — программа работает, но даёт неверный результат. Причина часто в неправильно выбранном типе данных.

На этом практическом занятии мы потренируемся с диапазонами типов, преобразованием типов, вводом и выводом.

:::note
**После этого занятия вы сможете:**

- выбирать подходящий для задачи тип данных (`int`, `long long`, `double`);
- избегать переполнения целых чисел (overflow) и ошибки целочисленного деления;
- читать несколько значений, введённых в одной строке;
- выводить результат с нужной точностью и в нужном виде (`01:02:05`, `4.67`);
- пользоваться составными операторами `+=`, `-=`, `++`.
:::

## Размер и диапазон типов

Память компьютера ограничена, поэтому каждый тип выделяет под значение определённый объём. Число, которое туда не помещается, сохранить нельзя.

| Тип (C++ / Java) | Размер | Диапазон значений (примерно) |
|---|---|---|
| `int` | 4 байта | −2,1 млрд … 2,1 млрд (−2³¹ … 2³¹−1) |
| `long long` / `long` | 8 байт | ±9,2 · 10¹⁸ |
| `double` | 8 байт | ±1,7 · 10³⁰⁸, ~15–16 точных цифр |
| `char` | C++: 1 байт, Java: 2 байта | один символ |
| `bool` / `boolean` | обычно 1 байт | `true` или `false` |

В Python `int` не ограничен: чем больше число, тем больше места оно занимает. А `float` совпадает с `double` в C++ и Java.

**Переполнение (overflow)** — выход результата за границы типа. В C++ и Java в переменной `int` 2 147 483 647 + 1 без всякой ошибки превращается в −2 147 483 648. Поэтому для больших чисел (численность населения, миллисекунды, факториалы) выбирают `long long` (C++) или `long` (Java).

## Преобразование типов

Если в выражении встречаются значения разных типов, язык приводит их к одному типу.

- **Неявное (implicit) преобразование** — автоматически от меньшего типа к большему: при сложении `int` и `double` результат — `double`. Например, `7 / 2.0` = 3.5.
- **Явное (explicit) преобразование** — по указанию программиста: в C++ и Java `(double) a`, в C++ также `static_cast<double>(a)`; в Python `float(a)`, `int(x)`.

| Выражение | Python | Java / C++ |
|---|---|---|
| `14 / 3` | `4.666…` | `4` |
| `14 / 3.0` | `4.666…` | `4.666…` |
| `(double) 14 / 3` | — | `4.666…` |
| `int(4.99)` / `(int) 4.99` | `4` | `4` (дробь отбрасывается, а не округляется) |

## Ввод: несколько значений в одной строке

Часто значения даются в одной строке через пробел: `4 5 5`.

- **C++**: `cin >> a >> b >> c;` — сам пропускает пробелы и переводы строк.
- **Java**: метод `nextInt()` класса `Scanner` работает так же.
- **Python**: `input()` возвращает всю строку как текст; её нужно разбить на части методом `split()` и каждую превратить в число: `a, b, c = map(int, input().split())`.

## Форматированный вывод

Чтобы вывести результат в нужном виде, задают формат:

| Задача | Python | Java | C++ |
|---|---|---|---|
| 2 знака после запятой | `f"{x:.2f}"` | `String.format("%.2f", x)` | `fixed << setprecision(2) << x` |
| Ширина 2, впереди ноль | `f"{n:02d}"` | `String.format("%02d", n)` | `setw(2) << setfill('0') << n` |

В C++ для `setprecision` и `setw` нужен `#include <iomanip>`.

## Составные операторы

| Запись | Смысл |
|---|---|
| `x += 5` | `x = x + 5` |
| `x -= 2` | `x = x - 2` |
| `x *= 3` | `x = x * 3` |
| `x /= 2` | `x = x / 2` |
| `x %= 60` | `x = x % 60` |
| `x++` / `++x` (Java, C++) | `x = x + 1` |
| `x--` / `--x` (Java, C++) | `x = x - 1` |

В Python нет `++` и `--`: пишут `x += 1`.

## Разобранный пример 1: секунды в формат часов

Вводится целое число — количество секунд (0 ≤ *n* < 86 400). Выведите его в виде `ЧЧ:ММ:сс`.

```python
n = int(input())

soat = n // 3600          # полные часы
n %= 3600                 # оставшиеся секунды
daqiqa = n // 60
soniya = n % 60

print(f"{soat:02d}:{daqiqa:02d}:{soniya:02d}")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();

        int soat = n / 3600;      // полные часы
        n %= 3600;                // оставшиеся секунды
        int daqiqa = n / 60;
        int soniya = n % 60;

        System.out.println(String.format("%02d:%02d:%02d", soat, daqiqa, soniya));
    }
}
```
```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int n;
    cin >> n;

    int soat = n / 3600;      // полные часы
    n %= 3600;                // оставшиеся секунды
    int daqiqa = n / 60;
    int soniya = n % 60;

    cout << setfill('0') << setw(2) << soat << ":"
         << setw(2) << daqiqa << ":" << setw(2) << soniya << endl;
    return 0;
}
```

При вводе `3725`:

1. `soat = 3725 // 3600` = 1 (целочисленное деление).
2. `n %= 3600` — остаток: *n* = 125.
3. `daqiqa = 125 // 60` = 2, `soniya = 125 % 60` = 5.
4. Каждое число выводится двузначным, с ведущим нулём: `01:02:05`.

Целочисленное деление и остаток здесь не «ошибка», а именно нужный инструмент.

## Разобранный пример 2: среднее трёх оценок

В одной строке вводятся три оценки студента (целые числа). Выведите среднюю оценку с точностью до двух знаков после запятой.

```python
a, b, c = map(int, input().split())

ortacha = (a + b + c) / 3     # в Python / всегда даёт вещественное число
print(f"{ortacha:.2f}")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int a = in.nextInt();
        int b = in.nextInt();
        int c = in.nextInt();

        // (a + b + c) / 3 было бы целочисленным делением, поэтому приводим к double
        double ortacha = (double) (a + b + c) / 3;
        System.out.println(String.format("%.2f", ortacha));
    }
}
```
```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;

    // (a + b + c) / 3 было бы целочисленным делением, поэтому приводим к double
    double ortacha = static_cast<double>(a + b + c) / 3;
    cout << fixed << setprecision(2) << ortacha << endl;
    return 0;
}
```

При вводе `4 5 5`:

1. Читаются три числа; в Python `input().split()` разбивает строку на список `["4", "5", "5"]`, а `map(int, ...)` превращает каждый элемент в число.
2. Сумма — 14. В Java и C++ `14 / 3` дало бы 4 — поэтому сумма сначала приводится к `double`: 14.0 / 3 = 4.666…
3. Выводится с округлением до двух знаков: `4.67`.

:::warning
**Частые ошибки**

- **`(double) (a + b + c / 3)`** — скобка не на месте: сначала целочисленно делится `c / 3`. Преобразование должно выполняться *до* деления.
- **Большое число в `int`.** 50 000 · 50 000 = 2,5 млрд не помещается в `int`, результат получается отрицательным. Используйте `long long` или `long`.
- **Не превратить `input().split()` в числа в Python.** `"4" + "5"` = `"45"`.
- **Не учитывать, что `setfill('0')` действует дальше.** В C++ `setfill` влияет на весь последующий вывод, а `setw` — только на одно следующее значение.
:::

:::tip
Перед выводом результата спросите себя: «какого типа это значение?» Если в выражении только целые числа, а ответ должен быть дробным, — нужно преобразование.
:::

## Итоги

- У каждого типа есть размер и диапазон; `int` ≈ ±2,1 млрд, для больших чисел — `long long` / `long`. `int` в Python не ограничен.
- Деление целых чисел отбрасывает дробную часть; если нужна дробь, приводите к `double`.
- В Python значения из одной строки читаются через `map(int, input().split())`; в C++ и Java `cin >>` и `nextInt()` сами пропускают пробелы.
- Форматирование: `.2f` — два знака после запятой, `02d` — двузначное число с ведущим нулём.
- `x += 5` — короткая запись `x = x + 5`; в Java и C++ есть ещё `x++`.

## Проверьте себя

:::check
Q: Чему равно *x* в Java после `int x = 2147483647; x++;`?
A: −2147483648: `int` переполняется и переходит к наименьшему значению.
Q: Чем в C++ отличаются `(double) 7 / 2` и `(double) (7 / 2)`?
A: Первое равно 3.5 (сначала 7 приводится к `double`), второе — 3.0 (сначала целочисленное деление даёт 3, потом оно приводится к `double`).
Q: Как в Python прочитать три числа из строки `1 2 3`?
A: `a, b, c = map(int, input().split())`.
Q: Чему равны `n // 60` и `n % 60` при `n = 200`?
A: 3 и 20: 200 секунд — это 3 минуты 20 секунд.
Q: Как вывести число 5 в виде `05` (Python и Java)?
A: Python: `f"{5:02d}"`, Java: `String.format("%02d", 5)`.
