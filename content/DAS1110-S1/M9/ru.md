## Почему это важно

Когда программа пишется, неизвестно, сколько студентов будет в группе, сколько фотографий загрузит пользователь, сколько строк в файле. Статическим массивом `int a[1000];` мы угадываем «худший случай»: на маленьких данных память тратится впустую, а на больших места не хватает.

**Динамическая память** решает проблему: во время работы программы запрашивается память ровно нужного объёма и возвращается, когда больше не нужна. Именно этот механизм работает внутри списка Python и `vector` в C++. Понимание его помогает увидеть причину самых тяжёлых ошибок, связанных с памятью: утечек, висячих указателей, выхода за границы.

:::note
**После этого занятия вы сможете:**

- объяснить разницу между памятью стека и кучи (heap);
- объявлять указатель в C++ и пользоваться операциями `&` и `*`;
- создавать динамический массив через `new` / `delete` и правильно его освобождать;
- распознавать ошибки утечки памяти и висячего указателя;
- объяснять, как память управляется автоматически в Java и Python.
:::

## Стек и куча

Две основные части памяти программы:

| | Стек (stack) | Куча (heap) |
|---|---|---|
| Что хранится | локальные переменные, параметры, кадры вызовов | динамически выделенные данные |
| Кто управляет | автоматически: освобождается при завершении функции | в C++ программист (`new` / `delete`); в Java, Python — сборщик мусора |
| Размер | небольшой (обычно 1–8 МБ) | большой (порядка объёма оперативной памяти) |
| Скорость | очень быстро | медленнее |
| Когда известен размер | при компиляции | во время работы программы |

Поэтому большой массив, объявленный в стеке (`int a[10000000];` внутри функции), может переполнить стек; в куче такой массив помещается свободно.

## Адрес и указатель (C++)

У каждого байта памяти есть свой **адрес** — порядковый номер. Переменная где-то располагается в памяти и имеет адрес.

**Указатель (pointer)** — переменная, хранящая адрес другой переменной.

| Запись | Смысл |
|---|---|
| `int* p;` | *p* — указатель на `int` |
| `p = &x;` | `&x` — адрес *x*; теперь *p* указывает на *x* |
| `*p` | значение по адресу *p* («разыменование», dereference) |
| `*p = 10;` | в *x* записывается 10 — через *p* |
| `nullptr` | указатель, который никуда не указывает |

Операции `&` и `*` обратны друг другу: `*(&x)` — это сама *x*.

**Ссылка (reference)** `int& r = x;` — второе имя *x*. Отличие от указателя: ссылка обязательно связана с какой-то переменной, потом не перепривязывается и используется без `*`. Для параметров функций ссылка удобнее (`vector<int>& a` в M7).

## new и delete

В C++ память в куче берётся через `new` и возвращается через `delete`:

| Задача | Запись |
|---|---|
| Один `int` | `int* p = new int(5);` … `delete p;` |
| Массив из *n* `int` | `int* a = new int[n];` … `delete[] a;` |

Правило: на каждый `new` — один `delete`, на каждый `new[]` — один `delete[]`.

Три опасные ошибки при работе с динамической памятью:

| Ошибка | Что происходит | Результат |
|---|---|---|
| **Утечка памяти (memory leak)** | забыли `delete` | программа со временем занимает всё больше памяти |
| **Висячий указатель (dangling pointer)** | указатель используется после `delete` | неопределённое поведение, случайные падения |
| **Двойное освобождение (double free)** | одну память освободили дважды | программа падает |

Поэтому в современном C++ вместо ручных `new` / `delete` чаще используют `vector` и «умные указатели» (`unique_ptr`) — они возвращают память автоматически. Но внутри них работает именно этот механизм.

## Java и Python: сборщик мусора

В Java и Python программист не освобождает память вручную:

- **Java**: `new int[n]` создаёт объект в куче; переменная хранит **ссылку** на объект. Когда на объект не остаётся ни одной ссылки, **сборщик мусора (garbage collector)** удаляет его автоматически.
- **Python**: все значения — объекты в куче, переменные — ссылки на них. Когда счётчик ссылок падает до нуля, объект удаляется.

Это устраняет большинство утечек и висячих указателей. Взамен программист не управляет точно моментом освобождения памяти, а сборщик мусора тратит немного времени и памяти. В Java и Python нет арифметики указателей: работать с адресами напрямую нельзя.

## Разобранный пример 1: обмен значений через функцию

Вводятся два целых числа. Поменяйте их местами с помощью **функции** и выведите. Каждый язык делает это по-своему.

```python
def almashtir(a, b):
    # в Python int — неизменяемый объект: функция возвращает новую пару
    return b, a


x, y = map(int, input().split())
x, y = almashtir(x, y)
print(x, y)
```
```java
import java.util.Scanner;

public class Main {
    // в Java int передаётся по значению, а массив — по ссылке
    static void almashtir(int[] juft) {
        int t = juft[0];
        juft[0] = juft[1];
        juft[1] = t;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int[] juft = {in.nextInt(), in.nextInt()};
        almashtir(juft);
        System.out.println(juft[0] + " " + juft[1]);
    }
}
```
```cpp
#include <iostream>
using namespace std;

// Через указатели: функция меняет исходные переменные
void almashtir(int* a, int* b) {
    int t = *a;
    *a = *b;
    *b = t;
}

int main() {
    int x, y;
    cin >> x >> y;
    almashtir(&x, &y);           // передаются адреса
    cout << x << " " << y << endl;
    return 0;
}
```

При вводе `3 8` все три программы выводят `8 3`.

- **C++**: `almashtir(&x, &y)` («поменять») передаёт адреса *x* и *y*. Внутри функции `*a` — это сама *x*, поэтому обмен происходит в исходных переменных. Можно и через ссылки: `void almashtir(int& a, int& b)` и вызов `almashtir(x, y)`.
- **Java**: `int` передаётся по значению, поэтому два числа кладём в массив и передаём ссылку на массив.
- **Python**: функция возвращает новые значения; числа в Python нельзя изменить на месте.

## Разобранный пример 2: динамический массив

В первой строке *n*, во второй — *n* чисел. Создайте новый массив только из чётных чисел — размером ровно с их количество — и выведите его.

```python
n = int(input())
a = list(map(int, input().split()))

juftlar = [x for x in a if x % 2 == 0]   # список создаётся нужного размера

print(len(juftlar))
print(*juftlar)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] a = new int[n];             // в куче, размер известен во время работы
        int soni = 0;
        for (int i = 0; i < n; i++) {
            a[i] = in.nextInt();
            if (a[i] % 2 == 0) soni++;
        }

        int[] juftlar = new int[soni];    // ровно нужный размер
        int k = 0;
        for (int x : a) {
            if (x % 2 == 0) juftlar[k++] = x;
        }

        System.out.println(soni);
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < soni; i++) {
            if (i > 0) sb.append(' ');
            sb.append(juftlar[i]);
        }
        System.out.println(sb);
        // delete не нужен: сборщик мусора уберёт сам
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int* a = new int[n];              // n int в куче
    int soni = 0;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        if (a[i] % 2 == 0) soni++;
    }

    int* juftlar = new int[soni];     // ровно нужный размер
    int k = 0;
    for (int i = 0; i < n; i++) {
        if (a[i] % 2 == 0) juftlar[k++] = a[i];
    }

    cout << soni << endl;
    for (int i = 0; i < soni; i++) {
        if (i > 0) cout << ' ';
        cout << juftlar[i];
    }
    cout << endl;

    delete[] a;                       // на каждый new[] — delete[]
    delete[] juftlar;
    return 0;
}
```

При вводе `7` и `3 8 5 12 7 6 1`: чётные (*juftlar*) — 8, 12, 6. Выводится: `3` и `8 12 6`.

В версии на C++ два `new[]` и два `delete[]`. Если забыть `delete[]`, в этой маленькой программе ничего не заметно (при завершении операционная система вернёт память), но в функции, вызываемой миллион раз в день, утечка остановит сервер. `juftlar[k++] = x` — сначала запись в `juftlar[k]`, затем *k* увеличивается на 1.

## Разобранный пример 3: растущий массив

Числа вводятся подряд и заканчиваются нулём. Храните их в массиве: ёмкость массива начинается с 2, а когда он заполнен, увеличивается **вдвое**. В конце выведите количество чисел, ёмкость и числа в обратном порядке.

Именно так работают `vector` и список Python.

```python
sigim = 2
massiv = [0] * sigim
soni = 0

x = int(input())
while x != 0:
    if soni == sigim:                  # место кончилось: массив вдвое больше
        sigim *= 2
        yangi = [0] * sigim
        for i in range(soni):
            yangi[i] = massiv[i]
        massiv = yangi                 # старый список удалит сборщик мусора
    massiv[soni] = x
    soni += 1
    x = int(input())

print(soni, sigim)
print(*[massiv[i] for i in range(soni - 1, -1, -1)])
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int sigim = 2;
        int[] massiv = new int[sigim];
        int soni = 0;

        int x = in.nextInt();
        while (x != 0) {
            if (soni == sigim) {           // место кончилось: массив вдвое больше
                sigim *= 2;
                int[] yangi = new int[sigim];
                for (int i = 0; i < soni; i++) {
                    yangi[i] = massiv[i];
                }
                massiv = yangi;            // старый массив удалит сборщик мусора
            }
            massiv[soni] = x;
            soni++;
            x = in.nextInt();
        }

        System.out.println(soni + " " + sigim);
        StringBuilder sb = new StringBuilder();
        for (int i = soni - 1; i >= 0; i--) {
            if (i < soni - 1) sb.append(' ');
            sb.append(massiv[i]);
        }
        System.out.println(sb);
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    int sigim = 2;
    int* massiv = new int[sigim];
    int soni = 0;

    int x;
    cin >> x;
    while (x != 0) {
        if (soni == sigim) {           // место кончилось: массив вдвое больше
            sigim *= 2;
            int* yangi = new int[sigim];
            for (int i = 0; i < soni; i++) {
                yangi[i] = massiv[i];
            }
            delete[] massiv;           // старый освобождаем вручную
            massiv = yangi;
        }
        massiv[soni] = x;
        soni++;
        cin >> x;
    }

    cout << soni << " " << sigim << endl;
    for (int i = soni - 1; i >= 0; i--) {
        if (i < soni - 1) cout << ' ';
        cout << massiv[i];
    }
    cout << endl;

    delete[] massiv;
    return 0;
}
```

При вводе `4`, `9`, `2`, `7`, `5`, `0` (каждое на отдельной строке; *soni* — количество, *sigim* — ёмкость):

| Введено | *soni* (до) | *sigim* | Что произошло |
|---|---|---|---|
| 4 | 0 | 2 | записано |
| 9 | 1 | 2 | записано |
| 2 | 2 | 2 → 4 | массив полон: новый массив, скопировано 2 элемента |
| 7 | 3 | 4 | записано |
| 5 | 4 | 4 → 8 | массив полон: новый массив, скопировано 4 элемента |

Выводится: `5 8` и `5 7 2 9 4`.

Почему вдвое? Если увеличивать каждый раз на один, при каждом добавлении копируется весь массив — ~*n*²/2 копирований для *n* чисел. При удвоении общее число копирований не превышает 2*n*. В версии на C++ `delete[] massiv` освобождает старый массив — без этого память утекала бы при каждом увеличении.

:::warning
**Частые ошибки**

- **Освобождение `new[]` через `delete` (без скобок).** Для массива — обязательно `delete[]`.
- **Использование указателя после `delete`.** Освобождённая память уже не ваша; присвойте указателю `nullptr`.
- **Возврат из функции адреса локальной переменной.** Когда функция завершается, локальная переменная исчезает из стека — указатель повисает.
- **Неинициализированный указатель.** `int* p; *p = 5;` — запись по случайному адресу.
- **`b = a` в Java как «копия» массива.** Это не копия, а вторая ссылка: `b[0] = 1` меняет и *a*.
:::

:::tip
В C++ сразу после `new` решите, где будет соответствующий `delete`. Если этого нельзя точно сказать — используйте `vector`: он сам управляет памятью и умеет проверять выход за границы через `at()`.
:::

## Итоги

- Стек — небольшая автоматическая память для локальных переменных; куча — большая память для динамических данных.
- Указатель хранит адрес: `&x` — адрес, `*p` — значение по адресу; ссылка — второе имя переменной.
- В C++ `new` / `new[]` берут память из кучи, `delete` / `delete[]` возвращают; у каждого должна быть пара.
- Утечка, висячий указатель и двойное освобождение — основные ошибки динамической памяти.
- В Java и Python память возвращает сборщик мусора; переменные хранят ссылки на объекты.
- Растущий массив при заполнении увеличивается вдвое — так работают `vector` и список Python.

## Проверьте себя

:::check
Q: Чему равно *x* после `int x = 7; int* p = &x; *p = 20;`?
A: 20: *p* указывает на *x*, `*p = 20` записывает в *x*.
Q: Как освободить память, выделенную `int* a = new int[100];`?
A: `delete[] a;`.
Q: Что такое утечка памяти?
A: Выделенная динамическая память не освобождается: по мере работы программа занимает всё больше памяти.
Q: Почему в Java нет `delete`?
A: Объекты, на которые не осталось ни одной ссылки, автоматически удаляет сборщик мусора.
Q: Какой будет итоговая ёмкость в примере 3, если ввести 9 чисел (до 0)?
A: 16: 2 → 4 → 8 → 16 (когда приходит 9-е число, 8 мест заняты).
