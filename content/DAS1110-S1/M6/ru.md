## Почему это важно

Электронный журнал — таблица: в строках студенты, в столбцах предметы. Кинозал — ряды и места. Шахматная доска — 8 × 8 клеток. Цифровое изображение — таблица пикселей. Лист Excel — строки и столбцы. Такие данные естественно представлять не одной строкой, а **таблицей**.

Табличные данные хранятся в программе в **двумерном массиве** — **матрице**. Это занятие учит создавать и заполнять матрицу и выполнять над ней самые частые операции.

:::note
**После этого занятия вы сможете:**

- объяснить устройство двумерного массива (строка, столбец, `a[i][j]`);
- создать матрицу *n* × *m* на Python, Java и C++, заполнить её и вывести в виде таблицы;
- вычислить суммы строк и столбцов, суммы главной и побочной диагоналей;
- транспонировать матрицу и избегать ловушки «одной и той же строки» в Python.
:::

## Двумерный массив

**Двумерный массив (матрица)** — массив массивов: каждый его элемент сам является массивом (строкой). В матрице *n* × *m* — *n* строк и *m* столбцов.

| Понятие | Запись | Пример (матрица 3 × 4) |
|---|---|---|
| Элемент | `a[i][j]` — строка *i*, столбец *j* | `a[1][2]` — 2-я строка, 3-й столбец |
| Число строк | *n* | 3 |
| Число столбцов | *m* | 4 |
| Индексы строк | 0 … *n* − 1 | 0, 1, 2 |
| Индексы столбцов | 0 … *m* − 1 | 0, 1, 2, 3 |

Первый индекс — **строка**, второй — **столбец**. Это соглашение соответствует порядку чтения таблицы: сначала ряд, потом место в нём.

В памяти матрица хранится по строкам: сначала все элементы 0-й строки, затем 1-й и так далее. Поэтому обход матрицы по строкам (внешний цикл — строка, внутренний — столбец) работает быстрее.

**Квадратная матрица** — число строк равно числу столбцов (*n* × *n*). У неё две диагонали:

| Диагональ | Элементы | Условие |
|---|---|---|
| Главная | `a[0][0]`, `a[1][1]`, …, `a[n-1][n-1]` | *i* = *j* |
| Побочная | `a[0][n-1]`, `a[1][n-2]`, …, `a[n-1][0]` | *i* + *j* = *n* − 1 |

## Создание матрицы

| Задача | Python | Java | C++ |
|---|---|---|---|
| *n* × *m* нулей | `a = [[0] * m for _ in range(n)]` | `int[][] a = new int[n][m];` | `vector<vector<int>> a(n, vector<int>(m));` |
| Со значениями | `a = [[1, 2], [3, 4]]` | `int[][] a = {{1, 2}, {3, 4}};` | `vector<vector<int>> a = {{1, 2}, {3, 4}};` |
| Число строк | `len(a)` | `a.length` | `a.size()` |
| Число столбцов | `len(a[0])` | `a[0].length` | `a[0].size()` |

В C++ есть и классическая статическая матрица: `int a[10][10];` — её размер задаётся заранее.

### Ловушка в Python

`a = [[0] * m] * n` — **неверно**! Это создаёт не *n* отдельных строк, а *n* ссылок на **одну** строку. Если написать `a[0][0] = 5`, первый элемент станет 5 во всех строках. Правильный способ — создавать каждую строку отдельно: `[[0] * m for _ in range(n)]`.

## Обход матрицы

Матрицу обходят **вложенным циклом**: внешний цикл по строкам, внутренний — по столбцам.

| Задача | Внешний цикл | Внутренний цикл | Действие |
|---|---|---|---|
| Все элементы | *i*: 0 … *n* − 1 | *j*: 0 … *m* − 1 | `a[i][j]` |
| Сумма строки *i* | — | по *j* | `s += a[i][j]` |
| Сумма столбца *j* | — | по *i* | `s += a[i][j]` |
| Главная диагональ | *i*: 0 … *n* − 1 | не нужен | `a[i][i]` |

Для диагонали вложенный цикл не нужен: на диагонали в каждой строке только один элемент. Вариант с вложенным циклом по *n*² элементам и `if i == j` тоже работает, но в *n* раз медленнее.

## Разобранный пример 1: суммы строк и столбцов

В первой строке *n* и *m*, в следующих *n* строках — по *m* целых чисел. Выведите сумму каждой строки (каждую на отдельной строке), затем все суммы столбцов в одной строке.

```python
n, m = map(int, input().split())
a = [list(map(int, input().split())) for _ in range(n)]

for i in range(n):
    satr = 0
    for j in range(m):
        satr += a[i][j]
    print(satr)

ustunlar = []
for j in range(m):
    ustun = 0
    for i in range(n):
        ustun += a[i][j]
    ustunlar.append(ustun)
print(*ustunlar)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int m = in.nextInt();
        int[][] a = new int[n][m];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                a[i][j] = in.nextInt();
            }
        }

        for (int i = 0; i < n; i++) {
            int satr = 0;
            for (int j = 0; j < m; j++) {
                satr += a[i][j];
            }
            System.out.println(satr);
        }

        StringBuilder sb = new StringBuilder();
        for (int j = 0; j < m; j++) {
            int ustun = 0;
            for (int i = 0; i < n; i++) {
                ustun += a[i][j];
            }
            if (j > 0) sb.append(' ');
            sb.append(ustun);
        }
        System.out.println(sb);
    }
}
```
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> a(n, vector<int>(m));
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cin >> a[i][j];
        }
    }

    for (int i = 0; i < n; i++) {
        int satr = 0;
        for (int j = 0; j < m; j++) {
            satr += a[i][j];
        }
        cout << satr << endl;
    }

    for (int j = 0; j < m; j++) {
        int ustun = 0;
        for (int i = 0; i < n; i++) {
            ustun += a[i][j];
        }
        if (j > 0) cout << ' ';
        cout << ustun;
    }
    cout << endl;
    return 0;
}
```

Ввод:

```text
3 4
5 4 3 5
4 4 5 3
3 5 4 4
```

Представьте, что это оценки 3 студентов по 4 предметам. Суммы строк (*satr*) — общий балл каждого студента: `17`, `16`, `16`. Суммы столбцов (*ustun*) — итог по каждому предмету: `12 13 12 12`.

В сумме столбца порядок циклов меняется: **внешний цикл — столбец** (*j*), внутренний — строка (*i*). Индексы же по-прежнему `a[i][j]` — сначала строка, потом столбец.

## Разобранный пример 2: диагонали и транспонирование

В первой строке *n*, в следующих *n* строках — по *n* чисел: квадратная матрица. Выведите суммы главной и побочной диагоналей, затем транспонированную матрицу.

**Транспонирование** — превращение строк в столбцы: в новой матрице `t[i][j] = a[j][i]`.

```python
n = int(input())
a = [list(map(int, input().split())) for _ in range(n)]

bosh = 0
yordamchi = 0
for i in range(n):
    bosh += a[i][i]
    yordamchi += a[i][n - 1 - i]
print("Главная диагональ:", bosh)
print("Побочная диагональ:", yordamchi)

for i in range(n):
    satr = []
    for j in range(n):
        satr.append(a[j][i])
    print(*satr)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[][] a = new int[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                a[i][j] = in.nextInt();
            }
        }

        int bosh = 0, yordamchi = 0;
        for (int i = 0; i < n; i++) {
            bosh += a[i][i];
            yordamchi += a[i][n - 1 - i];
        }
        System.out.println("Главная диагональ: " + bosh);
        System.out.println("Побочная диагональ: " + yordamchi);

        for (int i = 0; i < n; i++) {
            StringBuilder sb = new StringBuilder();
            for (int j = 0; j < n; j++) {
                if (j > 0) sb.append(' ');
                sb.append(a[j][i]);
            }
            System.out.println(sb);
        }
    }
}
```
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<vector<int>> a(n, vector<int>(n));
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            cin >> a[i][j];
        }
    }

    int bosh = 0, yordamchi = 0;
    for (int i = 0; i < n; i++) {
        bosh += a[i][i];
        yordamchi += a[i][n - 1 - i];
    }
    cout << "Главная диагональ: " << bosh << endl;
    cout << "Побочная диагональ: " << yordamchi << endl;

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            if (j > 0) cout << ' ';
            cout << a[j][i];
        }
        cout << endl;
    }
    return 0;
}
```

Ввод `3` и матрица:

```text
1 2 3
4 5 6
7 8 9
```

1. Главная диагональ: 1 + 5 + 9 = 15.
2. Побочная диагональ: `a[0][2]` + `a[1][1]` + `a[2][0]` = 3 + 5 + 7 = 15.
3. Транспонированная матрица (выводится `a[j][i]`):

```text
1 4 7
2 5 8
3 6 9
```

Транспонированная матрица отдельно не хранилась — для вывода достаточно поменять индексы местами. Если матрицу нужно транспонировать на месте, меняют местами с `a[j][i]` только элементы над главной диагональю (*j* > *i*); если менять все, матрица перевернётся дважды и вернётся в исходное состояние.

:::warning
**Частые ошибки**

- **`[[0] * m] * n` в Python.** Все строки — один объект: изменение одного элемента меняет весь столбец.
- **Перепутанные индексы.** `a[j][i]` и `a[i][j]` — разные элементы; при *n* ≠ *m* — выход за границы.
- **Путаница числа строк и столбцов.** Число столбцов — `len(a[0])` / `a[0].length`, а не `len(a)`.
- **`a[i][n - i]` для побочной диагонали.** Правильно `a[i][n - 1 - i]`; иначе при *i* = 0 — выход за границу.
- **Обнуление суммы строки вне цикла.** Накопитель для каждой строки обнуляется **внутри** внешнего цикла.
:::

:::tip
Прежде чем решать задачу с матрицей, выпишите на бумаге пример 3 × 3 с индексами (`a[0][0]` … `a[2][2]`). Отметьте нужные элементы и найдите связь между их индексами (например, *i* + *j* = 2).
:::

## Итоги

- Матрица — массив массивов; в `a[i][j]` сначала строка, потом столбец.
- Python: `[[0] * m for _ in range(n)]`, Java: `new int[n][m]`, C++: `vector<vector<int>> a(n, vector<int>(m))`.
- Матрицу обходят вложенным циклом; для суммы строки внешний цикл — строка, для суммы столбца — столбец.
- Главная диагональ: *i* = *j*; побочная: *i* + *j* = *n* − 1; для диагонали достаточно одного цикла.
- Транспонирование: `t[i][j] = a[j][i]`.
- Не используйте в Python `[[0] * m] * n` — строки окажутся одним объектом.

## Проверьте себя

:::check
Q: Сколько элементов в матрице 4 × 5 и каковы индексы последнего элемента?
A: 20; последний элемент — `a[3][4]`.
Q: На какой диагонали лежит `a[1][3]` в матрице 5 × 5?
A: На побочной: 1 + 3 = 4 = *n* − 1.
Q: Что выведет Python: `a = [[0] * 3] * 2; a[0][1] = 7; print(a)`?
A: `[[0, 7, 0], [0, 7, 0]]`: обе строки — ссылки на один список.
Q: Какого размера станет матрица 2 × 3 после транспонирования?
A: 3 × 2.
Q: Нужен ли вложенный цикл для суммы главной диагонали?
A: Нет: в каждой строке один диагональный элемент (`a[i][i]`), достаточно одного цикла.
