## Почему это важно

Кассовый аппарат принимает товары по одному, пока покупатель не закончит, — сколько их будет, заранее неизвестно. А месячный отчёт составляется ровно один раз для каждого из 30 дней. Первый случай — `while`, второй — `for`. Правильно выбранный цикл делает программу простой и безошибочной.

На лекции мы рассмотрели виды циклов. На этом практическом занятии применим их в трёх типичных задачах и потренируемся отвечать для каждого цикла на вопрос «когда он остановится?».

:::note
**После этого занятия вы сможете:**

- решать задачу с известным числом повторений с помощью `for`;
- решать задачу, где число повторений определяется условием, с помощью `while`;
- читать данные до ввода «сигнального значения» (например, 0);
- обосновывать, что цикл завершится, и проверять его таблицей значений.
:::

## for или while?

| Вопрос | Если ответ «да» |
|---|---|
| Число повторений известно до начала цикла? (*n* раз, от 1 до 100, для каждого дня) | `for` |
| Цикл продолжается, пока не произойдёт событие? (пока не введён 0, пока число не станет 1, пока остаток не станет 0) | `while` |

Любой `for` можно записать через `while` и наоборот, но подходящий цикл получается короче и понятнее:

| `for` | То же через `while` |
|---|---|
| `for i in range(1, n + 1):` | `i = 1` → `while i <= n:` → … → `i += 1` |
| `for (int i = 1; i <= n; i++)` | `int i = 1; while (i <= n) { … i++; }` |

В `while` легко забыть увеличить счётчик — в `for` он прямо в заголовке.

## Проверка завершения цикла

Для каждого цикла `while` определите две вещи:

1. **Условие остановки** — когда условие станет ложным?
2. **Продвижение** — что меняется на каждой итерации и приближает ли это к условию остановки?

Например, в алгоритме Евклида на каждой итерации второе число строго уменьшается и не становится отрицательным — значит, когда-нибудь оно достигнет 0, и цикл остановится.

## Разобранный пример 1: таблица умножения

Вводится целое число *n*. Выведите для него таблицу умножения от 1 до 10.

```python
n = int(input())

for i in range(1, 11):
    print(f"{n} x {i} = {n * i}")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();

        for (int i = 1; i <= 10; i++) {
            System.out.println(n + " x " + i + " = " + n * i);
        }
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    for (int i = 1; i <= 10; i++) {
        cout << n << " x " << i << " = " << n * i << endl;
    }
    return 0;
}
```

При вводе `7` цикл выполняется 10 раз и выводит:

```text
7 x 1 = 7
7 x 2 = 14
…
7 x 10 = 70
```

Число повторений (10) известно заранее — естественный выбор `for`. В Python `range(1, 11)` не включает 11, поэтому значений 10.

## Разобранный пример 2: алгоритм Евклида (НОД)

Вводятся два натуральных числа *a* и *b*. Найдите их наибольший общий делитель (НОД).

**Алгоритм Евклида**: НОД(*a*, *b*) = НОД(*b*, *a* mod *b*), и НОД(*a*, 0) = *a*. То есть пока *b* ≠ 0, заменяем пару на (*b*, *a* % *b*).

```python
a, b = map(int, input().split())

while b != 0:
    qoldiq = a % b
    a = b
    b = qoldiq

print("НОД:", a)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int a = in.nextInt();
        int b = in.nextInt();

        while (b != 0) {
            int qoldiq = a % b;
            a = b;
            b = qoldiq;
        }

        System.out.println("НОД: " + a);
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;

    while (b != 0) {
        int qoldiq = a % b;
        a = b;
        b = qoldiq;
    }

    cout << "НОД: " << a << endl;
    return 0;
}
```

При вводе `48 18`:

| *a* | *b* | *a* % *b* |
|---|---|---|
| 48 | 18 | 12 |
| 18 | 12 | 6 |
| 12 | 6 | 0 |
| 6 | 0 | цикл завершается |

Выводится: `НОД: 6`. Число итераций заранее неизвестно — поэтому `while`. Гарантия завершения: *b* на каждом шаге строго уменьшается (остаток меньше делителя). Этому алгоритму больше 2300 лет, и он до сих пор используется в криптографии.

## Разобранный пример 3: чтение до ввода 0

В каждой строке вводится по одному целому числу; последовательность заканчивается нулём (сам 0 не учитывается). Выведите сумму, количество и среднее чисел.

Такое значение, обозначающее конец, называется **сигнальным (sentinel) значением**.

```python
yigindi = 0
soni = 0

x = int(input())
while x != 0:
    yigindi += x
    soni += 1
    x = int(input())

if soni > 0:
    print(f"Сумма: {yigindi}, количество: {soni}, среднее: {yigindi / soni:.2f}")
else:
    print("Числа не введены")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int yigindi = 0;
        int soni = 0;

        int x = in.nextInt();
        while (x != 0) {
            yigindi += x;
            soni++;
            x = in.nextInt();
        }

        if (soni > 0) {
            System.out.println(String.format("Сумма: %d, количество: %d, среднее: %.2f",
                    yigindi, soni, (double) yigindi / soni));
        } else {
            System.out.println("Числа не введены");
        }
    }
}
```
```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int yigindi = 0;
    int soni = 0;

    int x;
    cin >> x;
    while (x != 0) {
        yigindi += x;
        soni++;
        cin >> x;
    }

    if (soni > 0) {
        cout << "Сумма: " << yigindi << ", количество: " << soni << ", среднее: "
             << fixed << setprecision(2) << (double) yigindi / soni << endl;
    } else {
        cout << "Числа не введены" << endl;
    }
    return 0;
}
```

При вводе `5`, `3`, `-2`, `0`:

1. Первое число читается **до** цикла: *x* = 5.
2. 5 ≠ 0 — прибавляется, читается следующее: 3. Затем −2.
3. *x* = 0 — цикл завершается; 0 к сумме не прибавляется.
4. Выводится: `Сумма: 6, количество: 3, среднее: 2.00`.

Это шаблон «чтения наперёд»: первое значение читается до цикла, следующие — в **конце** тела. Если первое число 0, цикл не выполняется ни разу, и проверка `soni > 0` предотвращает деление на ноль.

:::warning
**Частые ошибки**

- **Забыли увеличить счётчик в `while`** — бесконечный цикл.
- **Учли сигнальное значение.** Если чтение стоит в начале тела, 0 тоже прибавится, а `soni` окажется на единицу больше.
- **Деление на ноль при пустой последовательности.** Если первое число 0, `soni` = 0 — среднее посчитать нельзя.
- **Порядок в алгоритме Евклида.** `a = b; b = a % b;` — *a* уже изменилось, результат неверный. Сначала сохраните остаток во временной переменной.
:::

:::tip
Написав цикл `while`, проверьте его в трёх случаях: цикл не выполняется ни разу (сразу 0), выполняется один раз, выполняется много раз. Большинство ошибок проявляются в первых двух.
:::

## Итоги

- Если число повторений известно заранее — `for`, если определяется условием — `while`.
- Для каждого `while` определите условие остановки и продвижение на каждой итерации.
- Алгоритм Евклида: пока *b* ≠ 0, (*a*, *b*) ← (*b*, *a* % *b*); ответ — *a*.
- При чтении с сигнальным значением первое значение читается до цикла, следующие — в конце тела.
- Цикл проверяют в случаях 0, 1 и много итераций.

## Проверьте себя

:::check
Q: Какой цикл удобнее для суммы чисел от 1 до 100 и почему?
A: `for`: число повторений (100) известно заранее.
Q: Вычислите НОД(84, 36) алгоритмом Евклида.
A: (84, 36) → (36, 12) → (12, 0); НОД = 12.
Q: Почему в программе с сигнальным значением первое число читается до цикла?
A: При первой проверке условия (`x != 0`) у *x* уже должно быть значение; следующие числа читаются в конце тела, и тогда 0 не учитывается.
Q: Что выведет программа из примера 3, если первым введён 0?
A: `Числа не введены`: цикл не выполняется ни разу, и `soni` = 0.
Q: Сколько итераций выполнит цикл `for (int i = 10; i > 0; i -= 3)`?
A: 4: *i* = 10, 7, 4, 1.
