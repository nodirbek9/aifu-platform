## Почему это важно

Компьютер хранит только числа. И буква «A», и знак «ʻ», и смайлик лежат в памяти как числа. Какое число какой символ обозначает, определяет **кодировка (encoding)**. Непонимание кодировок приводит к проблемам, с которыми программисты сталкиваются постоянно: вместо «Oʻzbekiston» выводится «OÊ»zbekiston», длина строки больше ожидаемой, проверка пароля ломается на узбекских буквах.

На этом занятии разберём, как хранятся символы, как устроены строки в стиле C и на что обращать внимание при работе с буквами узбекского языка.

:::note
**После этого занятия вы сможете:**

- получать код символа и восстанавливать символ по коду, выполнять над символами арифметические операции;
- объяснять устройство строки в стиле C (`char[]` и `'\0'`);
- правильно читать целую строку с пробелами (`getline`, `nextLine`);
- классифицировать символы (буква, цифра, пробел);
- объяснять разницу между ASCII, Unicode и UTF-8 и почему узбекские буквы занимают несколько байт.
:::

## Символьный тип и ASCII

**Символ (character)** — одна буква, цифра, знак препинания или управляющий символ. Каждый символ хранится числом — **кодом**.

**ASCII** — самая старая таблица, сопоставляющая 128 символов (латинские буквы, цифры, знаки препинания, управляющие символы) кодам 0–127:

| Символы | Коды | Чтобы запомнить |
|---|---|---|
| `'0'` … `'9'` | 48 … 57 | `'0'` = 48 |
| `'A'` … `'Z'` | 65 … 90 | `'A'` = 65 |
| `'a'` … `'z'` | 97 … 122 | `'a'` = 97 |
| пробел `' '` | 32 | |
| перевод строки `'\n'` | 10 | |

Важные свойства: буквы и цифры идут **подряд**; код строчной буквы на 32 больше кода заглавной.

| Задача | Python | Java | C++ |
|---|---|---|---|
| Код символа | `ord('A')` → 65 | `(int) 'A'` → 65 | `(int) 'A'` → 65 |
| Символ по коду | `chr(66)` → `'B'` | `(char) 66` → `'B'` | `(char) 66` → `'B'` |
| Символ цифры в число | `ord(c) - ord('0')` | `c - '0'` | `c - '0'` |
| Следующая буква | `chr(ord(c) + 1)` | `(char) (c + 1)` | `(char) (c + 1)` |

В Java и C++ `char` — целочисленный тип, к нему можно прибавлять число. В Python отдельного символьного типа нет: символ — строка длины 1, поэтому нужны `ord` и `chr`.

## Строка в стиле C

C++ унаследовал от языка C **C-строку**: массив символов, в конце которого стоит **нулевой символ** `'\0'` (код 0). Длина строки отдельно не хранится — её считают до `'\0'`.

```text
char s[] = "Salom";
индекс:  0    1    2    3    4    5
символ: 'S'  'a'  'l'  'o'  'm'  '\0'
```

`"Salom"` — 5 букв, но массив занимает 6 мест. `strlen(s)` из `<cstring>` возвращает 5: он считает до `'\0'`. Если `'\0'` пропал, `strlen` и вывод продолжаются до следующего случайного нуля в памяти — ещё одна разновидность выхода за границы.

Работать с C-строками опасно и неудобно (их нельзя скопировать через `=`, а `==` сравнивает адреса), поэтому в C++ обычно используют класс `string` (M11). Но понимать C-строку важно: многие библиотеки и функции операционной системы работают именно с ней.

## Чтение строки целиком

`cin >> s` (C++) и `next()` (Java) читают только **одно слово** — до первого пробела. Если нужна вся строка:

| Язык | Чтение целой строки |
|---|---|
| Python | `input()` — всегда целая строка |
| Java | `in.nextLine()` |
| C++ | `getline(cin, s)` |

Ловушка: если сначала прочитано число (`cin >> k` или `nextInt()`), а потом строка, то `'\n'` после числа остаётся в потоке ввода, и `getline` / `nextLine` возвращают пустую строку. Решение: в C++ — `cin.ignore()` перед `getline`, в Java — читать и число через `nextLine()` и `Integer.parseInt`.

## Unicode и UTF-8

ASCII охватывает только английский алфавит. **Unicode** — стандарт, дающий единый номер символам всех письменностей мира (более 150 000): `A` — U+0041, `Ж` — U+0416, `ʻ` — U+02BB, `😀` — U+1F600.

Способ хранения номера Unicode в памяти — **кодировка**:

| Кодировка | Сколько байт на символ | Где |
|---|---|---|
| **UTF-8** | 1–4 байта; символы ASCII — 1 байт | веб, файлы, Linux, `string` в C++ |
| **UTF-16** | 2 или 4 байта | `char` и `String` в Java, Windows |
| **UTF-32** | всегда 4 байта | используется редко |

В UTF-8 узбекская буква `oʻ` состоит из двух символов: `o` (1 байт) и `ʻ` (U+02BB, 2 байта). Поэтому «Oʻzbekiston» — 11 символов, но 12 байт в UTF-8.

**Расширенные символы**: в C++ `char` — 1 байт, и один символ Unicode в него не помещается. Для этого есть `wchar_t` (широкий символ; 2 байта в Windows, 4 байта в Linux), `wstring`, а также типы `char16_t` и `char32_t`. На практике чаще хранят байты UTF-8 в `string`, а символы при необходимости считают отдельно.

| Язык | Длина «Oʻzbekiston» | Что считается |
|---|---|---|
| Python | `len(s)` → 11 | символы Unicode |
| Java | `s.length()` → 11 | единицы UTF-16 (здесь совпадает с числом символов) |
| C++ | `s.size()` → 12 | байты UTF-8 |

## Разобранный пример 1: шифр Цезаря

В первой строке сдвиг *k* (0 ≤ *k* < 26), во второй — текст (латинские буквы, пробелы, знаки препинания). Сдвиньте каждую букву по алфавиту на *k* позиций вправо (после Z — A), сохранив регистр; остальные символы не меняйте.

```python
k = int(input())
matn = input()

natija = []
for c in matn:
    if 'a' <= c <= 'z':
        c = chr((ord(c) - ord('a') + k) % 26 + ord('a'))
    elif 'A' <= c <= 'Z':
        c = chr((ord(c) - ord('A') + k) % 26 + ord('A'))
    natija.append(c)

print("".join(natija))
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int k = Integer.parseInt(in.nextLine().trim());
        String matn = in.nextLine();

        StringBuilder natija = new StringBuilder();
        for (char c : matn.toCharArray()) {
            if (c >= 'a' && c <= 'z') {
                c = (char) ((c - 'a' + k) % 26 + 'a');
            } else if (c >= 'A' && c <= 'Z') {
                c = (char) ((c - 'A' + k) % 26 + 'A');
            }
            natija.append(c);
        }

        System.out.println(natija);
    }
}
```
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int k;
    cin >> k;
    cin.ignore();                    // отбрасываем '\n' после числа
    string matn;
    getline(cin, matn);

    for (char& c : matn) {           // & — чтобы менять символ на месте
        if (c >= 'a' && c <= 'z') {
            c = (char) ((c - 'a' + k) % 26 + 'a');
        } else if (c >= 'A' && c <= 'Z') {
            c = (char) ((c - 'A' + k) % 26 + 'A');
        }
    }

    cout << matn << endl;
    return 0;
}
```

При вводе `3` и `Salom, Dunyo!`:

1. `'S'`: код 83, `83 - 65 = 18` (позиция в алфавите), `(18 + 3) % 26 = 21`, `21 + 65 = 86` → `'V'`.
2. `'a'` → `'d'`, `'l'` → `'o'`, `'o'` → `'r'`, `'m'` → `'p'`.
3. `','`, пробел и `'!'` не меняются.
4. `'y'`: позиция 24, `(24 + 3) % 26 = 1` → `'b'` — вернулись в начало алфавита.

Выводится: `Vdorp, Gxqbr!`. Для расшифровки та же программа запускается со сдвигом `26 - k`. Остаток (`% 26`) превращает алфавит в «кольцо».

## Разобранный пример 2: классификация символов

Вводится строка текста (символы ASCII). Выведите количество букв, цифр, пробелов и прочих символов.

```python
qator = input()

harf = raqam = probel = boshqa = 0
for c in qator:
    if 'a' <= c <= 'z' or 'A' <= c <= 'Z':
        harf += 1
    elif '0' <= c <= '9':
        raqam += 1
    elif c == ' ':
        probel += 1
    else:
        boshqa += 1

print(harf, raqam, probel, boshqa)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String qator = in.nextLine();

        int harf = 0, raqam = 0, probel = 0, boshqa = 0;
        for (int i = 0; i < qator.length(); i++) {
            char c = qator.charAt(i);
            if ((c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z')) {
                harf++;
            } else if (c >= '0' && c <= '9') {
                raqam++;
            } else if (c == ' ') {
                probel++;
            } else {
                boshqa++;
            }
        }

        System.out.println(harf + " " + raqam + " " + probel + " " + boshqa);
    }
}
```
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string qator;
    getline(cin, qator);

    int harf = 0, raqam = 0, probel = 0, boshqa = 0;
    for (char c : qator) {
        if ((c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z')) {
            harf++;
        } else if (c >= '0' && c <= '9') {
            raqam++;
        } else if (c == ' ') {
            probel++;
        } else {
            boshqa++;
        }
    }

    cout << harf << " " << raqam << " " << probel << " " << boshqa << endl;
    return 0;
}
```

При вводе `Room 214, AIFU-2026`: буквы R, o, o, m, A, I, F, U — 8; цифры 2, 1, 4, 2, 0, 2, 6 — 7; пробелы — 2; прочие `,` и `-` — 2. Выводится: `8 7 2 2`.

Символы проверены диапазонами — это работает, потому что в ASCII буквы идут подряд. Есть и стандартные функции: Python `c.isalpha()`, `c.isdigit()`; Java `Character.isLetter(c)`; C++ `isalpha(c)`, `isdigit(c)` (`<cctype>`). Они могут по-разному оценивать узбекские и другие буквы, поэтому в этом примере использованы диапазоны.

## Разобранный пример 3: символы и байты

Вводится строка текста (UTF-8). Выведите количество символов (Unicode) и байтов в ней.

```python
s = input()

belgilar = len(s)                       # символы Unicode
baytlar = len(s.encode("utf-8"))        # байты UTF-8

print("Символов:", belgilar, "байтов:", baytlar)
```
```java
import java.nio.charset.StandardCharsets;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in, StandardCharsets.UTF_8);
        String s = in.nextLine();

        int belgilar = s.codePointCount(0, s.length());          // символы Unicode
        int baytlar = s.getBytes(StandardCharsets.UTF_8).length; // байты UTF-8

        System.out.println("Символов: " + belgilar + " байтов: " + baytlar);
    }
}
```
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    getline(cin, s);                 // string хранит байты UTF-8

    int baytlar = s.size();
    int belgilar = 0;
    for (unsigned char c : s) {
        if ((c & 0xC0) != 0x80) {    // байты продолжения 10xxxxxx не считаем
            belgilar++;
        }
    }

    cout << "Символов: " << belgilar << " байтов: " << baytlar << endl;
    return 0;
}
```

При вводе `Oʻzbekiston` выводится: `Символов: 11 байтов: 12`. При вводе `Salom`: `Символов: 5 байтов: 5` — в тексте ASCII символов и байтов поровну.

В UTF-8 каждый символ состоит из одного «начального» и 0–3 байтов «продолжения»; байты продолжения в двоичном виде имеют вид `10xxxxxx`. Версия на C++ считает только байты, не являющиеся продолжением: `c & 0xC0` выделяет два старших бита, а `0x80` — это `10000000`. `ʻ` (U+02BB) в UTF-8 — `CA BB`, два байта, один из которых — байт продолжения.

:::warning
**Частые ошибки**

- **Считать `'5'` числом 5.** Код `'5'` — 53; значение цифры — `'5' - '0'`.
- **`getline` после `cin >> k`.** Из-за оставшегося `'\n'` читается пустая строка; добавьте `cin.ignore()`.
- **Не оставить места для `'\0'` в C-строке.** `char s[5] = "Salom";` — нужно 6 мест.
- **Считать `s.size()` в C++ числом символов.** В тексте UTF-8 это число байтов; узбекская `ʻ` и кириллические буквы занимают по 2 байта.
- **Писать `'` (апостроф) вместо узбекской `ʻ`.** Это другой символ: ломаются поиск и сортировка.
:::

:::tip
Обязательно проверяйте программу, работающую с текстом, на узбекском (`oʻ`, `gʻ`), русском тексте и тексте со смайликами. Код, работавший на ASCII, неожиданно ломается на другой письменности.
:::

## Итоги

- Символ хранится в памяти как число — код; в ASCII `'0'` = 48, `'A'` = 65, `'a'` = 97, буквы идут подряд.
- В Java и C++ `char` — целое число, в Python используются `ord` / `chr`.
- C-строка — массив `char`, оканчивающийся `'\0'`; длину считает `strlen`.
- Целая строка читается через `input()`, `nextLine()`, `getline()`; помните об `'\n'`, оставшемся после числа.
- Unicode даёт номер каждому символу, UTF-8 хранит его в 1–4 байтах; узбекская `ʻ` — 2 байта.
- В C++ `wchar_t` и `wstring` — расширенные символы; `string` хранит байты UTF-8.

## Проверьте себя

:::check
Q: Какова разница кодов `'a'` и `'A'` и как её использовать?
A: 32. Чтобы превратить строчную букву в заглавную, можно вычесть 32 из кода: `(char) (c - 32)` (только для латинских букв).
Q: Сколько байт занимает массив `char s[] = "Hi";`?
A: 3: `'H'`, `'i'` и `'\0'`.
Q: Почему в C++ после `cin >> k; getline(cin, s);` строка *s* может оказаться пустой?
A: `cin >> k` оставляет в потоке `'\n'` после числа, и `getline` читает эту пустую строку. Перед ним нужен `cin.ignore()`.
Q: Во что превратится `'z'` в шифре Цезаря при *k* = 3?
A: В `'c'`: позиция 25, (25 + 3) % 26 = 2.
Q: Почему «Oʻzbekiston» в UTF-8 занимает 12 байт?
A: 10 букв ASCII — по 1 байту, а `ʻ` (U+02BB) — 2 байта: 10 + 2 = 12.
