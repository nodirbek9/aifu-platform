## Почему это важно

Меню банкомата: 1 — баланс, 2 — наличные, 3 — платёж, 4 — выход. Каждая клавиша телефона даёт свои буквы. По номеру дня недели выводится расписание занятий. В таких задачах одна переменная сравнивается с одним из **нескольких точных значений**. Это можно записать и цепочкой `if-else if`, но для этого есть специальный, более читаемый оператор — **оператор выбора**.

Кроме того, познакомимся с коротким средством, записывающим выбор «одно из двух» одним выражением, — **тернарным оператором**.

:::note
**После этого занятия вы сможете:**

- записывать операторы `switch` (Java, C++) и `match` (Python);
- объяснять назначение `break` и `default` и избегать ошибки «проваливания»;
- выбирать значение по условию с помощью тернарного оператора;
- выбирать для задачи подходящее средство: `if`, `switch` или тернарный оператор.
:::

## Оператор switch (Java, C++)

**Оператор выбора `switch`** последовательно сравнивает значение выражения с константами в метках `case` и начинает выполнение с совпавшей.

| Часть | Назначение |
|---|---|
| `switch (выражение)` | какое значение проверяется (целое число, символ; в Java ещё и строка) |
| `case 1:` | «если значение равно 1, начать отсюда» |
| `break;` | выход из `switch` |
| `default:` | если не подошёл ни один `case` (необязательно, но рекомендуется) |

Важная особенность — **проваливание (fall-through)**: без `break` выполнение переходит в следующий `case`. Часто это источник ошибок, но иногда используется намеренно: одно действие для нескольких значений.

```text
case 6:
case 7:
    "выходной день"
    break
```

В C++ `switch` работает только с целыми и символьными типами; в Java — ещё и со строками (`String`). Начиная с Java 14 есть краткая запись: `case 1 -> ...;` — в ней нет проваливания и не нужен `break`.

## Оператор match (Python)

Начиная с Python 3.10 есть оператор `match`:

| Часть | Смысл |
|---|---|
| `match выражение:` | какое значение проверяется |
| `case 1:` | если значение равно 1 |
| `case 6 \| 7:` | если 6 или 7 |
| `case _:` | все остальные случаи (вместо `default`) |

В Python проваливания нет: выполняется только совпавший `case`, `break` не нужен. В версиях до 3.10 та же задача записывается через `if-elif`.

## Тернарный оператор

**Тернарный (трёхместный) оператор** возвращает одно из двух значений в зависимости от условия. Это не *оператор*, а *выражение*: результат можно присвоить переменной или сразу вывести.

| Язык | Запись | Пример |
|---|---|---|
| Java, C++ | `условие ? значение1 : значение2` | `mx = a > b ? a : b;` |
| Python | `значение1 if условие else значение2` | `mx = a if a > b else b` |

Тернарный оператор удобен для коротких выборов. Вложенные тернарные операторы (`a ? b : c ? d : e`) затрудняют чтение — в таких случаях лучше `if`.

## Когда что использовать?

| Ситуация | Выбор |
|---|---|
| Одна переменная сравнивается с несколькими точными значениями (меню, день, команда) | `switch` / `match` |
| Диапазоны (`ball >= 86`), сложные условия | `if-else if` |
| Одно из двух значений, в одном выражении | тернарный оператор |

## Разобранный пример 1: день недели

Вводится номер дня недели (1–7). Выведите название дня; для 6 и 7 добавьте «(выходной)». Для неверного номера — `неверный день`.

```python
kun = int(input())

match kun:
    case 1:
        print("Понедельник")
    case 2:
        print("Вторник")
    case 3:
        print("Среда")
    case 4:
        print("Четверг")
    case 5:
        print("Пятница")
    case 6:
        print("Суббота (выходной)")
    case 7:
        print("Воскресенье (выходной)")
    case _:
        print("неверный день")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int kun = in.nextInt();

        switch (kun) {
            case 1: System.out.println("Понедельник"); break;
            case 2: System.out.println("Вторник"); break;
            case 3: System.out.println("Среда"); break;
            case 4: System.out.println("Четверг"); break;
            case 5: System.out.println("Пятница"); break;
            case 6: System.out.println("Суббота (выходной)"); break;
            case 7: System.out.println("Воскресенье (выходной)"); break;
            default: System.out.println("неверный день");
        }
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    int kun;
    cin >> kun;

    switch (kun) {
        case 1: cout << "Понедельник" << endl; break;
        case 2: cout << "Вторник" << endl; break;
        case 3: cout << "Среда" << endl; break;
        case 4: cout << "Четверг" << endl; break;
        case 5: cout << "Пятница" << endl; break;
        case 6: cout << "Суббота (выходной)" << endl; break;
        case 7: cout << "Воскресенье (выходной)" << endl; break;
        default: cout << "неверный день" << endl;
    }
    return 0;
}
```

При вводе `3` совпадает `case 3`, выводится `Среда`, `break` выводит из `switch`. При вводе `9` не совпадает ни один `case` — выполняется `default`. Если в Java или C++ забыть `break` в `case 3`, после `Среда` выведется ещё и `Четверг`.

## Разобранный пример 2: калькулятор

В одной строке вводится выражение: целое число, знак операции (`+`, `-`, `*`, `/`) и целое число через пробел. Выведите результат; при делении — с точностью до двух знаков. При делении на ноль и неизвестной операции выведите сообщение.

```python
qism = input().split()
a = int(qism[0])
amal = qism[1]
b = int(qism[2])

match amal:
    case "+":
        print(a + b)
    case "-":
        print(a - b)
    case "*":
        print(a * b)
    case "/":
        if b == 0:
            print("Ошибка: деление на ноль")
        else:
            print(f"{a / b:.2f}")
    case _:
        print("Ошибка: неизвестная операция")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int a = in.nextInt();
        char amal = in.next().charAt(0);
        int b = in.nextInt();

        switch (amal) {
            case '+': System.out.println(a + b); break;
            case '-': System.out.println(a - b); break;
            case '*': System.out.println(a * b); break;
            case '/':
                if (b == 0) {
                    System.out.println("Ошибка: деление на ноль");
                } else {
                    System.out.println(String.format("%.2f", (double) a / b));
                }
                break;
            default: System.out.println("Ошибка: неизвестная операция");
        }
    }
}
```
```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int a, b;
    char amal;
    cin >> a >> amal >> b;

    switch (amal) {
        case '+': cout << a + b << endl; break;
        case '-': cout << a - b << endl; break;
        case '*': cout << a * b << endl; break;
        case '/':
            if (b == 0) {
                cout << "Ошибка: деление на ноль" << endl;
            } else {
                cout << fixed << setprecision(2) << (double) a / b << endl;
            }
            break;
        default: cout << "Ошибка: неизвестная операция" << endl;
    }
    return 0;
}
```

Разбор:

| Ввод | Выбранная ветвь | Результат |
|---|---|---|
| `7 * 6` | `*` | `42` |
| `7 / 2` | `/`, *b* ≠ 0 | `3.50` |
| `5 / 0` | `/`, *b* = 0 | `Ошибка: деление на ноль` |
| `5 % 2` | `default` | `Ошибка: неизвестная операция` |

Внутри `switch` может быть `if` — конструкции вкладываются друг в друга. В Java символ читается через `in.next().charAt(0)`: `next()` даёт следующее слово, `charAt(0)` — его первый символ.

## Разобранный пример 3: тернарный оператор

Вводится целое число. Выведите, чётное оно или нечётное, и его модуль.

```python
n = int(input())

turi = "чётное" if n % 2 == 0 else "нечётное"
modul = n if n >= 0 else -n

print(turi, modul)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();

        String turi = n % 2 == 0 ? "чётное" : "нечётное";
        int modul = n >= 0 ? n : -n;

        System.out.println(turi + " " + modul);
    }
}
```
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;

    string turi = n % 2 == 0 ? "чётное" : "нечётное";
    int modul = n >= 0 ? n : -n;

    cout << turi << " " << modul << endl;
    return 0;
}
```

При вводе `-7`: `-7 % 2` в Python равно 1, в Java и C++ — −1; ни то, ни другое не 0, поэтому `нечётное`; `-7 >= 0` — ложь, модуль `7`. Выводится: `нечётное 7`. Проверка нечётности через `n % 2 == 1` в Java и C++ ошибается на отрицательных числах — проверяйте `n % 2 != 0` или `== 0`.

:::warning
**Частые ошибки**

- **Забытый `break` (Java, C++).** Выполняются и следующие `case`: «Среда Четверг Пятница …».
- **Переменная или диапазон в `case`.** `case x > 5:` нельзя; в `case` только константа. Для диапазонов — `if`.
- **`switch` по строке в C++.** В C++ `switch` работает только с целыми числами и символами.
- **`switch` без `default`.** Неожиданное значение молча игнорируется, ошибка не обнаруживается.
- **Вложенные тернарные операторы.** Три-четыре `?` в одной строке — нечитаемый код.
:::

:::tip
Приучите себя завершать каждый `case` оператором `break`; если проваливание намеренное, напишите комментарий: `// намеренно продолжается`.
:::

## Итоги

- `switch` (Java, C++) и `match` (Python) сравнивают одно значение с несколькими точными константами.
- В Java и C++ без `break` выполнение проваливается в следующий `case`; в Python проваливания нет.
- `default` / `case _` — для всех остальных случаев.
- Тернарный оператор `условие ? a : b` (Python: `a if условие else b`) — короткий выбор, возвращающий значение.
- Для диапазонов и сложных условий — `if`, для точных значений — `switch`, для одного из двух значений — тернарный оператор.

## Проверьте себя

:::check
Q: Что произойдёт в Java, если в `switch` в `case 2:` пропущен `break`, а значение равно 2?
A: Выполнится действие `case 2`, затем и действие `case 3` (и следующих) — до первого `break` или до конца `switch`.
Q: Какая запись в Python выполняет роль `default`?
A: `case _:`.
Q: Можно ли проверить диапазон вроде `ball >= 86` через `switch`?
A: В классическом `switch` нельзя: в `case` бывает только точная константа. Для диапазонов используют `if-else if`.
Q: Как записать `mx = a > b ? a : b;` на Python?
A: `mx = a if a > b else b`.
Q: Почему в Java опасно проверять нечётность через `n % 2 == 1`?
A: Для отрицательных нечётных чисел `n % 2` равно −1, и условие оказывается ложным. Нужно проверять `n % 2 != 0`.
