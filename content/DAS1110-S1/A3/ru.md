## Почему это важно

Университет назначает стипендию только студенту, который сдал все предметы **и** имеет средний балл выше 4. Библиотека выдаёт книгу студенту **или** преподавателю. Такие правила записываются в программе логическими операциями. А расчёты расстояний, площадей, процентов не обходятся без математических функций: корня, степени, округления.

На этом практическом занятии мы потренируемся записывать сложные условия в виде логических выражений и пользоваться стандартными математическими функциями.

:::note
**После этого занятия вы сможете:**

- записывать сложное условие с помощью операций И, ИЛИ, НЕ;
- вычислять значение логического выражения с помощью таблицы истинности;
- правильно расставлять скобки с учётом приоритета операций;
- использовать на трёх языках корень, степень, модуль, округление и тригонометрические функции.
:::

## Логические операции

**Логическое (boolean) выражение** имеет только два значения: истина (`true`) или ложь (`false`). Сравнения (`>`, `==`, `!=` …) дают логическое значение; их можно объединять логическими операциями.

| Операция | Python | Java, C++ | Когда истинна |
|---|---|---|---|
| И (AND, конъюнкция) | `and` | `&&` | если истинны обе части |
| ИЛИ (OR, дизъюнкция) | `or` | `\|\|` | если истинна хотя бы одна часть |
| НЕ (NOT, отрицание) | `not` | `!` | если часть ложна |

**Таблица истинности (truth table)** показывает все случаи:

| *A* | *B* | *A* И *B* | *A* ИЛИ *B* | НЕ *A* |
|---|---|---|---|---|
| ложь | ложь | ложь | ложь | истина |
| ложь | истина | ложь | истина | истина |
| истина | ложь | ложь | истина | ложь |
| истина | истина | истина | истина | ложь |

Примеры: «число от 10 до 20» — `x >= 10 and x <= 20` (в Python короче: `10 <= x <= 20`); «чётное число» — `x % 2 == 0`; «выходной день» — `kun == 6 or kun == 7`.

### Короткое замыкание

**Короткое замыкание (short-circuit)**: если результат известен по первой части, вторая не вычисляется. В И при ложной первой части всё выражение ложно; в ИЛИ при истинной первой части всё выражение истинно. Это помогает избежать ошибок: выражение `b != 0 and a / b > 2` при *b* = 0 до деления на ноль не доходит.

### Приоритет операций

Если в выражении нет скобок, операции выполняются в таком порядке (сверху вниз):

| Приоритет | Операции |
|---|---|
| 1 | скобки `( )` |
| 2 | НЕ: `not`, `!` |
| 3 | `*`, `/`, `//`, `%` |
| 4 | `+`, `-` |
| 5 | сравнения: `<`, `<=`, `>`, `>=`, `==`, `!=` |
| 6 | И: `and`, `&&` |
| 7 | ИЛИ: `or`, `\|\|` |

И выполняется раньше ИЛИ: `a or b and c` — это `a or (b and c)`. Если сомневаетесь, ставьте скобки: скобки никогда не лишние.

## Математические функции

В каждом языке есть набор стандартных математических функций: в Python — модуль `math` (`import math`), в Java — класс `Math` (импорт не нужен), в C++ — заголовочный файл `<cmath>`.

| Функция | Python | Java | C++ | Пример |
|---|---|---|---|---|
| Квадратный корень | `math.sqrt(x)` | `Math.sqrt(x)` | `sqrt(x)` | √16 = 4.0 |
| Степень | `x ** y`, `math.pow(x, y)` | `Math.pow(x, y)` | `pow(x, y)` | 2¹⁰ = 1024 |
| Модуль | `abs(x)` | `Math.abs(x)` | `abs(x)`, `fabs(x)` | \|−7\| = 7 |
| Округление вниз | `math.floor(x)` | `Math.floor(x)` | `floor(x)` | ⌊3.7⌋ = 3 |
| Округление вверх | `math.ceil(x)` | `Math.ceil(x)` | `ceil(x)` | ⌈3.2⌉ = 4 |
| Округление до ближайшего | `round(x)` | `Math.round(x)` | `round(x)` | 3.5 → 4 |
| Синус, косинус | `math.sin(x)`, `math.cos(x)` | `Math.sin(x)` | `sin(x)` | угол в радианах |
| Число π | `math.pi` | `Math.PI` | `M_PI` или `acos(-1)` | 3.14159… |

Тригонометрические функции принимают угол в **радианах**: 180° = π радиан, то есть `радианы = градусы * pi / 180`.

Функция `round()` в Python округляет число, находящееся ровно посередине, к **чётному**: `round(2.5)` = 2, `round(3.5)` = 4 («банковское округление»). В Java и C++ 2.5 → 3.

## Разобранный пример 1: високосный год

Вводится год. Определите, високосный ли он. Правило: год високосный, если он делится на 4 и не делится на 100, либо делится на 400.

```python
yil = int(input())

kabisa = (yil % 4 == 0 and yil % 100 != 0) or yil % 400 == 0
print(kabisa)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int yil = in.nextInt();

        boolean kabisa = (yil % 4 == 0 && yil % 100 != 0) || yil % 400 == 0;
        System.out.println(kabisa);
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    int yil;
    cin >> yil;

    bool kabisa = (yil % 4 == 0 && yil % 100 != 0) || yil % 400 == 0;
    cout << boolalpha << kabisa << endl;   // boolalpha: true/false вместо 1/0
    return 0;
}
```

Для разных входных данных:

| Год | `% 4 == 0` | `% 100 != 0` | `% 400 == 0` | Результат |
|---|---|---|---|---|
| 2024 | истина | истина | ложь | истина |
| 1900 | истина | ложь | ложь | ложь |
| 2000 | истина | ложь | истина | истина |
| 2026 | ложь | истина | ложь | ложь |

Python выводит `True`/`False`, Java — `true`/`false`. C++ по умолчанию выводит `1`/`0`; манипулятор `boolalpha` включает вывод словами.

## Разобранный пример 2: формула Герона

В одной строке вводятся три стороны треугольника (вещественные числа). Вычислите его площадь по формуле Герона: *p* = (*a* + *b* + *c*) / 2, *S* = √(*p*(*p* − *a*)(*p* − *b*)(*p* − *c*)).

```python
import math

a, b, c = map(float, input().split())

p = (a + b + c) / 2                        # полупериметр
s = math.sqrt(p * (p - a) * (p - b) * (p - c))
print(f"{s:.2f}")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        double a = in.nextDouble();
        double b = in.nextDouble();
        double c = in.nextDouble();

        double p = (a + b + c) / 2;                 // полупериметр
        double s = Math.sqrt(p * (p - a) * (p - b) * (p - c));
        System.out.println(String.format("%.2f", s));
    }
}
```
```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;

int main() {
    double a, b, c;
    cin >> a >> b >> c;

    double p = (a + b + c) / 2;                 // полупериметр
    double s = sqrt(p * (p - a) * (p - b) * (p - c));
    cout << fixed << setprecision(2) << s << endl;
    return 0;
}
```

При вводе `3 4 5`:

1. *p* = (3 + 4 + 5) / 2 = 6.
2. Под корнем: 6 · 3 · 2 · 1 = 36.
3. √36 = 6, выводится: `6.00`.

При вводе `2 3 4`: *p* = 4.5, под корнем 4.5 · 2.5 · 1.5 · 0.5 = 8.4375, *S* ≈ 2.9047, выводится `2.90`.

:::warning
**Частые ошибки**

- **Писать `10 < x < 20` в Java или C++.** В Python это верно, в Java — ошибка компиляции, а в C++ — неверный смысл: сначала вычисляется `10 < x` (0 или 1), потом это сравнивается с 20 — результат всегда истина. Правильно: `x > 10 && x < 20`.
- **Путать `&` и `&&`.** `&` — побитовая операция, она работает без короткого замыкания.
- **Не переводить градусы в радианы.** `sin(30)` — синус 30 радиан, а не 0.5.
- **Сравнивать вещественные числа через `==`.** `0.1 + 0.2 == 0.3` — ложь! Вещественные числа хранятся приближённо; сравнивайте так: `abs(x - y) < 1e-9`.
:::

:::tip
Прежде чем записать сложное условие, произнесите его полным предложением: «год делится на 4 И не делится на 100, ИЛИ делится на 400». Затем переведите каждую часть в код и сгруппируйте скобками.
:::

## Итоги

- Логические операции: И (`and`, `&&`), ИЛИ (`or`, `||`), НЕ (`not`, `!`); результат определяется таблицей истинности.
- Короткое замыкание: если результат известен по первой части, вторая не вычисляется.
- Приоритет: НЕ → арифметика → сравнения → И → ИЛИ; при сомнении ставьте скобки.
- Математические функции: в Python — `math`, в Java — `Math`, в C++ — `<cmath>`; углы в радианах.
- Вещественные числа сравнивайте не через `==`, а через малую разность.

## Проверьте себя

:::check
Q: Каково значение `x > 10 and x % 2 == 0` при *x* = 15?
A: Ложь: первая часть истинна, но 15 не чётное.
Q: Как записать `not (a > 5)` без `not`?
A: `a <= 5`.
Q: Даст ли ошибку в Java выражение `true || 1 / 0 > 0`?
A: Нет: из-за короткого замыкания первая часть ИЛИ истинна, и вторая не вычисляется.
Q: Сколько нужно автобусов на 45 мест, чтобы перевезти 47 студентов, и какой функцией это посчитать?
A: 2: `ceil(47 / 45)` — округление вверх (чтобы избежать целочисленного деления — `47 / 45.0`).
Q: Чему равны `round(2.5)` и `round(3.5)` в Python?
A: 2 и 4: Python округляет число посередине к чётному.
