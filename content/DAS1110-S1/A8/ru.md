## Почему это важно

Банкомат запрашивает PIN-код — если он неверен, запрашивает снова. Ясно, что запрос будет хотя бы один раз, а сколько раз он повторится — неизвестно. Это классический случай **цикла с постусловием**.

А расписание составляется для каждого дня недели, для каждой пары каждого дня: цикл внутри цикла. Таблицы, матрицы, перебор пар — всё это пишется **вложенными циклами**.

:::note
**После этого занятия вы сможете:**

- записывать цикл `do-while` в Java и C++ и его замену `while True` + `break` в Python;
- повторять запрос, пока пользователь не введёт правильное значение;
- выводить таблицы и фигуры с помощью вложенных циклов;
- подсчитывать, сколько раз выполнится вложенный цикл, и объяснять действие `break` во внутреннем цикле.
:::

## Цикл do-while

**Цикл с постусловием** сначала выполняет тело, потом проверяет условие:

| Язык | Запись |
|---|---|
| Java, C++ | `do { тело } while (условие);` |
| Python | `while True:` → тело → `if not условие: break` |

В Python нет `do-while`. Вместо него используется шаблон **бесконечного цикла с выходом**: внутри `while True:` — тело, в конце `break`, если условие ложно.

`while` и `do-while` различаются только первой проверкой: `while` может не выполнить тело ни разу, а `do-while` выполняет его хотя бы один раз. Поэтому `do-while` естественен в задачах «сначала сделай, потом проверь»: проверка ввода, меню, «сыграем ещё?».

## Вложенные циклы

Если в теле одного цикла есть другой цикл, это **вложенный (nested) цикл**. На каждой итерации внешнего цикла внутренний выполняется **полностью**.

Если внешний цикл выполняется *n* раз, а внутренний *m* раз, тело внутреннего выполнится *n* · *m* раз. Пример с часами: за один оборот часовой стрелки минутная делает 60 шагов; за 24 часа — 24 · 60 = 1440.

Граница внутреннего цикла может зависеть от внешнего счётчика: `for j in range(1, i + 1)` — такой цикл даёт «треугольную» фигуру, и тело внутреннего цикла выполняется 1 + 2 + … + *n* = *n*(*n* + 1)/2 раз.

Два важных правила:

1. Давайте внешнему и внутреннему счётчикам **разные имена** (`i`, `j`). Одинаковое имя — самая частая ошибка.
2. `break` завершает только **тот** (внутренний) цикл, в котором стоит; внешний продолжается.

## Разобранный пример 1: проверка ввода

Пользователь должен ввести число от 1 до 100. При неверном числе выведите `Вне диапазона` и запросите снова. Когда введено правильное число, выведите `Принято: <число>`.

```python
while True:
    x = int(input())
    if 1 <= x <= 100:
        break
    print("Вне диапазона")

print("Принято:", x)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int x;
        boolean notogri;

        do {
            x = in.nextInt();
            notogri = x < 1 || x > 100;
            if (notogri) {
                System.out.println("Вне диапазона");
            }
        } while (notogri);

        System.out.println("Принято: " + x);
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    int x;
    bool notogri;

    do {
        cin >> x;
        notogri = x < 1 || x > 100;
        if (notogri) {
            cout << "Вне диапазона" << endl;
        }
    } while (notogri);

    cout << "Принято: " << x << endl;
    return 0;
}
```

При вводе `150`, `-3`, `42`:

1. 1-я итерация: *x* = 150 — неверно, выводится сообщение, цикл продолжается.
2. 2-я итерация: *x* = −3 — неверно, снова сообщение.
3. 3-я итерация: *x* = 42 — верно, цикл завершается.
4. Выводится: дважды `Вне диапазона`, затем `Принято: 42`.

Число нужно прочитать хотя бы один раз — поэтому цикл с постусловием. С `while` чтение пришлось бы повторить и до цикла, и внутри.

## Разобранный пример 2: треугольник из звёздочек

Вводится натуральное число *n*. Выведите треугольник из *n* строк: в *i*-й строке *i* звёздочек.

```python
n = int(input())

for i in range(1, n + 1):
    for j in range(i):
        print("*", end="")
    print()
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();

        for (int i = 1; i <= n; i++) {
            for (int j = 0; j < i; j++) {
                System.out.print("*");
            }
            System.out.println();
        }
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    for (int i = 1; i <= n; i++) {
        for (int j = 0; j < i; j++) {
            cout << "*";
        }
        cout << endl;
    }
    return 0;
}
```

При вводе `4` выводится:

```text
*
**
***
****
```

Внешний цикл считает строки, внутренний — символы в строке. Перевод строки выводится **после** внутреннего цикла, но внутри внешнего. Тело внутреннего цикла выполняется 1 + 2 + 3 + 4 = 10 раз. (В Python есть короткий вариант: `print("*" * i)` — но здесь мы тренируем вложенные циклы.)

## Разобранный пример 3: пифагоровы тройки

Вводится натуральное число *n*. Выведите все тройки *a* < *b* < *c* ≤ *n*, для которых *a*² + *b*² = *c*².

```python
n = int(input())

for a in range(1, n + 1):
    for b in range(a + 1, n + 1):
        for c in range(b + 1, n + 1):
            if a * a + b * b == c * c:
                print(a, b, c)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();

        for (int a = 1; a <= n; a++) {
            for (int b = a + 1; b <= n; b++) {
                for (int c = b + 1; c <= n; c++) {
                    if (a * a + b * b == c * c) {
                        System.out.println(a + " " + b + " " + c);
                    }
                }
            }
        }
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    for (int a = 1; a <= n; a++) {
        for (int b = a + 1; b <= n; b++) {
            for (int c = b + 1; c <= n; c++) {
                if (a * a + b * b == c * c) {
                    cout << a << " " << b << " " << c << endl;
                }
            }
        }
    }
    return 0;
}
```

При вводе `20` выводится:

```text
3 4 5
5 12 13
6 8 10
8 15 17
9 12 15
12 16 20
```

Внутренние циклы начинаются с *a* + 1 и *b* + 1 — так каждая тройка выводится один раз (`4 3 5` не повторяется), а условие *a* < *b* < *c* выполняется автоматически. Это **полный перебор (brute force)**: проверяются все варианты. Трёхуровневый цикл выполняется примерно *n*³/6 раз — около 1140 при *n* = 20 и около 166 миллионов при *n* = 1000. Для больших *n* нужен более быстрый алгоритм (например, вычислять *c* как √(*a*² + *b*²)).

:::warning
**Частые ошибки**

- **Одинаковый счётчик во внутреннем и внешнем цикле.** `for i …: for i …:` — внутренний цикл портит внешний.
- **Перевод строки не на своём месте.** Внутри внутреннего цикла — каждый символ на отдельной строке; после внешнего цикла — всё в одной строке.
- **Думать, что `break` остановит и внешний цикл.** Он завершает только внутренний; чтобы выйти из внешнего, нужен флаг.
- **Забытая `;` в конце `do-while`** (Java, C++) — ошибка компиляции.
- **Забытый выход из `while True:` в Python** — бесконечный цикл.
:::

Прежде чем писать вложенный цикл, нарисуйте на бумаге результат для маленького *n* и ответьте на вопрос: «что считает внешний цикл? а внутренний?»

## Итоги

- `do-while` выполняет тело хотя бы один раз; в Python вместо него — `while True:` и `break`.
- Проверка ввода — типичное применение цикла с постусловием.
- На каждой итерации внешнего цикла внутренний выполняется полностью; всего *n* · *m* раз.
- Граница внутреннего цикла может зависеть от внешнего счётчика (треугольные фигуры).
- `break` завершает только тот цикл, в котором стоит.

## Проверьте себя

:::check
Q: Сколько раз выполнится цикл `do { … } while (false);`?
A: Один раз: тело выполняется до проверки условия.
Q: Как записать `do-while` на Python?
A: Внутри `while True:` — тело, в конце `if not условие: break`.
Q: Сколько строк выведет `for i in range(5): for j in range(3): print(i, j)`?
A: 15: внешний цикл 5 раз, в каждом внутренний — 3 раза.
Q: Что произойдёт в примере 2, если перенести `print()` внутрь внутреннего цикла?
A: Каждая звёздочка окажется на отдельной строке: всего 10 строк, в каждой по одной `*`.
Q: Как изменится результат примера 3, если внутренние циклы начинать с 1?
A: Каждая тройка выведется дважды (`3 4 5` и `4 3 5`), а время работы вырастет. Если и *c* начинать с 1, зря будут проверяться и случаи *c* < *b*.
