## Почему это важно

Система очереди, музыкальный плейлист, игроки, сидящие по кругу, — такие данные хранятся в массиве, и часто нужно работать с **позицией** элементов: переворачивать, сдвигать, вращать. Все эти операции опираются на правильную связь между индексами. В этой самостоятельной работе вы сами найдёте такую связь и примените её в программе.

:::note
**После этой самостоятельной работы вы сможете:**

- заполнять массив с клавиатуры и выводить его в одну строку;
- находить формулу связи между старым и новым индексом;
- использовать «кольцевые» индексы с помощью операции `%`;
- составлять тесты для граничных случаев (1 элемент, *k* = 0, *k* ≥ *n*).
:::

## Краткое повторение темы

| Действие | Python | Java | C++ |
|---|---|---|---|
| Прочитать *n* чисел | `a = list(map(int, input().split()))` | `nextInt()` в цикле | `cin >>` в цикле |
| Длина | `len(a)` | `a.length` | `a.size()` |
| Последний элемент | `a[n - 1]` или `a[-1]` | `a[n - 1]` | `a[n - 1]` |
| Вывод в одну строку | `print(*a)` | `StringBuilder` и пробелы | цикл и пробелы |

Главный вопрос в задаче, меняющей позиции элементов: **куда должен попасть элемент с позиции *i*?** Ответ записывается формулой. Например, при обращении *i*-й элемент попадает на позицию *n* − 1 − *i*.

## Образец: циклический сдвиг

В первой строке *n*, во второй — *n* чисел, в третьей — *k* (0 ≤ *k* ≤ 10⁹). Сдвиньте массив **циклически** вправо на *k* позиций: элемент, вышедший с конца, возвращается в начало.

Анализ: при сдвиге вправо на одну позицию *i*-й элемент переходит на позицию *i* + 1, а последний — на позицию 0. При сдвиге на *k* — на позицию (*i* + *k*), но «по кругу»: **(*i* + *k*) mod *n***. Формула работает и при очень большом *k*: сдвиг на *n* позиций возвращает массив в исходное состояние.

```text
1. прочитать n, a, k
2. b — новый массив из n элементов
3. для каждого i = 0 … n-1: b[(i + k) mod n] = a[i]
4. вывести b
```

```python
n = int(input())
a = list(map(int, input().split()))
k = int(input())

b = [0] * n
for i in range(n):
    b[(i + k) % n] = a[i]

print(*b)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = in.nextInt();
        }
        long k = in.nextLong();

        int[] b = new int[n];
        for (int i = 0; i < n; i++) {
            b[(int) ((i + k) % n)] = a[i];
        }

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) sb.append(' ');
            sb.append(b[i]);
        }
        System.out.println(sb);
    }
}
```
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    long long k;
    cin >> k;

    vector<int> b(n);
    for (int i = 0; i < n; i++) {
        b[(i + k) % n] = a[i];
    }

    for (int i = 0; i < n; i++) {
        if (i > 0) cout << ' ';
        cout << b[i];
    }
    cout << endl;
    return 0;
}
```

При вводе `5`, `1 2 3 4 5`, `2`:

| *i* | `a[i]` | (*i* + 2) mod 5 |
|---|---|---|
| 0 | 1 | 2 |
| 1 | 2 | 3 |
| 2 | 3 | 4 |
| 3 | 4 | 0 |
| 4 | 5 | 1 |

Выводится: `4 5 1 2 3`. При *k* = 7 результат тот же (7 mod 5 = 2), при *k* = 5 массив не меняется. *k* читается как `long`, потому что 10⁹ + *i* близко к границе `int`.

## Задание самостоятельной работы

Решите приведённую ниже задачу о **выводе массива в обратном порядке**. Что сдаётся:

1. **Формула** — на какую позицию при обращении попадает *i*-й элемент; покажите это таблицей на примере из 5 элементов (как выше).
2. **Программа** — на Python, Java или C++; отправляется в окне задания ниже и должна пройти автоматические тесты.
3. **Тесты** — не меньше 4: 1 элемент, чётная длина, нечётная длина, отрицательные числа; для каждого — ожидаемый результат.
4. **Сравнение двух способов** — запись в новый массив и обмен на месте (два указателя): сколько дополнительной памяти требует каждый?

:::warning
**Критерии оценки и частые ошибки**

- Индексы — от 0 до *n* − 1; обращение к `a[n]` — выход за границы.
- Формат вывода должен быть как в условии (элементы через один пробел, в одной строке).
- При обмене на месте цикл должен выполняться *n*/2 раз, а не *n*.
- Формула и таблица составляются вручную.
:::

:::tip
Чтобы найти формулу, выпишите на бумаге массив из 5 элементов и стрелками покажите, куда переходит каждый элемент. Связь между индексами станет видна сама.
:::

## Итоги

- В задаче, меняющей позиции, ищут формулу «куда попадает *i*-й элемент».
- При циклическом сдвиге новая позиция — (*i* + *k*) mod *n*; большие *k* тоже работают правильно.
- При обращении *i*-й элемент попадает на позицию *n* − 1 − *i*.
- В тестах обязательно должны быть 1 элемент, чётная и нечётная длина.

## Проверьте себя

:::check
Q: На какую позицию попадёт элемент 0 массива из 6 элементов при сдвиге вправо на 8?
A: На позицию 2: (0 + 8) mod 6 = 2.
Q: Куда при обращении массива из 7 элементов попадает элемент с индексом 2?
A: На позицию 4: 7 − 1 − 2 = 4.
Q: Какой будет формула для сдвига влево на *k* позиций?
A: Новая позиция — (*i* − *k*) mod *n*; чтобы избежать отрицательного значения, (*i* − *k* mod *n* + *n*) mod *n*.
