## Почему это важно

Интернет-магазин делает доставку бесплатной, если сумма в корзине больше 300 000 сумов, а если больше 1 000 000 — даёт ещё 5 % скидки. Банк перед выдачей кредита проверяет ежемесячный доход, возраст и кредитную историю. Записывать такие правила оператором `if` без ошибок — ежедневная работа программиста.

На лекции мы изучили `if`, `else` и `elif` / `else if`. На этом практическом занятии применим их в типичных задачах и выработаем привычку проверять каждую ветвь тестом.

:::note
**После этого занятия вы сможете:**

- находить наибольшее (наименьшее) из трёх и более чисел;
- решать задачи, зависящие от нескольких условий (тип треугольника, четверть точки), условиями в правильном порядке;
- проверять правильность введённых данных и выводить сообщение при неверных;
- составлять тест для каждой ветви и граничного случая.
:::

## Условный оператор: краткое повторение

| Конструкция | Python | Java, C++ |
|---|---|---|
| Только если | `if s:` | `if (s) { }` |
| Если … иначе | `if s:` … `else:` | `if (s) { } else { }` |
| Цепочка | `if` … `elif` … `else` | `if` … `else if` … `else` |

Три правила:

1. В цепочке выполняется первое истинное условие — порядок условий определяет результат.
2. В Java и C++ всегда ставьте `{ }`, даже если в блоке одна строка.
3. Каждая ветвь должна быть проверена хотя бы одним тестом.

## Шаблон: поиск наибольшего

Надёжный способ найти наибольшее из нескольких значений — переменная **«наибольшее на данный момент»**:

1. Первое значение считаем наибольшим: `mx = a`.
2. Каждое следующее сравниваем с ним: `if b > mx: mx = b`.
3. В конце `mx` — ответ.

Этот способ работает для любого количества значений и позже применяется вместе с циклом. Для сравнения: способ «проверить, что каждое число больше остальных» (`a >= b and a >= c`) работает для трёх чисел, но при увеличении количества чисел условия резко удлиняются.

Есть и стандартные функции: в Python `max(a, b, c)`, в Java `Math.max(a, b)`, в C++ `max({a, b, c})`. На практическом занятии, чтобы понять алгоритм, сначала пишем вручную.

## Шаблон: проверка ввода

Программа должна правильно реагировать и на неверные данные. Например, стороны треугольника должны быть положительными и удовлетворять **неравенству треугольника**: каждая сторона меньше суммы двух других. Поэтому сначала проверка, потом вычисление:

```text
если данные неверны:
    вывести сообщение
иначе:
    основное вычисление
```

## Разобранный пример 1: наибольшее из трёх чисел

В одной строке вводятся три целых числа. Выведите наибольшее.

```python
a, b, c = map(int, input().split())

mx = a                 # наибольшее на данный момент
if b > mx:
    mx = b
if c > mx:
    mx = c

print(mx)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int a = in.nextInt();
        int b = in.nextInt();
        int c = in.nextInt();

        int mx = a;            // наибольшее на данный момент
        if (b > mx) {
            mx = b;
        }
        if (c > mx) {
            mx = c;
        }

        System.out.println(mx);
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;

    int mx = a;            // наибольшее на данный момент
    if (b > mx) {
        mx = b;
    }
    if (c > mx) {
        mx = c;
    }

    cout << mx << endl;
    return 0;
}
```

При вводе `7 12 9`:

1. `mx = 7`.
2. `12 > 7` — истина, `mx = 12`.
3. `9 > 12` — ложь, `mx` не меняется.
4. Выводится: `12`.

Обратите внимание: здесь два **отдельных** `if`, а не цепочка — потому что проверить нужно каждое число. Тесты: наибольшее на первом месте (`9 1 5`), в середине, в конце, равные числа (`4 4 4`), отрицательные (`-5 -2 -9` → `-2`).

## Разобранный пример 2: тип треугольника

Вводятся три стороны треугольника (положительные целые числа). Если такого треугольника нет, выведите `не существует`, иначе — его тип: `равносторонний`, `равнобедренный` или `разносторонний`.

```python
a, b, c = map(int, input().split())

if a + b <= c or a + c <= b or b + c <= a:
    print("не существует")
elif a == b and b == c:
    print("равносторонний")
elif a == b or b == c or a == c:
    print("равнобедренный")
else:
    print("разносторонний")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int a = in.nextInt();
        int b = in.nextInt();
        int c = in.nextInt();

        if (a + b <= c || a + c <= b || b + c <= a) {
            System.out.println("не существует");
        } else if (a == b && b == c) {
            System.out.println("равносторонний");
        } else if (a == b || b == c || a == c) {
            System.out.println("равнобедренный");
        } else {
            System.out.println("разносторонний");
        }
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;

    if (a + b <= c || a + c <= b || b + c <= a) {
        cout << "не существует" << endl;
    } else if (a == b && b == c) {
        cout << "равносторонний" << endl;
    } else if (a == b || b == c || a == c) {
        cout << "равнобедренный" << endl;
    } else {
        cout << "разносторонний" << endl;
    }
    return 0;
}
```

Разбор:

| Ввод | Какое условие истинно | Результат |
|---|---|---|
| `1 2 5` | первое: 1 + 2 ≤ 5 | `не существует` |
| `5 5 5` | второе | `равносторонний` |
| `5 5 8` | третье | `равнобедренный` |
| `3 4 5` | ни одно | `разносторонний` |

Порядок важен: условие «равносторонний» должно стоять **перед** «равнобедренным», ведь и у равностороннего треугольника две стороны равны. Иначе `5 5 5` окажется «равнобедренным». А проверка — самая первая: определять тип несуществующего треугольника бессмысленно.

## Разобранный пример 3: четверть точки

Вводятся координаты точки *x* и *y* (целые числа). Выведите, в какой четверти лежит точка; если на оси — `на оси`.

```python
x, y = map(int, input().split())

if x == 0 or y == 0:
    print("на оси")
elif x > 0:
    if y > 0:
        print(1)
    else:
        print(4)
else:
    if y > 0:
        print(2)
    else:
        print(3)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int x = in.nextInt();
        int y = in.nextInt();

        if (x == 0 || y == 0) {
            System.out.println("на оси");
        } else if (x > 0) {
            if (y > 0) {
                System.out.println(1);
            } else {
                System.out.println(4);
            }
        } else {
            if (y > 0) {
                System.out.println(2);
            } else {
                System.out.println(3);
            }
        }
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    int x, y;
    cin >> x >> y;

    if (x == 0 || y == 0) {
        cout << "на оси" << endl;
    } else if (x > 0) {
        if (y > 0) {
            cout << 1 << endl;
        } else {
            cout << 4 << endl;
        }
    } else {
        if (y > 0) {
            cout << 2 << endl;
        } else {
            cout << 3 << endl;
        }
    }
    return 0;
}
```

Здесь вложенное условие уместно: сначала знак *x*, потом знак *y*. Ввод `-3 4` → `2`, `5 -1` → `4`, `0 7` → `на оси`. Четыре четверти и ось — пять ветвей, значит, нужно не меньше пяти тестов.

:::warning
**Частые ошибки**

- **Поиск наибольшего цепочкой `if-elif`.** `if b > mx … elif c > mx` — если *b* больше, *c* вообще не проверяется.
- **Путаница `<` и `<=` в неравенстве треугольника.** `1 2 3` — «вырожденный» треугольник, его не существует: должно быть `a + b <= c`.
- **Проверка общего случая раньше частного.** Если «равнобедренный» стоит перед «равносторонним», равносторонний треугольник никогда не будет найден.
- **Забытый граничный случай.** Когда точка лежит на оси (*x* = 0), программа выводит неверную четверть.
:::

:::tip
Пишите тесты **до** кода в виде таблицы: ввод, ожидаемый результат, какая ветвь. Когда код готов, проверьте каждую строку таблицы.
:::

## Итоги

- Наибольшее (наименьшее) значение находят с помощью переменной «наибольшее на данный момент» и отдельных `if`.
- Сначала проверяют введённые данные, потом выполняют вычисление.
- В цепочке частный случай (равносторонний) стоит перед общим (равнобедренный).
- Вложенное условие уместно, когда есть логическая иерархия (сначала *x*, потом *y*).
- Для каждой ветви и граничного случая нужен отдельный тест.

## Проверьте себя

:::check
Q: Почему при поиске наибольшего используют отдельные `if`, а не `elif`?
A: В цепочке после первого истинного условия остальные не проверяются, а сравнить с «наибольшим на данный момент» нужно каждое число.
Q: Существует ли треугольник со сторонами `2 3 5`?
A: Нет: 2 + 3 = 5, неравенство нестрогое — треугольник вырожденный.
Q: Что выведет программа определения типа треугольника для `5 5 5`, если первым стоит условие «равнобедренный»?
A: «равнобедренный»: `a == b` истинно, и цепочка на этом останавливается.
Q: Сколько тестов как минимум нужно для задачи о четверти точки?
A: Пять: четыре четверти и точка на оси.
Q: Что изменить в программе, чтобы найти наименьшее из трёх чисел?
A: Заменить знак сравнения `>` на `<` (и лучше назвать переменную `mn`).
