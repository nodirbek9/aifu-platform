## Почему это важно

Чтобы составить предложение на русском языке, нужно знать буквы, слова, члены предложения и знаки препинания. С языком программирования то же самое: у него есть свой алфавит, свои «слова», «предложения» и строгая грамматика. С одним отличием — компьютер не «догадывается», что вы имели в виду. Человек прочитает слово «малако» и поймёт его, а компилятор, увидев `prnt`, остановится.

На этом занятии мы разберём «строительные материалы» языка программирования. В Python, Java и C++ они почти одинаковы: освоив их в одном языке, второй читать уже легко.

:::note
**После этого занятия вы сможете:**

- различать алфавит языка, идентификатор, ключевое слово и литерал;
- отличать правильные идентификаторы от неправильных;
- записывать основные типы данных (целый, вещественный, логический, символьный, строковый) на трёх языках;
- объяснять, что такое выражение, оператор и комментарий, и разбирать структуру простой программы.
:::

## Алфавит и лексемы

У каждого языка программирования есть **алфавит**: латинские буквы (`A–Z`, `a–z`), цифры (`0–9`), специальные символы (`+ - * / = < > ( ) [ ] { } ; , . : " '`) и пробельные символы (пробел, табуляция, перевод строки).

Компилятор или интерпретатор сначала разбивает текст программы на **лексемы (tokens)** — наименьшие осмысленные части. Например, строка `narx = 2500 * soni;` состоит из таких лексем:

| Лексема | Вид |
|---|---|
| `narx` | идентификатор |
| `=` | операция (присваивание) |
| `2500` | литерал (целое число) |
| `*` | операция (умножение) |
| `soni` | идентификатор |
| `;` | разделитель |

## Идентификаторы

**Идентификатор (identifier)** — имя элемента программы: переменной, функции, класса. Программист выбирает его сам, но обязан соблюдать правила:

1. Состоит только из букв, цифр и знака подчёркивания (`_`).
2. Не начинается с цифры: `2son` — неправильно, `son2` — правильно.
3. Не может быть ключевым словом: `int`, `class`, `for` — не имена.
4. Большие и маленькие буквы различаются: `Narx`, `narx` и `NARX` — три разных имени.

| Имя | Правильно? | Почему |
|---|---|---|
| `talaba_soni` | да | буквы и подчёркивание |
| `jami2026` | да | цифры в конце |
| `_temp` | да | может начинаться с подчёркивания |
| `2-guruh` | нет | начинается с цифры и содержит `-` |
| `oʻrtacha` | не рекомендуется | символ `ʻ` во многих языках не допускается |
| `for` | нет | ключевое слово |

**Хорошее имя** говорит о своём смысле: не `x`, а `talabalar_soni`; не `a1`, а `oylik_maosh`. В Python слова разделяют подчёркиванием (`oylik_maosh`), в Java и C++ чаще пишут «верблюжьим» стилем (`oylikMaosh`).

## Ключевые слова

**Ключевые (служебные) слова (keywords)** — заранее зарезервированные слова с особым смыслом для языка. Использовать их как имена нельзя.

| Назначение | Python | Java | C++ |
|---|---|---|---|
| Условие | `if`, `elif`, `else` | `if`, `else`, `switch` | `if`, `else`, `switch` |
| Повторение | `for`, `while` | `for`, `while`, `do` | `for`, `while`, `do` |
| Функция | `def`, `return` | `return` | `return` |
| Тип данных | — | `int`, `double`, `boolean`, `char` | `int`, `double`, `bool`, `char` |
| Логическое значение | `True`, `False` | `true`, `false` | `true`, `false` |

## Литералы и типы данных

**Литерал (literal)** — значение, записанное прямо в тексте программы: `42`, `3.14`, `'A'`, `"Salom"`, `true`.

У каждого значения есть **тип (type)**. Тип определяет, как значение хранится в памяти и какие действия с ним можно выполнять.

| Тип | Смысл | Python | Java | C++ | Пример |
|---|---|---|---|---|---|
| Целый | отрицательное, ноль, положительное целое | `int` | `int`, `long` | `int`, `long long` | `-7`, `0`, `2026` |
| Вещественный | есть дробная часть | `float` | `double` | `double` | `3.14`, `-0.5` |
| Логический | истина или ложь | `bool` | `boolean` | `bool` | `True` / `true` |
| Символьный | один символ | — (`str` из 1 символа) | `char` | `char` | `'A'` |
| Строковый | последовательность символов | `str` | `String` | `string` | `"Salom"` |

Java и C++ — языки со **статической типизацией**: тип переменной пишется при объявлении и потом не меняется (`int yosh = 19;`). Python — язык с **динамической типизацией**: тип определяется по значению (`yosh = 19`).

## Выражения и операторы

**Выражение (expression)** — конструкция, имеющая значение: `2 + 3`, `narx * soni`, `yosh >= 18`. **Оператор (statement)** — выполняемая команда: присваивание, вывод, условие, цикл.

Основные операции:

| Операция | Знак | Пример | Результат |
|---|---|---|---|
| Сложение, вычитание | `+`, `-` | `7 - 2` | `5` |
| Умножение | `*` | `7 * 2` | `14` |
| Деление | `/` | `7 / 2` | Python: `3.5`, Java/C++ (целые): `3` |
| Целочисленное деление | `//` (Python), `/` (Java/C++, для целых) | `7 // 2` | `3` |
| Остаток | `%` | `7 % 2` | `1` |
| Сравнение | `==`, `!=`, `<`, `>`, `<=`, `>=` | `7 > 2` | истина |
| Присваивание | `=` | `x = 5` | в *x* записывается 5 |

Различайте `=` и `==`: `=` присваивает значение, а `==` проверяет равенство.

## Комментарии

**Комментарий (comment)** — текст для человека, который компилятор не учитывает. Он объясняет, *почему* код написан именно так.

- Python: `# однострочный комментарий`
- Java и C++: `// однострочный комментарий` и `/* многострочный комментарий */`

## Общая структура программы

Следующая программа по введённому радиусу круга вычисляет его площадь. В ней есть все элементы этого занятия: комментарий, идентификатор, ключевое слово, литерал, тип, выражение и операторы.

```python
# Площадь круга: S = pi * r^2
PI = 3.14159            # литерал 3.14159, имя PI

r = float(input())      # вводится вещественное число
s = PI * r * r          # выражение
print(round(s, 2))      # результат с точностью 2 знака
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        // Площадь круга: S = pi * r^2
        final double PI = 3.14159;   // константа (final)

        Scanner in = new Scanner(System.in);
        double r = in.nextDouble();  // вводится вещественное число
        double s = PI * r * r;       // выражение
        System.out.printf("%.2f%n", s);
    }
}
```
```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    // Площадь круга: S = pi * r^2
    const double PI = 3.14159;   // константа (const)

    double r;
    cin >> r;                    // вводится вещественное число
    double s = PI * r * r;       // выражение
    cout << fixed << setprecision(2) << s << endl;
    return 0;
}
```

При вводе `5` все три программы выводят `78.54`:

1. `PI` — имя константы; в Java `final`, в C++ `const` гарантируют, что значение не изменится. В Python неизменность — соглашение: имя пишется заглавными буквами.
2. Радиус читается как вещественное число: `float(...)`, `nextDouble()`, `cin >> r`.
3. Вычисляется выражение `PI * r * r` и записывается в *s*: 3.14159 · 25 = 78.53975.
4. Результат округляется до двух знаков после запятой и выводится.

:::warning
**Частые ошибки**

- **Путать `=` и `==`.** `if (x = 5)` в C++ не ошибка компиляции, но условие всегда истинно — логическая ошибка.
- **Деление целых чисел.** В Java и C++ `7 / 2` даёт `3`. Если нужна дробь, одно из чисел должно быть вещественным: `7.0 / 2`.
- **Символ ʻ или пробел в имени.** `oʻrtacha ball` — не имя. Пишите `ortacha_ball`.
- **Сложный код без комментариев.** Через неделю вы и сами его не поймёте.
:::

:::tip
Выбирая имя, спросите себя: «поймёт ли его другой человек без комментария?» Хорошо выбранное имя — лучший комментарий.
:::

## Итоги

- Текст программы состоит из лексем: идентификаторов, ключевых слов, литералов, операций и разделителей.
- Идентификатор начинается с буквы или `_`, состоит из букв, цифр и `_`, не может быть ключевым словом; регистр важен.
- Основные типы: целый, вещественный, логический, символьный, строковый. Java и C++ типизированы статически, Python — динамически.
- Выражение даёт значение, оператор выполняется; `=` — присваивание, `==` — сравнение.
- Комментарии объясняют, почему код написан именно так.

## Проверьте себя

:::check
Q: Какие из имён `2guruh`, `guruh_2`, `class`, `_soni` — правильные идентификаторы?
A: `guruh_2` и `_soni`. `2guruh` начинается с цифры, а `class` — ключевое слово в Java и C++.
Q: Что выведет на Java `int a = 7, b = 2; System.out.println(a / b);`?
A: `3`. Оба числа целые, поэтому деление возвращает целую часть.
Q: В чём разница между статической и динамической типизацией?
A: При статической типизации (Java, C++) тип переменной указывается при объявлении и не меняется. При динамической (Python) тип определяется по значению, и переменной позже можно присвоить значение другого типа.
Q: Чем отличаются `x = 5` и `x == 5`?
A: Первое записывает 5 в *x* (присваивание), второе проверяет, равно ли *x* пяти, и возвращает истину или ложь.
Q: Чему равны `17 % 5` и `17 // 5` (Python)?
A: `17 % 5` = 2 (остаток), `17 // 5` = 3 (целая часть от деления).
:::
