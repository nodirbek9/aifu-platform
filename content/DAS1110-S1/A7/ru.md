## Почему это важно

Правильность номера банковской карты проверяется циклом по цифрам (алгоритм Луна). Шифрование в интернете опирается на большие простые числа. График платежей по кредиту — расчёт, повторяющийся для каждого месяца. Все эти задачи используют разные «приёмы» цикла `for`: шаг, досрочную остановку, запоминание предыдущих значений.

На этом практическом занятии потренируемся с этими возможностями цикла `for` на трёх классических задачах.

:::note
**После этого занятия вы сможете:**

- использовать в цикле `for` шаг и обратный порядок;
- досрочно останавливать цикл с помощью `break` и работать с флагом «найдено / не найдено»;
- вычислять последовательность, опирающуюся на два предыдущих значения (Фибоначчи);
- вычислять сумму ряда вещественных чисел и выводить результат в одну строку.
:::

## Возможности цикла for

| Задача | Python | Java, C++ |
|---|---|---|
| Чётные от 0 до 20 | `range(0, 21, 2)` | `for (int i = 0; i <= 20; i += 2)` |
| От 10 до 1 | `range(10, 0, -1)` | `for (int i = 10; i >= 1; i--)` |
| Пока *i*² ≤ *n* | `while i * i <= n:` | `for (int i = 2; i * i <= n; i++)` |

В Java и C++ условием `for` может быть любое логическое выражение (например, `i * i <= n`). В Python `range` даёт только арифметическую прогрессию; для сложного условия используют `while`.

## Флаг и break

Для вопросов вида «есть ли такой элемент?» применяют шаблон **флага (flag)**:

1. До цикла: `topildi = False`.
2. Если в цикле элемент найден: `topildi = True` и `break` — остальные проверять не нужно.
3. После цикла ответ выводится по флагу.

## Вывод результата в одну строку

Обычно `print` / `println` / `endl` каждый раз переходят на новую строку. Чтобы вывести значения в одну строку через пробел:

| Язык | Вывод без перевода строки |
|---|---|
| Python | `print(x, end=" ")` |
| Java | `System.out.print(x + " ")` |
| C++ | `cout << x << " "` (без `endl`) |

В конце выводится один перевод строки. Если лишний пробел мешает, выводите разделитель не перед первым элементом, а перед следующими.

## Разобранный пример 1: простое ли число?

Вводится натуральное число *n* (*n* ≥ 1). Если оно простое, выведите `простое`, иначе — `не простое`.

**Простое число** — число больше 1, которое делится только на 1 и на себя. Делители достаточно проверять до √*n*: если *n* = *a* · *b* и *a* ≤ *b*, то *a* ≤ √*n*.

```python
n = int(input())

tub = n >= 2
i = 2
while i * i <= n:
    if n % i == 0:
        tub = False
        break
    i += 1

print("простое" if tub else "не простое")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();

        boolean tub = n >= 2;
        for (int i = 2; i * i <= n; i++) {
            if (n % i == 0) {
                tub = false;
                break;
            }
        }

        System.out.println(tub ? "простое" : "не простое");
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    bool tub = n >= 2;
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            tub = false;
            break;
        }
    }

    cout << (tub ? "простое" : "не простое") << endl;
    return 0;
}
```

При вводе `91`: *i* = 2, 3, 4, 5, 6 — не делится; *i* = 7: 91 = 7 · 13 — `tub = False`, `break`. Выводится: `не простое`. При вводе `97`: *i* от 2 до 9 (10² = 100 > 97), ни одно не делит — `простое`. При вводе `1` флаг ложен с самого начала — `не простое`.

Проверка до √*n* даёт огромную разницу: при *n* ≈ 10⁹ цикл до *n* — миллиард шагов, а до √*n* — около 31 600.

## Разобранный пример 2: числа Фибоначчи

Вводится натуральное число *n*. Выведите в одну строку первые *n* членов последовательности Фибоначчи: 1, 1, 2, 3, 5, 8, … (каждый член — сумма двух предыдущих).

```python
n = int(input())

a, b = 1, 1
for i in range(n):
    print(a, end=" ")
    a, b = b, a + b
print()
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();

        long a = 1, b = 1;
        for (int i = 0; i < n; i++) {
            System.out.print(a + " ");
            long keyingi = a + b;
            a = b;
            b = keyingi;
        }
        System.out.println();
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    long long a = 1, b = 1;
    for (int i = 0; i < n; i++) {
        cout << a << " ";
        long long keyingi = a + b;
        a = b;
        b = keyingi;
    }
    cout << endl;
    return 0;
}
```

При вводе `8`:

| *i* | выводится (*a*) | новое *a* | новое *b* |
|---|---|---|---|
| 0 | 1 | 1 | 2 |
| 1 | 1 | 2 | 3 |
| 2 | 2 | 3 | 5 |
| 3 | 3 | 5 | 8 |
| … | … | … | … |
| 7 | 21 | 34 | 55 |

Выводится: `1 1 2 3 5 8 13 21 `. Хранить всю последовательность не нужно: достаточно двух последних членов (*a*, *b*). В Python `a, b = b, a + b` обновляет оба значения одновременно; в Java и C++ нужна временная переменная `keyingi` (следующий). Числа Фибоначчи растут быстро: 93-й член не помещается даже в `long`.

## Разобранный пример 3: сумма ряда

Вводится натуральное число *n*. Выведите сумму *S* = 1 + 1/2² + 1/3² + … + 1/*n*² с точностью до 6 знаков после запятой. (С ростом *n* эта сумма приближается к π²/6 ≈ 1.644934.)

```python
n = int(input())

s = 0.0
for k in range(1, n + 1):
    s += 1 / (k * k)

print(f"{s:.6f}")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();

        double s = 0.0;
        for (int k = 1; k <= n; k++) {
            s += 1.0 / ((double) k * k);
        }

        System.out.println(String.format("%.6f", s));
    }
}
```
```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int n;
    cin >> n;

    double s = 0.0;
    for (int k = 1; k <= n; k++) {
        s += 1.0 / ((double) k * k);
    }

    cout << fixed << setprecision(6) << s << endl;
    return 0;
}
```

При вводе `3`: 1 + 0.25 + 0.111111 = `1.361111`. При вводе `1000`: `1.643935` — очень близко к π²/6.

Две важные детали: (1) `1.0 / ...` — чтобы не было целочисленного деления; `1 / (k * k)` в Java и C++ при *k* > 1 даёт 0. (2) `(double) k * k` — чтобы при больших *k* `k * k` не переполнилось в `int`.

:::warning
**Частые ошибки**

- **Считать 1 простым.** Простое число должно быть больше 1; начинайте флаг с `n >= 2`.
- **Переустановка флага внутри цикла.** `else: tub = True` — следующая итерация «стирает» найденное ранее.
- **Порядок обновления в Фибоначчи.** `a = b; b = a + b;` — *a* уже изменилось, последовательность ломается.
- **Целочисленное деление в ряде.** `1 / (k * k)` в Java и C++ — 0; пишите `1.0 /`.
- **Брать 0 из `range(n + 1)`.** `1 / 0` — ошибка деления на ноль; ряд начинается с 1.
:::

:::tip
Проверяйте код и на больших *n*: для простого числа — число около 10⁹, для Фибоначчи — 90 членов. Проблемы скорости и переполнения на маленьких тестах не видны.
:::

## Итоги

- В `for` есть шаг (`range(a, b, step)`, `i += step`) и обратный порядок (`range(b, a, -1)`, `i--`).
- На вопрос «есть ли?» отвечают флагом и `break`.
- Простоту достаточно проверять до √*n*; 1 — не простое.
- Для Фибоначчи хранятся только два последних члена; в Python `a, b = b, a + b`.
- В вещественном ряде избегайте целочисленного деления и переполнения с помощью `1.0 /` и `(double)`.

## Проверьте себя

:::check
Q: Какие значения даёт `range(20, 0, -5)` в Python?
A: 20, 15, 10, 5.
Q: Почему простоту достаточно проверять до √*n*?
A: Если *n* = *a* · *b* и *a* ≤ *b*, то *a* · *a* ≤ *n*, то есть *a* ≤ √*n*. Значит, если делители есть, один из них обязательно не больше √*n*.
Q: Что выведет пример 2 при `n = 1`?
A: Только `1` (и пробел): цикл выполнится один раз.
Q: Чему равно в Java `1 / (k * k)` при *k* = 2 и почему?
A: 0: оба операнда целые, целочисленное деление отбрасывает дробь.
Q: Изменится ли результат программы проверки простоты, если убрать `break`?
A: Результат не изменится, но программа замедлится: остальные числа будут проверяться и после того, как делитель найден.
