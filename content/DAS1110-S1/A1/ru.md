## Почему это важно

Большая часть дня программиста уходит не на написание кода, а на то, чтобы понять, «что хочет сказать» компилятор. Студент, который умеет прочитать сообщение `error: expected ';' before 'return'`, исправит ошибку за минуту, а тот, кто не умеет, полчаса будет переписывать код.

На этом практическом занятии мы потренируемся компилировать и запускать программу на своём компьютере, читать сообщения компилятора и правильно выбирать имена.

:::note
**После этого занятия вы сможете:**

- различать основные компиляторы и интерпретаторы (GCC, Clang, MSVC, javac, CPython);
- запускать программу на Python, Java и C++ из командной строки;
- читать сообщения компилятора об ошибках (error) и предупреждениях (warning) и находить ошибку;
- записывать имена переменных, констант, функций и классов по правилам каждого языка.
:::

## Виды компиляторов

У одного языка может быть несколько компиляторов: они реализуют один и тот же стандарт, но созданы разными компаниями.

| Инструмент | Язык | Вид | Где встречается |
|---|---|---|---|
| **GCC** (`g++`) | C, C++ | компилятор в машинный код | Linux, Windows через MinGW |
| **Clang** (`clang++`) | C, C++ | компилятор в машинный код | macOS, Linux, Windows |
| **MSVC** (`cl`) | C, C++ | компилятор в машинный код | Visual Studio, Windows |
| **javac** | Java | компилятор в байт-код | входит в JDK |
| **JVM** (`java`) | байт-код Java | интерпретатор + JIT-компилятор | входит в JDK или JRE |
| **CPython** (`python`) | Python | интерпретатор (внутри байт-код) | устанавливается с python.org |

**JIT-компиляция (just-in-time)** — перевод часто выполняемых частей программы в машинный код во время её работы. Поэтому программа на Java по ходу работы ускоряется.

Практические задания этого курса проверяются на платформе в GCC 13 (C++17), Java 21 и Python 3.11.

## Компиляция и запуск программы

В командной строке (терминале) последовательность для каждого языка такая:

| Язык | Компиляция | Запуск |
|---|---|---|
| C++ | `g++ -std=c++17 -o main main.cpp` | `./main` (Windows: `main.exe`) |
| Java | `javac Main.java` | `java Main` |
| Python | — | `python main.py` |

При компиляции программа на C++ проходит три этапа:

1. **Препроцессор** выполняет директивы `#include` и `#define`: например, вставляет в программу текст файла `<iostream>`.
2. **Компиляция** переводит текст в объектный файл (машинный код); здесь находятся синтаксические ошибки.
3. **Компоновка (linking)** объединяет объектные файлы и библиотеки в один исполняемый файл.

В Java имя файла обязано совпадать с именем `public`-класса: `public class Main` может находиться только в файле `Main.java`.

## Чтение сообщений компилятора

Компилятор выдаёт сообщения двух видов:

- **Ошибка (error)** — программа не компилируется, исправить обязательно.
- **Предупреждение (warning)** — программа компилируется, но компилятор указывает на подозрительное место. Не игнорируйте предупреждения: часто они указывают на логическую ошибку.

Сообщение обычно состоит из **имени файла, номера строки, номера столбца и описания**:

| Язык | Пример сообщения | Смысл |
|---|---|---|
| C++ | `main.cpp:6:18: error: expected ';' before 'return'` | в строке 6 пропущена точка с запятой |
| Java | `Main.java:5: error: cannot find symbol` | имя в строке 5 не объявлено или написано с ошибкой |
| Python | `NameError: name 'pirnt' is not defined` | имя `print` написано неправильно |

Правило: **начинайте с первой ошибки**. Одна пропущенная скобка может породить десятки «ошибок»; исправите первую — остальные исчезнут сами. Смотрите и на строку *перед* указанной — точка с запятой обычно пропущена именно там.

## Идентификаторы и их виды

Каждое имя в программе что-то обозначает. В зависимости от того, что именно, имена записываются по-разному — это **соглашения об именовании (naming conventions)**:

| Что | Python | Java | C++ (распространённый стиль) |
|---|---|---|---|
| Переменная | `talaba_soni` | `talabaSoni` | `talabaSoni` или `talaba_soni` |
| Константа | `MAX_BALL` | `MAX_BALL` | `MAX_BALL` или `kMaxBall` |
| Функция | `ortacha_ball()` | `ortachaBall()` | `ortachaBall()` |
| Класс | `Talaba` | `Talaba` | `Talaba` |

Названия стилей: `snake_case` (через подчёркивание), `camelCase` (следующие слова с большой буквы), `PascalCase` (и первая буква большая), `UPPER_CASE` (все большие). Компилятор стиль не проверяет, но в команде все пишут одинаково — так код легче читать.

Значение **переменной (variable)** может меняться во время работы программы. Значение **константы (constant)** задаётся один раз: в C++ с помощью `const`, в Java — `final`; в Python — только по соглашению (имя большими буквами).

## Разобранный пример 1: прямоугольник

Вводятся две стороны прямоугольника (целые числа). Выведите периметр и площадь.

```python
# Периметр и площадь прямоугольника
a = int(input())
b = int(input())

perimetr = 2 * (a + b)
yuza = a * b

print("Периметр:", perimetr)
print("Площадь:", yuza)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        // Периметр и площадь прямоугольника
        Scanner in = new Scanner(System.in);
        int a = in.nextInt();
        int b = in.nextInt();

        int perimetr = 2 * (a + b);
        int yuza = a * b;

        System.out.println("Периметр: " + perimetr);
        System.out.println("Площадь: " + yuza);
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    // Периметр и площадь прямоугольника
    int a, b;
    cin >> a >> b;

    int perimetr = 2 * (a + b);
    int yuza = a * b;

    cout << "Периметр: " << perimetr << endl;
    cout << "Площадь: " << yuza << endl;
    return 0;
}
```

При вводе `7` и `4`:

1. Читаются *a* = 7, *b* = 4.
2. `2 * (a + b)` — сначала скобки: 7 + 4 = 11, затем 2 · 11 = 22. Без скобок `2 * a + b` = 18 — порядок операций важен.
3. `a * b` = 28.
4. Выводится: `Периметр: 22` и `Площадь: 28`.

Имена осмысленные: `perimetr`, `yuza` (площадь). И через месяц понятно, что делает программа.

## Разобранный пример 2: обмен значений двух переменных

Вводятся два целых числа *a* и *b*. Поменяйте их значения местами и выведите результат.

```python
a = int(input())
b = int(input())

# Меняем через третью, временную переменную
temp = a
a = b
b = temp

print("a =", a, "b =", b)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int a = in.nextInt();
        int b = in.nextInt();

        // Меняем через третью, временную переменную
        int temp = a;
        a = b;
        b = temp;

        System.out.println("a = " + a + " b = " + b);
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;

    // Меняем через третью, временную переменную
    int temp = a;
    a = b;
    b = temp;

    cout << "a = " << a << " b = " << b << endl;
    return 0;
}
```

При вводе `5` и `9` значения меняются по шагам так:

| Шаг | *a* | *b* | *temp* |
|---|---|---|---|
| После ввода | 5 | 9 | — |
| `temp = a` | 5 | 9 | 5 |
| `a = b` | 9 | 9 | 5 |
| `b = temp` | 9 | 5 | 5 |

Результат: `a = 9 b = 5`. Если написать `a = b; b = a;`, обе переменные станут равны 9: старое значение *a* теряется. В Python есть и короткая запись: `a, b = b, a`.

:::warning
**Частые ошибки**

- **Имя файла Java не совпадает с именем класса.** `public class Main` в файле `main.java` — ошибка: `class Main is public, should be declared in a file named Main.java`.
- **Начинать с последней ошибки.** После исправления первой ошибки остальные часто исчезают.
- **Игнорировать предупреждения.** `warning: unused variable` или `warning: suggest parentheses` могут быть признаком настоящей ошибки.
- **Забыть временную переменную при обмене.** Одно значение теряется.
:::

:::tip
Компилируйте программы на C++ с `g++ -Wall -Wextra`: компилятор выдаст больше предупреждений, и многие ошибки найдутся ещё до запуска программы.
:::

## Итоги

- Для C++ есть компиляторы GCC, Clang и MSVC; Java компилируется `javac` в байт-код и работает в JVM; программу на Python выполняет интерпретатор CPython.
- Компиляция C++: препроцессор → компиляция → компоновка.
- В сообщении компилятора есть файл, строка и описание; начинайте с первой ошибки, читайте и предупреждения.
- Имена записываются по-разному в зависимости от вида: `snake_case`, `camelCase`, `PascalCase`, `UPPER_CASE`.
- Чтобы поменять значения двух переменных, нужна третья, временная.

## Проверьте себя

:::check
Q: В чём основное различие GCC, javac и CPython?
A: GCC компилирует программу на C++ в машинный код, javac переводит программу на Java в байт-код для JVM, а CPython интерпретирует программу на Python.
Q: На каком этапе компиляции C++ выполняется `#include <iostream>`?
A: На этапе препроцессора: текст файла вставляется в программу.
Q: Что означает сообщение `main.cpp:12:5: error: 'cout' was not declared in this scope`?
A: В файле `main.cpp`, строка 12, столбец 5, имя `cout` не распознано: пропущены `#include <iostream>` или `using namespace std;` (или `std::cout`).
Q: Как в Java записываются имена констант и классов?
A: Константы — `UPPER_CASE` (`MAX_BALL`), классы — `PascalCase` (`Talaba`).
Q: Почему `a = b; b = a;` не меняет значения местами?
A: После первой строки старое значение *a* теряется, в обеих переменных остаётся значение *b*.
