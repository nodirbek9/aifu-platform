## Почему это важно

Все программы, которые мы писали до сих пор, каждый раз выполняли одни и те же шаги: прочитай, вычисли, выведи. А в жизни приходится принимать решения. Если балл студента ниже 56 — пересдача, иначе — переход на следующий курс. Если на карте достаточно денег — платёж проходит, если нет — отклоняется. Навигатор при пробке выбирает другой путь.

Чтобы программа шла разными путями в зависимости от ситуации, нужно **ветвление**. Это одна из самых основных идей программирования: после неё ваши программы начнут «думать».

:::note
**После этого занятия вы сможете:**

- отличать линейный алгоритм от разветвляющегося и изображать ветвление на блок-схеме;
- записывать `if`, `if-else` и цепочку `else-if` на трёх языках;
- решать задачи с разбиением на несколько диапазонов (оценки, тарифы) условиями в правильном порядке;
- читать вложенные условия и упрощать их логическими операциями.
:::

## Линейные и разветвляющиеся алгоритмы

**Линейный алгоритм** — алгоритм, шаги которого всегда выполняются в одном и том же порядке и ни один не пропускается. Все программы прошлых занятий были линейными.

**Разветвляющийся алгоритм** — алгоритм, в котором в зависимости от **условия** выбирается один из двух или более путей. Условие — логическое выражение со значением истина или ложь: `ball >= 56`, `balans >= narx`, `x % 2 == 0`.

На блок-схеме условие изображается **ромбом**. Из ромба выходят две линии: «да» (истина) и «нет» (ложь). Затем две ветви снова сходятся в одной точке, и алгоритм продолжается.

## Оператор if

Простейшее ветвление — **`if` (если)**: если условие истинно, блок выполняется; если ложно — пропускается.

| Язык | Запись |
|---|---|
| Python | `if условие:` и следующие строки с **отступом** (4 пробела) |
| Java, C++ | `if (условие) { ... }` — условие в круглых скобках, блок в фигурных |

В Python блок задаётся отступом: строки с одинаковым отступом — один блок. В Java и C++ блок — это код между `{` и `}`; отступ нужен только для чтения, но и его надо ставить правильно.

## if-else: два пути

**`if-else` (если … иначе)**: если условие истинно, выполняется первый блок, если ложно — второй. Один из них выполняется обязательно, оба вместе — никогда.

Например, «чётное число или нечётное»: `if x % 2 == 0` — чётное, `else` — нечётное.

## Цепочка else-if: много путей

Если путей больше двух, условия соединяются в цепочку: в Python — `elif`, в Java и C++ — `else if`. Условия проверяются **сверху вниз**; выполняется блок первого истинного условия, остальные не проверяются. Если ни одно не истинно, выполняется последний `else` (если он есть).

Поэтому **порядок** условий важен. Перевод 100-балльной системы в 5-балльную оценку в AIFU:

| Балл | Оценка |
|---|---|
| 86–100 | 5 (отлично) |
| 71–85 | 4 (хорошо) |
| 56–70 | 3 (удовлетворительно) |
| 0–55 | 2 (неудовлетворительно) |

Если писать условия от большего к меньшему, в каждом достаточно проверить только нижнюю границу: при переходе ко второму условию уже известно, что балл меньше 86.

## Вложенные условия

Внутри одного условия может быть другое — это **вложенное (nested) условие**. Например, сначала проверяется «оплатил ли студент?», затем «есть ли долг?».

Вложенные условия часто можно упростить логическими операциями:

| Вложенное | Упрощённое |
|---|---|
| `if a > 0:` внутри `if b > 0:` | `if a > 0 and b > 0:` |
| `if x >= 10:` внутри `if x <= 20:` | `if 10 <= x <= 20:` (Python) или `x >= 10 && x <= 20` |

Правило: условия глубже трёх уровней затрудняют чтение — упрощайте их или превращайте в цепочку.

## Разобранный пример 1: перевод балла в оценку

Вводится целое число — балл студента (0–100). Выведите оценку.

```python
ball = int(input())

if ball >= 86:
    baho = 5
elif ball >= 71:
    baho = 4
elif ball >= 56:
    baho = 3
else:
    baho = 2

print("Оценка:", baho)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int ball = in.nextInt();

        int baho;
        if (ball >= 86) {
            baho = 5;
        } else if (ball >= 71) {
            baho = 4;
        } else if (ball >= 56) {
            baho = 3;
        } else {
            baho = 2;
        }

        System.out.println("Оценка: " + baho);
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    int ball;
    cin >> ball;

    int baho;
    if (ball >= 86) {
        baho = 5;
    } else if (ball >= 71) {
        baho = 4;
    } else if (ball >= 56) {
        baho = 3;
    } else {
        baho = 2;
    }

    cout << "Оценка: " << baho << endl;
    return 0;
}
```

При вводе `78`:

1. `78 >= 86` — ложь, переходим к следующему условию.
2. `78 >= 71` — истина: `baho = 4`, остальная часть цепочки не проверяется.
3. Выводится: `Оценка: 4`.

При вводе `56` первые два условия ложны, третье истинно — `Оценка: 3`. Обязательно проверяйте граничные значения (55, 56, 70, 71, 85, 86): ошибки чаще всего именно там.

## Разобранный пример 2: квадратное уравнение

Вводятся целые числа *a*, *b*, *c* (*a* ≠ 0). Найдите корни уравнения *ax*² + *bx* + *c* = 0. Дискриминант *D* = *b*² − 4*ac*: *D* < 0 — корней нет, *D* = 0 — один корень *x* = −*b* / 2*a*, *D* > 0 — два корня *x* = (−*b* ± √*D*) / 2*a*.

```python
import math

a, b, c = map(int, input().split())
d = b * b - 4 * a * c

if d < 0:
    print("Корней нет")
elif d == 0:
    x = -b / (2 * a)
    print(f"x = {x:.2f}")
else:
    x1 = (-b + math.sqrt(d)) / (2 * a)
    x2 = (-b - math.sqrt(d)) / (2 * a)
    print(f"x1 = {x1:.2f}, x2 = {x2:.2f}")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int a = in.nextInt();
        int b = in.nextInt();
        int c = in.nextInt();
        int d = b * b - 4 * a * c;

        if (d < 0) {
            System.out.println("Корней нет");
        } else if (d == 0) {
            double x = -b / (2.0 * a);
            System.out.println(String.format("x = %.2f", x));
        } else {
            double x1 = (-b + Math.sqrt(d)) / (2.0 * a);
            double x2 = (-b - Math.sqrt(d)) / (2.0 * a);
            System.out.println(String.format("x1 = %.2f, x2 = %.2f", x1, x2));
        }
    }
}
```
```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    int d = b * b - 4 * a * c;

    cout << fixed << setprecision(2);
    if (d < 0) {
        cout << "Корней нет" << endl;
    } else if (d == 0) {
        double x = -b / (2.0 * a);
        cout << "x = " << x << endl;
    } else {
        double x1 = (-b + sqrt(d)) / (2.0 * a);
        double x2 = (-b - sqrt(d)) / (2.0 * a);
        cout << "x1 = " << x1 << ", x2 = " << x2 << endl;
    }
    return 0;
}
```

При вводе `1 -3 2`:

1. *D* = 9 − 8 = 1 > 0 — третья ветвь.
2. *x*₁ = (3 + 1) / 2 = 2, *x*₂ = (3 − 1) / 2 = 1.
3. Выводится: `x1 = 2.00, x2 = 1.00`.

При вводе `1 2 1`: *D* = 0, `x = -1.00`. При вводе `1 0 1`: *D* = −4, `Корней нет`. Каждая из трёх ветвей проверена хотя бы одним тестом — это хорошая привычка.

В Java и C++ написано `2.0 * a`: при `2 * a` выражение `-b / (2 * a)` оказалось бы целочисленным делением.

:::warning
**Частые ошибки**

- **Точка с запятой после условия (Java, C++).** `if (x > 0);` — условие управляет пустым оператором, следующий блок выполняется всегда.
- **Несколько строк без фигурных скобок.** `if (x > 0) a = 1; b = 2;` — `b = 2` не зависит от условия. Всегда ставьте `{ }`.
- **Смешивание отступов в Python.** Если смешаны табуляция и пробелы, возникает `IndentationError`.
- **Неправильный порядок условий.** Если первым стоит `if ball >= 56`, то и 95 баллов получат «3».
- **Условие у `else`.** `else (x < 0)` — ошибка; если нужно условие — `else if` / `elif`.
:::

:::tip
Для каждой ветви придумайте хотя бы один тест и отдельно проверьте граничные значения. Число ветвей — это минимальное число тестов.
:::

## Итоги

- В разветвляющемся алгоритме путь выбирается в зависимости от условия; на блок-схеме условие — ромб.
- `if` — один путь, `if-else` — один из двух, цепочка `else-if` / `elif` — один из многих.
- В цепочке условия проверяются сверху вниз и выполняется первое истинное; порядок важен.
- В Python блок задаётся отступом, в Java и C++ — `{ }`.
- Вложенные условия часто можно упростить с помощью `and` / `&&`.
- Каждая ветвь и каждое граничное значение должны быть протестированы.

## Проверьте себя

:::check
Q: Чем линейный алгоритм отличается от разветвляющегося?
A: В линейном алгоритме все шаги всегда выполняются в одном порядке; в разветвляющемся в зависимости от условия выбираются разные шаги.
Q: Если в программе оценивания первое условие `ball >= 56`, какой будет результат для 95 баллов и почему?
A: 3: в цепочке выполняется первое истинное условие, 95 >= 56 — истина, остальные не проверяются.
Q: Что делает в Java `if (x > 5); { System.out.println("katta"); }`?
A: Выводит «katta» при любом *x*: точка с запятой — пустой оператор, блок от условия не зависит.
Q: Как записать `if a > 0:` с вложенным `if b > 0:` одним условием?
A: `if a > 0 and b > 0:` (Java/C++: `if (a > 0 && b > 0)`).
Q: Сколько тестов как минимум нужно, чтобы полностью проверить программу для квадратного уравнения?
A: Три: по одному для случаев *D* < 0, *D* = 0 и *D* > 0.
:::
