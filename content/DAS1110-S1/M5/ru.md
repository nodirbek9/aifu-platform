## Почему это важно

В группе 25 студентов. Чтобы найти средний балл, достаточно прибавлять баллы к одному накопителю. Но чтобы ответить на вопрос «сколько студентов набрали выше среднего?», нужно сначала узнать среднее, а потом **заново** просмотреть каждый балл. 25 отдельных переменных (`ball1`, `ball2`, …, `ball25`) — неудобно, а если в группе 30 человек, программа не сработает.

Решение — **массив**: последовательность значений одного типа под одним именем. Журнал, прайс-лист, суточная температура, пиксели изображения — всё это массивы. С этого занятия программы начинают работать с большими объёмами данных.

:::note
**После этого занятия вы сможете:**

- объяснить понятия массива, элемента, индекса и длины;
- создавать массив на Python, Java и C++, заполнять его с клавиатуры и выводить;
- обходить массив циклом и находить сумму, среднее, наибольший элемент и его позицию;
- переставлять массив в обратном порядке на месте и избегать выхода за границы.
:::

## Понятие массива

**Массив (array)** — упорядоченная именованная совокупность элементов одного типа. Каждый элемент получают по его **индексу** (порядковому номеру).

| Понятие | Смысл | Пример (`a = [7, 3, 9, 4]`) |
|---|---|---|
| Элемент | одно значение в массиве | 9 |
| Индекс | позиция элемента, начинается **с 0** | индекс 9 — 2 |
| Длина (размер) | количество элементов | 4 |
| Первый элемент | `a[0]` | 7 |
| Последний элемент | `a[n - 1]` | 4 |

Индекс начинается с 0 потому, что индекс — это **смещение** от начала массива. Первый элемент находится на расстоянии 0 шагов от начала.

В памяти элементы массива располагаются **подряд**. Поэтому обращение к `a[i]` очень быстрое: адрес элемента = начальный адрес + *i* · размер элемента. К какому элементу ни обращайся — всё одинаково быстро.

## Создание массива

| Задача | Python (`list`) | Java | C++ (`vector`) |
|---|---|---|---|
| Со значениями | `a = [7, 3, 9, 4]` | `int[] a = {7, 3, 9, 4};` | `vector<int> a = {7, 3, 9, 4};` |
| *n* нулей | `a = [0] * n` | `int[] a = new int[n];` | `vector<int> a(n);` |
| Длина | `len(a)` | `a.length` | `a.size()` |
| Элемент | `a[i]` | `a[i]` | `a[i]` |

Размер `list` в Python меняется: `a.append(x)` добавляет элемент в конец. Длина массива в Java задаётся при создании и не меняется. В C++ `vector` (`#include <vector>`) — массив переменного размера; классический массив C++ `int a[100];` — статический, его размер известен при компиляции (рассматривается на занятии A9).

## Заполнение и обход массива

Обычно ввод задаётся так: в первой строке *n*, во второй — *n* чисел.

- **Python**: `n = int(input())`, `a = list(map(int, input().split()))`.
- **Java, C++**: создаётся массив, и циклом читаются *n* чисел.

**Обход (traversal)** массива — обращение к каждому элементу по очереди:

| Язык | С индексом | Только значения |
|---|---|---|
| Python | `for i in range(len(a)):` | `for x in a:` |
| Java | `for (int i = 0; i < a.length; i++)` | `for (int x : a)` |
| C++ | `for (int i = 0; i < (int) a.size(); i++)` | `for (int x : a)` |

Если индекс не нужен (сумма, подсчёт), удобна короткая форма. Если нужен (поиск позиции, соседние элементы, изменение), используют цикл с индексом.

## Выход за границы

Индекс меняется от 0 до *n* − 1. `a[n]` — элемент, которого в массиве **нет**:

| Язык | При обращении к `a[n]` |
|---|---|
| Python | `IndexError: list index out of range` |
| Java | `ArrayIndexOutOfBoundsException` |
| C++ | сообщения об ошибке **нет**: читается или портится чужая память — «неопределённое поведение» |

Эта особенность C++ — одна из самых опасных ошибок: программа то работает, то падает. Значительная часть уязвимостей безопасности возникает именно из-за выхода за границы. Поэтому условие цикла всегда пишите `i < n`, а не `i <= n`.

В Python есть и отрицательные индексы: `a[-1]` — последний элемент, `a[-2]` — второй с конца. В Java и C++ такой возможности нет.

## Разобранный пример 1: статистические показатели

В первой строке *n* (1 ≤ *n* ≤ 1000), во второй — *n* целых чисел: баллы студентов. Выведите сумму, среднее, наибольший балл и его порядковый номер (с 1), а также количество баллов выше среднего.

```python
n = int(input())
a = list(map(int, input().split()))

yigindi = 0
for x in a:
    yigindi += x
ortacha = yigindi / n

mx_i = 0                          # индекс наибольшего
for i in range(1, n):
    if a[i] > a[mx_i]:
        mx_i = i

yuqori = 0
for x in a:
    if x > ortacha:
        yuqori += 1

print("Сумма:", yigindi)
print(f"Среднее: {ortacha:.2f}")
print("Наибольший:", a[mx_i], "номер:", mx_i + 1)
print("Выше среднего:", yuqori)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = in.nextInt();
        }

        int yigindi = 0;
        for (int x : a) {
            yigindi += x;
        }
        double ortacha = (double) yigindi / n;

        int mxI = 0;                      // индекс наибольшего
        for (int i = 1; i < n; i++) {
            if (a[i] > a[mxI]) {
                mxI = i;
            }
        }

        int yuqori = 0;
        for (int x : a) {
            if (x > ortacha) {
                yuqori++;
            }
        }

        System.out.println("Сумма: " + yigindi);
        System.out.println(String.format("Среднее: %.2f", ortacha));
        System.out.println("Наибольший: " + a[mxI] + " номер: " + (mxI + 1));
        System.out.println("Выше среднего: " + yuqori);
    }
}
```
```cpp
#include <iostream>
#include <iomanip>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    int yigindi = 0;
    for (int x : a) {
        yigindi += x;
    }
    double ortacha = (double) yigindi / n;

    int mxI = 0;                      // индекс наибольшего
    for (int i = 1; i < n; i++) {
        if (a[i] > a[mxI]) {
            mxI = i;
        }
    }

    int yuqori = 0;
    for (int x : a) {
        if (x > ortacha) {
            yuqori++;
        }
    }

    cout << "Сумма: " << yigindi << endl;
    cout << fixed << setprecision(2) << "Среднее: " << ortacha << endl;
    cout << "Наибольший: " << a[mxI] << " номер: " << mxI + 1 << endl;
    cout << "Выше среднего: " << yuqori << endl;
    return 0;
}
```

Ввод: `5` и `78 92 65 88 70`.

1. Сумма: 78 + 92 + 65 + 88 + 70 = 393; среднее 393 / 5 = 78.60.
2. Наибольший: `mx_i` начинается с 0; при *i* = 1 92 > 78 — `mx_i = 1`; следующие не больше 92. Наибольший — 92, номер 2.
3. Выше среднего (78.60): 92 и 88 — 2.

Выводится:

```text
Сумма: 393
Среднее: 78.60
Наибольший: 92 номер: 2
Выше среднего: 2
```

Третий шаг показывает, зачем нужен массив: среднее известно только после чтения всех баллов, а потом баллы нужно просмотреть **второй раз**. Хранится не значение наибольшего, а его **индекс** — так мы знаем и значение (`a[mx_i]`), и позицию.

## Разобранный пример 2: обращение массива

В первой строке *n*, во второй — *n* чисел. Переставьте массив в обратном порядке **на месте** (не создавая новый массив) и выведите его.

Метод **двух указателей**: левый указатель идёт с начала, правый — с конца; пока они не встретились, элементы меняются местами.

```python
n = int(input())
a = list(map(int, input().split()))

chap, ong = 0, n - 1
while chap < ong:
    a[chap], a[ong] = a[ong], a[chap]
    chap += 1
    ong -= 1

print(*a)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = in.nextInt();
        }

        int chap = 0, ong = n - 1;
        while (chap < ong) {
            int t = a[chap];
            a[chap] = a[ong];
            a[ong] = t;
            chap++;
            ong--;
        }

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) sb.append(' ');
            sb.append(a[i]);
        }
        System.out.println(sb);
    }
}
```
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    int chap = 0, ong = n - 1;
    while (chap < ong) {
        int t = a[chap];
        a[chap] = a[ong];
        a[ong] = t;
        chap++;
        ong--;
    }

    for (int i = 0; i < n; i++) {
        if (i > 0) cout << ' ';
        cout << a[i];
    }
    cout << endl;
    return 0;
}
```

При вводе `5` и `1 2 3 4 5` (*chap* — левый, *ong* — правый):

| *chap* | *ong* | обмен | массив |
|---|---|---|---|
| 0 | 4 | 1 ↔ 5 | 5 2 3 4 1 |
| 1 | 3 | 2 ↔ 4 | 5 4 3 2 1 |
| 2 | 2 | цикл завершается | 5 4 3 2 1 |

Выводится: `5 4 3 2 1`. При чётной длине (например, 4) указатели останавливаются, когда проходят друг через друга. Цикл выполняется *n*/2 раз. В Python `print(*a)` выводит элементы списка через пробел; есть и короткий путь — `a.reverse()` или `a[::-1]`.

:::warning
**Частые ошибки**

- **Индексы с 1.** Первый элемент — `a[0]`; `for i in range(1, n + 1)` в конце выходит за границу.
- **Условие `i <= n`.** На последней итерации `a[n]` — ошибка в Python и Java, тихая порча чужой памяти в C++.
- **Наибольшее с начальным значением 0.** Если все числа отрицательные, ответ будет неверный — 0. Начинайте с первого элемента.
- **Обмены до конца массива при обращении.** Если сделать *n* обменов, массив перевернётся дважды и вернётся в исходное состояние.
- **`a.length()` в Java.** У массива `length` — без скобок; `length()` — у строки.
:::

:::tip
Проверяйте программу с массивом в трёх случаях: один элемент, два элемента (чётное) и три элемента (нечётное). Почти все ошибки на границах видны именно на этих маленьких случаях.
:::

## Итоги

- Массив — именованная упорядоченная совокупность элементов одного типа; элементы лежат в памяти подряд.
- Индексы от 0 до *n* − 1; обращение к `a[i]` одинаково быстрое для любого *i*.
- В Python — `list`, в Java — `int[]` (длина неизменна), в C++ — `vector<int>`; длина: `len(a)`, `a.length`, `a.size()`.
- Обход: цикл с индексом или цикл «для каждого элемента».
- Храните индекс наибольшего элемента; начальное значение — первый элемент.
- Выход за границы в Python и Java даёт ошибку, а в C++ тихо портит память.

## Проверьте себя

:::check
Q: Чему равны `a[2]`, `a[5]` и `len(a)` для `a = [4, 8, 15, 16, 23, 42]`?
A: 15, 42 и 6.
Q: Почему индекс массива начинается с 0?
A: Индекс — смещение от начала массива: первый элемент находится на расстоянии 0 элементов от начала.
Q: Что даст в Java `a[5] = 1;` после `int[] a = new int[5];`?
A: `ArrayIndexOutOfBoundsException`: индексы от 0 до 4.
Q: Почему при поиске наибольшего нужно начинать не с `mx = 0`, а с первого элемента?
A: Если все элементы отрицательные, 0 не меньше ни одного из них, и ответ будет неверный — 0.
Q: Сколько обменов выполняется при обращении массива из 7 элементов?
A: 3 (7 // 2): средний элемент остаётся на месте.
