## Почему это важно

Найти в журнале группы высшую оценку каждого студента и лучшего студента, определить самый эффективный филиал по таблице месячных продаж, найти самую яркую строку изображения — всё это одни и те же операции над матрицей. В этой самостоятельной работе вы сами потренируетесь выбирать нужные элементы матрицы через условие на индексы.

:::note
**После этой самостоятельной работы вы сможете:**

- читать матрицу *n* × *m* и обходить её вложенным циклом;
- вычислять отдельный результат для каждой строки (или столбца);
- выражать нужные элементы условием на индексы (*i* = *j*, *i* + *j* = *n* − 1, *i* < *j* …);
- вручную считать результат на примерах 2 × 2 и 3 × 3 и проверять программу.
:::

## Краткое повторение темы

Многие «части» матрицы описываются условием на индексы (квадратная матрица *n* × *n*):

| Часть | Условие | Элементы в 3 × 3 |
|---|---|---|
| Главная диагональ | *i* = *j* | `a[0][0]`, `a[1][1]`, `a[2][2]` |
| Побочная диагональ | *i* + *j* = *n* − 1 | `a[0][2]`, `a[1][1]`, `a[2][0]` |
| Над главной диагональю | *i* < *j* | `a[0][1]`, `a[0][2]`, `a[1][2]` |
| Под главной диагональю | *i* > *j* | `a[1][0]`, `a[2][0]`, `a[2][1]` |
| Строка *k* | *i* = *k* | `a[k][0]` … `a[k][n-1]` |

Если в части по одному элементу в строке (диагонали), достаточно одного цикла. Если много — вложенный цикл и условие.

## Образец: анализ строк

В первой строке *n* и *m*, в следующих *n* строках — по *m* чисел. В первой строке вывода — наибольший элемент каждой строки, во второй — номер строки с наибольшей суммой (с 1; если таких несколько — первой).

```text
1. прочитать n, m и матрицу
2. eng_yaxshi = 0, eng_katta = сумма первой строки
3. для каждой строки i:
       mx = a[i][0], s = 0
       для каждого j: mx = max(mx, a[i][j]); s += a[i][j]
       запомнить mx
       если s > eng_katta: eng_yaxshi = i, eng_katta = s
4. вывести все mx, затем eng_yaxshi + 1
```

```python
n, m = map(int, input().split())
a = [list(map(int, input().split())) for _ in range(n)]

maksimumlar = []
eng_yaxshi = 0
eng_katta = sum(a[0])
for i in range(n):
    mx = a[i][0]
    s = 0
    for j in range(m):
        if a[i][j] > mx:
            mx = a[i][j]
        s += a[i][j]
    maksimumlar.append(mx)
    if s > eng_katta:
        eng_katta = s
        eng_yaxshi = i

print(*maksimumlar)
print(eng_yaxshi + 1)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int m = in.nextInt();
        int[][] a = new int[n][m];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                a[i][j] = in.nextInt();
            }
        }

        StringBuilder sb = new StringBuilder();
        int engYaxshi = 0;
        long engKatta = Long.MIN_VALUE;
        for (int i = 0; i < n; i++) {
            int mx = a[i][0];
            long s = 0;
            for (int j = 0; j < m; j++) {
                if (a[i][j] > mx) mx = a[i][j];
                s += a[i][j];
            }
            if (i > 0) sb.append(' ');
            sb.append(mx);
            if (s > engKatta) {
                engKatta = s;
                engYaxshi = i;
            }
        }

        System.out.println(sb);
        System.out.println(engYaxshi + 1);
    }
}
```
```cpp
#include <iostream>
#include <vector>
#include <climits>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> a(n, vector<int>(m));
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cin >> a[i][j];
        }
    }

    int engYaxshi = 0;
    long long engKatta = LLONG_MIN;
    for (int i = 0; i < n; i++) {
        int mx = a[i][0];
        long long s = 0;
        for (int j = 0; j < m; j++) {
            if (a[i][j] > mx) mx = a[i][j];
            s += a[i][j];
        }
        if (i > 0) cout << ' ';
        cout << mx;
        if (s > engKatta) {
            engKatta = s;
            engYaxshi = i;
        }
    }
    cout << endl << engYaxshi + 1 << endl;
    return 0;
}
```

Ввод:


| Строка | Наибольший | Сумма |
|---|---|---|
| 1 | 8 | 18 |
| 2 | 8 | 19 |
| 3 | 4 | 10 |

Выводится: `8 8 4` и `2`. Для каждой строки `mx` и `s` начинаются заново **внутри** внешнего цикла — это самое важное место. В Java и C++ наибольшая сумма (*eng_katta*) начинается с наименьшего возможного значения (`Long.MIN_VALUE`, `LLONG_MIN`); в Python — с суммы первой строки.

## Задание самостоятельной работы

Решите приведённую ниже задачу о **диагоналях матрицы**. Что сдаётся:

1. **Условия на индексы** — запишите условия для элементов главной и побочной диагоналей, нарисуйте матрицу 4 × 4 и отметьте диагональные элементы.
2. **Случай нечётного *n*** — в каком элементе пересекаются диагонали при нечётном *n*? Входит ли он по условию задачи в обе суммы — определите и следуйте этому в программе.
3. **Программа** — на Python, Java или C++; отправляется в окне задания ниже и должна пройти автоматические тесты.
4. **Тесты** — не меньше 3: матрицы 1 × 1, 2 × 2 и 3 × 3, результаты посчитаны вручную.

:::warning
**Критерии оценки и частые ошибки**

- Побочная диагональ: `a[i][n - 1 - i]`, а не `a[i][n - i]`.
- Для диагонали вложенный цикл не обязателен; если он используется, результат всё равно должен быть верным.
- Не создавайте в Python матрицу через `[[0] * n] * n` — строки окажутся одним объектом.
- Результаты должны быть проверены вручную.
:::

:::tip
В матрице 1 × 1 единственный элемент стоит на обеих диагоналях. Заранее запишите на бумаге, что программа должна вывести в этом случае, и сравните с результатом.
:::

## Итоги

- Части матрицы описываются условием на индексы: *i* = *j*, *i* + *j* = *n* − 1, *i* < *j*.
- Если в строке один элемент — один цикл, если много — вложенный.
- Для результатов по строкам накопитель и максимум начинаются внутри внешнего цикла.
- Проверяйте результат вручную на маленьких матрицах (1 × 1, 2 × 2, 3 × 3).

## Проверьте себя

:::check
Q: Сколько элементов над главной диагональю в матрице 5 × 5?
A: 10: (25 − 5) / 2.
Q: В каком элементе пересекаются главная и побочная диагонали при нечётном *n*?
A: В центральном: `a[n // 2][n // 2]`.
Q: Что будет, если в образце задать начальное `mx` один раз вне цикла?
A: Для каждой строки будет учитываться и максимум предыдущих строк — результат будет неверным.
