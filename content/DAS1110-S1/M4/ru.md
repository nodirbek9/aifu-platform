## Почему это важно

Деканату нужно посчитать итоговые баллы 600 студентов. Писать отдельную строку для каждого студента — 600 строк одинакового кода. А если завтра студентов станет 700, переписывать программу? Нет: достаточно сказать компьютеру «повтори эту работу для каждого студента».

Главная сила компьютера именно в повторении: одно и то же действие он выполняет миллион раз без ошибок и без усталости. Конструкция, организующая повторение, — **цикл (loop)**. С помощью циклов и ветвлений можно записать любой алгоритм.

:::note
**После этого занятия вы сможете:**

- объяснить, что такое тело цикла, итерация, счётчик и условие продолжения;
- записывать циклы `for`, `while` и `do-while` на трёх языках и выбирать подходящий для задачи;
- писать программы с накопителем (сумма, произведение) и счётчиком;
- применять `break` и `continue` и находить ошибку бесконечного цикла.
:::

## Понятие цикла

**Цикл** — конструкция, повторяющая группу действий несколько раз. Его части:

- **Тело цикла (body)** — повторяемые действия.
- **Итерация** — однократное выполнение тела.
- **Условие продолжения** — проверяется перед каждой итерацией (или после неё); если истинно, цикл продолжается.
- **Переменная цикла (счётчик)** — переменная, которая меняется на каждой итерации и влияет на условие.

На блок-схеме цикл изображается линией, возвращающейся после ромба условия назад — к началу тела.

Есть три вида циклов:

| Вид | Когда используется | Когда проверяется условие |
|---|---|---|
| **С параметром** (`for`) | число повторений известно заранее | перед каждой итерацией |
| **С предусловием** (`while`) | число повторений неизвестно, определяется условием | перед каждой итерацией; тело может не выполниться ни разу |
| **С постусловием** (`do-while`) | тело должно выполниться хотя бы раз | после каждой итерации |

## Цикл с параметром: for

Цикл **`for`** работает со счётчиком: начальное значение, условие-граница и шаг.

| Язык | От 1 до *n* |
|---|---|
| Python | `for i in range(1, n + 1):` |
| Java, C++ | `for (int i = 1; i <= n; i++) { ... }` |

В Python у `range(начало, конец, шаг)` `конец` **не входит**: `range(1, 5)` → 1, 2, 3, 4. `range(5)` → 0, 1, 2, 3, 4. В обратном порядке: `range(10, 0, -1)` → 10, 9, …, 1.

В Java и C++ в скобках `for` три части: `int i = 1` (один раз, в начале), `i <= n` (перед каждой итерацией), `i++` (после каждой итерации).

## Цикл с предусловием: while

**`while`** повторяет тело, пока условие истинно. Применяется, когда число повторений заранее неизвестно: «пока число не станет 0», «пока пользователь не введёт правильный пароль», «пока долг не погашен».

| Язык | Запись |
|---|---|
| Python | `while условие:` |
| Java, C++ | `while (условие) { ... }` |

В теле цикла переменная, влияющая на условие, обязательно должна меняться, иначе цикл никогда не закончится — это **бесконечный цикл**.

## Цикл с постусловием: do-while

**`do-while`**: сначала выполняется тело, потом проверяется условие. Поэтому тело выполняется хотя бы один раз. Есть в Java и C++: `do { ... } while (условие);` (с точкой с запятой в конце!). В Python `do-while` нет; вместо него используют `while True:` с `break` внутри. Подробно этот цикл разбирается на занятии A8.

## Счётчик и накопитель

Большинство задач с циклами опираются на два шаблона:

- **Накопитель (accumulator)** — до цикла получает начальное значение (0 для суммы, 1 для произведения), на каждой итерации к нему прибавляется или на него умножается новое значение: `s += x`, `p *= x`.
- **Счётчик (counter)** — считает, сколько раз выполнилось условие: до цикла `k = 0`, если условие истинно — `k += 1`.

Начальное значение задаётся **до цикла**. Если задать его внутри, на каждой итерации оно будет сбрасываться.

## break и continue

- **`break`** — немедленно завершает цикл; управление переходит к оператору после цикла. Например, остановить поиск, когда нужный элемент найден.
- **`continue`** — пропускает остаток текущей итерации и переходит к следующей. Например, пропустить отрицательные числа.

Оба записываются одинаково во всех трёх языках.

## Разобранный пример 1: факториал

Вводится целое число *n* (0 ≤ *n* ≤ 20). Вычислите *n*! = 1 · 2 · … · *n* (0! = 1).

```python
n = int(input())

f = 1                          # начальное значение произведения — 1
for i in range(1, n + 1):
    f *= i

print(f"{n}! = {f}")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();

        long f = 1;                // 20! не помещается в int, поэтому long
        for (int i = 1; i <= n; i++) {
            f *= i;
        }

        System.out.println(n + "! = " + f);
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    long long f = 1;           // 20! не помещается в int, поэтому long long
    for (int i = 1; i <= n; i++) {
        f *= i;
    }

    cout << n << "! = " << f << endl;
    return 0;
}
```

При вводе `5` цикл работает по шагам:

| *i* | `f *= i` | *f* |
|---|---|---|
| в начале | — | 1 |
| 1 | 1 · 1 | 1 |
| 2 | 1 · 2 | 2 |
| 3 | 2 · 3 | 6 |
| 4 | 6 · 4 | 24 |
| 5 | 24 · 5 | 120 |

Выводится: `5! = 120`. При вводе `0` цикл не выполняется ни разу, и выводится `0! = 1` — благодаря правильно выбранному начальному значению. `20! = 2432902008176640000` — такое число не помещается в `int`, нужен `long` / `long long`.

## Разобранный пример 2: сумма цифр числа

Вводится положительное целое число. Найдите сумму его цифр и количество цифр.

```python
n = int(input())

yigindi = 0
soni = 0
while n > 0:
    yigindi += n % 10          # последняя цифра
    n //= 10                   # отбрасываем последнюю цифру
    soni += 1

print("Сумма:", yigindi)
print("Цифр:", soni)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();

        int yigindi = 0;
        int soni = 0;
        while (n > 0) {
            yigindi += n % 10;     // последняя цифра
            n /= 10;               // отбрасываем последнюю цифру
            soni++;
        }

        System.out.println("Сумма: " + yigindi);
        System.out.println("Цифр: " + soni);
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    int yigindi = 0;
    int soni = 0;
    while (n > 0) {
        yigindi += n % 10;     // последняя цифра
        n /= 10;               // отбрасываем последнюю цифру
        soni++;
    }

    cout << "Сумма: " << yigindi << endl;
    cout << "Цифр: " << soni << endl;
    return 0;
}
```

При вводе `2026`:

| *n* (в начале итерации) | `n % 10` | *yigindi* | *soni* |
|---|---|---|---|
| 2026 | 6 | 6 | 1 |
| 202 | 2 | 8 | 2 |
| 20 | 0 | 8 | 3 |
| 2 | 2 | 10 | 4 |
| 0 | — | цикл завершается | |

Выводится: `Сумма: 10` и `Цифр: 4`. Число повторений заранее неизвестно (зависит от количества цифр), поэтому выбран `while`. На каждой итерации *n* уменьшается — цикл обязательно завершится.

:::warning
**Частые ошибки**

- **Бесконечный цикл.** Если внутри `while (n > 0)` *n* не меняется, программа никогда не закончится. На платформе это даёт результат «превышен лимит времени».
- **Ошибка на единицу (off-by-one).** `range(1, n)` не включает *n*; не путайте `i < n` и `i <= n`.
- **Обнуление накопителя внутри цикла.** Результат будет равен только последнему значению.
- **Произведение, начатое с 0.** При `f = 0` результат всегда 0.
- **Забытая точка с запятой в конце `do-while`** — ошибка компиляции.
:::

## Итоги

- Цикл повторяет тело, пока условие истинно; однократное выполнение тела — итерация.
- `for` — когда число повторений известно; `while` — по условию, тело может не выполниться ни разу; `do-while` — тело выполняется хотя бы раз.
- В Python в `range(a, b)` *b* не входит; в Java и C++ `for (начало; условие; шаг)`.
- Накопитель начинается до цикла с 0 (сумма) или 1 (произведение).
- `break` завершает цикл, `continue` переходит к следующей итерации.
- В теле цикла переменная, влияющая на условие, должна меняться, иначе цикл бесконечен.

## Проверьте себя

:::check
Q: Какие значения даёт `range(2, 10, 3)` в Python?
A: 2, 5, 8 (10 не входит).
Q: В чём основное различие `while` и `do-while`?
A: `while` проверяет условие перед телом, и тело может не выполниться ни разу; `do-while` сначала выполняет тело, поэтому оно выполняется хотя бы один раз.
Q: Чему равно *s* после `s = 0; for i in range(1, 6): s += i`?
A: 15 (1 + 2 + 3 + 4 + 5).
Q: Какая ошибка в коде: `i = 1` `while i <= 10:` `print(i)`?
A: *i* внутри цикла не меняется — бесконечный цикл. В тело нужно добавить `i += 1`.
Q: Чем отличаются `break` и `continue`?
A: `break` полностью завершает цикл; `continue` пропускает только остаток текущей итерации и начинает следующую.
