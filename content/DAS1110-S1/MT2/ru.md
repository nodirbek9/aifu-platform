## Почему это важно

График кредита, проценты по вкладу, прогноз роста населения, сумма ряда — всё это основано на многократном повторении одного и того же вычисления. Чтобы правильно построить цикл, нужно знать три вещи: с чего он начинается, что меняется на каждом шаге и когда он останавливается. В этой самостоятельной работе вы сами ответите на эти три вопроса и от начала до конца напишете программу, вычисляющую циклом.

:::note
**После этой самостоятельной работы вы сможете:**

- выбирать для задачи подходящий цикл (`for` или `while`) и обосновывать выбор;
- точно записывать начальное значение, шаг и условие остановки цикла;
- вручную заполнять таблицу значений для маленького входа и проверять ею программу;
- выполнять вычисления с вещественными числами и выводить результат с нужной точностью.
:::

## Краткое повторение темы

Для каждого цикла ответьте на три вопроса:

| Вопрос | В `for` | В `while` |
|---|---|---|
| С чего начинается? | начальное значение счётчика | значения до цикла |
| Что меняется на каждом шаге? | счётчик + тело | переменная внутри тела |
| Когда останавливается? | когда счётчик достигает границы | когда условие становится ложным |

Если число повторений известно — `for`, если «пока не произойдёт событие» — `while`. Накопитель для суммы начинается с 0, для произведения — с 1. Работая с вещественными числами, избегайте целочисленного деления: `1.0 / k`.

## Образец: вклад

На вклад положено *S* сумов, годовой процент *p* % (начисляется в конце каждого года). Через сколько лет сумма впервые станет не меньше *M* сумов? Выведите число лет и сумму в этот момент (два знака после запятой). Ввод: *S*, *p*, *M* в одной строке (*S* < *M*, *p* > 0).

Число повторений заранее неизвестно — `while`. Условие остановки: `summa >= M`. На каждом шаге: `summa = summa * (1 + p / 100)` и `yil += 1`. Цикл обязательно завершится: при *p* > 0 сумма растёт каждый год.

```text
1. прочитать S, p, M
2. summa = S, yil = 0
3. пока summa < M:
       summa = summa * (1 + p / 100)
       yil = yil + 1
4. вывести yil и summa
```

```python
s, p, m = map(float, input().split())

summa = s
yil = 0
while summa < m:
    summa = summa * (1 + p / 100)
    yil += 1

print(yil, f"{summa:.2f}")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        double s = in.nextDouble();
        double p = in.nextDouble();
        double m = in.nextDouble();

        double summa = s;
        int yil = 0;
        while (summa < m) {
            summa = summa * (1 + p / 100);
            yil++;
        }

        System.out.println(yil + " " + String.format("%.2f", summa));
    }
}
```
```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double s, p, m;
    cin >> s >> p >> m;

    double summa = s;
    int yil = 0;
    while (summa < m) {
        summa = summa * (1 + p / 100);
        yil++;
    }

    cout << yil << " " << fixed << setprecision(2) << summa << endl;
    return 0;
}
```

Таблица значений для ввода `1000000 20 2000000` (*yil* — год, *summa* — сумма):

| *yil* | *summa* (на конец года) | `summa < M`? |
|---|---|---|
| 0 | 1 000 000 | да |
| 1 | 1 200 000 | да |
| 2 | 1 440 000 | да |
| 3 | 1 728 000 | да |
| 4 | 2 073 600 | нет — остановка |

Выводится: `4 2073600.00`. Заполнение такой таблицы вручную до написания программы — обязательная часть самостоятельной работы.

## Задание самостоятельной работы

Решите приведённую ниже задачу о **сумме гармонического ряда**. Что сдаётся:

1. **Анализ** — ответы на три вопроса: с чего начинается цикл, что прибавляется на каждом шаге, когда он останавливается; почему выбран именно этот вид цикла.
2. **Таблица значений** — слагаемое и сумма на каждом шаге для *n* = 4 (вручную).
3. **Программа** — на Python, Java или C++; отправляется в окне задания ниже и должна пройти автоматические тесты.
4. **Эксперимент** — результаты для *n* = 10, 100, 1000 и короткий вывод: как меняется сумма с ростом *n*?

:::warning
**Критерии оценки и частые ошибки**

- `1 / k` в Java и C++ даёт целочисленное деление (0); для вещественного деления — `1.0 / k`.
- Цикл должен начинаться с 1: `1 / 0` — деление на ноль.
- Результат выводится с точностью, указанной в условии (4 знака после запятой).
- Таблица значений заполняется вручную, а не копируется из программы.
:::

:::tip
Сначала проверьте программу при *n* = 1 (ответ 1.0000) и *n* = 2 (ответ 1.5000) — это самые простые тесты, и они находят больше всего ошибок.
:::

## Проверьте себя

:::check
Q: Почему в образце выбран `while`, а не `for`?
A: Сколько лет понадобится, заранее неизвестно — цикл продолжается, пока сумма не достигнет цели.
Q: Что сделает программа-образец, если *p* = 0?
A: Сумма не меняется, и цикл никогда не завершится — поэтому в условии требуется *p* > 0.
Q: Ограничена ли сумма гармонического ряда с ростом *n*?
A: Нет: она растёт очень медленно, но неограниченно (примерно ln *n* + 0,577).
