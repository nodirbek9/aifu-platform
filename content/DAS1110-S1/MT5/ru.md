## Почему это важно

**Вектор** в математике — упорядоченный набор чисел: точка на плоскости (*x*, *y*), скорость в пространстве (*vx*, *vy*, *vz*), оценки студента по пяти предметам. Рекомендательные системы (YouTube, интернет-магазины) представляют пользователя и товар векторами из сотен измерений и находят сходство через «расстояние» или скалярное произведение. В программе вектор хранится как обычный одномерный массив.

:::note
**После этой самостоятельной работы вы сможете:**

- хранить вектор размерности *n* в массиве;
- вычислять сумму векторов, умножение на число, длину и расстояние;
- создавать вектор динамического размера: `vector` в C++, массив в Java, список в Python;
- вручную вычислять результат по формуле и проверять программу.
:::

## Краткое повторение темы

Для векторов *a* = (*a*₁, …, *aₙ*) и *b* = (*b*₁, …, *bₙ*):

| Операция | Формула | В программе |
|---|---|---|
| Сумма | (*a*₁ + *b*₁, …, *aₙ* + *bₙ*) | `c[i] = a[i] + b[i]` |
| Умножение на число | (*k* · *a*₁, …, *k* · *aₙ*) | `c[i] = k * a[i]` |
| Длина | √(*a*₁² + … + *aₙ*²) | сумма циклом, затем `sqrt` |
| Расстояние | √((*a*₁ − *b*₁)² + … ) | корень из суммы квадратов разностей |
| Скалярное произведение | *a*₁*b*₁ + … + *aₙbₙ* | `s += a[i] * b[i]` |

Все операции выполняются одним циклом, и размерности двух векторов должны совпадать.

В C++ слово «вектор» имеет два смысла: математический вектор и `std::vector` — массив переменного размера. Второй удобен для хранения первого: `vector<double> a(n);`.

## Образец: сумма и расстояние

В первой строке *n*, во второй и третьей — по *n* целых чисел: векторы *a* и *b*. В первой строке выведите *a* + *b*, во второй — расстояние между *a* и *b* (два знака после запятой).

```python
import math

n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

yigindi = [a[i] + b[i] for i in range(n)]

kvadratlar = 0
for i in range(n):
    kvadratlar += (a[i] - b[i]) ** 2
masofa = math.sqrt(kvadratlar)

print(*yigindi)
print(f"{masofa:.2f}")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] a = new int[n];
        int[] b = new int[n];
        for (int i = 0; i < n; i++) a[i] = in.nextInt();
        for (int i = 0; i < n; i++) b[i] = in.nextInt();

        StringBuilder sb = new StringBuilder();
        long kvadratlar = 0;
        for (int i = 0; i < n; i++) {
            if (i > 0) sb.append(' ');
            sb.append(a[i] + b[i]);
            long d = a[i] - b[i];
            kvadratlar += d * d;
        }

        System.out.println(sb);
        System.out.println(String.format("%.2f", Math.sqrt(kvadratlar)));
    }
}
```
```cpp
#include <iostream>
#include <iomanip>
#include <vector>
#include <cmath>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n), b(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    for (int i = 0; i < n; i++) cin >> b[i];

    long long kvadratlar = 0;
    for (int i = 0; i < n; i++) {
        if (i > 0) cout << ' ';
        cout << a[i] + b[i];
        long long d = a[i] - b[i];
        kvadratlar += d * d;
    }
    cout << endl;
    cout << fixed << setprecision(2) << sqrt((double) kvadratlar) << endl;
    return 0;
}
```

При вводе `3`, `1 2 3`, `4 6 3`:

| *i* | *aᵢ* | *bᵢ* | *aᵢ* + *bᵢ* | (*aᵢ* − *bᵢ*)² |
|---|---|---|---|---|
| 1 | 1 | 4 | 5 | 9 |
| 2 | 2 | 6 | 8 | 16 |
| 3 | 3 | 3 | 6 | 0 |

Выводится: `5 8 6` и `5.00` (√25). Квадрат разности считается в типе `long`: при больших координатах квадрат в `int` может переполниться.

## Задание самостоятельной работы

Решите приведённую ниже задачу о **скалярном произведении векторов**. Что сдаётся:

1. **Ручной расчёт** — посчитайте скалярное произведение для *a* = (1, −2, 3), *b* = (4, 0, −1) в виде таблицы.
2. **Геометрический смысл** — что можно сказать о векторах, если их скалярное произведение равно 0? Приведите два примера.
3. **Программа** — на Python, Java или C++; отправляется в окне задания ниже и должна пройти автоматические тесты.
4. **Анализ переполнения** — если координаты до 10⁶, а *n* = 10⁵, поместится ли результат в `int`? Какой тип вы выбрали и почему?

:::warning
**Критерии оценки и частые ошибки**

- Накопитель обнуляется **до** цикла, а не внутри него.
- При больших значениях произведение превышает `int` — используйте `long` / `long long`.
- Два вектора должны читаться одинаковой длины; не прочитайте второй вектор внутрь первого.
- Ручной расчёт и анализ не копируются из программы.
:::

:::tip
Запишите два вектора друг под другом и перемножьте их попарно: это самый быстрый ручной расчёт скалярного произведения, и программа работает точно так же.
:::

## Итоги

- Вектор размерности *n* хранится в программе как массив длины *n*.
- Сумма, умножение на число, длина, расстояние и скалярное произведение вычисляются одним циклом.
- Квадраты и произведения при больших значениях могут переполниться — выбирайте широкий тип.
- `vector` в C++ — удобный массив переменного размера для хранения вектора.
