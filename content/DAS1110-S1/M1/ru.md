## Почему это важно

В конце каждого семестра деканат подсчитывает итоговые баллы 600 студентов: складываются баллы текущего, промежуточного и итогового контроля, результат сравнивается со шкалой оценок, составляется список должников. Вручную это занимает несколько дней, и в каждом подсчёте возможна ошибка. Компьютер выполняет ту же работу за секунду и без ошибок — но только если мы **точно объясним ему, что делать**.

Объяснить компьютеру работу — это и есть программирование. На этом занятии мы разберём основные понятия «разговора» с компьютером: что такое алгоритм, как устроена программа, как компьютер её выполняет и как выглядит самая простая программа.

## Алгоритм

**Алгоритм (algorithm)** — конечная последовательность шагов, выполняемых в строго определённом порядке для решения задачи.

Алгоритмы встречаются повсюду и в обычной жизни. Рецепт заваривания чая, порядок снятия денег в банкомате, этапы подачи документов в университет — всё это алгоритмы. Например, алгоритм нахождения большего из двух чисел:

1. Возьмите первое число и назовите его *a*.
2. Возьмите второе число и назовите его *b*.
3. Если *a* > *b*, ответ — *a*; иначе ответ — *b*.
4. Сообщите ответ.

Алгоритм остаётся тем же, на каком бы языке его ни записали: словами, блок-схемой или на языке программирования. Самая важная работа в программировании — найти алгоритм; перевести его на язык — следующий шаг.

### Свойства алгоритма

| Свойство | Смысл | Что будет, если нарушить |
|---|---|---|
| **Дискретность** | Алгоритм состоит из отдельных последовательных шагов | Неясно, что и когда делать |
| **Определённость** | Каждый шаг понимается однозначно | «Посолите по вкусу» — каждый посолит по-своему |
| **Конечность** | Алгоритм завершается за конечное число шагов | Программа «зависает», результата нет |
| **Результативность** | Алгоритм даёт определённый результат | Работа сделана, а ответа нет |
| **Массовость** | Алгоритм работает для всех задач данного типа | Алгоритм «сложения», работающий только для 5 и 7, бесполезен |

### Способы записи алгоритма

- **Словесный** — пронумерованные шаги, как выше. Удобен для простых задач.
- **Блок-схема** — геометрические фигуры: овал — начало и конец, прямоугольник — действие, ромб — условие, параллелограмм — ввод и вывод. Удобна, чтобы увидеть условия и повторения.
- **Псевдокод** — запись, похожая на язык программирования, но без строгих правил.
- **На языке программирования** — единственная форма, которую выполняет компьютер.

## Программа и язык программирования

**Программа (program)** — запись алгоритма на языке, понятном компьютеру. **Язык программирования (programming language)** — искусственный язык со строгими правилами для написания программ.

У каждого языка программирования две стороны:

- **Синтаксис (syntax)** — правила записи: какие слова используются, где ставятся скобки, точка с запятой, отступы. При нарушении синтаксиса программа вообще не запустится.
- **Семантика (semantics)** — смысл написанного: что программа делает на самом деле. Программа с правильным синтаксисом, но неверным смыслом работает, но выдаёт неверный ответ. Такие ошибки найти гораздо труднее.

В этом курсе мы рассматриваем три языка рядом: **Python**, **Java** и **C++**. Все три широко используются в индустрии, но каждый работает по-своему — это мы увидим ниже.

## Как компьютер выполняет программу

Процессор понимает только **машинный код** — очень простые команды в двоичном виде (сложить два числа, записать в память, перейти к следующей команде). Текст, который пишем мы, называется **исходным кодом (source code)**. Есть два основных способа превратить его в машинный код.

**Компилятор (compiler)** переводит всю программу заранее, один раз, и создаёт исполняемый файл. Потом этот файл работает быстро, без перевода. Если есть ошибка, компилятор сообщает о ней уже при переводе, и файл не создаётся. Так работает C++.

**Интерпретатор (interpreter)** во время выполнения читает программу строка за строкой и сразу её выполняет. Программу удобно быстро пробовать, но выполнение медленнее, а ошибка проявляется только тогда, когда очередь доходит до этой строки. Так работает Python.

**Java** выбирает промежуточный путь: компилятор переводит программу в **байт-код**, а его выполняет **виртуальная машина Java (JVM)**. Поэтому одна и та же программа на Java работает и в Windows, и в Linux без повторной компиляции.

| | C++ | Java | Python |
|---|---|---|---|
| Перевод | Компилятор → машинный код | Компилятор → байт-код → JVM | Интерпретатор |
| Когда находится ошибка | При компиляции | При компиляции | Во время выполнения |
| Скорость | Очень высокая | Высокая | Средняя |
| Размер первой программы | Несколько строк | Нужны класс и метод `main` | Одна строка |

## Структура программы: ввод, обработка, вывод

Большинство учебных задач состоят из трёх частей:

1. **Ввод (input)** — программа получает данные: с клавиатуры, из файла или по сети.
2. **Обработка (processing)** — над данными выполняются действия.
3. **Вывод (output)** — результат выдаётся на экран, в файл или другой программе.

Во время работы программы данные хранятся в **переменных (variables)**. Переменная — именованное место в памяти: запись `a = 5` означает «запиши 5 в место с именем *a*».

Следующая программа читает два целых числа и выводит их сумму. Сравните варианты на трёх языках.

```python
# Читаем два числа (каждое на отдельной строке)
a = int(input())
b = int(input())

# Вычисляем сумму и выводим
s = a + b
print("Сумма:", s)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        // Читаем два числа
        int a = in.nextInt();
        int b = in.nextInt();

        // Вычисляем сумму и выводим
        int s = a + b;
        System.out.println("Сумма: " + s);
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    // Читаем два числа
    int a, b;
    cin >> a >> b;

    // Вычисляем сумму и выводим
    int s = a + b;
    cout << "Сумма: " << s << endl;
    return 0;
}
```

## Программа шаг за шагом

Пусть входные данные — `12` и `30`. Программа работает так:

1. Читается первая строка и превращается в целое число: *a* = 12. В Python `input()` возвращает строку, поэтому нужен `int(...)`; в Java `nextInt()`, а в C++ `cin >>` читают число сразу.
2. Читается второе число: *b* = 30.
3. `s = a + b` — вычисляется сумма и записывается в переменную *s*: *s* = 42.
4. Выводится результат: `Сумма: 42`.

Во всех трёх программах **один и тот же алгоритм**, отличается только синтаксис. В Java и C++ тип переменной (`int` — целое число) указывается заранее; в Python тип определяется по значению. Программа на Java пишется внутри `class Main`, на C++ — внутри функции `main()`: с неё и начинается выполнение.

:::warning
**Частые ошибки**

- **Забыть `int()` в Python.** `input()` возвращает строку: `"12" + "30"` даёт `"1230"`, а не 42.
- **Пропустить точку с запятой (`;`) в C++ и Java.** Это синтаксическая ошибка — программа не скомпилируется.
- **Путать большие и маленькие буквы.** `Print`, `Main`, `System.Out` — это другие имена. Все три языка различают регистр.
- **Писать код, не подумав над задачей.** Сначала составьте алгоритм на бумаге: что на входе, что на выходе, что делается между ними.
:::

:::tip
Перед написанием любой программы задайте себе три вопроса: **что дано? что нужно найти? как?** Ответ на эти три вопроса — готовый алгоритм.
:::

## Итоги

- **Алгоритм** — точная конечная последовательность шагов решения задачи; **программа** — его запись на языке программирования.
- Основные свойства алгоритма: дискретность, определённость, конечность, результативность, массовость.
- **Компилятор** заранее переводит всю программу (C++), **интерпретатор** работает строка за строкой во время выполнения (Python), Java работает через байт-код и JVM.
- **Синтаксис** — правила записи, **семантика** — смысл; правильными должны быть оба.
- Простая программа состоит из трёх частей: ввод, обработка, вывод; данные хранятся в переменных.

## Проверьте себя

:::check
Q: В чём разница между алгоритмом и программой?
A: Алгоритм — шаги решения задачи, он может быть записан в любой форме (словами, блок-схемой). Программа — запись именно этого алгоритма на языке программирования, который может выполнить компьютер.
Q: Какое свойство алгоритма может нарушить шаг «ждите, пока вода закипит»?
A: Конечность: если плита не включена, вода никогда не закипит и алгоритм не завершится.
Q: В чём основное различие компилятора и интерпретатора?
A: Компилятор заранее переводит всю программу и создаёт исполняемый файл; интерпретатор переводит и выполняет программу строка за строкой во время работы.
Q: Что выведет программа на Python `print(input() + input())`, если ввести `12` и `30`, и почему?
A: Выведет `1230`, потому что `input()` возвращает строки, а при сложении строки склеиваются. Чтобы сложить числа, нужен `int(input())`.
Q: Чем синтаксическая ошибка отличается от логической (семантической)?
A: При синтаксической ошибке программа вообще не запускается (сообщает компилятор или интерпретатор). При логической ошибке программа работает, но выдаёт неверный результат.
:::
