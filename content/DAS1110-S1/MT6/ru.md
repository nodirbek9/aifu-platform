## Почему это важно

В турнире каждая команда играет с каждой по одному разу. Сколько будет игр и как их перечислить? Это задача **перебора всех пар**, и решается она вложенным циклом. Тот же шаблон используется при поиске похожих документов, ближайшей пары точек, при измерении «отсортированности» данных. В этой самостоятельной работе вы потренируетесь работать с парами и оценивать, сколько работы выполняет программа.

:::note
**После этой самостоятельной работы вы сможете:**

- перебирать все пары (*i*, *j*) массива без повторов с условием *i* < *j*;
- связывать границу внутреннего цикла с внешним счётчиком;
- подсчитывать, сколько раз выполняется тело внутреннего цикла (*n*(*n* − 1)/2);
- вручную перечислять все пары для маленького входа и проверять программу.
:::

## Краткое повторение темы

Два способа перебрать все пары:

| Способ | Циклы | Число пар | Проблема |
|---|---|---|---|
| Каждый с каждым | *i*: 0 … *n* − 1, *j*: 0 … *n* − 1 | *n*² | попадают (*i*, *i*) и (*j*, *i*) |
| Только *i* < *j* | *i*: 0 … *n* − 1, *j*: *i* + 1 … *n* − 1 | *n*(*n* − 1)/2 | — |

Во втором способе каждая пара встречается **ровно один раз**. Внутренний цикл начинается с *i* + 1 — граница зависит от внешнего счётчика.

*n*(*n* − 1)/2 быстро растёт: при *n* = 10 — 45, при *n* = 1000 — ~500 тысяч, при *n* = 100 000 — ~5 миллиардов пар. Поэтому при большом *n* вложенный цикл работает медленно, и нужен более быстрый алгоритм (сортировка, хеш-таблицы — в следующих семестрах).

## Образец: число инверсий

В первой строке *n*, во второй — *n* чисел. Найдите число **инверсий** — пар с *i* < *j* и *aᵢ* > *aⱼ*. Число инверсий показывает, насколько массив «далёк» от отсортированного: в отсортированном массиве 0, в упорядоченном по убыванию — *n*(*n* − 1)/2.

```text
1. прочитать n и a
2. soni = 0
3. для каждого i = 0 … n-2:
       для каждого j = i+1 … n-1:
           если a[i] > a[j]: soni = soni + 1
4. вывести soni
```

```python
n = int(input())
a = list(map(int, input().split()))

soni = 0
for i in range(n):
    for j in range(i + 1, n):
        if a[i] > a[j]:
            soni += 1

print(soni)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = in.nextInt();
        }

        long soni = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (a[i] > a[j]) {
                    soni++;
                }
            }
        }

        System.out.println(soni);
    }
}
```
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    long long soni = 0;
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            if (a[i] > a[j]) {
                soni++;
            }
        }
    }

    cout << soni << endl;
    return 0;
}
```

При вводе `5` и `3 1 4 2 5` из всех 10 пар инверсии такие (*soni* — счётчик):

| Пара (значения) | Инверсия? |
|---|---|
| (3, 1) | да |
| (3, 2) | да |
| (4, 2) | да |
| остальные 7 | нет |

Выводится: `3`. При вводе `4` и `4 3 2 1` все 6 пар — инверсии, выводится `6` = 4 · 3 / 2. Счётчик имеет тип `long`: при большом *n* число инверсий может превысить `int`.

## Задание самостоятельной работы

Решите приведённую ниже задачу о **парах с суммой *k***. Что сдаётся:

1. **Ручной подсчёт** — для *a* = (1, 5, 3, 3, 2), *k* = 6 выпишите в таблицу все 10 пар и отметьте подходящие.
2. **Число итераций** — сколько раз выполнится тело внутреннего цикла при *n* = 5, 100, 10 000? Оцените, сколько времени ваша программа будет работать при *n* = 10 000.
3. **Программа** — на Python, Java или C++; отправляется в окне задания ниже и должна пройти автоматические тесты.
4. **Тесты** — не меньше 3: подходящих пар нет, есть одинаковые числа (например, 3 + 3), подходят все пары.

:::warning
**Критерии оценки и частые ошибки**

- Если внутренний цикл начинается с `j = 0`, каждая пара считается дважды и попадает (*i*, *i*) — начинайте с `j = i + 1`.
- Элементы с одинаковым значением, но на разных позициях (3 и 3), — это отдельная пара.
- Счётчики внутреннего и внешнего цикла должны называться по-разному (`i`, `j`).
- Таблица ручного подсчёта не копируется из программы.
:::

:::tip
Сначала выпишите все пары для *n* = 3: (0, 1), (0, 2), (1, 2). Проверьте через `print`, что тело внутреннего цикла видит именно эти три пары, затем уберите этот вывод.
:::

## Итоги

- Все пары перебираются с условием *i* < *j*: внутренний цикл начинается с *i* + 1.
- Число пар — *n*(*n* − 1)/2, оно быстро растёт с ростом *n*.
- Счётчик может стать большим — выбирайте широкий тип (`long`).
- Для маленького входа перечислите пары вручную и проверьте программу.
