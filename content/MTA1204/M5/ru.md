## Почему это важно

В современном процессоре 8–16 ядер, а в видеокарте — тысячи вычислительных блоков. Обычные алгоритмы сортировки работают последовательно: каждое сравнение ждёт результата предыдущего. **Параллельные** алгоритмы сортировки рассчитаны на выполнение многих сравнений **одновременно** — они применяются в видеокартах, сетевых коммутаторах и специальной аппаратуре.

Вторая часть лекции — **динамические структуры**: стек, очередь и дек. Они есть почти в каждой программе: вызовы функций хранятся в стеке, документы, отправленные на принтер, ждут в очереди, кнопки браузера «назад» и «вперёд» работают со стеками.

## Сортирующие сети

**Сортирующая сеть** — заранее заданная последовательность **компараторов**. Каждый компаратор (*i*, *j*) сравнивает два элемента и при необходимости меняет их, так что `a[i] ≤ a[j]`. Ключевое свойство: порядок сравнений **не зависит** от данных — поэтому непересекающиеся компараторы можно выполнять одновременно.

| Понятие | Смысл |
|---|---|
| Компаратор | пара (*i*, *j*): обменять, если `a[i] > a[j]` |
| Размер сети | число компараторов — определяет время при последовательной работе |
| Глубина сети | число параллельных этапов — определяет время при параллельной работе |

**Сеть Боуза–Нельсона** (1962) — один из первых способов рекурсивного построения сортирующей сети: массив делится пополам, каждая половина сортируется своей сетью, затем два результата объединяются специальной сливающей сетью.

**Чётно-нечётная сливающая сеть Бэтчера** (К. Бэтчер, 1968) развивает эту идею: элементы на чётных и нечётных позициях двух упорядоченных последовательностей сливаются отдельно, затем проверяются соседние пары. Результат:

| *n* | Компараторов | Глубина |
|---|---|---|
| 2 | 1 | 1 |
| 4 | 5 | 3 |
| 8 | 19 | 6 |
| 16 | 63 | 10 |

Размер — *O*(*n* log² *n*), больше, чем у последовательных алгоритмов (*O*(*n* log *n*)), но глубина всего *O*(log² *n*): с *n* процессорами сортировка заканчивается за log² *n* этапов. Ещё одна известная сеть Бэтчера — **битоническая сортировка**; она широко применяется в видеокартах.

## Чётно-нечётная транспозиционная сортировка

Простейшая параллельная сортировка: в **чётной фазе** сравниваются и при необходимости меняются пары (0, 1), (2, 3), (4, 5), …, в **нечётной** — пары (1, 2), (3, 4), …. Сравнения внутри одной фазы не пересекаются — их можно выполнять одновременно. *n* фаз всегда достаточно, поэтому с *n*/2 процессорами время *O*(*n*) (последовательно — *O*(*n*²); по сути это параллельная форма сортировки пузырьком).

## Стек, очередь и дек

| Структура | Принцип | Основные операции | Применение |
|---|---|---|---|
| **Стек** | последним пришёл — первым ушёл (LIFO) | `push`, `pop`, `top` | вызовы функций, «отменить» (Ctrl+Z), вычисление выражений, проверка скобок |
| **Очередь** | первым пришёл — первым ушёл (FIFO) | `enqueue` (в конец), `dequeue` (из начала) | очередь печати, запросы к серверу, обход графа в ширину |
| **Дек** | добавление и удаление с обоих концов | `push_front`, `push_back`, `pop_front`, `pop_back` | скользящее окно, история браузера |

Все операции — *O*(1). Есть два способа их реализации:

- **Массивом**: стек — массив и индекс «вершины». Для очереди обычный массив не годится (взятие из начала требует сдвига элементов), поэтому используют **кольцевой буфер**: индексы `bosh` (голова) и `oxir` (хвост), дойдя до конца массива, возвращаются в начало через `% ёмкость`.
- **Указателями** (связанные узлы): каждый элемент хранит указатель на следующий; ёмкость не ограничена, но каждому элементу нужна дополнительная память.

В стандартных библиотеках: Python — `list` (стек), `collections.deque` (очередь, дек); Java — `ArrayDeque`; C++ — `stack`, `queue`, `deque`.

## Разобранный пример 1: чётно-нечётная транспозиционная сортировка

В первой строке *n*, во второй — *n* чисел. Отсортируйте их чётно-нечётной сортировкой: фазы чередуют чётные пары (с 0) и нечётные (с 1); остановитесь, когда две фазы подряд прошли без обменов (или выполнено *n* фаз). Выведите отсортированный массив и число выполненных фаз.

```python
n = int(input())
a = list(map(int, input().split()))

faza = 0
tinch = 0                                   # фаз подряд без обменов
while tinch < 2 and faza < n:
    almashdi = False
    for i in range(faza % 2, n - 1, 2):     # эти сравнения не пересекаются
        if a[i] > a[i + 1]:
            a[i], a[i + 1] = a[i + 1], a[i]
            almashdi = True
    faza += 1
    tinch = 0 if almashdi else tinch + 1

print(*a)
print(faza)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = in.nextInt();

        int faza = 0, tinch = 0;                    // фаз подряд без обменов
        while (tinch < 2 && faza < n) {
            boolean almashdi = false;
            for (int i = faza % 2; i < n - 1; i += 2) {     // эти сравнения не пересекаются
                if (a[i] > a[i + 1]) {
                    int t = a[i]; a[i] = a[i + 1]; a[i + 1] = t;
                    almashdi = true;
                }
            }
            faza++;
            tinch = almashdi ? 0 : tinch + 1;
        }

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) sb.append(' ');
            sb.append(a[i]);
        }
        System.out.println(sb);
        System.out.println(faza);
    }
}
```
```cpp
#include <iostream>
#include <utility>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int& v : a) cin >> v;

    int faza = 0, tinch = 0;                        // фаз подряд без обменов
    while (tinch < 2 && faza < n) {
        bool almashdi = false;
        for (int i = faza % 2; i < n - 1; i += 2) {         // эти сравнения не пересекаются
            if (a[i] > a[i + 1]) {
                swap(a[i], a[i + 1]);
                almashdi = true;
            }
        }
        faza++;
        tinch = almashdi ? 0 : tinch + 1;
    }

    for (int i = 0; i < n; i++) cout << (i ? " " : "") << a[i];
    cout << endl << faza << endl;
    return 0;
}
```

Для `8` и `5 1 4 2 8 3 7 6` выводится `1 2 3 4 5 6 7 8` и `6`; для обратного `8 7 6 5 4 3 2 1` — 8 фаз (худший случай: *n* фаз). *n*/2 сравнений внутри одной фазы независимы друг от друга: на параллельном компьютере каждое выполняет свой процессор, и фаза заканчивается за один шаг (*faza* — фаза, *tinch* — «тихие» фазы, *almashdi* — «был обмен»). На последовательном же компьютере это ничем не отличается от обычной сортировки пузырьком.

## Разобранный пример 2: сортирующая сеть Бэтчера

Дано *k* (1 ≤ *k* ≤ 4), затем 2ᵏ чисел. Постройте рекурсивно чётно-нечётную сливающую сеть Бэтчера, примените её к массиву; выведите число компараторов и отсортированный массив.

```python
def birlashtir(chap, ong, r, tarmoq):
    qadam = r * 2
    if qadam < ong - chap:
        birlashtir(chap, ong, qadam, tarmoq)            # чётные позиции
        birlashtir(chap + r, ong, qadam, tarmoq)        # нечётные позиции
        for i in range(chap + r, ong - r, qadam):       # проверка соседей
            tarmoq.append((i, i + r))
    else:
        tarmoq.append((chap, chap + r))


def tarmoq_qur(chap, ong, tarmoq):
    if ong - chap >= 1:
        orta = chap + (ong - chap) // 2
        tarmoq_qur(chap, orta, tarmoq)
        tarmoq_qur(orta + 1, ong, tarmoq)
        birlashtir(chap, ong, 1, tarmoq)


k = int(input())
a = list(map(int, input().split()))
tarmoq = []
tarmoq_qur(0, 2 ** k - 1, tarmoq)
for i, j in tarmoq:                                     # компаратор
    if a[i] > a[j]:
        a[i], a[j] = a[j], a[i]
print(len(tarmoq))
print(*a)
```
```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Main {
    static List<int[]> tarmoq = new ArrayList<>();

    static void birlashtir(int chap, int ong, int r) {
        int qadam = r * 2;
        if (qadam < ong - chap) {
            birlashtir(chap, ong, qadam);                   // чётные позиции
            birlashtir(chap + r, ong, qadam);               // нечётные позиции
            for (int i = chap + r; i < ong - r; i += qadam) tarmoq.add(new int[] {i, i + r});   // проверка соседей
        } else {
            tarmoq.add(new int[] {chap, chap + r});
        }
    }

    static void tarmoqQur(int chap, int ong) {
        if (ong - chap >= 1) {
            int orta = chap + (ong - chap) / 2;
            tarmoqQur(chap, orta);
            tarmoqQur(orta + 1, ong);
            birlashtir(chap, ong, 1);
        }
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int k = in.nextInt();
        int n = 1 << k;
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = in.nextInt();

        tarmoqQur(0, n - 1);
        for (int[] t : tarmoq) {                            // компаратор
            if (a[t[0]] > a[t[1]]) {
                int x = a[t[0]]; a[t[0]] = a[t[1]]; a[t[1]] = x;
            }
        }

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) sb.append(' ');
            sb.append(a[i]);
        }
        System.out.println(tarmoq.size());
        System.out.println(sb);
    }
}
```
```cpp
#include <iostream>
#include <utility>
#include <vector>
using namespace std;

vector<pair<int, int>> tarmoq;

void birlashtir(int chap, int ong, int r) {
    int qadam = r * 2;
    if (qadam < ong - chap) {
        birlashtir(chap, ong, qadam);                       // чётные позиции
        birlashtir(chap + r, ong, qadam);                   // нечётные позиции
        for (int i = chap + r; i < ong - r; i += qadam) tarmoq.push_back({i, i + r});   // проверка соседей
    } else {
        tarmoq.push_back({chap, chap + r});
    }
}

void tarmoqQur(int chap, int ong) {
    if (ong - chap >= 1) {
        int orta = chap + (ong - chap) / 2;
        tarmoqQur(chap, orta);
        tarmoqQur(orta + 1, ong);
        birlashtir(chap, ong, 1);
    }
}

int main() {
    int k;
    cin >> k;
    int n = 1 << k;
    vector<int> a(n);
    for (int& v : a) cin >> v;

    tarmoqQur(0, n - 1);
    for (auto [i, j] : tarmoq) {                            // компаратор
        if (a[i] > a[j]) swap(a[i], a[j]);
    }

    cout << tarmoq.size() << endl;
    for (int i = 0; i < n; i++) cout << (i ? " " : "") << a[i];
    cout << endl;
    return 0;
}
```

Для `3` и `5 1 4 2 8 3 7 6` выводится `19` и `1 2 3 4 5 6 7 8`. Сеть строится **до данных**: какой бы ни был вход, выполняются те же 19 компараторов в том же порядке — это позволяет «зашить» их в аппаратуру или выполнять параллельно на видеокарте (*tarmoq* — сеть, *birlashtir* — слить, *qadam* — шаг). При последовательной работе сеть делает чуть больше работы: сортировка слиянием для 8 элементов делает не более 17 сравнений.

## Разобранный пример 3: очередь в кольцевом буфере

В первой строке ёмкость *C* и число команд *q*, затем *q* команд: `qosh X` — добавить в конец очереди (если она полна — `полна`), `ol` — взять из начала и вывести (если пуста — `пуста`), `hajm` — число элементов. Очередь хранится в обычном массиве размера *C*.

```python
c, q = map(int, input().split())
bufer = [0] * c
bosh = 0                                    # индекс первого элемента
hajm = 0

for _ in range(q):
    buyruq = input().split()
    if buyruq[0] == "qosh":
        if hajm == c:
            print("полна")
        else:
            bufer[(bosh + hajm) % c] = int(buyruq[1])    # хвост — по кольцу
            hajm += 1
    elif buyruq[0] == "ol":
        if hajm == 0:
            print("пуста")
        else:
            print(bufer[bosh])
            bosh = (bosh + 1) % c                        # голова тоже идёт по кольцу
            hajm -= 1
    else:
        print(hajm)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int c = in.nextInt(), q = in.nextInt();
        int[] bufer = new int[c];
        int bosh = 0, hajm = 0;                             // bosh — индекс первого элемента

        for (int k = 0; k < q; k++) {
            String buyruq = in.next();
            if (buyruq.equals("qosh")) {
                int x = in.nextInt();
                if (hajm == c) {
                    System.out.println("полна");
                } else {
                    bufer[(bosh + hajm) % c] = x;           // хвост — по кольцу
                    hajm++;
                }
            } else if (buyruq.equals("ol")) {
                if (hajm == 0) {
                    System.out.println("пуста");
                } else {
                    System.out.println(bufer[bosh]);
                    bosh = (bosh + 1) % c;                  // голова тоже идёт по кольцу
                    hajm--;
                }
            } else {
                System.out.println(hajm);
            }
        }
    }
}
```
```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    int c, q;
    cin >> c >> q;
    vector<int> bufer(c);
    int bosh = 0, hajm = 0;                                 // bosh — индекс первого элемента

    for (int k = 0; k < q; k++) {
        string buyruq;
        cin >> buyruq;
        if (buyruq == "qosh") {
            int x;
            cin >> x;
            if (hajm == c) {
                cout << "полна" << endl;
            } else {
                bufer[(bosh + hajm) % c] = x;               // хвост — по кольцу
                hajm++;
            }
        } else if (buyruq == "ol") {
            if (hajm == 0) {
                cout << "пуста" << endl;
            } else {
                cout << bufer[bosh] << endl;
                bosh = (bosh + 1) % c;                      // голова тоже идёт по кольцу
                hajm--;
            }
        } else {
            cout << hajm << endl;
        }
    }
    return 0;
}
```

```text

qosh 7
qosh 9
qosh 1
ol
qosh 1
ol

ol
ol

```

Вывод:

```text

5
7

1
пуста

```

Ёмкость 3: четвёртый `qosh` отклонён. После взятия `5` в освободившееся место (`bufer[0]`) записана `1` — хотя `bosh` теперь стоит на индексе 1: хвост `(bosh + hajm) % c` = (1 + 2) % 3 = 0. Так массив работает как кольцо, и элементы никогда не нужно сдвигать — каждая операция *O*(1) (*bufer* — буфер, *hajm* — размер). Сетевые карты, аудио- и видеопотоки используют именно кольцевые буферы.

:::warning
**Частые ошибки**

- **Взятие из начала очереди в обычном массиве.** `a.pop(0)` или сдвиг элементов — *O*(*n*); используйте кольцевой буфер или `deque`.
- **Забытый `% ёмкость` в кольцевом буфере.** Индекс выходит за границы массива.
- **Попытка различить «полна» и «пуста» только по `bosh == oxir`.** В обоих случаях индексы равны; храните отдельный счётчик `hajm`.
- **Изменение сортирующей сети в зависимости от данных.** Смысл сети — порядок сравнений известен заранее; если он зависит от данных, параллельность теряется.
:::

:::tip
Нарисуйте кольцевой буфер на бумаге в виде круга: ячейки по часовой стрелке, `bosh` и `oxir` — две стрелки. После каждой команды отмечайте, как сдвигаются стрелки.
:::

## Итоги

- Сортирующая сеть — последовательность компараторов, не зависящая от данных; размер определяет последовательное время, глубина — параллельное.
- Чётно-нечётная транспозиционная сортировка заканчивается за *n* фаз; сравнения в каждой фазе можно выполнять одновременно.
- Сеть Бэтчера: размер *O*(*n* log² *n*), глубина *O*(log² *n*); 19 компараторов для 8 элементов.
- Стек (LIFO), очередь (FIFO) и дек (оба конца) — все операции *O*(1).
- Очередь реализуется массивом как кольцевой буфер: индексы оборачиваются через `% ёмкость`.

## Проверьте себя

:::check
Q: Что означают размер и глубина сортирующей сети?
A: Размер — число компараторов (последовательное время), глубина — число параллельных этапов (параллельное время).
Q: Почему сравнения внутри одной фазы чётно-нечётной сортировки можно выполнять параллельно?
A: Они работают с непересекающимися парами — каждый элемент участвует только в одном сравнении.
Q: В кольцевом буфере ёмкости 5 при `bosh` = 3 и `hajm` = 4 на какой индекс запишется новый элемент?
A: (3 + 4) % 5 = 2.
Q: С какой структурой работает кнопка браузера «назад»?
A: Со стеком: последняя открытая страница возвращается первой.
