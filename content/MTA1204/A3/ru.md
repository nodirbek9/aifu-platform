## Почему это важно

На лекциях мы рассматривали алгоритмы поиска с точки зрения нахождения элемента в массиве. На практике же самое мощное применение двоичного поиска — поиск не в массиве, а **в диапазоне ответов**: «какое наибольшее число удовлетворяет условию?» Хеширование же во многих задачах превращает вложенный цикл в один.

На этом занятии решим три практические задачи: целый квадратный корень большого числа (двоичный поиск по ответу), корень уравнения (бисекция) и пару с заданной суммой (хеш-множество).

:::note
**После этого занятия вы сможете:**

- применять двоичный поиск «по ответу» — на диапазоне с монотонным условием;
- решать уравнение для вещественных чисел методом бисекции;
- находить пару за *O*(*n*) с помощью хеш-множества;
- выбирать подходящий метод поиска для задачи.
:::

## Двоичный поиск по ответу

Двоичный поиск работает не только в отсортированном массиве. Если вопрос — «какое наибольшее *x*, для которого выполняется *P*(*x*)?», и *P* **монотонно** (истинно до некоторой границы и ложно после неё), ответ можно найти, деля диапазон пополам:

```text
chap = наименьший возможный ответ, ong = наибольший возможный ответ
пока chap < ong:
    orta = (chap + ong + 1) / 2        ← округление вверх
    если P(orta): chap = orta          (ответ orta или больше)
    иначе:        ong = orta − 1
ответ: chap
```

`+ 1` важен: без него шаг `chap = orta` может не сокращать диапазон и привести к бесконечному циклу. Для диапазона ответов от 0 до 2 · 10⁹ хватает ~31 шага.

## Метод бисекции

Для вещественных чисел та же идея называется **бисекцией** (делением отрезка пополам): если *f*(*x*) непрерывна и на концах [*a*, *b*] имеет разные знаки, делим отрезок пополам и оставляем половину с корнем. Погрешность уменьшается вдвое на каждом шаге: через 100 шагов она составляет 2⁻¹⁰⁰ исходной длины — меньше даже точности `double`.

## Поиск с хешем

«Есть ли в массиве пара с суммой *t*?» — прямое решение проверяет все пары: *O*(*n*²). С хеш-множеством: для каждого *x* вопрос «встречалось ли *t* − *x* раньше?» решается за *O*(1), всего *O*(*n*). Этот приём «искать дополнение в хеше» работает в очень многих задачах.

| Задача | Подходящий метод |
|---|---|
| разовый поиск в неотсортированном массиве | линейный |
| многократный поиск в отсортированном массиве | двоичный |
| отсортированные равномерно распределённые данные | интерполяционный |
| очень много поисков по ключу, порядок не нужен | хеш-таблица |
| наибольшее/наименьшее значение при монотонном условии | двоичный поиск по ответу |

## Разобранный пример 1: целый квадратный корень

Дано *n* (0 ≤ *n* ≤ 10¹⁸). Выведите наибольшее целое *x*, для которого *x*² ≤ *n*, и число шагов двоичного поиска. Не используйте вещественный `sqrt` — при больших *n* он даёт ошибки округления.

```python
n = int(input())
chap, ong = 0, 2 * 10**9                # ответ в этом диапазоне
qadam = 0
while chap < ong:
    qadam += 1
    orta = (chap + ong + 1) // 2        # округление вверх
    if orta * orta <= n:                # условие истинно — ответ orta или больше
        chap = orta
    else:
        ong = orta - 1
print(chap, qadam)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        long n = new Scanner(System.in).nextLong();
        long chap = 0, ong = 2_000_000_000L;        // ответ в этом диапазоне
        int qadam = 0;
        while (chap < ong) {
            qadam++;
            long orta = (chap + ong + 1) / 2;       // округление вверх
            if (orta * orta <= n) chap = orta;      // условие истинно — ответ orta или больше
            else ong = orta - 1;
        }
        System.out.println(chap + " " + qadam);
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    long long chap = 0, ong = 2000000000LL;         // ответ в этом диапазоне
    int qadam = 0;
    while (chap < ong) {
        qadam++;
        long long orta = (chap + ong + 1) / 2;      // округление вверх
        if (orta * orta <= n) chap = orta;          // условие истинно — ответ orta или больше
        else ong = orta - 1;
    }
    cout << chap << " " << qadam << endl;
    return 0;
}
```

| *n* | Результат | Шагов |
|---|---|---|
| 10 | 3 | 31 |
| 10¹⁸ | 1 000 000 000 | 30 |
| 999 999 999 999 999 999 | 999 999 999 | 31 |

В последней строке `sqrt` мог бы вернуть 10⁹ (из-за вещественного округления), а двоичный поиск даёт точный ответ. `orta * orta` ≤ 4 · 10¹⁸ помещается в `long` (`long long`); если взять верхнюю границу больше 2 · 10⁹, произведение может переполниться (*chap*/*ong*/*orta* — левая/правая/середина, *qadam* — шаг).

## Разобранный пример 2: бисекция — корень уравнения

Дано *c* > 0. Найдите положительный корень уравнения *x*³ + *x* = *c* методом бисекции с точностью 6 знаков после запятой. *f*(*x*) = *x*³ + *x* возрастает, значит корень единствен и лежит на [0, max(1, *c*)].

```python
c = float(input())
chap, ong = 0.0, max(1.0, c)            # f(chap) < c <= f(ong)
for _ in range(100):                    # каждый шаг вдвое уменьшает погрешность
    orta = (chap + ong) / 2
    if orta**3 + orta < c:
        chap = orta
    else:
        ong = orta
print(f"{chap:.6f}")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        double c = new Scanner(System.in).nextDouble();
        double chap = 0.0, ong = Math.max(1.0, c);  // f(chap) < c <= f(ong)
        for (int k = 0; k < 100; k++) {             // каждый шаг вдвое уменьшает погрешность
            double orta = (chap + ong) / 2;
            if (orta * orta * orta + orta < c) chap = orta;
            else ong = orta;
        }
        System.out.printf("%.6f%n", chap);
    }
}
```
```cpp
#include <algorithm>
#include <cstdio>
#include <iostream>
using namespace std;

int main() {
    double c;
    cin >> c;
    double chap = 0.0, ong = max(1.0, c);           // f(chap) < c <= f(ong)
    for (int k = 0; k < 100; k++) {                 // каждый шаг вдвое уменьшает погрешность
        double orta = (chap + ong) / 2;
        if (orta * orta * orta + orta < c) chap = orta;
        else ong = orta;
    }
    printf("%.6f\n", chap);
    return 0;
}
```

Для `10` выводится `2.000000` (2³ + 2 = 10), для `1000` — `9.966667`, для `0.5` — `0.423854`. Здесь вместо «пока отрезок не станет малым» выполнено ровно 100 шагов: точность `double` ограничена, поэтому условие «отрезок < 10⁻¹⁵» иногда может никогда не выполниться. Бисекция медленная (одна двоичная цифра за шаг), но очень надёжная: если корень на отрезке, он обязательно будет найден.

## Разобранный пример 3: пара с заданной суммой (хеш-множество)

В первой строке *n* и *t*, во второй — *n* целых чисел. Выведите позиции (с 1) пары с суммой *t*, второй элемент которой стоит левее всего; если такой пары нет — `-`.

```python
n, t = map(int, input().split())
a = list(map(int, input().split()))

korilgan = {}                           # значение -> его первая позиция
javob = None
for j, x in enumerate(a):
    if t - x in korilgan:               # встречалось ли дополнение раньше? — O(1)
        javob = (korilgan[t - x] + 1, j + 1)
        break
    if x not in korilgan:
        korilgan[x] = j

print(*javob if javob else "-")
```
```java
import java.util.HashMap;
import java.util.Map;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        long t = in.nextLong();
        Map<Long, Integer> korilgan = new HashMap<>();      // значение -> его первая позиция
        String javob = "-";
        for (int j = 0; j < n; j++) {
            long x = in.nextLong();
            Integer i = korilgan.get(t - x);                // встречалось ли дополнение раньше? — O(1)
            if (i != null) {
                javob = (i + 1) + " " + (j + 1);
                break;
            }
            korilgan.putIfAbsent(x, j);
        }
        System.out.println(javob);
    }
}
```
```cpp
#include <iostream>
#include <unordered_map>
#include <vector>
using namespace std;

int main() {
    int n;
    long long t;
    cin >> n >> t;
    vector<long long> a(n);
    for (auto& v : a) cin >> v;

    unordered_map<long long, int> korilgan;                 // значение -> его первая позиция
    for (int j = 0; j < n; j++) {
        auto it = korilgan.find(t - a[j]);                  // встречалось ли дополнение раньше? — O(1)
        if (it != korilgan.end()) {
            cout << it->second + 1 << " " << j + 1 << endl;
            return 0;
        }
        korilgan.emplace(a[j], j);                          // не добавляется, если уже есть
    }
    cout << "-" << endl;
    return 0;
}
```

Для `6 12` и `8 3 11 5 7 2` выводится `4 5` (5 + 7 = 12); для `3 10` и `1 2 3` — `-`; для `2 8` и `4 4` — `1 2`. Каждый элемент просматривается один раз с одним обращением к хеш-множеству — *O*(*n*) (*korilgan* — «просмотренные», *javob* — ответ). Вложенный цикл проверил бы на 10⁵ элементах 5 · 10⁹ пар, а с хешем — 10⁵ операций. Случай равных элементов (`4 4`) требует внимания: чтобы элемент не составил пару сам с собой, его сначала проверяют, а потом добавляют.

:::warning
**Частые ошибки**

- **Забытый `+ 1` в двоичном поиске по ответу.** `orta = (chap + ong) / 2` вместе с `chap = orta` приводит к бесконечному циклу.
- **Доверие к `sqrt` для больших чисел.** `double` не хранит точно целые больше 2⁵³; используйте целочисленный двоичный поиск.
- **Остановка бисекции по условию точности.** Условие `ong - chap > 1e-15` из-за округления может никогда не стать ложным; задайте число шагов.
- **Сначала добавить элемент в хеш, потом проверить.** При `t = 2x` элемент составит пару сам с собой.
:::

:::tip
Прежде чем писать двоичный поиск по ответу, запишите монотонное условие одной строкой: «*x*² ≤ *n*», «*x*³ + *x* < *c*». Если с ростом *x* условие лишь однажды переключается с истины на ложь (или наоборот), двоичный поиск работает.
:::

## Итоги

- Двоичный поиск работает на любом диапазоне с монотонным условием: деление диапазона ответов пополам находит ответ за *O*(log диапазона) шагов.
- Для целых чисел пара `orta = (chap + ong + 1) / 2` и `chap = orta` защищает от бесконечного цикла.
- Бисекция надёжно решает вещественное уравнение с фиксированным числом шагов.
- Хеш-множество отвечает «есть ли дополнение?» за *O*(1), сокращая поиск пары с *O*(*n*²) до *O*(*n*).
- Метод поиска выбирают по устройству данных и вопросу.
