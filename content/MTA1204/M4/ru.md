## Почему это важно

Простые способы сортировки — пузырьком, выбором, вставками — работают за *O*(*n*²) и замедляются уже на 10⁵ элементах. Три алгоритма этой лекции решают проблему по-разному: **Шелл** ускоряет сортировку вставками, начиная «издалека», **пирамидальная сортировка** использует особую структуру — кучу — и даёт гарантированное *O*(*n* log *n*), а **быстрая сортировка Хоара** на практике считается самой быстрой универсальной сортировкой и лежит в основе многих стандартных библиотек.

У каждого алгоритма своя идея ответа на вопрос «как быстрее?» — их понимание учит проектировать новые алгоритмы.

## Сортировка пузырьком

Если соседние элементы стоят в неверном порядке, они меняются местами; на каждом проходе наибольший элемент «всплывает» в конец. *n* − 1 проходов, *O*(*n*²) сравнений.

**Улучшенный вариант**: если за проход не было ни одного обмена, массив отсортирован — цикл останавливается. Тогда отсортированному массиву нужен лишь один проход (*O*(*n*)). Сортировка пузырьком устойчива, но на практике почти не используется: это учебный алгоритм.

## Сортировка Шелла

**Сортировка Шелла** (Дональд Шелл, 1959) — обобщение сортировки вставками. Сортировка вставками сдвигает элемент каждый раз лишь на одну позицию, поэтому маленький элемент в конце долго добирается до начала. Идея Шелла: сначала сортировать элементы, стоящие на расстоянии *h* (*h*-сортировка), затем уменьшать *h* и закончить при *h* = 1 обычной сортировкой вставками. Большие шаги быстро приводят элементы «примерно» на свои места.

| Последовательность шагов | Пример (*n* = 100) | Худший случай |
|---|---|---|
| Шелл: *n*/2, *n*/4, …, 1 | 50, 25, 12, 6, 3, 1 | *O*(*n*²) |
| Кнут: (3ᵏ − 1)/2 | 40, 13, 4, 1 | *O*(*n*^1,5) |
| Седжвик, Сиура и другие | | ещё лучше |

Сортировка Шелла не требует дополнительной памяти и хорошо работает на массивах среднего размера; её точная сложность зависит от шагов и полностью не проанализирована.

## Пирамида (куча) и пирамидальная сортировка

**Max-пирамида** (max-heap) — полное двоичное дерево, в котором значение каждого узла не меньше значений его потомков. Она хранится в массиве без указателей:

| Узел | Индекс (с 0) |
|---|---|
| корень | 0 |
| левый потомок *i* | 2*i* + 1 |
| правый потомок *i* | 2*i* + 2 |
| родитель *i* | (*i* − 1) / 2 |

Главная операция — **просеивание вниз** (sift down): если узел меньше потомков, он меняется с бо́льшим потомком, и это продолжается вниз; *O*(log *n*). Построение пирамиды из массива: просеять каждый узел от последнего внутреннего (*n*/2 − 1) до корня — всего *O*(*n*).

**Пирамидальная сортировка** (heapsort, Дж. Уильямс, 1964):

```text
1. из массива строится max-пирамида
2. для последний = n − 1 до 1:
       обменять a[0] (наибольший) и a[последний]
       просеять a[0] вниз на отрезке 0..последний−1
```

Каждый шаг ставит наибольший элемент на своё место; *n* просеиваний × *O*(log *n*) = **гарантированное *O*(*n* log *n*)**, дополнительная память *O*(1). Недостатки — неустойчива и на практике немного медленнее быстрой сортировки.

## Быстрая сортировка Хоара

**Быстрая сортировка** (quicksort, Тони Хоар, 1960) — «разделяй и властвуй»: выбирается **опорный** элемент (pivot), массив **разбивается** — влево элементы не больше опорного, вправо не меньше — и две части сортируются рекурсивно.

**Разбиение Хоара**: два указателя — *i* слева ищет элемент не меньше опорного, *j* справа — не больше; найденные меняются местами; разбиение заканчивается, когда *i* ≥ *j*.

| Случай | Сложность | Когда |
|---|---|---|
| Средний | *O*(*n* log *n*) | опорный делит части примерно поровну |
| Худший | *O*(*n*²) | опорный всегда наименьший или наибольший элемент |

Как избежать худшего случая: брать опорный **из середины**, **случайно** или как «медиану трёх» (медиану первого, среднего и последнего элементов). `std::sort` в C++ страхует быструю сортировку пирамидальной (introsort), а Python и Java для объектов используют Timsort на основе сортировки слиянием.

## Разобранный пример 1: сортировка Шелла и последовательность шагов

Дано *n* (1 ≤ *n* ≤ 1000). Отсортируйте убывающий массив `n, n−1, …, 1` тремя способами и выведите число сравнений: вставками (*h* = 1), Шелл (*n*/2, *n*/4, …) и шаги Кнута (… 40, 13, 4, 1).

```python
def shell(a, qadamlar):
    a = a[:]
    taqqoslash = 0
    for h in qadamlar:
        for i in range(h, len(a)):          # h-сортировка: вставки с шагом h
            joriy = a[i]
            j = i
            while j >= h:
                taqqoslash += 1
                if a[j - h] > joriy:
                    a[j] = a[j - h]
                    j -= h
                else:
                    break
            a[j] = joriy
    return taqqoslash


n = int(input())
a = list(range(n, 0, -1))

yarim = []
h = n // 2
while h > 0:
    yarim.append(h)
    h //= 2

knut = []
h = 1
while h < n // 3:
    h = 3 * h + 1
while h >= 1:
    knut.append(h)
    h //= 3

print(shell(a, [1]), shell(a, yarim), shell(a, knut))
```
```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Main {
    static long shell(int[] asl, List<Integer> qadamlar) {
        int[] a = asl.clone();
        long taqqoslash = 0;
        for (int h : qadamlar) {
            for (int i = h; i < a.length; i++) {    // h-сортировка: вставки с шагом h
                int joriy = a[i];
                int j = i;
                while (j >= h) {
                    taqqoslash++;
                    if (a[j - h] > joriy) {
                        a[j] = a[j - h];
                        j -= h;
                    } else {
                        break;
                    }
                }
                a[j] = joriy;
            }
        }
        return taqqoslash;
    }

    public static void main(String[] args) {
        int n = new Scanner(System.in).nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = n - i;

        List<Integer> yarim = new ArrayList<>();
        for (int h = n / 2; h > 0; h /= 2) yarim.add(h);

        List<Integer> knut = new ArrayList<>();
        int h = 1;
        while (h < n / 3) h = 3 * h + 1;
        for (; h >= 1; h /= 3) knut.add(h);

        System.out.println(shell(a, List.of(1)) + " " + shell(a, yarim) + " " + shell(a, knut));
    }
}
```

| *n* | Вставками | Шелл (*n*/2) | Кнут |
|---|---|---|---|
| 10 | 45 | 27 | 21 |
| 100 | 4 950 | 668 | 500 |
| 1000 | 499 500 | 11 716 | 8 550 |

Обратно упорядоченный массив — худший случай для сортировки вставками: *n*(*n* − 1)/2 сравнений. Сортировка Шелла использует тот же внутренний цикл, но благодаря большим шагам на 1000 элементах делает в 40–60 раз меньше работы (*qadamlar* — шаги, *yarim* — последовательность делений пополам, *knut* — Кнута). Шаги Кнута лучше и *n*/2 — выбор последовательности шагов — важнейшая часть алгоритма.

## Разобранный пример 2: разбиение Хоара и выбор опорного элемента

В первой строке *n*, во второй — *n* чисел. Отсортируйте массив быстрой сортировкой с разбиением Хоара; выведите отсортированный массив, затем число сравнений, когда опорным был первый элемент и когда — средний.

```python
import sys

sys.setrecursionlimit(10000)


def tez_saralash(asl, tayanch_turi):
    a = asl[:]
    taqqoslash = 0

    def ajrat(chap, ong):
        nonlocal taqqoslash
        p = a[chap] if tayanch_turi == "birinchi" else a[(chap + ong) // 2]
        i, j = chap - 1, ong + 1
        while True:
            while True:                 # слева: элемент >= p
                i += 1
                taqqoslash += 1
                if a[i] >= p:
                    break
            while True:                 # справа: элемент <= p
                j -= 1
                taqqoslash += 1
                if a[j] <= p:
                    break
            if i >= j:
                return j
            a[i], a[j] = a[j], a[i]

    def saralash(chap, ong):
        if chap < ong:
            m = ajrat(chap, ong)
            saralash(chap, m)
            saralash(m + 1, ong)

    saralash(0, len(a) - 1)
    return a, taqqoslash


n = int(input())
a = list(map(int, input().split()))
natija, t1 = tez_saralash(a, "birinchi")
_, t2 = tez_saralash(a, "orta")
print(*natija)
print(t1, t2)
```
```java
import java.util.Scanner;

public class Main {
    static int[] a;
    static long taqqoslash;
    static boolean ortadan;

    static int ajrat(int chap, int ong) {
        int p = ortadan ? a[(chap + ong) / 2] : a[chap];
        int i = chap - 1, j = ong + 1;
        while (true) {
            do { i++; taqqoslash++; } while (a[i] < p);     // слева: элемент >= p
            do { j--; taqqoslash++; } while (a[j] > p);     // справа: элемент <= p
            if (i >= j) return j;
            int t = a[i]; a[i] = a[j]; a[j] = t;
        }
    }

    static void saralash(int chap, int ong) {
        if (chap < ong) {
            int m = ajrat(chap, ong);
            saralash(chap, m);
            saralash(m + 1, ong);
        }
    }

    static long tezSaralash(int[] asl, boolean ortadanTayanch) {
        a = asl.clone();
        taqqoslash = 0;
        ortadan = ortadanTayanch;
        saralash(0, a.length - 1);
        return taqqoslash;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] asl = new int[n];
        for (int i = 0; i < n; i++) asl[i] = in.nextInt();

        long t1 = tezSaralash(asl, false);
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) sb.append(' ');
            sb.append(a[i]);
        }
        long t2 = tezSaralash(asl, true);
        System.out.println(sb);
        System.out.println(t1 + " " + t2);
    }
}
```
```cpp
#include <iostream>
#include <utility>
#include <vector>
using namespace std;

long long taqqoslash;
bool ortadan;

int ajrat(vector<int>& a, int chap, int ong) {
    int p = ortadan ? a[(chap + ong) / 2] : a[chap];
    int i = chap - 1, j = ong + 1;
    while (true) {
        do { i++; taqqoslash++; } while (a[i] < p);     // слева: элемент >= p
        do { j--; taqqoslash++; } while (a[j] > p);     // справа: элемент <= p
        if (i >= j) return j;
        swap(a[i], a[j]);
    }
}

void saralash(vector<int>& a, int chap, int ong) {
    if (chap < ong) {
        int m = ajrat(a, chap, ong);
        saralash(a, chap, m);
        saralash(a, m + 1, ong);
    }
}

long long tezSaralash(vector<int>& a, bool ortadanTayanch) {
    taqqoslash = 0;
    ortadan = ortadanTayanch;
    saralash(a, 0, (int) a.size() - 1);
    return taqqoslash;
}

int main() {
    int n;
    cin >> n;
    vector<int> asl(n);
    for (int& v : asl) cin >> v;

    vector<int> a1 = asl, a2 = asl;
    long long t1 = tezSaralash(a1, false);
    long long t2 = tezSaralash(a2, true);
    for (int i = 0; i < n; i++) cout << (i ? " " : "") << a1[i];
    cout << endl << t1 << " " << t2 << endl;
    return 0;
}
```

Для `10` и `35 33 42 10 14 19 27 44 26 31` выводится `10 14 19 26 27 31 33 35 42 44` и `55 58` — на случайном порядке оба опорных почти одинаковы. Но на **отсортированном** массиве `1 2 … 20` при опорном первом элементе — 228 сравнений, при среднем — 107; на 200 элементах — 20 298 и 1 743. В отсортированном массиве первый элемент всегда наименьший — разбиение отделяет один элемент, и алгоритм деградирует до *O*(*n*²). Средний опорный спасает от этой ловушки (*tayanch* — опорный, *ajrat* — разбить).

## Разобранный пример 3: построение max-пирамиды из массива

В первой строке *n*, во второй — *n* чисел. Превратите массив на месте в max-пирамиду (просеивание от последнего внутреннего узла до корня) и выведите получившийся массив.

```python
def choktir(a, i, n):
    while True:
        chap = 2 * i + 1
        if chap >= n:                       # детей нет — лист
            return
        katta = chap
        if chap + 1 < n and a[chap + 1] > a[chap]:
            katta = chap + 1                # больший потомок
        if a[i] >= a[katta]:                # свойство кучи выполнено
            return
        a[i], a[katta] = a[katta], a[i]
        i = katta


n = int(input())
a = list(map(int, input().split()))
for i in range(n // 2 - 1, -1, -1):         # от последнего внутреннего узла до корня
    choktir(a, i, n)
print(*a)
```
```java
import java.util.Scanner;

public class Main {
    static void choktir(int[] a, int i, int n) {
        while (true) {
            int chap = 2 * i + 1;
            if (chap >= n) return;                      // детей нет — лист
            int katta = chap;
            if (chap + 1 < n && a[chap + 1] > a[chap]) katta = chap + 1;   // больший потомок
            if (a[i] >= a[katta]) return;               // свойство кучи выполнено
            int t = a[i]; a[i] = a[katta]; a[katta] = t;
            i = katta;
        }
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = in.nextInt();
        for (int i = n / 2 - 1; i >= 0; i--) choktir(a, i, n);   // от последнего внутреннего узла до корня
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) sb.append(' ');
            sb.append(a[i]);
        }
        System.out.println(sb);
    }
}
```
```cpp
#include <iostream>
#include <utility>
#include <vector>
using namespace std;

void choktir(vector<int>& a, int i, int n) {
    while (true) {
        int chap = 2 * i + 1;
        if (chap >= n) return;                          // детей нет — лист
        int katta = chap;
        if (chap + 1 < n && a[chap + 1] > a[chap]) katta = chap + 1;   // больший потомок
        if (a[i] >= a[katta]) return;                   // свойство кучи выполнено
        swap(a[i], a[katta]);
        i = katta;
    }
}

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int& v : a) cin >> v;
    for (int i = n / 2 - 1; i >= 0; i--) choktir(a, i, n);   // от последнего внутреннего узла до корня
    for (int i = 0; i < n; i++) cout << (i ? " " : "") << a[i];
    cout << endl;
    return 0;
}
```

Для `7` и `4 10 3 5 1 8 9` выводится `10 5 9 4 1 8 3`. В виде дерева: корень 10, его потомки 5 и 9, потомки 5 — 4 и 1, потомки 9 — 8 и 3 — каждый родитель больше потомков. Наибольший элемент теперь в `a[0]`: отсюда начинается пирамидальная сортировка — остаётся обменять его с последним элементом и снова просеять корень (это вы сделаете в практическом задании). Построение пирамиды — *O*(*n*): большинство нижних узлов — листья, и просеивание для них почти бесплатно (*choktir* — просеять, *katta* — бо́льший).

:::warning
**Частые ошибки**

- **Всегда брать первый элемент опорным в быстрой сортировке.** На отсортированных или почти отсортированных данных — *O*(*n*²) и глубокая рекурсия; берите средний или случайный опорный.
- **Индексы пирамиды с 1.** При индексации с 0 потомки — 2*i* + 1 и 2*i* + 2; с 1 — 2*i* и 2*i* + 1; не смешивайте.
- **Обмен с меньшим потомком при просеивании.** Свойство пирамиды сохраняет только обмен с **бо́льшим** потомком.
- **Сортировка Шелла без *h* = 1.** Последний шаг обязательно равен 1, иначе массив не будет полностью отсортирован.
:::

:::tip
Нарисуйте пирамиду на бумаге в виде дерева: подпишите индексы массива на узлах и покажите каждое просеивание стрелкой. В виде дерева проверять свойство пирамиды гораздо проще, чем в массиве.
:::

## Итоги

- Сортировка пузырьком — *O*(*n*²); остановка после прохода без обменов завершает отсортированный массив за *O*(*n*).
- Сортировка Шелла начинает сортировку вставками с больших шагов; эффективность зависит от последовательности шагов.
- Max-пирамида хранится в массиве (потомки 2*i* + 1, 2*i* + 2); построение — *O*(*n*), просеивание — *O*(log *n*).
- Пирамидальная сортировка даёт гарантированное *O*(*n* log *n*) и *O*(1) дополнительной памяти, но неустойчива.
- Быстрая сортировка Хоара — в среднем *O*(*n* log *n*), в худшем *O*(*n*²); правильный выбор опорного защищает от худшего случая.

## Проверьте себя

:::check
Q: Чем сортировка Шелла отличается от сортировки вставками?
A: Сначала сортирует элементы на расстоянии *h* и уменьшает *h* до 1; элементы большими прыжками быстро приближаются к своим местам.
Q: На каких индексах потомки узла с индексом 4 в пирамиде с индексацией с 0?
A: 9 и 10.
Q: Почему быстрая сортировка замедляется на отсортированном массиве, если опорный — первый элемент?
A: Опорный всегда наименьший, и разбиение делит массив на части 1 и *n* − 1 — *O*(*n*²).
Q: В чём преимущество пирамидальной сортировки перед быстрой?
A: Даже в худшем случае гарантировано *O*(*n* log *n*), а дополнительная память *O*(1).
