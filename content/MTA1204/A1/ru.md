## Почему это важно

На лекции мы теоретически познакомились со свойствами алгоритма и машиной Тьюринга. На практике ответим на два вопроса: являются ли данные указания действительно алгоритмом и как записать их на «языке машины» — точными шагами и состояниями?

На этом занятии проверим древний алгоритм умножения с помощью таблицы шагов и напишем **универсальный** симулятор машины Тьюринга: он читает таблицу переходов из входа и выполняет любую машину. Заодно увидим практическую сторону конечности: как «поймать» машину, которая не останавливается.

:::note
**После этого занятия вы сможете:**

- проверять, удовлетворяют ли данные указания свойствам алгоритма;
- отслеживать выполнение алгоритма по таблице шагов;
- составлять таблицу переходов машины Тьюринга и проверять её в симуляторе;
- обнаруживать незавершающийся процесс по пределу шагов.
:::

## Порядок проверки алгоритма

Прежде чем назвать список указаний алгоритмом, отвечают на пять вопросов:

| Свойство | Проверочный вопрос |
|---|---|
| Дискретность | разбит ли процесс на отдельные шаги? |
| Определённость | знает ли исполнитель на каждом шаге однозначно, что делать? |
| Результативность | получается ли в конце нужный результат? |
| Массовость | указания для одного входа или для целого класса? |
| Конечность | останавливается ли процесс при любом допустимом входе и почему? |

Обычный способ показать конечность — найти величину, которая на каждом шаге **строго убывает** и ограничена снизу. Например, если *a* на каждом шаге уменьшается вдвое и условие *a* > 0, то шагов не больше log₂ *a*.

## Запись машины Тьюринга

Машина задаётся **таблицей переходов**. В симуляторе каждое правило — одна строка:

```text
состояние прочитанный_символ записываемый_символ движение новое_состояние
```

Движение: `L` — влево, `R` — вправо, `N` — на месте. Пустая ячейка — `_`. Машина останавливается, придя в состояние `stop` или если в таблице нет подходящего правила.

Поскольку лента бесконечна, в симуляторе она хранится как **словарь** (позиция → символ): незаписанные ячейки автоматически считаются пустыми. Проблема останова алгоритмически неразрешима, поэтому симулятор ставит **предел шагов**: машина, не остановившаяся за 10 000 шагов, считается «не остановившейся». Это не доказательство, а практическая защита.

## Разобранный пример 1: умножение «русского крестьянина»

Алгоритм, известный с древности: чтобы умножить *a* на *b*, *a* делят пополам (отбрасывая остаток), а *b* удваивают; складывают значения *b* в строках, где *a* нечётно. Даны *a* и *b* (1 ≤ *a*, *b* ≤ 10⁶). Выведите произведение и число шагов.

```python
a, b = map(int, input().split())
kopaytma = 0
qadam = 0
while a > 0:                    # a убывает на каждом шаге — конечность
    qadam += 1
    if a % 2 == 1:
        kopaytma += b
    a //= 2
    b *= 2
print(kopaytma, qadam)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        long a = in.nextLong(), b = in.nextLong();
        long kopaytma = 0, qadam = 0;
        while (a > 0) {                 // a убывает на каждом шаге — конечность
            qadam++;
            if (a % 2 == 1) kopaytma += b;
            a /= 2;
            b *= 2;
        }
        System.out.println(kopaytma + " " + qadam);
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    long long a, b;
    cin >> a >> b;
    long long kopaytma = 0, qadam = 0;
    while (a > 0) {                     // a убывает на каждом шаге — конечность
        qadam++;
        if (a % 2 == 1) kopaytma += b;
        a /= 2;
        b *= 2;
    }
    cout << kopaytma << " " << qadam << endl;
    return 0;
}
```

Таблица шагов для `13 21`:

| *a* | *b* | *a* нечётно? | Сумма |
|---|---|---|---|
| 13 | 21 | да | 21 |
| 6 | 42 | нет | 21 |
| 3 | 84 | да | 105 |
| 1 | 168 | да | 273 |

Выводится `273 4`. Проверка свойств: **дискретен** (каждая строка — шаг), **определён** (одно правило на шаг), **массов** (любые натуральные *a*, *b*), **результативен** (13 · 21 = 273), **конечен** (*a* на каждом шаге уменьшается не менее чем вдвое, значит шагов ⌊log₂ *a*⌋ + 1). По сути алгоритм записывает *a* в двоичной системе: 13 = 1101₂, то есть 13 · 21 = 21 + 4 · 21 + 8 · 21 (*kopaytma* — произведение, *qadam* — шаг). Процессоры компьютеров умножают похожим способом.

## Разобранный пример 2: универсальный симулятор машины Тьюринга

В первой строке число правил *k*, в следующих *k* строках — правила (`состояние символ записать движение новое`), затем начальное состояние и лента. Головка стоит на первом символе ленты. Выполните машину: если она остановилась, выведите запись на ленте (без пустых краёв; если лента пуста — `_`) и число шагов; если за 10 000 шагов не остановилась — `не остановилась`.

```python
k = int(input())
jadval = {}
for _ in range(k):
    holat, belgi, yoz, harakat, yangi = input().split()
    jadval[(holat, belgi)] = (yoz, harakat, yangi)
holat = input().strip()
lenta = dict(enumerate(input().strip()))    # позиция -> символ
kallak = 0
qadam = 0
SURILISH = {"L": -1, "R": 1, "N": 0}

while holat != "stop" and qadam < 10000:
    belgi = lenta.get(kallak, "_")
    if (holat, belgi) not in jadval:        # нет подходящего правила — остановка
        break
    yoz, harakat, holat = jadval[(holat, belgi)]
    lenta[kallak] = yoz
    kallak += SURILISH[harakat]
    qadam += 1

if holat != "stop" and qadam >= 10000:
    print("не остановилась")
else:
    band = [i for i in lenta if lenta[i] != "_"]
    if band:
        print("".join(lenta.get(i, "_") for i in range(min(band), max(band) + 1)))
    else:
        print("_")
    print(qadam)
```
```java
import java.util.HashMap;
import java.util.Map;
import java.util.Scanner;
import java.util.TreeMap;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int k = in.nextInt();
        Map<String, String[]> jadval = new HashMap<>();
        for (int i = 0; i < k; i++) {
            String holat = in.next(), belgi = in.next();
            jadval.put(holat + " " + belgi, new String[] {in.next(), in.next(), in.next()});
        }
        String holat = in.next();
        String kirish = in.next();
        TreeMap<Integer, Character> lenta = new TreeMap<>();   // позиция -> символ
        for (int i = 0; i < kirish.length(); i++) lenta.put(i, kirish.charAt(i));

        int kallak = 0, qadam = 0;
        while (!holat.equals("stop") && qadam < 10000) {
            char belgi = lenta.getOrDefault(kallak, '_');
            String[] q = jadval.get(holat + " " + belgi);
            if (q == null) break;                               // нет подходящего правила — остановка
            lenta.put(kallak, q[0].charAt(0));
            kallak += q[1].equals("L") ? -1 : q[1].equals("R") ? 1 : 0;
            holat = q[2];
            qadam++;
        }

        if (!holat.equals("stop") && qadam >= 10000) {
            System.out.println("не остановилась");
            return;
        }
        Integer bosh = null, oxir = null;
        for (Map.Entry<Integer, Character> e : lenta.entrySet()) {
            if (e.getValue() != '_') {
                if (bosh == null) bosh = e.getKey();
                oxir = e.getKey();
            }
        }
        StringBuilder sb = new StringBuilder();
        if (bosh == null) sb.append('_');
        else for (int i = bosh; i <= oxir; i++) sb.append(lenta.getOrDefault(i, '_'));
        System.out.println(sb);
        System.out.println(qadam);
    }
}
```
```cpp
#include <iostream>
#include <map>
#include <string>
#include <tuple>
using namespace std;

int main() {
    int k;
    cin >> k;
    map<pair<string, char>, tuple<char, char, string>> jadval;
    for (int i = 0; i < k; i++) {
        string holat, yangi;
        char belgi, yoz, harakat;
        cin >> holat >> belgi >> yoz >> harakat >> yangi;
        jadval[{holat, belgi}] = {yoz, harakat, yangi};
    }
    string holat, kirish;
    cin >> holat >> kirish;
    map<int, char> lenta;                               // позиция -> символ
    for (int i = 0; i < (int) kirish.size(); i++) lenta[i] = kirish[i];

    int kallak = 0, qadam = 0;
    while (holat != "stop" && qadam < 10000) {
        char belgi = lenta.count(kallak) ? lenta[kallak] : '_';
        auto it = jadval.find({holat, belgi});
        if (it == jadval.end()) break;                  // нет подходящего правила — остановка
        auto [yoz, harakat, yangi] = it->second;
        lenta[kallak] = yoz;
        kallak += harakat == 'L' ? -1 : harakat == 'R' ? 1 : 0;
        holat = yangi;
        qadam++;
    }

    if (holat != "stop" && qadam >= 10000) {
        cout << "не остановилась" << endl;
        return 0;
    }
    int bosh = 0, oxir = -1;
    bool bor = false;
    for (auto& [pozitsiya, belgi] : lenta) {
        if (belgi != '_') {
            if (!bor) bosh = pozitsiya;
            oxir = pozitsiya;
            bor = true;
        }
    }
    string natija;
    if (!bor) natija = "_";
    for (int i = bosh; bor && i <= oxir; i++) natija += lenta.count(i) ? lenta[i] : '_';
    cout << natija << endl << qadam << endl;
    return 0;
}
```

**Машина унарного сложения.** В унарной системе число *n* записывается *n* единицами: 3 + 2 — это `111+11`. Машина заменяет `+` на `1` и стирает последнюю `1`:

```text
5
q0 1 1 R q0
q0 + 1 R q1
q1 1 1 R q1
q1 _ _ L q2
q2 1 _ N stop
q0
111+11
```

Выводится `11111` и `8` — 3 + 2 = 5. Машина сначала идёт вправо (`q0`, `q1`), дойдя до конца, возвращается на одну ячейку (`q2`) и стирает лишнюю `1`.

**Неостанавливающаяся машина.** С такой таблицей машина доходит до конца ленты, возвращается на ячейку и снова идёт вперёд — бесконечно:

```text
3
q0 1 1 R q0
q0 _ _ L q1
q1 1 1 R q0
q0
11
```

Выводится `не остановилась`. Симулятор не доказал, что машина **никогда** не остановится, — он лишь перестал ждать после 10 000 шагов. В этом и суть проблемы останова: в общем случае алгоритм не может ответить на вопрос «ждать ли ещё?» (*jadval* — таблица, *lenta* — лента, *kallak* — головка, *holat* — состояние).

:::warning
**Частые ошибки**

- **Лента как обычный массив.** Если головка уйдёт влево, отрицательный индекс вызовет ошибку; используйте словарь или структуру, растущую в обе стороны.
- **Симулятор без предела шагов.** Неостанавливающаяся машина повесит программу.
- **Два правила для одной пары (состояние, символ).** Это нарушает определённость — машина перестаёт быть детерминированной.
- **Обоснование конечности фразой «попробовал несколько раз — остановилась».** Доказательство даётся через убывающую величину.
:::

:::tip
Прежде чем отдать свою машину симулятору, выполните 3–4 её шага на бумаге: на каждом шаге записывайте ленту, положение головки и состояние. Ошибка в таблице чаще всего находится именно на этом этапе.
:::

## Итоги

- Чтобы указания были алгоритмом, проверяют каждое из пяти свойств; конечность обосновывают убывающей величиной.
- Таблица шагов показывает, как работает алгоритм, и помогает проверить результат.
- Универсальный симулятор принимает таблицу переходов как вход — сменится таблица, сменится и машина.
- Бесконечная лента моделируется словарём; неостанавливающаяся машина на практике выявляется пределом шагов.

## Проверьте себя

:::check
Q: Сколько шагов делает способ «русского крестьянина» при *a* = 100?
A: 7: 100 → 50 → 25 → 12 → 6 → 3 → 1 → 0 (⌊log₂ 100⌋ + 1 = 7).
Q: Почему в симуляторе лента хранится как словарь?
A: Лента бесконечна в обе стороны; словарь хранит любую (даже отрицательную) позицию и позволяет считать незаписанные ячейки пустыми.
Q: Каковы результат и число шагов машины унарного сложения для `1+1`?
A: `11` и 5 шагов.
Q: Если симулятор сообщил «не остановилась», доказывает ли это, что машина никогда не остановится?
A: Нет — это значит лишь, что она не остановилась за заданное число шагов.
:::
