## Цель семинара

## Виды данных

| Вид | Описание | Пример |
|---|---|---|
| **Структурированные** | строгая табличная форма | банковские транзакции, бухгалтерские записи |
| **Полуструктурированные** | с метками, но гибкие | JSON, XML, веб-журналы |
| **Неструктурированные** | без чёткой структуры | тексты, отзывы, изображения, видео, голосовые записи |

Исследования показывают, что значительная часть данных неструктурирована — для их анализа нужны анализ текстов и искусственный интеллект.

## Этапы обработки и технологии

| Этап | Содержание | Средства |
|---|---|---|
| **Сбор** | с касс, приложений, датчиков, сайтов | API, Apache Kafka (потоки), средства ETL |
| **Хранение** | большие и разнообразные данные | HDFS (распределённая файловая система Hadoop), озёра данных, NoSQL, облачные хранилища |
| **Очистка** | дубликаты, ошибки, пропуски, согласование форматов | Python (pandas), Spark, Power Query |
| **Анализ** | расчёты, статистика, машинное обучение | Apache Spark, SQL, Python, R |
| **Визуализация** | дашборды и отчёты | Power BI, Tableau, Looker Studio |

**Hadoop** хранит данные, распределяя их по множеству обычных компьютеров (HDFS), и обрабатывает их параллельно методом **MapReduce**: *Map* — каждый компьютер обрабатывает свою часть, *Reduce* — результаты объединяются. **Apache Spark** намного быстрее, так как работает в памяти, и поддерживает пакетную и потоковую аналитику, SQL и машинное обучение.

**Пакетная и потоковая обработка**: пакетная (batch) — данные накапливаются и обрабатываются, например, раз в ночь (месячный отчёт); потоковая (stream) — каждое событие обрабатывается сразу по поступлении (платёж по карте, биржевая цена). Для выявления мошенничества нужна потоковая обработка — платёж должен быть подтверждён или остановлен за доли секунды.

## Виды аналитики

| Вид | Вопрос | Пример |
|---|---|---|
| **Описательная** (descriptive) | что произошло? | месячный отчёт о продажах |
| **Диагностическая** | почему произошло? | в каком регионе и почему упали продажи |
| **Прогнозная** (predictive) | что произойдёт? | спрос в следующем месяце, вероятность возврата кредита клиентом |
| **Предписывающая** | что делать? | оптимальная цена, объём запаса, маршрут |

## Разобранный пример: выявление подозрительной транзакции

Банк проверяет каждый платёж по карте в реальном времени. Простое правило: если сумма платежа более чем в *k* раз превышает среднее предыдущих (принятых) платежей клиента — она **подозрительная**, платёж останавливается для подтверждения и не добавляется в историю; правило применяется при наличии не менее 3 предыдущих платежей. Ввод: *k*, затем последовательность платежей (тыс. сумов).

```python
import sys

t = list(map(int, sys.stdin.read().split()))
k, tolovlar = t[0], t[1:]
jami = soni = shubhali = 0
for i, summa in enumerate(tolovlar, start=1):
    if soni >= 3 and summa * soni > k * jami:        # сумма > k * среднее (в целых числах)
        shubhali += 1
        print(f"{i}: {summa} ПОДОЗРИТЕЛЬНО (среднее {jami / soni:.1f})")
        continue                                      # подозрительный платёж не добавляется в историю
    jami += summa
    soni += 1
print(f"проверено: {len(tolovlar)}, подозрительных: {shubhali}")
```
```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        long k = in.nextLong();
        List<Long> tolovlar = new ArrayList<>();
        while (in.hasNextLong()) tolovlar.add(in.nextLong());
        long jami = 0, soni = 0;
        int shubhali = 0;
        for (int i = 0; i < tolovlar.size(); i++) {
            long summa = tolovlar.get(i);
            if (soni >= 3 && summa * soni > k * jami) {       // сумма > k * среднее (в целых числах)
                shubhali++;
                System.out.println(String.format("%d: %d ПОДОЗРИТЕЛЬНО (среднее %.1f)", i + 1, summa, (double) jami / soni));
                continue;                                      // подозрительный платёж не добавляется в историю
            }
            jami += summa;
            soni++;
        }
        System.out.println("проверено: " + tolovlar.size() + ", подозрительных: " + shubhali);
    }
}
```
```cpp
#include <cstdio>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    long long k, x;
    cin >> k;
    vector<long long> tolovlar;
    while (cin >> x) tolovlar.push_back(x);
    long long jami = 0, soni = 0;
    int shubhali = 0;
    for (size_t i = 0; i < tolovlar.size(); i++) {
        long long summa = tolovlar[i];
        if (soni >= 3 && summa * soni > k * jami) {           // сумма > k * среднее (в целых числах)
            shubhali++;
            printf("%zu: %lld ПОДОЗРИТЕЛЬНО (среднее %.1f)\n", i + 1, summa, (double) jami / soni);
            continue;                                          // подозрительный платёж не добавляется в историю
        }
        jami += summa;
        soni++;
    }
    printf("проверено: %zu, подозрительных: %d\n", tolovlar.size(), shubhali);
    return 0;
}
```

Ввод:

```text
3 120 135 128 140 118 980 125 132 130 415 127 138
```

Вывод:

```text
6: 980 ПОДОЗРИТЕЛЬНО (среднее 128.2)
10: 415 ПОДОЗРИТЕЛЬНО (среднее 128.5)
проверено: 12, подозрительных: 2
```

Правило не пересчитывает среднее каждый раз, а лишь обновляет сумму и количество — это главная идея потоковой обработки: данные проходят один раз, памяти нужно мало. Кроме того, условие `сумма > k × среднее` проверяется в целых числах как `сумма × количество > k × итог` — без ошибок дробей. Настоящие банки используют сотни признаков (место, время, устройство, тип магазина) и модели машинного обучения, но принцип тот же: выявить резкое отклонение от обычного поведения.

## Применение в экономике

- **Банки**: кредитный скоринг, выявление мошенничества, сегментация клиентов.
- **Торговля**: прогноз спроса, рекомендательные системы («с этим покупают»), динамическое ценообразование.
- **Телеком**: прогноз оттока клиентов, планирование нагрузки на сеть.
- **Государство**: отбор налоговых проверок по риску, таможенная аналитика, транспортные потоки.
- **Сельское хозяйство**: прогноз урожая, погодные и спутниковые данные.

**Конфиденциальность и этика**: персональные данные используются только на законном основании и по назначению (Закон «О персональных данных»); анонимизация данных; алгоритмы не должны приводить к дискриминации (например, в кредитовании).

:::warning
**Частые ошибки**

- **«Много данных — значит, верный вывод».** Некачественные данные и в большом объёме дают неверный результат.
- **Принимать корреляцию за причину.** Если два показателя меняются вместе, один может не быть причиной другого.
- **Добавлять подозрительную транзакцию в историю.** Аномалия искажает среднее и скрывает следующие.
- **Использовать персональные данные без согласия.** Нарушение закона и потеря репутации.
:::

:::tip
Попробуйте в примере *k* = 2 и *k* = 5: чем строже правило, тем больше платежей помечается (но и больше ложных тревог) — выбор, похожий на баланс FAR и FRR в M10.
:::
