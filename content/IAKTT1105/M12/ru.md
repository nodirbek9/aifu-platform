## Почему эта тема важна?

В экономике доверие стоит дорого: договоры, нотариусы, банки, аудиторы нужны, чтобы гарантировать, что «данные верны и не изменены». **Блокчейн** даёт это доверие с помощью технологии: записи хранятся в копиях у многих участников, и изменить их незаметно нельзя. Прославившаяся благодаря биткоину технология сегодня испытывается в цепочках поставок, финансах, государственных реестрах и подтверждении документов.

## Понятие блокчейна

**Блокчейн** — **распределённый реестр**, в котором записи (транзакции) группируются в блоки, а каждый блок содержит **хеш-значение предыдущего блока**. Хеш — короткий «отпечаток» данных: при малейшем изменении данных хеш становится совсем другим.

| Свойство | Содержание |
|---|---|
| **Распределённость** | копии реестра хранятся у многих участников (узлов) |
| **Неизменность** | изменение прошлой записи ломает все следующие блоки, и другие узлы её отвергают |
| **Прозрачность** | участники видят историю транзакций |
| **Децентрализация** | нет единого центрального управляющего (в публичных блокчейнах) |
| **Криптографическая защита** | транзакции подписываются ЭЦП |

**Консенсус** — как сеть договаривается, какой блок добавить:

| Механизм | Содержание | Пример |
|---|---|---|
| **Proof of Work** (доказательство работы) | сложные вычисления для добавления блока; много электроэнергии | биткоин |
| **Proof of Stake** (доказательство доли) | выбор по размеру внесённого залога; энергоэффективно | Ethereum (с 2022 года) |
| **Разрешительный консенсус** | голоса известных участников | корпоративные системы вроде Hyperledger Fabric |

## Виды блокчейнов

| Вид | Кто участвует | Применение |
|---|---|---|
| **Публичный** | любой | криптовалюты, открытые платформы |
| **Частный** | одна организация | внутренний учёт и аудит |
| **Консорциумный** | несколько организаций (группа банков, компаний) | межбанковские расчёты, цепочки поставок |

## Смарт-контракты и цифровые активы

**Смарт-контракт** — программа, хранящаяся в блокчейне и **автоматически** запускающаяся при выполнении условий. Пример: как только подтверждено поступление товара на склад, оплата автоматически уходит поставщику — без посредников и задержек.

**Цифровые активы**: криптовалюты (биткоин, Ether), стейблкоины (привязанные к фиатной валюте), токены (доля в активе, например недвижимости или облигациях). Ряд центральных банков изучает проекты **цифровой валюты центрального банка** (CBDC). Цены криптовалют очень изменчивы — как инвестиция они высокорисковые.

**В Узбекистане** оборот криптоактивов регулируется законодательством: криптобиржи и другие поставщики услуг обязаны получать лицензию уполномоченного государственного органа; действующие требования проверяйте по официальным источникам.

## Применение в экономике

| Сфера | Применение | Ценность |
|---|---|---|
| **Цепочка поставок** | происхождение товара и каждый этап (хлопок → пряжа → ткань) | защита от подделок, прозрачный экспорт |
| **Финансы** | международные переводы, торговое финансирование, токенизированные активы | скорость, меньше посредников |
| **Подтверждение документов** | хранение хешей дипломов, сертификатов, договоров | быстрое выявление поддельного документа |
| **Государственные реестры** | земля и недвижимость, лицензии | записи нельзя тайно изменить |
| **Госзакупки** | история этапов тендера | прозрачность |

## Разобранный пример: цепочка хешей

Для каждой записи хеш блока = *H*(предыдущий хеш | запись), предыдущий хеш первого блока — 00000000. В учебных целях *H* — 32-битный FNV-1a (в реальных блокчейнах SHA-256). Вводятся записи цепочки поставок (хлопок, пряжа, ткань от фермера к заводу, фабрике и на экспорт); выведите каждый блок.

```python
import sys


def fnv1a(matn):                                 # учебная хеш-функция (в реальной системе SHA-256)
    h = 2166136261
    for b in matn.encode("utf-8"):
        h = ((h ^ b) * 16777619) & 0xFFFFFFFF
    return h


oldingi = "00000000"
yozuvlar = [s for s in sys.stdin.read().split("\n") if s.strip()]
for i, yozuv in enumerate(yozuvlar, start=1):
    xesh = format(fnv1a(oldingi + "|" + yozuv), "08x")   # блок связывается с предыдущим хешем
    print(f"блок {i}: {yozuv} | предыдущий {oldingi} | хеш {xesh}")
    oldingi = xesh
```
```java
import java.nio.charset.StandardCharsets;
import java.util.Scanner;

public class Main {
    static int fnv1a(String matn) {                             // учебная хеш-функция (в реальной системе SHA-256)
        int h = 0x811C9DC5;
        for (byte b : matn.getBytes(StandardCharsets.UTF_8)) h = (h ^ (b & 0xFF)) * 16777619;
        return h;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in, StandardCharsets.UTF_8);
        String oldingi = "00000000";
        int i = 0;
        while (in.hasNextLine()) {
            String yozuv = in.nextLine();
            if (yozuv.isBlank()) continue;
            i++;
            String xesh = String.format("%08x", fnv1a(oldingi + "|" + yozuv));   // блок связывается с предыдущим хешем
            System.out.println("блок " + i + ": " + yozuv + " | предыдущий " + oldingi + " | хеш " + xesh);
            oldingi = xesh;
        }
    }
}
```
```cpp
#include <cstdint>
#include <cstdio>
#include <iostream>
#include <string>
using namespace std;

uint32_t fnv1a(const string& matn) {                           // учебная хеш-функция (в реальной системе SHA-256)
    uint32_t h = 2166136261u;
    for (unsigned char b : matn) h = (h ^ b) * 16777619u;
    return h;
}

int main() {
    string oldingi = "00000000", yozuv;
    int i = 0;
    while (getline(cin, yozuv)) {
        if (!yozuv.empty() && yozuv.back() == '\r') yozuv.pop_back();
        if (yozuv.find_first_not_of(' ') == string::npos) continue;
        i++;
        char buf[16];
        snprintf(buf, sizeof buf, "%08x", fnv1a(oldingi + "|" + yozuv));   // блок связывается с предыдущим хешем
        string xesh = buf;
        cout << "блок " << i << ": " << yozuv << " | предыдущий " << oldingi << " | хеш " << xesh << endl;
        oldingi = xesh;
    }
    return 0;
}
```

Ввод:

```text
Paxta 20t Fermer->Zavod
Ip 15t Zavod->Fabrika
Mato 9000m Fabrika->Eksport
```

Вывод:

```text
блок 1: Paxta 20t Fermer->Zavod | предыдущий 00000000 | хеш 174beafb
блок 2: Ip 15t Zavod->Fabrika | предыдущий 174beafb | хеш a6917dc3
блок 3: Mato 9000m Fabrika->Eksport | предыдущий a6917dc3 | хеш d839ca87
```

Если теперь в первой записи изменить количество хлопка с «20t» на «25t», программа выведет:

```text
блок 1: Paxta 25t Fermer->Zavod | предыдущий 00000000 | хеш 1483cdfe
блок 2: Ip 15t Zavod->Fabrika | предыдущий 1483cdfe | хеш 2e0c2669
блок 3: Mato 9000m Fabrika->Eksport | предыдущий 2e0c2669 | хеш f6e44f26
```

Хотя вторая и третья записи не менялись, их хеши изменились — последний хеш (d839ca87) больше не совпадает с копиями других участников, и подделка обнаруживается сразу. Поэтому в цепочке поставок каждому участнику достаточно сохранить последний хеш. В настоящем блокчейне к этому добавляются консенсус и ЭЦП (подробно с доказательством работы — в M9 курса KIA).

## Преимущества, ограничения и риски

| Преимущество | Ограничение и риск |
|---|---|
| доверие без посредников | низкая скорость, иногда высокая стоимость транзакций |
| неизменяемая история | даже ошибочную запись нельзя «удалить» |
| прозрачность и аудит | конфликт с персональными данными («право на забвение») |
| автоматизация (смарт-контракты) | ошибки смарт-контрактов приводили к большим потерям |
| | изменчивость цен криптовалют, мошеннические проекты |
| | **«мусор на входе — мусор на выходе»**: блокчейн не гарантирует правильность введённых данных |

**Когда нужен блокчейн?** Когда несколько сторон, не полностью доверяющих друг другу, должны вести один общий реестр и не хотят передавать его единому центру. Если данными управляет одна доверенная организация, обычная база данных дешевле и быстрее.

:::warning
**Частые ошибки**

- **Считать блокчейн решением любой проблемы.** Во многих случаях хватает обычной базы данных.
- **Отождествлять блокчейн с криптовалютой.** Криптовалюта — лишь одно из применений блокчейна.
- **Доверять криптопроектам с «гарантированным доходом».** Это часто признак мошенничества.
- **Потерять закрытый ключ или передать его другому.** Цифровой актив теряется безвозвратно.
:::

Измените в программе-примере вторую запись: какие хеши изменятся, а какие нет? Объясните результат схемой цепочки блоков.
:::

## Итоги

- Блокчейн — распределённый реестр, блоки которого связаны через хеш предыдущего блока; неизменный, прозрачный, децентрализованный.
- Консенсус: Proof of Work, Proof of Stake, разрешительный; виды: публичный, частный, консорциумный.
- Смарт-контракт срабатывает автоматически при выполнении условий; цифровые активы высокорисковые.
- Применение: цепочки поставок, финансы, подтверждение документов, реестры, закупки.
- Блокчейн полезен, когда не доверяющие друг другу стороны ведут общий реестр; иначе хватает обычной базы.
