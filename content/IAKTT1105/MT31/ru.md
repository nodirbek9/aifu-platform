## Этапы отправки отчёта

| Этап | Действие | Обратите внимание |
|---|---|---|
| **1. Подготовка** | действующий ключ ЭЦП (MT30), E-IMZO или мобильная подпись | срок действия ключа и полномочия (руководитель или доверенность) |
| **2. Вход** | вход в личный кабинет налогоплательщика (my.soliq.uz) с ЭЦП | только с официального сайта (безопасность в S13) |
| **3. Выбор формы** | вид налога, отчётный период (месяц, квартал, год) | действующая версия формы |
| **4. Заполнение** | вручную или импорт файла из учётной программы (M15) | цифры соответствуют учётным регистрам |
| **5. Проверка** | форматные и логические проверки системы, список ошибок | не игнорируйте предупреждения |
| **6. Подписание** | подписание ЭЦП | подпись — ответственность за правильность отчёта |
| **7. Отправка** | отчёт отправляется в налоговый орган | не откладывайте на последний день срока (S15) |
| **8. Уведомление** | сообщение о принятии или отклонении | при отклонении устраните причину и отправьте снова |
| **9. Хранение** | архив отчёта, уведомления и первичных документов | хранить в течение установленного законом срока |

## Корректирующий отчёт

Если в сданном отчёте найдена ошибка (например, не учтён поздно пришедший ЭСФ), сдаётся **корректирующий отчёт** — он заменяет предыдущий и показывает верные цифры за весь период. Если ошибка занизила налог, быстрая уплата недоимки и пени уменьшает ущерб; если ошибку обнаружит сам налоговый орган, могут добавиться штрафы. Важно своевременно сдать корректировку — до начала налоговой проверки.

## Календарь отчётности

У каждого вида налога свой период и срок (ежемесячно, ежеквартально, ежегодно). Практичный способ — **налоговый календарь**: таблица или электронный календарь, где указаны каждый отчёт, срок платежа и ответственный сотрудник; напоминание за 3–5 дней до срока. Действующие сроки проверяйте в Налоговом кодексе и на сайте налогового комитета — они меняются.

## Жизненный цикл ЭСФ

```text
Продавец: создание → подписание ЭЦП → отправка
                                          │
Покупатель:              принятие (подписание) или отклонение (с причиной)
                                          │
        Принятый ЭСФ отражается в учёте обеих сторон и в системе налогового органа
```

- В ЭСФ: ИНН сторон, товары или услуги и их идентификационные коды (ИКПУ, MT15), количество, цена, ставка и сумма НДС.
- При ошибке — исправленный ЭСФ или аннулирование (с согласия покупателя).
- Покупатель принимает НДС к зачёту **только по принятым** ЭСФ.

## Механизм НДС

**Налог на добавленную стоимость** взимается на каждом этапе только с **добавленной стоимости**:

- **НДС с продаж** (исходящий) — по ставке с суммы проданных товаров и услуг.
- **НДС по покупкам** (входящий) — НДС в принятых ЭСФ от поставщиков; он принимается к зачёту.
- **НДС к уплате** = НДС с продаж − НДС по покупкам к зачёту. Если результат отрицательный, излишек переносится на следующие периоды или возвращается в установленном законом порядке.

Налоговый орган автоматически сверяет цифры отчёта с **данными ЭСФ и онлайн-касс** (S15): расхождение — основание для вопросов или проверки. Поэтому перед отчётом нужно проверить свои ЭСФ.

## Разобранный пример: НДС по ЭСФ

В каждой строке: тип (`sale` — продажа, `purchase` — покупка), номер ЭСФ, сумма без НДС (сум) и статус (`accepted` — принят, `rejected` — отклонён, `pending` — ожидает). Учитываются только принятые ЭСФ; ставка НДС в учебных целях — 12%.

```python
import sys

QQS_STAVKA = 12     # в процентах; действующую ставку проверяйте в Налоговом кодексе

sotuv_qqs = xarid_qqs = 0
for satr in sys.stdin.read().split("\n"):
    if not satr.strip():
        continue
    tur, raqam, summa, holat = satr.split()
    if holat != "accepted":                           # учитываются только принятые ЭСФ
        print(f"{raqam}: не учтён ({holat})")
        continue
    qqs = int(summa) * QQS_STAVKA // 100
    if tur == "sale":
        sotuv_qqs += qqs
    else:
        xarid_qqs += qqs

print(f"НДС с продаж: {sotuv_qqs}")
print(f"НДС по покупкам (к зачёту): {xarid_qqs}")
farq = sotuv_qqs - xarid_qqs
if farq >= 0:
    print(f"НДС к уплате: {farq}")
else:
    print(f"Излишек НДС (на следующий период): {-farq}")
```
```java
import java.util.Scanner;

public class Main {
    static final long QQS_STAVKA = 12;     // в процентах; действующую ставку проверяйте в Налоговом кодексе

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        long sotuvQqs = 0, xaridQqs = 0;
        while (in.hasNext()) {
            String tur = in.next(), raqam = in.next();
            long summa = in.nextLong();
            String holat = in.next();
            if (!holat.equals("accepted")) {                  // учитываются только принятые ЭСФ
                System.out.println(raqam + ": не учтён (" + holat + ")");
                continue;
            }
            long qqs = summa * QQS_STAVKA / 100;
            if (tur.equals("sale")) sotuvQqs += qqs;
            else xaridQqs += qqs;
        }
        System.out.println("НДС с продаж: " + sotuvQqs);
        System.out.println("НДС по покупкам (к зачёту): " + xaridQqs);
        long farq = sotuvQqs - xaridQqs;
        if (farq >= 0) System.out.println("НДС к уплате: " + farq);
        else System.out.println("Излишек НДС (на следующий период): " + (-farq));
    }
}
```

Обратите внимание:

- **ESF-202** (покупка, ожидает) не учтён — поставщик или ваш собственный сотрудник его ещё не принял. Если его примут после сдачи отчёта, 1 140 000 сумов НДС будут зачтены в следующем периоде или через корректирующий отчёт. Проверка ЭСФ в статусе «ожидает» перед отчётом — экономия денег.
- **ESF-103** (продажа, отклонён) — покупатель не согласился: выясните причину и отправьте исправленный ЭСФ; иначе фактические продажи и цифры отчёта разойдутся.
- Этот расчёт — упрощённый вариант автоматической сверки в системе налогового органа.

## Хранение документов и ответственность

- Отчёты, уведомления, ЭСФ и первичные документы хранятся в течение установленного законом срока (электронный архив, резервные копии — M14).
- Подписавший отчёт отвечает за его правильность; передача своей ЭЦП другому — серьёзный риск (MT30).
- За нарушение сроков, занижение и непредставление отчётности установлены штрафы и пени — действующие размеры проверяйте в Налоговом кодексе.

:::warning
**Частые ошибки**

- **Ждать последнего дня.** Ключ ЭЦП может оказаться просроченным, а система — перегруженной.
- **Не проверять ЭСФ в статусах «ожидает» и «отклонён».** Теряется НДС к зачёту или возникает расхождение.
- **Игнорировать предупреждения системы.** Форматные ошибки ведут к отклонению отчёта.
- **Не исправлять вовремя ошибку корректирующим отчётом.** Пеня растёт каждый день.
- **Не сохранять уведомление.** Труднее доказать, что отчёт сдан вовремя.
:::

## Итоги

- Отправка отчёта: ЭЦП → вход → форма → заполнение или импорт → проверка → подпись → отправка → уведомление → хранение.
- При ошибке — корректирующий отчёт; сроки контролируются налоговым календарём.
- ЭСФ: создание, подписание, отправка, принятие или отклонение; покупатель зачитывает НДС только по принятым ЭСФ.
- НДС к уплате = НДС с продаж − НДС по покупкам к зачёту; налоговый орган автоматически сверяет отчёт с ЭСФ и онлайн-кассами.
