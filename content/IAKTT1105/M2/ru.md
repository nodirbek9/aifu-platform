## Почему эта тема важна?

За любым цифровым сервисом — онлайн-кассой, банковским приложением, бухгалтерской программой — стоит **инфраструктура** из оборудования, сетей и программ. Для экономиста это не только технический, но и финансовый вопрос: сколько нужно компьютеров и серверов, выгоднее купить их или арендовать в облаке, какими будут общие затраты за годы? Правильное решение заметно экономит расходы на инфраструктуру.

- рассчитывать совокупную стоимость владения (TCO).

## Состав ИТ-инфраструктуры

| Уровень | Состав |
|---|---|
| **Оборудование** | рабочие компьютеры, ноутбуки, серверы, системы хранения, принтеры, кассовые аппараты, мобильные устройства |
| **Сеть** | кабели, точки Wi-Fi, коммутаторы, маршрутизаторы, канал интернета (M6) |
| **Системные программы** | операционные системы, виртуализация, системы управления базами данных (S3, M7) |
| **Прикладные программы** | офисные пакеты, бухгалтерия, ERP, CRM (M3) |
| **Центр обработки данных** | серверная или внешний ЦОД: электропитание, охлаждение, безопасность |
| **Услуги и люди** | техническая поддержка, администраторы, процессы обновления и резервного копирования |

## Архитектура компьютера

| Устройство | Назначение | Основной показатель |
|---|---|---|
| **Процессор** (CPU) | выполняет команды, вычисляет | число ядер, частота (ГГц) |
| **Оперативная память** (RAM) | временно хранит работающие программы и данные; очищается при отключении питания | объём (ГБ) |
| **Постоянная память** | долго хранит файлы: HDD (дёшево, медленно), SSD (быстро, надёжно) | объём (ТБ), скорость |
| **Устройства ввода** | клавиатура, мышь, сканер, считыватель штрихкодов (S2) | — |
| **Устройства вывода** | монитор, принтер, чековый принтер (S2) | разрешение, скорость |
| **Материнская плата и шина** | соединяют устройства | — |

**Единицы измерения информации**: 1 байт = 8 бит; 1 КБ ≈ 10³ байт, 1 МБ ≈ 10⁶, 1 ГБ ≈ 10⁹, 1 ТБ ≈ 10¹² байт (в двоичных единицах 1 КиБ = 1024 байта). Скорость сети измеряется в **битах** (Мбит/с), объём файла — в **байтах**: канал 100 Мбит/с передаёт примерно 12,5 МБ в секунду.

## Серверы и центры обработки данных

**Сервер** — мощный надёжный компьютер, обслуживающий другие компьютеры (файловый, почтовый, сервер базы данных, веб-сервер). С помощью **виртуализации** на одном физическом сервере может работать несколько виртуальных — это эффективнее использует оборудование.

**Центр обработки данных** — специальное здание или помещение для серверов: бесперебойное питание, охлаждение, пожаротушение, физическая защита. Небольшой компании строить свой ЦОД дорого, поэтому часто выбирают **колокацию** (размещение своего сервера во внешнем ЦОД) или **облако** (M11).

## CAPEX, OPEX и совокупная стоимость владения

| Модель | Вид затрат | Достоинство | Недостаток |
|---|---|---|---|
| **Собственная инфраструктура** (on-premise) | **CAPEX** — крупные капитальные затраты в начале (покупка), затем обслуживание | полный контроль, в долгосрочной перспективе может быть дешевле | большие начальные вложения, нужен персонал, устаревание |
| **Облако** | **OPEX** — ежемесячная плата за использование | быстрый старт, масштабирование по мере нужды, нет начальных вложений | в долгосрочной перспективе может подорожать, зависимость от провайдера |

**Совокупная стоимость владения (TCO)** — все затраты на инфраструктуру за весь срок: покупка, установка, лицензии, электроэнергия, обслуживание, зарплата персонала, ремонт и утилизация. Решение только по цене покупки — распространённая ошибка.

## Разобранный пример: сервер или облако?

Даны цена покупки сервера, годовые затраты на обслуживание, ежемесячная плата за облако и число лет. Выведите накопленные затраты на конец каждого года и найдите первый год, когда собственный сервер станет дешевле облака (год окупаемости).

```python
import sys

xarid, xizmat, bulut_oy, yillar = map(int, sys.stdin.read().split())
server_jami, bulut_jami = xarid, 0              # сервер покупается в начале
qoplanish = 0
for y in range(1, yillar + 1):
    server_jami += xizmat                        # ежегодное обслуживание
    bulut_jami += bulut_oy * 12                  # 12 ежемесячных платежей
    if qoplanish == 0 and server_jami < bulut_jami:
        qoplanish = y
    print(f"год {y}: server {server_jami}, облако {bulut_jami}")
print(f"год окупаемости: {qoplanish}" if qoplanish else "сервер не окупается")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        long xarid = in.nextLong(), xizmat = in.nextLong(), bulutOy = in.nextLong();
        int yillar = in.nextInt();
        long serverJami = xarid, bulutJami = 0;          // сервер покупается в начале
        int qoplanish = 0;
        for (int y = 1; y <= yillar; y++) {
            serverJami += xizmat;                          // ежегодное обслуживание
            bulutJami += bulutOy * 12;                     // 12 ежемесячных платежей
            if (qoplanish == 0 && serverJami < bulutJami) qoplanish = y;
            System.out.println("год " + y + ": server " + serverJami + ", облако " + bulutJami);
        }
        System.out.println(qoplanish > 0 ? "год окупаемости: " + qoplanish : "сервер не окупается");
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    long long xarid, xizmat, bulutOy;
    int yillar;
    cin >> xarid >> xizmat >> bulutOy >> yillar;
    long long serverJami = xarid, bulutJami = 0;          // сервер покупается в начале
    int qoplanish = 0;
    for (int y = 1; y <= yillar; y++) {
        serverJami += xizmat;                              // ежегодное обслуживание
        bulutJami += bulutOy * 12;                         // 12 ежемесячных платежей
        if (qoplanish == 0 && serverJami < bulutJami) qoplanish = y;
        cout << "год " << y << ": server " << serverJami << ", облако " << bulutJami << endl;
    }
    if (qoplanish > 0) cout << "год окупаемости: " << qoplanish << endl;
    else cout << "сервер не окупается" << endl;
    return 0;
}
```

Ввод:

```text
60000000 8000000 3000000 5
```

Вывод:

```text
год 1: server 68000000, облако 36000000
год 2: server 76000000, облако 72000000
год 3: server 84000000, облако 108000000
год 4: server 92000000, облако 144000000
год 5: server 100000000, облако 180000000
год окупаемости: 3
```

Если облако стоит 3 млн сумов в месяц, сервер за 60 млн сумов выгоднее с третьего года. Если облако стоит 1,5 млн сумов в месяц (`60000000 8000000 1500000 5`), сервер за 5 лет не окупается — облако дешевле. В реальном расчёте учитывают также устаревание сервера за 4–5 лет, электроэнергию, зарплату персонала, временную стоимость денег (дисконтирование) и гибкость облака.

:::warning
**Частые ошибки**

- **Сравнивать только цены покупки.** В TCO входят обслуживание, электроэнергия, персонал и устаревание.
- **Путать биты и байты.** 100 Мбит/с — это не 100 мегабайт в секунду, а примерно 12,5 мегабайта.
- **Путать оперативную и постоянную память.** RAM очищается при отключении питания; файлы хранятся на диске.
- **Не планировать резервное копирование и бесперебойное питание.** Остановка инфраструктуры напрямую вредит бизнесу.
:::

:::tip
На своём компьютере посмотрите показатели процессора, памяти и диска в Диспетчере задач → Производительность (Windows); сравните их со своей нагрузкой и сделайте вывод, достаточно ли компьютера для задач или нужно обновление.
:::

## Итоги

- ИТ-инфраструктура: оборудование, сеть, системные и прикладные программы, ЦОД, услуги и люди.
- Компьютер: процессор, оперативная и постоянная память, устройства ввода-вывода.
- Единицы: биты и байты, КБ–ТБ; скорость сети — в битах, объём файла — в байтах.
- Собственная инфраструктура — CAPEX, облако — OPEX; решение принимается на основе TCO.
- TCO учитывает все затраты за весь срок.

## Проверьте себя

:::check
Q: Чем оперативная память отличается от постоянной?
A: Оперативная память хранит данные временно и очищается при отключении питания; постоянная долго хранит файлы.
Q: Сколько примерно мегабайт в секунду передаёт канал 100 Мбит/с?
A: Около 12,5 МБ (100 / 8).
Q: В чём разница между CAPEX и OPEX?
A: CAPEX — начальные капитальные затраты (покупка); OPEX — постоянные операционные затраты (например, ежемесячная плата).
Q: Какие затраты входят в TCO?
A: Покупка, установка, лицензии, электроэнергия, обслуживание, персонал, ремонт и утилизация.
