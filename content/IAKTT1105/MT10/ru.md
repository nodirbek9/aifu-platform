## Понятие и история

**Алгоритм** — точная и понятная последовательность из конечного числа шагов, данная исполнителю для решения поставленной задачи. Исполнителем может быть человек, компьютер, робот или банкомат.

Слово происходит от имени нашего великого соотечественника IX века **Мухаммада ибн Мусы аль-Хорезми**: его трактат о счёте индийскими цифрами был переведён на латынь как «Algoritmi de numero Indorum». А его трактат об «аль-джабр» дал начало слову «алгебра».

## Свойства алгоритма

| Свойство | Смысл | Пример нарушения |
|---|---|---|
| **Дискретность** | алгоритм разбит на отдельные, последовательно выполняемые шаги | «Подготовь отчёт» — одна большая неделимая команда |
| **Определённость** (детерминированность) | каждый шаг однозначен; при одинаковом входе — одинаковый результат | «Немного поднимите цену» — сколько это «немного»? |
| **Результативность** (конечность) | даёт результат за конечное число шагов | цикл без условия остановки |
| **Массовость** | применим к целому классу однотипных задач, к разным входным данным | расчёт, написанный только для одного конкретного клиента |
| **Понятность** | состоит из команд, которые исполнитель может выполнить | компьютеру «Почувствуй настроение клиента» |

## Способы описания

| Способ | Преимущество | Недостаток |
|---|---|---|
| **Словесный** | понятен всем | длинный, склонен к неоднозначности |
| **Блок-схема** (S8, MT11) | видна структура | неудобна для больших алгоритмов |
| **Псевдокод** | краткий, близок к программе, не зависит от языка | нет строгого стандарта |
| **Программа** | выполняет компьютер | нужно знать язык программирования (MT12) |

**Один алгоритм в трёх видах** — проверка остатка товара на складе:

```text
Словесно:   Если остаток меньше минимального запаса, сделай заказ поставщику,
            иначе ничего не делай.

Псевдокод:  ЕСЛИ остаток < мин_запас ТО
                сделать_заказ(мин_запас * 2 - остаток)
            ВСЁ

Программа:  if stock < min_reserve:
                place_order(min_reserve * 2 - stock)
```

## Базовые структуры

Любой алгоритм можно построить из трёх структур (теорема Бёма — Якопини):

- **Линейная** (следование) — шаги один за другим: прочитать данные → вычислить → вывести.
- **Разветвляющаяся** (условие) — разный путь в зависимости от условия (MT13, S8).
- **Циклическая** — шаги повторяются, пока выполняется условие, или заданное число раз (S15).

## Эффективность алгоритма

Одну задачу могут решать разные алгоритмы, но затрачиваемое ими время резко различается. Эффективность оценивается числом шагов относительно размера входа **n**:

| Сложность | Название | n = 1 000 | n = 1 000 000 | Пример |
|---|---|---|---|---|
| **O(1)** | константная | 1 | 1 | получить элемент таблицы по номеру |
| **O(log n)** | логарифмическая | ~10 | ~20 | двоичный поиск в упорядоченном списке |
| **O(n)** | линейная | 1 000 | 1 000 000 | просмотр списка от начала до конца |
| **O(n²)** | квадратичная | 1 000 000 | 10¹² | сравнение каждого клиента с каждым |

Идея **двоичного поиска** — поиск в телефонном справочнике: открываете середину; если нужное имя раньше — переходите к левой половине, если позже — к правой. На каждом шаге область поиска сокращается вдвое. Условие: список должен быть **упорядочен**.

## Разобранный пример: линейный и двоичный поиск

В первой строке — упорядоченный список цен, во второй — искомые цены. Для каждой выведите позицию (или что не найдено) и число сравнений при линейном и двоичном поиске.

```python
import sys

def chiziqli(roy, x):
    qadam = 0
    for i, v in enumerate(roy):
        qadam += 1
        if v == x:
            return i, qadam
    return -1, qadam

def ikkilik(roy, x):
    past, yuqori, qadam = 0, len(roy) - 1, 0
    while past <= yuqori:
        orta = (past + yuqori) // 2
        qadam += 1
        if roy[orta] == x:
            return orta, qadam
        if roy[orta] < x:
            past = orta + 1                 # поиск в правой половине
        else:
            yuqori = orta - 1               # поиск в левой половине
    return -1, qadam

satrlar = sys.stdin.read().strip().split("\n")
narxlar = [int(v) for v in satrlar[0].split()]
for x in [int(v) for v in satrlar[1].split()]:
    joy, a = chiziqli(narxlar, x)
    _, b = ikkilik(narxlar, x)
    natija = f"позиция {joy + 1}" if joy >= 0 else "не найдено"
    print(f"{x}: {natija}, линейный поиск {a}, двоичный поиск {b} (число сравнений)")
```
```java
import java.util.Arrays;
import java.util.Scanner;

public class Main {
    static int[] chiziqli(int[] roy, int x) {
        int qadam = 0;
        for (int i = 0; i < roy.length; i++) {
            qadam++;
            if (roy[i] == x) return new int[]{i, qadam};
        }
        return new int[]{-1, qadam};
    }

    static int[] ikkilik(int[] roy, int x) {
        int past = 0, yuqori = roy.length - 1, qadam = 0;
        while (past <= yuqori) {
            int orta = (past + yuqori) / 2;
            qadam++;
            if (roy[orta] == x) return new int[]{orta, qadam};
            if (roy[orta] < x) past = orta + 1;          // поиск в правой половине
            else yuqori = orta - 1;                      // поиск в левой половине
        }
        return new int[]{-1, qadam};
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int[] narxlar = Arrays.stream(in.nextLine().trim().split("\\s+")).mapToInt(Integer::parseInt).toArray();
        int[] soralgan = Arrays.stream(in.nextLine().trim().split("\\s+")).mapToInt(Integer::parseInt).toArray();
        for (int x : soralgan) {
            int[] a = chiziqli(narxlar, x);
            int[] b = ikkilik(narxlar, x);
            String natija = a[0] >= 0 ? "позиция " + (a[0] + 1) : "не найдено";
            System.out.println(x + ": " + natija + ", линейный поиск " + a[1] + ", двоичный поиск " + b[1] + " (число сравнений)");
        }
    }
}
```

```cpp
#include <iostream>
#include <sstream>
#include <string>
#include <utility>
#include <vector>
using namespace std;

pair<int, int> chiziqli(const vector<int>& roy, int x) {
    int qadam = 0;
    for (int i = 0; i < (int) roy.size(); i++) {
        qadam++;
        if (roy[i] == x) return {i, qadam};
    }
    return {-1, qadam};
}

pair<int, int> ikkilik(const vector<int>& roy, int x) {
    int past = 0, yuqori = roy.size() - 1, qadam = 0;
    while (past <= yuqori) {
        int orta = (past + yuqori) / 2;
        qadam++;
        if (roy[orta] == x) return {orta, qadam};
        if (roy[orta] < x) past = orta + 1;              // поиск в правой половине
        else yuqori = orta - 1;                          // поиск в левой половине
    }
    return {-1, qadam};
}

vector<int> oqi(const string& satr) {
    istringstream ss(satr);
    vector<int> v;
    int x;
    while (ss >> x) v.push_back(x);
    return v;
}

int main() {
    string a, b;
    getline(cin, a);
    getline(cin, b);
    vector<int> narxlar = oqi(a);
    for (int x : oqi(b)) {
        auto c = chiziqli(narxlar, x);
        auto d = ikkilik(narxlar, x);
        string natija = c.first >= 0 ? "позиция " + to_string(c.first + 1) : "не найдено";
        cout << x << ": " << natija << ", линейный поиск " << c.second << ", двоичный поиск " << d.second << " (число сравнений)\n";
    }
    return 0;
}
```

На 15 элементах разница мала, но в базе из 1 000 000 клиентов линейный поиск в худшем случае делает 1 000 000 сравнений, а двоичный — всего ~20. **Индексы** баз данных (MT8) основаны на той же идее: именно поэтому клиента можно найти по ИНН за доли миллисекунды.

:::warning
**Частые ошибки**

- **Неточные шаги** («примерно», «если нужно») — это не алгоритм.
- **Забыть условие остановки.** Цикл работает бесконечно — нарушена результативность.
- **Двоичный поиск в неупорядоченном списке.** Даёт неверный результат.
- **Проверять эффективность только на малых данных.** Алгоритм, быстрый на 100 записях, на миллионе может работать часами.
:::

## Итоги

- Алгоритм — точная конечная последовательность шагов; название — от аль-Хорезми.
- Свойства: дискретность, определённость, результативность, массовость, понятность.
- Описание: словесное, блок-схема, псевдокод, программа; структуры: линейная, разветвляющаяся, циклическая.
- Эффективность: O(1), O(log n), O(n), O(n²); двоичный поиск очень быстр в упорядоченном списке.
