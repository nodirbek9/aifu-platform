## Почему эта тема важна?

Сегодня покупатель выбирает товар в телефоне, платит по QR-коду и на следующий день получает его у двери. Электронная коммерция позволяет даже малому предпринимателю выйти на рынок всей страны и за рубеж. Главные вопросы для экономиста: какая бизнес-модель выгодна, какой рекламный канал окупается, во сколько обходится привлечение клиента?

## Понятия

**Электронный бизнес** — организация бизнес-процессов (закупки, производство, продажи, учёт, связь с партнёрами) с помощью цифровых технологий. **Электронная коммерция** — его часть: продажа и покупка товаров и услуг через интернет вместе с оплатой.

| Модель | Кто кому | Пример |
|---|---|---|
| **B2C** | бизнес → потребитель | интернет-магазин, онлайн-билеты |
| **B2B** | бизнес → бизнес | оптовые торговые платформы, электронные счета-фактуры |
| **C2C** | потребитель → потребитель | сайты объявлений (вроде OLX) |
| **B2G** | бизнес → государство | порталы госзакупок |
| **D2C** | производитель → потребитель | собственный интернет-магазин бренда |

## Бизнес-модели

| Модель | Как зарабатывает | Пример |
|---|---|---|
| **Интернет-магазин** | продажа собственного товара | сайт бренда или магазина |
| **Маркетплейс** | комиссия с продавцов, реклама | Uzum Market, Wildberries, Amazon |
| **Подписка** | ежемесячная или ежегодная плата | стриминговые сервисы, SaaS (M11) |
| **Платформа** (двусторонний рынок) | посредничество между водителем и пассажиром, курьером и рестораном | приложения такси и доставки |
| **Фримиум** | базовая услуга бесплатна, расширенная — платная | офисные и облачные сервисы |
| **Реклама** | за счёт внимания пользователей | социальные сети, поисковые системы |

## Инфраструктура электронной коммерции

- **Сайт и мобильное приложение**: каталог, поиск, корзина, заказ.
- **Оплата**: банковские карты (Uzcard, Humo, Visa), платёжные системы (Click, Payme и др.), QR-оплата, рассрочка (BNPL), наличные при доставке.
- **Логистика**: склады, курьерские службы, пункты выдачи, отслеживание заказа.
- **Обслуживание клиентов**: чат, чат-бот, политика возврата и обмена, отзывы.
- **Аналитика**: CRM (M3), веб-аналитика, A/B-тесты.

## Мобильная коммерция

**Мобильная коммерция** (m-commerce) — покупки и оплата через смартфон. Особенности: всегда под рукой, услуги на основе местоположения, push-уведомления, биометрическое подтверждение, оплата одной кнопкой. В Узбекистане широко распространены: мобильный банкинг, коммунальные и государственные платежи через Click и Payme, QR-оплата в магазинах, приложения маркетплейсов, такси и доставка. **Суперприложение** — платежи, покупки, такси и банковские услуги в одном приложении (азиатский опыт: WeChat, Grab).

## Показатели цифрового маркетинга

| Показатель | Формула | Смысл |
|---|---|---|
| **Конверсия** | заказы / посещения × 100% | какая доля посетителей совершила покупку |
| **Средний чек** (AOV) | выручка / заказы | средняя сумма одного заказа |
| **CAC** (стоимость привлечения клиента) | затраты на рекламу / новые клиенты (заказы) | во сколько обошлось привлечение одного покупателя |
| **ROAS** | выручка / затраты на рекламу | сколько выручки принёс каждый сум рекламы |
| **LTV** (пожизненная ценность клиента) | прибыль от клиента за весь период | если CAC < LTV, привлечение окупается |

## Разобранный пример: сравнение рекламных каналов

Интернет-магазин за месяц рекламировался через три канала. В каждой строке: канал, посещения, заказы, выручка, затраты на рекламу (сумы). Выведите конверсию, средний чек, CAC и ROAS.

```python
import sys

for satr in sys.stdin.read().split("\n"):
    if not satr.strip():
        continue
    kanal, tashrif, buyurtma, tushum, reklama = satr.split()
    tashrif, buyurtma, tushum, reklama = int(tashrif), int(buyurtma), int(tushum), int(reklama)
    konversiya = 100 * buyurtma / tashrif               # в процентах
    chek = tushum // buyurtma                            # средний чек
    cac = reklama // buyurtma                            # стоимость одного покупателя
    roas = tushum / reklama                              # окупаемость рекламы
    print(f"{kanal}: конверсия {konversiya:.2f}%, средний чек {chek}, CAC {cac}, ROAS {roas:.2f}")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        while (in.hasNext()) {
            String kanal = in.next();
            long tashrif = in.nextLong(), buyurtma = in.nextLong(), tushum = in.nextLong(), reklama = in.nextLong();
            double konversiya = 100.0 * buyurtma / tashrif;          // в процентах
            long chek = tushum / buyurtma;                            // средний чек
            long cac = reklama / buyurtma;                            // стоимость одного покупателя
            double roas = (double) tushum / reklama;                  // окупаемость рекламы
            System.out.println(String.format("%s: конверсия %.2f%%, средний чек %d, CAC %d, ROAS %.2f", kanal, konversiya, chek, cac, roas));
        }
    }
}
```
```cpp
#include <cstdio>
#include <iostream>
#include <string>
using namespace std;

int main() {
    string kanal;
    long long tashrif, buyurtma, tushum, reklama;
    while (cin >> kanal >> tashrif >> buyurtma >> tushum >> reklama) {
        double konversiya = 100.0 * buyurtma / tashrif;              // в процентах
        long long chek = tushum / buyurtma;                           // средний чек
        long long cac = reklama / buyurtma;                           // стоимость одного покупателя
        double roas = (double) tushum / reklama;                      // окупаемость рекламы
        printf("%s: конверсия %.2f%%, средний чек %lld, CAC %lld, ROAS %.2f\n", kanal.c_str(), konversiya, chek, cac, roas);
    }
    return 0;
}
```

Ввод:

```text
Instagram 12000 240 36000000 6000000
Telegram 8000 200 26000000 3000000
Google 15000 180 31500000 9000000
```

Вывод:

```text
Instagram: конверсия 2.00%, средний чек 150000, CAC 25000, ROAS 6.00
Telegram: конверсия 2.50%, средний чек 130000, CAC 15000, ROAS 8.67
Google: конверсия 1.20%, средний чек 175000, CAC 50000, ROAS 3.50
```

Google дал больше всего посещений и самый крупный средний чек, но покупатель обошёлся дороже всего (CAC 50 000), а ROAS самый низкий. Telegram — самый эффективный: 8,67 сума выручки на каждый сум рекламы. Но для вывода важна **прибыль**, а не выручка: если маржа товара 20%, канал с ROAS 3,5 (0,7 сума прибыли на сум) убыточен. На основе такого анализа можно перераспределить бюджет.

## Правовые основы и риски

- Закон «Об электронной коммерции», защита прав потребителей, законодательство о персональных данных и налогах (онлайн-кассы, электронный чек).
- Риски: мошеннические интернет-магазины и поддельные страницы оплаты, утечки данных, проблемы с доставкой, зависимость от платформ (рост комиссий).
- Защита: официальные сайты, 3-D Secure, отзывы покупателей, понятная политика возврата, защита данных.

:::warning
**Частые ошибки**

- **Смотреть только на число посещений.** Важны конверсия, CAC и прибыль.
- **Путать выручку с прибылью.** Даже высокий ROAS при низкой марже может означать убыток.
- **Игнорировать мобильный опыт.** Большая часть покупок — с телефона; медленный или неудобный сайт теряет клиентов.
- **Скрывать условия возврата и доставки.** Нарушаются права потребителей и теряется доверие.
:::

:::tip
Приняв маржу 30% для каналов из примера, найдите прибыль каждого канала (выручка × 0,3 − реклама). Бюджет какого канала стоит увеличить, а какого — сократить?
:::

## Итоги

- Электронный бизнес — цифровизация процессов; электронная коммерция — торговля и оплата через интернет.
- Модели: B2C, B2B, C2C, B2G, D2C; бизнес-модели: магазин, маркетплейс, подписка, платформа, фримиум, реклама.
- Инфраструктура: сайт и приложение, оплата, логистика, обслуживание, аналитика; мобильная коммерция — покупки и QR-оплата через смартфон.
- Показатели: конверсия, средний чек, CAC, ROAS, LTV; решения принимаются на основе прибыли.

A: Электронный бизнес — цифровизация всех бизнес-процессов; электронная коммерция — его часть, продажа и покупка через интернет.

A: Затраты на рекламу / число привлечённых клиентов (заказов).

A: Каждый сум, потраченный на рекламу, принёс 3,5 сума выручки.
