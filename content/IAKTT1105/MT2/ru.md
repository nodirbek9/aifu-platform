## Этапы статистического анализа

1. **Постановка вопроса**: «Влияют ли расходы на рекламу на продажи?»
2. **Сбор данных**: бухгалтерия, CRM, опросы, официальная статистика (stat.uz).
3. **Очистка**: пустые значения, дубликаты, ошибочно введённые числа, приведение единиц (млн и тыс. сумов).
4. **Описательный анализ**: среднее, разброс, форма распределения.
5. **Визуализация**: графики и диаграммы (M4, M5).
6. **Взаимосвязи и выводы**: корреляция, регрессия, проверка гипотез; интерпретация результата языком бизнеса.

:::tip
Большая часть времени анализа (часто больше половины) уходит на очистку данных. «Мусор на входе — мусор на выходе»: из грязных данных верных выводов не получить.
:::

## Описательная статистика

| Показатель | Смысл | Функция Excel |
|---|---|---|
| **Среднее** | сумма значений / их количество | `СРЗНАЧ` (`AVERAGE`) |
| **Медиана** | значение в середине упорядоченного ряда; нечувствительна к крайним значениям | `МЕДИАНА` (`MEDIAN`) |
| **Мода** | наиболее частое значение | `МОДА.ОДН` (`MODE.SNGL`) |
| **Стандартное отклонение** | среднее удаление значений от среднего | `СТАНДОТКЛОН.В` (выборка), `СТАНДОТКЛОН.Г` (генеральная совокупность) |
| **Коэффициент вариации** | стандартное отклонение / среднее × 100%; для сравнения рядов разного масштаба | по формуле |
| **Квартили** | значения, делящие ряд на четыре равные части | `КВАРТИЛЬ.ВКЛ` |
| **Мин, макс, размах** | наименьшее, наибольшее значение и их разность | `МИН`, `МАКС` |

**Среднее или медиана?** В неравномерно распределённых данных — зарплаты, цены жилья — несколько очень больших значений «тянут» среднее. Например, если 9 сотрудников получают 5 млн, а руководитель 50 млн сумов, среднее — 9,5 млн, а медиана — 5 млн: типичную зарплату сотрудников лучше показывает медиана.

## Взаимосвязи: корреляция и регрессия

- **Коэффициент корреляции** (r, Excel: `КОРРЕЛ`) от −1 до 1: близко к 1 — сильная прямая связь, близко к −1 — сильная обратная, близко к 0 — линейной связи нет.
- **Линейная регрессия** (Excel: `НАКЛОН`, `ОТРЕЗОК`, `ЛИНЕЙН`, линия тренда на диаграмме): y = a + b·x; например, при дополнительных 1 млн сумов на рекламу продажи в среднем растут на b млн.
- **R²** (коэффициент детерминации) показывает, какую долю изменения y объясняет модель.

:::warning
**Корреляция — не причинность.** Продажи мороженого и случаи утопления растут вместе — причина обоих в жаре. То, что реклама и продажи растут вместе, не доказывает, что реклама увеличила продажи: оба показателя могут зависеть от сезона. Для проверки причинности нужен эксперимент (A/B-тест) или специальные эконометрические методы.
:::

## Инструменты статистического анализа

| Инструмент | Сильная сторона | Кому подходит |
|---|---|---|
| **Excel** + «Пакет анализа» (Данные → Анализ данных) | есть везде; описательная статистика, гистограмма, корреляция, регрессия в несколько кликов | базовый и средний анализ |
| **Google Таблицы** | в облаке, совместная работа | небольшой командный анализ |

| **Python** (pandas, statsmodels, matplotlib) | бесплатный, большие данные, автоматизация, машинное обучение | аналитики, Big Data (M7, S7) |
| **Power BI, Tableau** | интерактивные дашборды, отчёты для руководства | бизнес-аналитика |

## Разобранный пример: продажи и реклама

Продажи компании за 12 месяцев (первая строка) и расходы на рекламу (вторая строка), млн сумов. Вычислите описательные показатели и корреляцию продаж с рекламой. Это взгляд «изнутри» на функции Excel `СРЗНАЧ`, `МЕДИАНА`, `СТАНДОТКЛОН.В` и `КОРРЕЛ`.

```python
import math
import sys

satrlar = sys.stdin.read().strip().split("\n")
sotuv = [float(x) for x in satrlar[0].split()]       # продажи за месяц, млн сумов
reklama = [float(x) for x in satrlar[1].split()]     # расходы на рекламу за месяц
n = len(sotuv)

ortacha = sum(sotuv) / n
tartib = sorted(sotuv)
if n % 2 == 1:
    mediana = tartib[n // 2]
else:
    mediana = (tartib[n // 2 - 1] + tartib[n // 2]) / 2
# выборочное стандартное отклонение (СТАНДОТКЛОН.В в Excel)
sd = math.sqrt(sum((x - ortacha) ** 2 for x in sotuv) / (n - 1))
cv = sd / ortacha * 100

# коэффициент корреляции (КОРРЕЛ в Excel)
ortacha_r = sum(reklama) / n
kov = sum((x - ortacha) * (y - ortacha_r) for x, y in zip(sotuv, reklama))
sx = sum((x - ortacha) ** 2 for x in sotuv)
sy = sum((y - ortacha_r) ** 2 for y in reklama)
r = kov / math.sqrt(sx * sy)

print(f"Месяцев: {n}")
print(f"Среднее: {ortacha:.2f}")
print(f"Медиана: {mediana:.2f}")
print(f"Стандартное отклонение: {sd:.2f}")
print(f"Коэффициент вариации: {cv:.2f}%")
print(f"Минимум: {min(sotuv):.0f}, максимум: {max(sotuv):.0f}")
print(f"Корреляция с рекламой: {r:.2f}")
```
```java
import java.util.Arrays;
import java.util.Scanner;

public class Main {
    static double[] oqi(String satr) {
        return Arrays.stream(satr.trim().split("\\s+")).mapToDouble(Double::parseDouble).toArray();
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        double[] sotuv = oqi(in.nextLine());        // продажи за месяц, млн сумов
        double[] reklama = oqi(in.nextLine());      // расходы на рекламу за месяц
        int n = sotuv.length;

        double ortacha = Arrays.stream(sotuv).sum() / n;
        double[] tartib = sotuv.clone();
        Arrays.sort(tartib);
        double mediana = n % 2 == 1 ? tartib[n / 2] : (tartib[n / 2 - 1] + tartib[n / 2]) / 2;
        // выборочное стандартное отклонение (СТАНДОТКЛОН.В в Excel)
        double sx = 0;
        for (double x : sotuv) sx += (x - ortacha) * (x - ortacha);
        double sd = Math.sqrt(sx / (n - 1));
        double cv = sd / ortacha * 100;

        // коэффициент корреляции (КОРРЕЛ в Excel)
        double ortachaR = Arrays.stream(reklama).sum() / n;
        double kov = 0, sy = 0;
        for (int i = 0; i < n; i++) {
            kov += (sotuv[i] - ortacha) * (reklama[i] - ortachaR);
            sy += (reklama[i] - ortachaR) * (reklama[i] - ortachaR);
        }
        double r = kov / Math.sqrt(sx * sy);

        System.out.println("Месяцев: " + n);
        System.out.println(String.format("Среднее: %.2f", ortacha));
        System.out.println(String.format("Медиана: %.2f", mediana));
        System.out.println(String.format("Стандартное отклонение: %.2f", sd));
        System.out.println(String.format("Коэффициент вариации: %.2f%%", cv));
        System.out.println(String.format("Минимум: %.0f, максимум: %.0f", tartib[0], tartib[n - 1]));
        System.out.println(String.format("Корреляция с рекламой: %.2f", r));
    }
}
```
```cpp
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <iostream>
#include <sstream>
#include <string>
#include <vector>
using namespace std;

vector<double> oqi(const string& satr) {
    istringstream ss(satr);
    vector<double> v;
    double x;
    while (ss >> x) v.push_back(x);
    return v;
}

int main() {
    string a, b;
    getline(cin, a);
    getline(cin, b);
    vector<double> sotuv = oqi(a);          // продажи за месяц, млн сумов
    vector<double> reklama = oqi(b);        // расходы на рекламу за месяц
    int n = sotuv.size();

    double ortacha = 0;
    for (double x : sotuv) ortacha += x;
    ortacha /= n;
    vector<double> tartib = sotuv;
    sort(tartib.begin(), tartib.end());
    double mediana = n % 2 == 1 ? tartib[n / 2] : (tartib[n / 2 - 1] + tartib[n / 2]) / 2;
    // выборочное стандартное отклонение (СТАНДОТКЛОН.В в Excel)
    double sx = 0;
    for (double x : sotuv) sx += (x - ortacha) * (x - ortacha);
    double sd = sqrt(sx / (n - 1));
    double cv = sd / ortacha * 100;

    // коэффициент корреляции (КОРРЕЛ в Excel)
    double ortachaR = 0;
    for (double y : reklama) ortachaR += y;
    ortachaR /= n;
    double kov = 0, sy = 0;
    for (int i = 0; i < n; i++) {
        kov += (sotuv[i] - ortacha) * (reklama[i] - ortachaR);
        sy += (reklama[i] - ortachaR) * (reklama[i] - ortachaR);
    }
    double r = kov / sqrt(sx * sy);

    printf("Месяцев: %d\n", n);
    printf("Среднее: %.2f\n", ortacha);
    printf("Медиана: %.2f\n", mediana);
    printf("Стандартное отклонение: %.2f\n", sd);
    printf("Коэффициент вариации: %.2f%%\n", cv);
    printf("Минимум: %.0f, максимум: %.0f\n", tartib[0], tartib[n - 1]);
    printf("Корреляция с рекламой: %.2f\n", r);
    return 0;
}
```

Продажи в среднем около 50 млн сумов, разброс умеренный (CV ≈ 15%), среднее и медиана близки — распределение примерно симметрично. Корреляция с рекламой очень сильная (0,98), но это ещё не доказывает, что реклама подняла продажи: летом оба показателя высоки. Следующий шаг — эксперимент с изменением рекламы в нескольких регионах.

:::warning
**Частые ошибки**

- **Смотреть только на среднее.** Важны и разброс, и крайние значения; сравнивайте с медианой.
- **Путать СТАНДОТКЛОН.В и СТАНДОТКЛОН.Г.** Для выборки (части) используется СТАНДОТКЛОН.В.
- **Делать выводы о причинности по корреляции.**
- **Анализировать неочищенные данные.** Один ошибочно введённый ноль портит весь результат.
:::

- Анализ: вопрос → сбор → очистка → описание → визуализация → выводы.

Q: Когда медиана лучше среднего?
A: Когда данные распределены неравномерно или есть очень большие крайние значения (например, зарплаты).
Q: Для чего нужен коэффициент вариации?
A: Для сравнения разброса рядов разного масштаба в относительном виде.
Q: Что означает r = −0,9?
A: Сильную обратную линейную связь: когда одно растёт, другое уменьшается.
Q: Какой функцией Excel вычисляется выборочное стандартное отклонение?
A: СТАНДОТКЛОН.В (STDEV.S).
