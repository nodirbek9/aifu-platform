## Почему эта тема важна?

Любой расчёт — зарплата, налог, кредит, скидка, отчёт — это точная последовательность шагов, то есть **алгоритм**. Алгоритмическое мышление позволяет экономисту разбивать сложную задачу на этапы, находить ошибки и автоматизировать повторяющуюся работу (макросы Excel, скрипты Python). Сегодня во многих вакансиях в финансах и аналитике требуется знание Python или SQL.

## Алгоритм и его свойства

**Алгоритм** — точная и конечная последовательность действий для решения поставленной задачи. Слово происходит от имени Мухаммада ибн Мусы аль-Хорезми.

| Свойство | Содержание |
|---|---|
| **Дискретность** | состоит из отдельных шагов |
| **Определённость** | каждый шаг однозначен |
| **Понятность** | исполнитель (человек или компьютер) может его выполнить |
| **Результативность** | даёт результат за конечное число шагов |
| **Массовость** | работает для целого класса однотипных задач (с разными входными данными) |

## Способы описания

- **Словесный**: «Раздели сумму на 12, округли результат…»
- **Блок-схема** (подробно в S8 и MT11): овал — начало/конец, параллелограмм — ввод/вывод, прямоугольник — действие, ромб — условие, стрелки — порядок.
- **Псевдокод**: близок к программе, но записывается свободно.
- **Программа**: точная запись на языке программирования.

## Основные структуры

| Структура | Содержание | Экономический пример |
|---|---|---|
| **Линейная** | действия по порядку, один раз | расчёт цены с НДС |
| **Разветвляющаяся** | разные пути в зависимости от условия | прибыль или убыток; есть ли налоговая льгота |
| **Циклическая** | действия повторяются несколько раз | расчёт за каждый месяц, зарплата всех сотрудников из списка |

**Переменная** — именованная ячейка памяти (`narx` — цена, `miqdor` — количество); **типы данных**: целое, вещественное число, текст, логический; **операции**: арифметические (`+ − * /`), сравнения (`> < =`), логические (И, ИЛИ, НЕ).

## Разобранный пример 1: точка безубыточности

Предприятие несёт ежемесячные постоянные затраты *F* (аренда, зарплата), цена продукции *p*, переменные затраты на единицу *v*. Каждая единица даёт маржу *p − v*; для безубыточности нужно продать не менее ⌈*F* / (*p − v*)⌉ единиц. Если *p ≤ v*, продажи не покрывают убыток. В каждой строке — *F p v*.

```python
import sys

for satr in sys.stdin.read().split("\n"):
    if not satr.strip():
        continue
    doimiy, narx, ozgaruvchan = map(int, satr.split())
    marja = narx - ozgaruvchan                     # сумма, остающаяся с одной единицы
    if marja <= 0:                                  # ветвление: условие
        print("убыток не покрывается: цена слишком низкая")
    else:
        miqdor = (doimiy + marja - 1) // marja      # деление с округлением вверх
        print(f"точка безубыточности: {miqdor} шт., выручка {miqdor * narx}")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        while (in.hasNextLong()) {
            long doimiy = in.nextLong(), narx = in.nextLong(), ozgaruvchan = in.nextLong();
            long marja = narx - ozgaruvchan;                   // сумма, остающаяся с одной единицы
            if (marja <= 0) {                                   // ветвление: условие
                System.out.println("убыток не покрывается: цена слишком низкая");
            } else {
                long miqdor = (doimiy + marja - 1) / marja;     // деление с округлением вверх
                System.out.println("точка безубыточности: " + miqdor + " шт., выручка " + miqdor * narx);
            }
        }
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    long long doimiy, narx, ozgaruvchan;
    while (cin >> doimiy >> narx >> ozgaruvchan) {
        long long marja = narx - ozgaruvchan;                  // сумма, остающаяся с одной единицы
        if (marja <= 0) {                                       // ветвление: условие
            cout << "убыток не покрывается: цена слишком низкая" << endl;
        } else {
            long long miqdor = (doimiy + marja - 1) / marja;    // деление с округлением вверх
            cout << "точка безубыточности: " << miqdor << " шт., выручка " << miqdor * narx << endl;
        }
    }
    return 0;
}
```

Ввод:

```text
12000000 50000 30000
5000000 15000 15000
9100000 40000 25000
```

Вывод:

```text
точка безубыточности: 600 шт., выручка 30000000
убыток не покрывается: цена слишком низкая
точка безубыточности: 607 шт., выручка 24280000
```

В третьем случае 9 100 000 / 15 000 = 606,67 — 606 единиц не хватает, поэтому округляем **вверх**: формула (*F* + *m* − 1) div *m* даёт именно это в целых числах. Во втором случае цена равна переменным затратам — сколько ни продавай, постоянные затраты не покрываются.

## Разобранный пример 2: анализ месячных продаж

Первое число — количество месяцев *n*, затем *n* месячных продаж (млн сумов). Выведите итог, среднее, лучший месяц и число месяцев выше среднего.

```python
import sys

t = list(map(int, sys.stdin.read().split()))
n, savdo = t[0], t[1:]
jami, eng = 0, 0
for i in range(n):                               # цикл: каждый месяц
    jami += savdo[i]
    if savdo[i] > savdo[eng]:
        eng = i
ortacha = jami / n
yuqori = 0
for x in savdo:                                  # второй цикл: сравнение со средним
    if x > ortacha:
        yuqori += 1
print(f"итого: {jami}")
print(f"среднее: {ortacha:.1f}")
print(f"лучший месяц: {eng + 1} ({savdo[eng]})")
print(f"месяцев выше среднего: {yuqori}")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] savdo = new int[n];
        for (int i = 0; i < n; i++) savdo[i] = in.nextInt();
        long jami = 0;
        int eng = 0;
        for (int i = 0; i < n; i++) {                    // цикл: каждый месяц
            jami += savdo[i];
            if (savdo[i] > savdo[eng]) eng = i;
        }
        double ortacha = (double) jami / n;
        int yuqori = 0;
        for (int x : savdo) {                             // второй цикл: сравнение со средним
            if (x > ortacha) yuqori++;
        }
        System.out.println("итого: " + jami);
        System.out.println(String.format("среднее: %.1f", ortacha));
        System.out.println("лучший месяц: " + (eng + 1) + " (" + savdo[eng] + ")");
        System.out.println("месяцев выше среднего: " + yuqori);
    }
}
```
```cpp
#include <cstdio>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> savdo(n);
    for (int i = 0; i < n; i++) cin >> savdo[i];
    long long jami = 0;
    int eng = 0;
    for (int i = 0; i < n; i++) {                        // цикл: каждый месяц
        jami += savdo[i];
        if (savdo[i] > savdo[eng]) eng = i;
    }
    double ortacha = (double) jami / n;
    int yuqori = 0;
    for (int x : savdo) {                                // второй цикл: сравнение со средним
        if (x > ortacha) yuqori++;
    }
    printf("итого: %lld\n", jami);
    printf("среднее: %.1f\n", ortacha);
    printf("лучший месяц: %d (%d)\n", eng + 1, savdo[eng]);
    printf("месяцев выше среднего: %d\n", yuqori);
    return 0;
}
```

Ввод:

```text
6 120 135 98 160 142 110
```

Вывод:

```text
итого: 765
среднее: 127.5
лучший месяц: 4 (160)
месяцев выше среднего: 3
```

Нужны два цикла: чтобы знать среднее, сначала нужно всё просуммировать, а затем сравнить с ним каждый месяц. В Excel тот же результат дают `SUM`, `AVERAGE`, `MAX`, `MATCH` и `COUNTIF` (M4), а программа автоматически повторяет тот же анализ для тысяч файлов и отчётов.

:::warning
**Частые ошибки**

- **Неверное направление округления.** Для безубыточности количество округляется вверх, скидка обычно вниз — читайте условие задачи.
- **Не проверять граничные случаи.** Проверяйте ноль, отрицательные, очень большие значения и случай «ровно равно».
- **Смешивать целые и вещественные числа.** В некоторых языках `7 / 2 = 3` (целочисленное деление).
- **Вещественные числа для денег.** Чтобы избежать ошибок округления, храните деньги целым числом в тийинах или сумах.
- **Писать сложную программу без блок-схемы.** Сначала нарисуйте алгоритм, потом кодируйте.
:::
