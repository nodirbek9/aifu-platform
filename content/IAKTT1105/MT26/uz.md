## Mustaqil ishning maqsadi

M13 da elektron biznes turlari (B2C, B2B, C2C, B2G, D2C) va asosiy biznes modellari bilan tanishdik. Bu mustaqil ishda biznes modelini **tizimli tasvirlash** (kanvas) va uning **iqtisodiy hayotiyligini** birlik iqtisodiyoti orqali tekshirishni oʻrganamiz.

:::note
**Bu mustaqil ishdan soʻng siz:**

- elektron biznes uchun biznes modeli kanvasini toʻldira olasiz;
- daromad modellarini farqlay olasiz;
- zamonaviy elektron tijorat shakllarini ayta olasiz;
- LTV, CAC va qoplash muddatini hisoblab, modelning sogʻlomligini baholay olasiz.
:::

## Biznes modeli kanvasi

Aleksandr Ostervalderning **biznes modeli kanvasi** biznesni toʻqqiz blokda bir varaqda tasvirlaydi. Misol — kitoblarni onlayn sotuvchi kichik doʻkon:

| Blok | Savol | Misol |
|---|---|---|
| **Mijoz segmentlari** | kimga xizmat qilamiz? | talabalar, oʻqituvchilar, kitobxonlar |
| **Qiymat taklifi** | qanday muammoni hal qilamiz? | kerakli kitobni tez topish va ertasi kuni yetkazish |
| **Kanallar** | mijozga qanday yetamiz? | sayt, Telegram-bot, marketpleys |
| **Mijozlar bilan munosabat** | qanday aloqa qilamiz? | shaxsiy tavsiyalar, sodiqlik ballari |
| **Daromad oqimlari** | nimadan pul topamiz? | kitob sotuvi marjasi, obuna (oyiga 1 ta kitob) |
| **Asosiy resurslar** | nima kerak? | katalog, ombor, mijozlar bazasi |
| **Asosiy faoliyat** | nima qilamiz? | xarid, marketing, yetkazib berish |
| **Asosiy hamkorlar** | kim bilan ishlaymiz? | nashriyotlar, kuryerlik xizmati, toʻlov tizimlari |
| **Xarajatlar tuzilishi** | nimaga pul sarflaymiz? | kitoblar, reklama, ish haqi, logistika |

## Zamonaviy elektron tijorat shakllari

- **D2C** (toʻgʻridan-toʻgʻri isteʼmolchiga) — ishlab chiqaruvchi vositachilarsiz oʻz sayti orqali sotadi: yuqori marja va mijoz maʼlumotlari, lekin marketing xarajati oʻziga.
- **Dropshipping** — sotuvchida ombor yoʻq; buyurtma yetkazib beruvchiga uzatiladi va u toʻgʻridan-toʻgʻri mijozga joʻnatadi: kirish arzon, lekin marja past va sifat nazorati qiyin.
- **Ijtimoiy tijorat** — Instagram, Telegram, TikTok orqali savdo; **jonli efir savdosi** (live commerce) — efir davomida tovar koʻrsatiladi va darhol buyurtma qilinadi.
- **Obuna qutilari** — har oy tanlangan tovarlar toʻplami (kosmetika, kofe, kitoblar).
- **Omnikanal** — onlayn va oflayn kanallar bitta tizim: saytda buyurtma, doʻkondan olish, istalgan joyda qaytarish.

## Birlik iqtisodiyoti

Biznes modeli **bitta mijoz darajasida** foydali boʻlishi kerak — aks holda oʻsish faqat zararni oshiradi.

| Koʻrsatkich | Formula | Maʼnosi |
|---|---|---|
| **ARPU** | tushum / mijozlar soni (oyiga) | bitta mijozdan oʻrtacha oylik tushum |
| **Marja** | (tushum − oʻzgaruvchan xarajat) / tushum | tushumning qancha qismi foyda sifatida qoladi |
| **Churn** (yoʻqotish darajasi) | oy davomida ketgan mijozlar / oy boshidagi mijozlar | mijozlar qanchalik tez ketadi |
| **Mijoz "umri"** | 1 / churn | mijoz oʻrtacha necha oy qoladi |
| **LTV** | ARPU × marja × umr | mijozning butun davr davomidagi foydasi (M13) |
| **CAC** | marketing xarajati / yangi mijozlar | bitta mijozni jalb qilish narxi |
| **Qoplash muddati** | CAC / (ARPU × marja) | CAC necha oyda qaytadi |

**Amaliy qoida**: LTV/CAC ≥ 3 — sogʻlom model; 1 dan 3 gacha — ehtiyot boʻlish kerak; 1 dan kam — har bir yangi mijoz zarar keltiradi.

## Ishlangan misol: modellarni solishtirish

Har bir satrda: model, oylik ARPU (soʻm), marja (%), oylik churn (%), CAC (soʻm). LTV, LTV/CAC, qoplash muddatini (oy, yuqoriga yaxlitlab) va holatni chiqaring.

```python
import sys

for satr in sys.stdin.read().split("\n"):
    if not satr.strip():
        continue
    nom, arpu, marja, churn, cac = satr.split()
    arpu, marja, churn, cac = int(arpu), int(marja), int(churn), int(cac)
    oylik_foyda = arpu * marja // 100                  # bir mijozdan oylik foyda
    ltv = oylik_foyda * 100 // churn                   # umr = 1 / churn
    nisbat = ltv / cac
    qoplash = (cac + oylik_foyda - 1) // oylik_foyda   # yuqoriga yaxlitlash
    if nisbat >= 3:
        holat = "sogʻlom"
    elif nisbat >= 1:
        holat = "ehtiyot"
    else:
        holat = "zarar"
    print(f"{nom}: LTV {ltv}, CAC {cac}, LTV/CAC {nisbat:.1f}, qoplash {qoplash} oy, {holat}")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        while (in.hasNext()) {
            String nom = in.next();
            long arpu = in.nextLong(), marja = in.nextLong(), churn = in.nextLong(), cac = in.nextLong();
            long oylikFoyda = arpu * marja / 100;                  // bir mijozdan oylik foyda
            long ltv = oylikFoyda * 100 / churn;                   // umr = 1 / churn
            double nisbat = (double) ltv / cac;
            long qoplash = (cac + oylikFoyda - 1) / oylikFoyda;    // yuqoriga yaxlitlash
            String holat = nisbat >= 3 ? "sogʻlom" : nisbat >= 1 ? "ehtiyot" : "zarar";
            System.out.println(String.format("%s: LTV %d, CAC %d, LTV/CAC %.1f, qoplash %d oy, %s", nom, ltv, cac, nisbat, qoplash, holat));
        }
    }
}
```

Obuna modeli yuqori marja va past churn tufayli eng sogʻlom: mijoz oʻrtacha 20 oy qoladi. Marketpleysda marja past (15%) — mijozni jalb qilish narxini kamaytirish yoki xarid chastotasini oshirish kerak. Reklama modelida mijozlar tez ketadi (oyiga 25%) va LTV CAC dan kam — har bir yangi foydalanuvchi zarar. Yechim: churn ni kamaytirish (sifat, sodiqlik dasturi) yoki arzonroq kanallar.

:::warning
**Koʻp uchraydigan xatolar**

- **Tushumni foyda bilan adashtirish.** LTV marja bilan hisoblanadi, tushum bilan emas.
- **Churn ni eʼtiborsiz qoldirish.** Oylik 10% churn — mijoz oʻrtacha atigi 10 oy qoladi.
- **"Oʻsish hammasini hal qiladi" deb oʻylash.** LTV/CAC < 1 boʻlsa, oʻsish zararni koʻpaytiradi.
- **Bitta kanal yoki platformaga qaramlik.** Marketpleys komissiyasi yoki reklama narxi oshsa, model buziladi.
:::

## Topshiriq

1. Oʻzingiz tanlagan elektron biznes (mavjud kompaniya yoki oʻz gʻoyangiz) uchun biznes modeli kanvasini toʻldiring.
2. Uning daromad modelini va qoʻllanayotgan elektron tijorat shakllarini yozing.
3. Taxminiy ARPU, marja, churn va CAC qiymatlarini asoslab, misol dasturi bilan birlik iqtisodiyotini hisoblang.
4. LTV/CAC ni 3 dan oshirish uchun 3 ta chora taklif qiling va har birining taʼsirini dasturda tekshiring.
