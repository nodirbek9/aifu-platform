## Канва бизнес-модели

**Канва бизнес-модели** Александра Остервальдера описывает бизнес на одном листе в девяти блоках. Пример — небольшой магазин, продающий книги онлайн:

| Блок | Вопрос | Пример |
|---|---|---|
| **Сегменты клиентов** | кого мы обслуживаем? | студенты, преподаватели, читатели |
| **Ценностное предложение** | какую проблему решаем? | быстро найти нужную книгу и доставить на следующий день |
| **Каналы** | как доходим до клиента? | сайт, Telegram-бот, маркетплейс |
| **Отношения с клиентами** | как поддерживаем связь? | персональные рекомендации, баллы лояльности |
| **Потоки доходов** | на чём зарабатываем? | наценка на продажу книг, подписка (1 книга в месяц) |
| **Ключевые ресурсы** | что нужно? | каталог, склад, клиентская база |
| **Ключевая деятельность** | что делаем? | закупка, маркетинг, доставка |
| **Ключевые партнёры** | с кем работаем? | издательства, курьерская служба, платёжные системы |
| **Структура затрат** | на что тратим? | книги, реклама, зарплата, логистика |

## Модели дохода

| Модель | Содержание | Пример |
|---|---|---|
| **Торговая наценка** | разница цен покупки и продажи | интернет-магазин |
| **Комиссия** | доля с каждой продажи | маркетплейс, приложение такси |
| **Подписка** | регулярные платежи | SaaS, онлайн-кинотеатр, подписочные боксы |
| **Реклама** | продажа внимания аудитории | соцсети, новостные сайты |
| **Плата за транзакцию** | за платёж или перевод | платёжные системы |
| **Партнёрская (affiliate)** | доля за привод клиента к другому продавцу | сайты обзоров, блогеры |
| **Лицензия** | за право использования | программы, контент |
| **Freemium** | бесплатная основа + платные дополнения | MT25 |

## Современные формы электронной коммерции

- **D2C** (напрямую потребителю) — производитель продаёт через свой сайт без посредников: высокая маржа и данные о клиентах, но маркетинговые расходы на нём.
- **Дропшиппинг** — у продавца нет склада; заказ передаётся поставщику, который отправляет его прямо клиенту: вход дешёвый, но маржа низкая, контроль качества сложен.
- **Социальная коммерция** — продажи через Instagram, Telegram, TikTok; **продажи в прямом эфире** (live commerce) — товар показывают в эфире и сразу заказывают.
- **Подписочные боксы** — ежемесячный набор отобранных товаров (косметика, кофе, книги).
- **Омниканальность** — онлайн- и офлайн-каналы как одна система: заказ на сайте, получение в магазине, возврат где угодно.

## Юнит-экономика

Бизнес-модель должна быть прибыльной **на уровне одного клиента** — иначе рост лишь увеличивает убытки.

| Показатель | Формула | Смысл |
|---|---|---|
| **ARPU** | выручка / число клиентов (в месяц) | средняя месячная выручка с клиента |
| **Маржа** | (выручка − переменные затраты) / выручка | какая доля выручки остаётся прибылью |
| **Churn** (отток) | ушедшие за месяц / клиенты на начало месяца | как быстро уходят клиенты |
| **«Срок жизни» клиента** | 1 / churn | сколько месяцев в среднем остаётся клиент |
| **LTV** | ARPU × маржа × срок жизни | прибыль от клиента за весь период (M13) |
| **CAC** | маркетинговые затраты / новые клиенты | стоимость привлечения одного клиента |
| **Срок окупаемости** | CAC / (ARPU × маржа) | за сколько месяцев возвращается CAC |

**Практическое правило**: LTV/CAC ≥ 3 — здоровая модель; от 1 до 3 — нужна осторожность; меньше 1 — каждый новый клиент приносит убыток.

## Разобранный пример: сравнение моделей

В каждой строке: модель, месячный ARPU (сум), маржа (%), месячный отток (%), CAC (сум). Выведите LTV, LTV/CAC, срок окупаемости (месяцев, с округлением вверх) и состояние.

```python
import sys

for satr in sys.stdin.read().split("\n"):
    if not satr.strip():
        continue
    nom, arpu, marja, churn, cac = satr.split()
    arpu, marja, churn, cac = int(arpu), int(marja), int(churn), int(cac)
    oylik_foyda = arpu * marja // 100                  # месячная прибыль с одного клиента
    ltv = oylik_foyda * 100 // churn                   # срок жизни = 1 / churn
    nisbat = ltv / cac
    qoplash = (cac + oylik_foyda - 1) // oylik_foyda   # округление вверх
    if nisbat >= 3:
        holat = "здоровая"
    elif nisbat >= 1:
        holat = "осторожно"
    else:
        holat = "убыточная"
    print(f"{nom}: LTV {ltv}, CAC {cac}, LTV/CAC {nisbat:.1f}, окупаемость {qoplash} мес., {holat}")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        while (in.hasNext()) {
            String nom = in.next();
            long arpu = in.nextLong(), marja = in.nextLong(), churn = in.nextLong(), cac = in.nextLong();
            long oylikFoyda = arpu * marja / 100;                  // месячная прибыль с одного клиента
            long ltv = oylikFoyda * 100 / churn;                   // срок жизни = 1 / churn
            double nisbat = (double) ltv / cac;
            long qoplash = (cac + oylikFoyda - 1) / oylikFoyda;    // округление вверх
            String holat = nisbat >= 3 ? "здоровая" : nisbat >= 1 ? "осторожно" : "убыточная";
            System.out.println(String.format("%s: LTV %d, CAC %d, LTV/CAC %.1f, окупаемость %d мес., %s", nom, ltv, cac, nisbat, qoplash, holat));
        }
    }
}
```
```cpp
#include <cstdio>
#include <iostream>
#include <string>
using namespace std;

int main() {
    string nom;
    long long arpu, marja, churn, cac;
    while (cin >> nom >> arpu >> marja >> churn >> cac) {
        long long oylikFoyda = arpu * marja / 100;                 // месячная прибыль с одного клиента
        long long ltv = oylikFoyda * 100 / churn;                  // срок жизни = 1 / churn
        double nisbat = (double) ltv / cac;
        long long qoplash = (cac + oylikFoyda - 1) / oylikFoyda;   // округление вверх
        string holat = nisbat >= 3 ? "здоровая" : nisbat >= 1 ? "осторожно" : "убыточная";
        printf("%s: LTV %lld, CAC %lld, LTV/CAC %.1f, окупаемость %lld мес., %s\n", nom.c_str(), ltv, cac, nisbat, qoplash, holat.c_str());
    }
    return 0;
}
```

Ввод:

```text

marketplace 20000 15 10 25000

```

Вывод:

```text
subscription: LTV 700000, CAC 140000, LTV/CAC 5.0, окупаемость 4 мес., здоровая
marketplace: LTV 30000, CAC 25000, LTV/CAC 1.2, окупаемость 9 мес., осторожно
shop: LTV 300000, CAC 150000, LTV/CAC 2.0, окупаемость 7 мес., осторожно
ads: LTV 16000, CAC 20000, LTV/CAC 0.8, окупаемость 5 мес., убыточная
```

Модель подписки самая здоровая благодаря высокой марже и низкому оттоку: клиент в среднем остаётся 20 месяцев. У маркетплейса маржа низкая (15%) — нужно снижать стоимость привлечения или повышать частоту покупок. В рекламной модели клиенты быстро уходят (25% в месяц), и LTV меньше CAC — каждый новый пользователь убыточен. Решение: снизить отток (качество, программа лояльности) или использовать более дешёвые каналы.

:::warning
**Частые ошибки**

- **Путать выручку и прибыль.** LTV считается с маржой, а не с выручкой.
- **Игнорировать отток.** Ежемесячный отток 10% — клиент в среднем остаётся всего 10 месяцев.
- **Думать, что «рост всё решит».** При LTV/CAC < 1 рост умножает убытки.
- **Зависимость от одного канала или платформы.** Если вырастут комиссия маркетплейса или цены рекламы, модель сломается.
:::
