## Понятие и поколения

**Язык программирования** — искусственный язык со строгими правилами (синтаксис и семантика) для записи указаний, выполняемых компьютером.

| Поколение | Описание | Пример |
|---|---|---|
| **1GL** | машинный код — нули и единицы | `10110000 01100001` |
| **2GL** | ассемблер — краткие имена машинных команд | `MOV AL, 61h` |
| **3GL** | высокоуровневые, близкие к человеческому языку | C, Java, Python |
| **4GL** | описание результата («что нужно», а не «как») | SQL, часть R, генераторы отчётов |
| **Low-code / no-code** | визуальные конструкторы, минимум кода | Power Apps, Zapier, Bubble |

## Как выполняется программа

| Способ | Как работает | Преимущество | Пример |
|---|---|---|---|
| **Компиляция** | вся программа заранее переводится в машинный код | быстро работает, ошибки находятся заранее | C, C++, Go |
| **Интерпретация** | программа выполняется построчно | быстрая проверка, гибкость | Python, R, JavaScript (традиционно) |
| **Байт-код + JIT** | компиляция в промежуточный код, ускорение при выполнении | независимость от платформы, хорошая скорость | Java, C# |

## Парадигмы

| Парадигма | Идея | Пример |
|---|---|---|
| **Процедурная** | программа — последовательность команд и функций | `calculate_tax(amount)` |
| **Объектно-ориентированная (ООП)** | данные и операции объединяются в объекты | `account.deposit(500)` — объект «Счёт» |
| **Функциональная** | результат — композиция функций, состояние не меняется | `sum(map(tax, amounts))` |
| **Декларативная** | пишется «что» нужно, а не «как» | `SELECT SUM(amount) FROM sales` |

Современные языки часто поддерживают несколько парадигм (Python — процедурную, ООП и функциональную).

**Типизация**: **статическая** (Java, C++) — тип переменной объявляется заранее, ошибки находятся при компиляции; **динамическая** (Python, R) — тип определяется при выполнении, писать быстрее, но некоторые ошибки проявляются только при работе.

## Языки для экономиста

| Язык | Где | Чем полезен |
|---|---|---|
| **Python** | анализ, автоматизация, машинное обучение | простой синтаксис, pandas, большое сообщество (MT2, MT9) |
| **R** | статистика, эконометрика, научные исследования | статистические пакеты, качественные графики |
| **SQL** | базы данных (M7, MT8) | есть почти в каждой компании; главный инструмент аналитика |
| **VBA** | автоматизация Excel и Office | макросы, повторяющиеся отчёты |
| **Java, C#** | банковские и корпоративные системы (M15) | надёжность, крупные проекты |
| **C++** | высокочастотная торговля, вычислительные ядра | максимальная скорость |
| **JavaScript** | сайты, дашборды, скрипты Google Таблиц | работает в браузере |
| **Язык 1С** | конфигурации 1С:Бухгалтерия и 1С:ERP | учётные системы в СНГ и Узбекистане |

:::tip
Эффективный путь для экономиста: **Excel → SQL → Python (или R)**. SQL даёт получение данных, Python — анализ и автоматизацию.
:::

## Деньги и вещественные числа

Компьютер хранит числа `double` (`float`) в двоичной системе. Простая десятичная дробь вроде 0,1 в двоичной системе становится бесконечной и хранится приближённо. В результате в денежных расчётах накапливаются мелкие ошибки — для бухгалтерии это недопустимо. Правильное решение: хранить деньги как **целое число в наименьших единицах** (тийины, центы) или в специальном десятичном типе (`Decimal`, `BigDecimal`).

**Разобранный пример**: в первой строке — суммы (сумы, с двумя знаками тийинов), во второй — ожидаемый итог. Посчитайте сумму в `double` и целым числом в тийинах и проверьте равенство ожидаемому значению.

```python
import sys

def tiyin(matn):
    som, tiyinlar = matn.split(".")
    return int(som) * 100 + int(tiyinlar)

satrlar = sys.stdin.read().strip().split("\n")
summalar = satrlar[0].split()
kutilgan = satrlar[1].strip()

haqiqiy = 0.0
for s in summalar:
    haqiqiy += float(s)                    # сложение в double
butun = sum(tiyin(s) for s in summalar)    # целое число в тийинах

print(f"double: сумма == {kutilgan} -> {'да' if haqiqiy == float(kutilgan) else 'нет'}")
print(f"тийины (целое): сумма == {tiyin(kutilgan)} -> {'да' if butun == tiyin(kutilgan) else 'нет'}")
```
```java
import java.util.Scanner;

public class Main {
    static long tiyin(String matn) {
        String[] q = matn.split("\\.");
        return Long.parseLong(q[0]) * 100 + Long.parseLong(q[1]);
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String[] summalar = in.nextLine().trim().split("\\s+");
        String kutilgan = in.nextLine().trim();

        double haqiqiy = 0.0;
        long butun = 0;
        for (String s : summalar) {
            haqiqiy += Double.parseDouble(s);      // сложение в double
            butun += tiyin(s);                     // целое число в тийинах
        }
        System.out.println("double: сумма == " + kutilgan + " -> " + (haqiqiy == Double.parseDouble(kutilgan) ? "да" : "нет"));
        System.out.println("тийины (целое): сумма == " + tiyin(kutilgan) + " -> " + (butun == tiyin(kutilgan) ? "да" : "нет"));
    }
}
```
```cpp
#include <iostream>
#include <sstream>
#include <string>
using namespace std;

long long tiyin(const string& matn) {
    size_t nuqta = matn.find('.');
    return stoll(matn.substr(0, nuqta)) * 100 + stoll(matn.substr(nuqta + 1));
}

int main() {
    string satr, kutilgan, s;
    getline(cin, satr);
    getline(cin, kutilgan);
    kutilgan = kutilgan.substr(0, kutilgan.find_last_not_of(" \r") + 1);

    double haqiqiy = 0.0;
    long long butun = 0;
    istringstream ss(satr);
    while (ss >> s) {
        haqiqiy += stod(s);                        // сложение в double
        butun += tiyin(s);                         // целое число в тийинах
    }
    cout << "double: сумма == " << kutilgan << " -> " << (haqiqiy == stod(kutilgan) ? "да" : "нет") << "\n";
    cout << "тийины (целое): сумма == " << tiyin(kutilgan) << " -> " << (butun == tiyin(kutilgan) ? "да" : "нет") << "\n";
    return 0;
}
```

Ввод:

```text
0.10 0.10 0.10 0.10 0.10 0.10 0.10 0.10 0.10 0.10
1.00
```

Вывод:

```text
double: сумма == 1.00 -> нет
тийины (целое): сумма == 100 -> да
```

Сумма десяти сумм по 10 тийинов в `double` равна 0,9999999999999999 и не равна 1,00! Во всех трёх языках результат одинаков — это не ошибка языка, а природа двоичных чисел. На миллионе транзакций такие разницы приводят к расхождениям в отчётах. Поэтому банковские и бухгалтерские системы хранят деньги в тийинах или в типе `Decimal`, а в Excel используется функция `ОКРУГЛ`.

## Среды разработки и помощники

- **IDE** (интегрированная среда разработки): Visual Studio Code, PyCharm, IntelliJ IDEA, RStudio — редактирование кода, поиск ошибок (отладчик), автодополнение.
- **Ноутбуки**: Jupyter, Google Colab — код, результаты и пояснения в одном документе; удобно для анализа.
- **Контроль версий**: Git и GitHub — история изменений, командная работа.
- **Помощники с искусственным интеллектом** (GitHub Copilot и др.) ускоряют написание кода, но понимать и проверять результат — задача программиста (вспомните академическую честность в MT1).

:::warning
**Частые ошибки**

- **Искать «лучший язык».** Язык выбирается под задачу.
- **Хранить деньги во `float`/`double`.** Используйте целые числа в тийинах или `Decimal`.
- **Копировать код, не понимая его.** Вместе с ним приходят ошибки и проблемы безопасности.
- **Пытаться учить много языков одновременно.** Сначала глубоко изучите один — следующие дадутся легче.
:::

## Итоги

- Поколения языков: машинный код → ассемблер → высокоуровневые → языки запросов → low-code.
- Выполнение: компиляция, интерпретация, байт-код и JIT; типизация статическая или динамическая.
- Парадигмы: процедурная, ООП, функциональная, декларативная.
- Для экономиста: SQL, Python или R, VBA; в корпоративных системах — Java, C#, 1С.
- Хранение денег в вещественных числах ведёт к ошибкам — целые числа в тийинах или Decimal.
