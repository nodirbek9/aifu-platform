## Цель самостоятельной работы

В M9 информационные системы классифицировались по уровням управления (TPS, MIS, DSS, EIS) и функциональным областям. Но одну систему можно описать и по многим другим признакам. В этой самостоятельной работе построим полную схему классификации — она нужна при выборе, сравнении и документировании систем.

:::note
**После этой самостоятельной работы вы сможете:**

- классифицировать информационные системы минимум по восьми признакам;
- приводить пример из Узбекистана и мира для каждого класса;
- составлять полный классификационный «паспорт» реальной системы.
:::

## По степени автоматизации

| Вид | Содержание | Пример |
|---|---|---|
| **Ручные** | все операции выполняет человек, без компьютера | бумажный журнал, картотека |
| **Автоматизированные** | человек и компьютер вместе; решение остаётся за человеком | бухгалтерская программа, CRM — большинство систем в экономике |
| **Автоматические** | без участия человека | автоматические платёжные переводы, управление производственной линией, алгоритмическая торговля на бирже |

## По характеру обработки

| Вид | Содержание | Пример |
|---|---|---|
| **Информационно-поисковые** | поиск и выдача информации, без расчётов | Lex.uz, библиотечный каталог, справочные системы |
| **Информационно-решающие: управляющие** | выполняют расчёты и выдают результаты для управленческих решений | зарплата, склад, планирование |
| **Информационно-решающие: советующие** | предлагают варианты и рекомендации, решение принимает человек | поддержка принятия решений (DSS), экспертные системы, скоринг |

## По уровню управления и функциональной области

Это подробно рассмотрено в M9: **операционные** (TPS), **управленческие** (MIS), **поддержки принятия решений** (DSS), **для руководства** (EIS); функциональные — **бухгалтерия**, **кадры**, **маркетинг**, **производство**, **финансы**; корпоративные — **ERP**, **CRM**, **SCM**.

## По сфере применения

| Сфера | Системы |
|---|---|
| **Банковская** | АБС банка, карточный процессинг, интернет-банкинг (S13, M15) |
| **Налоговая** | личный кабинет налогоплательщика, ЭСФ, онлайн-кассы (S15) |
| **Статистическая** | системы сбора и обработки статистической отчётности |
| **Бухгалтерская** | 1С, зарубежные аналоги (M15) |
| **Государственное управление** | единый портал интерактивных госуслуг, межведомственные системы (M10) |
| **Геоинформационные (ГИС)** | данные на основе карт: земельный кадастр, логистические маршруты, анализ торговых точек |
| **Медицинские** | электронные медкарты, больничные системы |
| **Образовательные** | LMS, учёт контингента студентов |
| **Правовые** | базы законодательства, системы судебных документов |

## По масштабу

| Вид | Пользователи | Пример |
|---|---|---|
| **Персональные (однопользовательские)** | один пользователь | приложение домашнего бюджета, личная модель в Excel |
| **Групповые** | отдел или небольшая команда (десятки человек) | документы отдела, управление проектами |
| **Корпоративные** | вся организация, с филиалами | ERP, АБС банка |
| **Межотраслевые / государственные** | много организаций и граждан | налоговая система, портал госуслуг |
| **Глобальные** | по всему миру | SWIFT, международные системы бронирования |

## По архитектуре

| Вид | Содержание | Особенность |
|---|---|---|
| **Локальные (на одном компьютере)** | программа и данные на одном компьютере | просто; нет совместной работы |
| **Файл-сервер** | файлы данных на общем сервере, обработка на каждом компьютере | большая нагрузка на сеть, медленно при многих пользователях |
| **Клиент-сервер** | сервер СУБД обрабатывает запросы, клиент получает только результат | надёжно, подходит для многих пользователей |
| **Многоуровневые** | представление, бизнес-логика и данные раздельно (MT15) | масштабируются, веб- и мобильные приложения |
| **Облачные (SaaS)** | система на сервере провайдера, через браузер (M11) | быстрый старт, абонентская плата |

## По виду данных

- **Фактографические** — конкретные факты в структурированном виде: числа, даты, названия (бухгалтерия, склад).
- **Документальные** — текстовые документы и поиск по ним: электронный документооборот, архив, Lex.uz.
- **Мультимедийные и пространственные** — изображения, видео, карты (ГИС, видеонаблюдение).

## Классификационный «паспорт» — пример

**Система**: единый портал интерактивных государственных услуг (my.gov.uz).

| Признак | Класс |
|---|---|
| Степень автоматизации | автоматизированная (многие услуги — автоматически) |
| Характер обработки | информационно-решающая (приём и обработка заявлений) + информационно-поисковая (каталог услуг) |
| Уровень управления | операционный (услуги G2C) |
| Сфера применения | государственное управление |
| Масштаб | государственный |
| Архитектура | многоуровневая, веб и мобильная, с межведомственной интеграцией |
| Вид данных | фактографические и документальные |

:::tip
Классификация — не теоретическое упражнение: при покупке или разработке системы «паспорт» уточняет требования — например, описание «корпоративная, клиент-сервер, автоматизированная, бухгалтерская» облегчает сравнение поставщиков.
:::

:::warning
**Частые ошибки**

- **Относить систему только к одному классу.** Классификация многомерна — отдельно по каждому признаку.
- **Путать «автоматизированную» и «автоматическую».** В первой решение остаётся за человеком.
- **Не различать файл-сервер и клиент-сервер.** При многих пользователях файл-сервер резко замедляется.
- **Упрощать облачную систему до «сайта в Интернете».** В ней есть вопросы размещения данных, SLA и безопасности (S11).
:::

## Задание

1. Составьте классификационный «паспорт» для трёх систем: (а) мобильное приложение банка, (б) LMS университета, (в) онлайн-касса в небольшом магазине.
2. Для каждого признака (всего 8) найдите хотя бы один пример из Узбекистана и составьте таблицу.
3. Опишите, как одна система со временем сменила класс (например, от файл-серверной бухгалтерии к облачной).

## Итоги

- Информационные системы классифицируются по многим признакам: автоматизация, характер обработки, уровень управления, функция, сфера, масштаб, архитектура, вид данных.
- Большинство систем в экономике — автоматизированные и информационно-решающие.
- Архитектура переходит от локальных и файл-серверных к клиент-серверным, многоуровневым и облачным системам.
- Классификационный «паспорт» — практический инструмент выбора и сравнения систем.

## Проверьте себя

:::check
Q: Чем автоматизированная система отличается от автоматической?
A: В автоматизированной человек и компьютер работают вместе и решение принимает человек; в автоматической процесс идёт без участия человека.
Q: Приведите пример информационно-поисковой системы.
A: База законодательства Lex.uz или библиотечный каталог.
Q: В чём главное отличие архитектуры файл-сервер от клиент-сервер?
A: В файл-серверной данные обрабатываются на каждом компьютере; в клиент-серверной запрос выполняет сервер и отправляет клиенту только результат.
Q: Где в экономике используется геоинформационная система?
A: В земельном кадастре, логистических маршрутах, анализе размещения торговых точек.
:::
