## Электронная налоговая отчётность

- **Личный кабинет налогоплательщика** (my.soliq.uz): подготовка и отправка отчётов, уведомление о принятии, просмотр задолженности и переплат, получение справок.
- Отчёты подписываются **электронной цифровой подписью** (S14) — бумажные формы и визит в налоговую не нужны.
- **Сроки**: ежемесячно, ежеквартально или ежегодно в зависимости от налога; нарушение срока — штрафы и пени.
- **Электронные счета-фактуры (ЭСФ)** и **онлайн-кассы** передают данные налоговому органу в реальном времени, поэтому цифры отчётности должны с ними совпадать.
- Учётные системы (M15) могут формировать отчёты автоматически и отправлять их напрямую.

## Основные налоги

| Налог | Объект | Примечание |
|---|---|---|
| **Налог на добавленную стоимость (НДС)** | реализация товаров и услуг | НДС по покупкам принимается к зачёту (уменьшает налог) |
| **Налог на прибыль** | прибыль предприятия | для крупных предприятий |
| **Налог с оборота** | выручка | упрощённый режим для малого бизнеса |
| **Налог на доходы физических лиц (НДФЛ)** | зарплата сотрудника | удерживает и уплачивает работодатель |
| **Социальный налог** | фонд оплаты труда | работодатель платит за свой счёт |
| **Налоги на имущество, землю, за пользование водными ресурсами** | активы и ресурсы | |

:::warning
Ставки и льготы меняются. Перед расчётом проверяйте действующие ставки в **Налоговом кодексе** (lex.uz) и на сайте налогового комитета. Ставки в примере ниже — учебные.
:::

## Разобранный пример: налоги с зарплаты

В каждой строке — фамилия сотрудника и начисленная месячная зарплата (сум). НДФЛ 12% (удерживается из зарплаты), социальный налог 12% (платит работодатель), налоги округляются вниз до целых сумов. Выведите цифры по каждому сотруднику и итог для отчётности.

```python
import sys

JSHDS = 12        # в процентах, удерживается из зарплаты сотрудника
IJTIMOIY = 12     # в процентах, платит работодатель

jami = [0, 0, 0, 0]
for satr in sys.stdin.read().split("\n"):
    if not satr.strip():
        continue
    familiya, hisob = satr.split()
    hisob = int(hisob)
    jshds = hisob * JSHDS // 100
    qolga = hisob - jshds                       # сотрудник получает на руки
    ijtimoiy = hisob * IJTIMOIY // 100
    print(f"{familiya}: начислено {hisob}, НДФЛ {jshds}, на руки {qolga}, социальный налог {ijtimoiy}")
    for i, x in enumerate([hisob, jshds, qolga, ijtimoiy]):
        jami[i] += x
print(f"Итого: начислено {jami[0]}, НДФЛ {jami[1]}, на руки {jami[2]}, социальный налог {jami[3]}")
```
```java
import java.util.Scanner;

public class Main {
    static final int JSHDS = 12;        // в процентах, удерживается из зарплаты сотрудника
    static final int IJTIMOIY = 12;     // в процентах, платит работодатель

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        long[] jami = new long[4];
        while (in.hasNext()) {
            String familiya = in.next();
            long hisob = in.nextLong();
            long jshds = hisob * JSHDS / 100;
            long qolga = hisob - jshds;                  // сотрудник получает на руки
            long ijtimoiy = hisob * IJTIMOIY / 100;
            System.out.println(familiya + ": начислено " + hisob + ", НДФЛ " + jshds + ", на руки " + qolga + ", социальный налог " + ijtimoiy);
            long[] satr = {hisob, jshds, qolga, ijtimoiy};
            for (int i = 0; i < 4; i++) jami[i] += satr[i];
        }
        System.out.println("Итого: начислено " + jami[0] + ", НДФЛ " + jami[1] + ", на руки " + jami[2] + ", социальный налог " + jami[3]);
    }
}
```

## Банковские кредиты

| Вид | Цель | Особенности |
|---|---|---|
| **Потребительский кредит** | бытовая техника, ремонт, образование | короткий и средний срок, относительно высокий процент |
| **Ипотека** | покупка жилья | длительный срок (10–20 лет), жильё в залоге, первоначальный взнос |
| **Автокредит** | автомобиль | автомобиль в залоге |
| **Микрозайм** | небольшая сумма, быстро | высокий процент, короткий срок |
| **Бизнес-кредиты** | оборотные средства, оборудование, инвестпроекты | бизнес-план, залог, поручительство |
| **Кредитные карты и овердрафт** | краткосрочные потребности | льготный период, затем высокий процент |

**Способы погашения**:

- **Аннуитетный** — каждый месяц одинаковая сумма; вначале большая часть платежа — проценты, в конце — основной долг. Легко планировать.
- **Дифференцированный** — каждый месяц равная часть основного долга + проценты на остаток; вначале платёж большой, затем уменьшается. Общая сумма процентов меньше, чем при аннуитете.

**Важно**: сравнивайте кредиты не по номинальной ставке, а по **годовой эффективной процентной ставке** (со всеми комиссиями и платежами) — банк обязан указывать её в договоре. Ежемесячные платежи не должны занимать большую часть дохода (долговая нагрузка).

## Банковские вклады

| Вид | Особенности |
|---|---|
| **До востребования** | деньги можно снять в любое время, процент низкий или отсутствует |
| **Срочный** | на определённый срок, процент выше; при досрочном снятии процент снижается |
| **Накопительный** | можно регулярно пополнять, для целевых накоплений |
| **Валютный** | в иностранной валюте, процент обычно ниже, валютный риск |

**Виды процентов**:

- **Простые проценты** — каждый год проценты начисляются только на **первоначальную сумму**; баланс растёт каждый год на одну и ту же величину.
- **Сложные проценты (капитализация)** — проценты начисляются на **текущий баланс**, то есть вместе с ранее начисленными процентами; баланс растёт всё быстрее («проценты на проценты»).

На длительном сроке сложные проценты дают заметную разницу. Расчёт обоих способов по годам — **задание по программированию** семинара: выполните его самостоятельно с помощью цикла (повторяющегося алгоритма).

**Реальная доходность** вклада зависит и от инфляции: если ставка по вкладу 20%, а инфляция 10%, покупательная способность растёт примерно на 10%. Вклады гарантируются законом (система гарантирования банковских вкладов).

:::warning
**Частые ошибки**

- **Сравнивать кредиты только по номинальной ставке.** Комиссии и страховки увеличивают реальную стоимость.
- **Откладывать отчёт на последний день.** Из-за перегрузки системы или проблем с ЭЦП можно пропустить срок.
- **Расхождение цифр ЭСФ и отчётности.** Налоговый орган выявляет расхождения автоматически.
- **Не учитывать инфляцию.** Высокая номинальная ставка не означает реальной доходности.
:::
