## Purpose of the seminar

Every computer and phone works with an operating system (OS). Choosing an OS for a company is not only a technical but also an economic decision: the licence price, whether the needed accounting and business programs run, staff learning, and maintenance costs. In the seminar we compare the three main desktop OSs and make a choice suited to the situation.

:::note
**After this seminar you will be able to:**

- explain the tasks of an operating system;
- name the main features of and differences between Windows, macOS and Linux;
- know the concept of a file system;
- justify the choice of an OS for a company by economic criteria.
:::

## Tasks of an operating system

An **operating system** is the core software that manages hardware resources and serves programs.

| Task | Meaning |
|---|---|
| **Process management** | running several programs at once and sharing processor time |
| **Memory management** | distributing main memory among programs |
| **File system** | determines how data is stored on disk, named and arranged in folders |
| **Device management** | working with printers, scanners, network cards and others through drivers |
| **Users and security** | accounts, passwords, permissions, updates |
| **Interface** | graphical (windows, mouse) and the command line |

## The three main desktop OSs

| Feature | **Microsoft Windows** | **Apple macOS** | **Linux** |
|---|---|---|---|
| Developer | Microsoft (since 1985) | Apple (Mac OS 1984; macOS — based on UNIX) | an open community, kernel — Linus Torvalds (1991) |
| Licence | commercial (paid, often bundled with the computer) | free with Apple computers | open source, many distributions are free |
| Devices | computers from many manufacturers | Apple computers (Mac) only | almost any computer, servers |
| Programs | the most commercial and business programs, accounting systems such as 1C | creative and office programs, Microsoft 365 | LibreOffice, server software, development tools |
| File system | NTFS | APFS | ext4 and others |
| Share | the most widespread on desktops | popular in design and media | leading on servers and in the cloud, rare on desktops |
| Where it excels | office and enterprise workplaces | design, media, ease of use | servers, the cloud, scientific computing, saving money |

**Mobile OSs**: **Android** (Google; based on the Linux kernel, open; on phones from many manufacturers) and **iOS** (Apple, iPhone only). Mobile apps (banking, payments, tax) are released for both systems.

## The file system and basic operations

The file system manages the folder tree, file names and extensions (for example `.xlsx`, `.docx`, `.pdf`), permissions and free space. The basic operations are similar in all OSs: creating a folder, moving and copying a file, renaming, searching, compressing (ZIP), deleting and restoring from the recycle bin.

| Action | Windows | macOS | Linux (graphical) |
|---|---|---|---|
| File manager | Explorer (`Win + E`) | Finder | Files (Nautilus) and others |
| Program list | Start menu | Launchpad, Dock | applications menu |
| System settings | Settings, Control Panel | System Settings | Settings |
| Task manager | Task Manager (`Ctrl + Shift + Esc`) | Activity Monitor | System Monitor |

## Choosing an OS from an economic point of view

| Criterion | Questions |
|---|---|
| **Licence cost** | how much per computer? Is there a free alternative? |
| **Availability of programs** | do the needed accounting, bank-client, tax and industry programs run on this OS? |
| **Staff skills** | which OS do staff know, and how much does retraining cost? |
| **Maintenance** | updates, availability of administrators, security |
| **Hardware requirements** | does it run on old computers? Is special hardware needed? |
| **TCO** | all costs over several years (M2) |

## Practical tasks

1. Find out the OS name and version, the processor and the memory size of your computer (Windows: Settings → System → About; macOS: Apple menu → About This Mac; Linux: Settings → About).
2. In the file manager create a "Seminar_S3" folder, create three files in it, compress one into a ZIP, then move it to another folder.
3. In the task manager find the three programs using the most memory.
4. **Situation**: an accounting firm with 15 employees is buying new computers. The 1C accounting and bank-client programs are required. Which OS do you choose and why? Estimate the licence cost.
5. **Situation**: a university computer lab has a limited budget and mainly needs a browser, office programs and programming. Is Linux suitable? Write down the advantages and risks.

:::warning
**Common mistakes**

- **Confusing an OS with an application.** Excel is an application, not an OS.
- **Choosing by licence price only.** If a needed program does not run, even a free OS becomes expensive.
- **Using an unlicensed ("cracked") OS.** It is illegal and a security risk: there are no updates or protection.
- **Turning off updates.** Without security fixes the system is vulnerable (M14).
:::

:::tip
You do not have to install Linux on your computer to try it: create a virtual machine in VirtualBox or use Ubuntu's "Live USB" mode.
:::

## Summary

- An OS manages hardware resources and serves programs: processes, memory, file system, devices, users, interface.
- Windows is the most widespread, with many business programs; macOS — Apple devices, design and convenience; Linux — open source, servers and savings.
- Mobile OSs: Android and iOS.
- File systems: NTFS (Windows), APFS (macOS), ext4 (Linux).
- Choosing an OS: licence, programs, staff, maintenance, hardware and TCO.
