## Цель самостоятельной работы

На семинаре S10 мы рассмотрели понятие и виды интерактивных услуг и этапы получения услуги. В этой самостоятельной работе изучим методы **оценки и повышения качества услуг**: как сделать услугу удобной для пользователя и как измерить это удобство в цифрах.

## Карта пути клиента

**Карта пути клиента** (customer journey map) — шаги, которые пользователь проходит при получении услуги, его действия, ощущения и проблемы.

| Этап | Действие | Проблема («болевая точка») | Идея улучшения |
|---|---|---|---|
| Осведомлённость | узнаёт о существовании услуги | не знает, с чего начать | понятное название в поиске, инструкция |
| Вход | входит через OneID | забыл пароль | мобильная ЭЦП, простое восстановление |
| Заявление | заполняет форму | 20 полей, лишние документы | автоматически брать данные из реестров (MT17) |
| Оплата | платит госпошлину | нужно переходить в другое приложение | встроенная кнопка оплаты |
| Ожидание | отслеживает статус | статус не обновляется | SMS и push-уведомления |
| Результат | получает документ | PDF не открывается | электронный документ с QR-кодом |

**Схема услуги** (service blueprint) дополняет путь клиента процессами «за кулисами»: какой сотрудник, какая система и какая интеграция обеспечивают каждый шаг (связано с дорожками BPMN в MT11).

## Десять эвристик удобства использования

Известные принципы Якоба Нильсена используются для быстрой оценки интерфейса:

| Эвристика | Вопрос |
|---|---|
| 1. Видимость состояния системы | знает ли пользователь, что происходит (загрузка, статус заявления)? |
| 2. Язык реального мира | понятны ли термины пользователю, а не ведомственный жаргон? |
| 3. Свобода и контроль | можно ли отменить ошибку, вернуться назад? |
| 4. Единообразие и стандарты | одинаковые действия везде выглядят одинаково? |
| 5. Предотвращение ошибок | поле даты — календарь или свободный текст? |
| 6. Узнавание, а не запоминание | показываются ли ранее введённые данные? |
| 7. Гибкость | есть ли быстрые пути для опытных пользователей? |
| 8. Минималистичный дизайн | нет ли лишнего текста и элементов? |
| 9. Помощь в исправлении ошибок | понятно ли сообщение об ошибке и предлагает ли оно решение? |
| 10. Справка и документация | есть ли краткая инструкция там, где она нужна? |

## Доступность

Услугой должны пользоваться и люди с нарушениями зрения, слуха или движения, пожилые и пользователи с медленным Интернетом. Международный стандарт **WCAG** основан на четырёх принципах:

- **Воспринимаемость** — текстовые описания изображений, достаточный контраст, субтитры к видео.
- **Управляемость** — работа с клавиатуры, достаточно времени, крупные кнопки.
- **Понятность** — простой язык, предсказуемое поведение.
- **Надёжность** — работает в разных браузерах, программах экранного доступа и на разных устройствах.

## Показатели качества

| Показатель | Как рассчитывается | Что показывает |
|---|---|---|
| **Доля завершения** | завершённые заявления / начатые × 100% | не «бросают» ли пользователи где-то процесс |
| **Время исполнения** | среднее время от заявления до результата | скорость, соблюдение обещанного срока |
| **CSAT** (удовлетворённость клиента) | «Вы довольны?» (1–5) — среднее или доля ответов 4–5 | удовлетворённость одним взаимодействием |
| **NPS** (индекс лояльности) | «Порекомендуете ли?» (0–10): % промоутеров (9–10) − % критиков (0–6) | общая лояльность, от −100 до +100 |
| **CES** (затраченные усилия) | «Насколько легко было получить услугу?» | есть ли лишние трудности |

## Разобранный пример: результаты опроса

В первой строке — ответы 0–10 на вопрос «Порекомендуете ли вы услугу?», во второй — число начатых и завершённых заявлений. Рассчитайте NPS, среднюю оценку и долю завершения.

```python
import sys

satrlar = sys.stdin.read().strip().split("\n")
baholar = [int(x) for x in satrlar[0].split()]
boshlangan, yakunlangan = map(int, satrlar[1].split())
n = len(baholar)

targibotchi = sum(1 for b in baholar if b >= 9)      # 9–10 баллов
tanqidchi = sum(1 for b in baholar if b <= 6)        # 0–6 баллов
neytral = n - targibotchi - tanqidchi                # 7–8 баллов
nps = (targibotchi - tanqidchi) * 100 / n

print(f"Ответов: {n}")
print(f"Промоутеры: {targibotchi}, нейтралы: {neytral}, критики: {tanqidchi}")
print(f"NPS: {nps:.1f}")
print(f"Средняя оценка: {sum(baholar) / n:.2f}")
print(f"Доля завершения: {yakunlangan * 100 / boshlangan:.1f}%")
```
```java
import java.util.Arrays;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int[] baholar = Arrays.stream(in.nextLine().trim().split("\\s+")).mapToInt(Integer::parseInt).toArray();
        int boshlangan = in.nextInt(), yakunlangan = in.nextInt();
        int n = baholar.length, targibotchi = 0, tanqidchi = 0, jami = 0;
        for (int b : baholar) {
            if (b >= 9) targibotchi++;                   // 9–10 баллов
            if (b <= 6) tanqidchi++;                     // 0–6 баллов
            jami += b;
        }
        int neytral = n - targibotchi - tanqidchi;       // 7–8 баллов
        double nps = (targibotchi - tanqidchi) * 100.0 / n;

        System.out.println("Ответов: " + n);
        System.out.println("Промоутеры: " + targibotchi + ", нейтралы: " + neytral + ", критики: " + tanqidchi);
        System.out.println(String.format("NPS: %.1f", nps));
        System.out.println(String.format("Средняя оценка: %.2f", (double) jami / n));
        System.out.println(String.format("Доля завершения: %.1f%%", yakunlangan * 100.0 / boshlangan));
    }
}
```
```cpp
#include <cstdio>
#include <iostream>
#include <sstream>
#include <string>
#include <vector>
using namespace std;

int main() {
    string satr;
    getline(cin, satr);
    istringstream ss(satr);
    vector<int> baholar;
    int b;
    while (ss >> b) baholar.push_back(b);
    int boshlangan, yakunlangan;
    cin >> boshlangan >> yakunlangan;

    int n = baholar.size(), targibotchi = 0, tanqidchi = 0, jami = 0;
    for (int x : baholar) {
        if (x >= 9) targibotchi++;                       // 9–10 баллов
        if (x <= 6) tanqidchi++;                         // 0–6 баллов
        jami += x;
    }
    int neytral = n - targibotchi - tanqidchi;           // 7–8 баллов
    double nps = (targibotchi - tanqidchi) * 100.0 / n;

    printf("Ответов: %d\n", n);
    printf("Промоутеры: %d, нейтралы: %d, критики: %d\n", targibotchi, neytral, tanqidchi);
    printf("NPS: %.1f\n", nps);
    printf("Средняя оценка: %.2f\n", (double) jami / n);
    printf("Доля завершения: %.1f%%\n", yakunlangan * 100.0 / boshlangan);
    return 0;
}
```

NPS положителен (+15), но критиков 30% — нужно прочитать их комментарии и сгруппировать причины. Доля завершения 70%: из каждых 10 начатых заявлений 3 брошены. С помощью карты пути клиента нужно найти, на каком шаге уходят пользователи (часто — загрузка документов или оплата), и упростить этот шаг.

## Обратная связь и A/B-тестирование

- **Сбор обратной связи**: короткий опрос в конце услуги (1–3 вопроса), отзывы, анализ обращений, записи колл-центра.
- **A/B-тест**: половине пользователей показывают старый вариант формы, половине — новый; сравнивают долю завершения. Решение принимается на основе данных, а не ощущений.
- **«Замыкание петли»**: сообщить пожаловавшемуся пользователю, что изменено, — это повышает доверие.

## Чат-боты и сервисы в мессенджерах

Хороший чат-бот решает одну понятную задачу (узнать статус, получить справку), ведёт пользователя кнопками, при непонимании переключает на оператора, запрашивает персональные данные только при необходимости и по защищённому каналу. Официальных ботов проверяйте по отметке о верификации и ссылке на официальном сайте (правила безопасности в S10).

:::warning
**Частые ошибки**

- **Проектировать услугу для ведомства.** Начинайте с шагов пользователя и «болевых точек».
- **Смотреть только на один показатель.** Высокий NPS может сочетаться с низкой долей завершения.
- **Откладывать доступность на последний этап.** Исправлять потом дороже.
- **Собирать обратную связь и не отвечать.** Пользователи перестанут отвечать на опросы.
:::
