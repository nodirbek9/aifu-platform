## Purpose of the seminar

In lecture M5 we covered presentation structure and design principles. In the seminar we apply them in practice, prepare a short, clear presentation based on real economic data and assess each other's work.

:::note
**After this seminar you will be able to:**

- carry out the main operations in a presentation editor independently;
- create a consistent design through the slide master;
- insert Excel data as a linked chart;
- prepare a presentation for showing and distribution.
:::

## Main operations

| Operation | In PowerPoint | Advice |
|---|---|---|
| New presentation, choosing a theme | File → New; Design → Themes | a simple theme with 2–3 colours |
| Slide master | View → Slide Master | set the logo, fonts and colours here once |
| Adding a slide and a layout | Home → New Slide → Layout | "Title and Content", "Two Content", "Title Only" |
| Text and lists | type into layout placeholders; `Tab` / `Shift + Tab` — level | 3–5 points, short phrases |
| Table | Insert → Table | no more than 4–5 rows, highlight the key value |
| A chart from Excel | copy in Excel → Paste Special → Paste Link in PowerPoint | the chart updates when the data changes |
| SmartArt | Insert → SmartArt | process, hierarchy, cycle |
| Images and icons | Insert → Pictures / Icons | icons in one consistent style |
| Animation | Animations → Appear/Fade | only for revealing step by step |
| Transitions | Transitions → Fade | one simple transition for the whole presentation |
| Notes | the Notes area below the slide | what to say and the numbers |
| Sections and order | Slide Sorter, Add Section | dividing a large presentation into sections |
| Checking | Review → Spelling; Check Accessibility | alternative text (Alt Text) for images |
| Export | File → Export → PDF | for handouts and archiving |
| Collaboration | Share, Comments | co-editing in OneDrive/Google Drive |

## Practical task: "Small business report"

Based on the sales table you built in seminar S4 (or data given by the teacher), prepare a **7–8-slide** presentation:

1. **Title**: topic, name, group, date.
2. **Key conclusion** (with one number): for example, "Quarterly sales 4.8 million soums, Tashkent's share 50%".
3. **Sales by region**: a column chart linked from Excel.
4. **Product shares**: a pie or 100% stacked column chart (few parts).
5. **Dynamics over time**: a line chart.
6. **Problem and causes**: SmartArt or a three-point list.
7. **Proposals**: 2–3 concrete measures and the expected result.
8. **A slide for questions**.

Requirements: the logo and fonts in the slide master; each slide title is a full sentence; at least one chart linked to Excel; speaker notes on every slide; presentation time — 5 minutes; also submit a PDF version.

## Assessment criteria

| Criterion | Points |
|---|---|
| Structure and logic (problem → evidence → proposal) | 25 |
| Correctness of data and sources | 20 |
| Charts chosen correctly and readable | 20 |
| Design consistency (slide master, fonts, colours) | 15 |
| Delivery: keeping to time, using notes, answering questions | 20 |

**Peer assessment**: each group writes 2 strengths and 1 improvement suggestion for another group's presentation.

:::warning
**Common mistakes**

- **Decorating every slide by hand.** Use the slide master — changes are made in one place.
- **Inserting a chart as a picture.** When the data is updated it has to be redrawn; insert a linked chart.
- **Reading the text on the slide aloud.** Use notes and look at the audience.
- **Not rehearsing the timing.** If a 5-minute presentation runs to 15 minutes, the key conclusion is never said.
:::

:::tip
Before submitting, export the presentation to PDF and open it on a phone: is it readable on a small screen? If not, enlarge the fonts and charts.
:::

## Summary

- Main operations: theme and slide master, layouts, text, tables, linked charts, SmartArt, images, animation, notes, export.
- A consistent design is created through the slide master.
- A chart linked to Excel updates when the data changes.
- A good presentation: a clear structure, correct charts, full-sentence titles, a rehearsed delivery.

## Check yourself

:::check
Q: How do you insert an Excel chart into PowerPoint so that it updates with the data?
A: Linked, through Paste Special → Paste Link.
Q: Where are the logo and fonts set once for all slides?
A: In the slide master (View → Slide Master).
Q: Why is alternative text (Alt Text) added to images?
A: For users with visual impairments and screen reader programs.
Q: Which format is convenient for exporting a presentation for distribution?
A: PDF.
:::
