## Цель семинара

На лекции M5 мы рассмотрели структуру презентации и принципы дизайна. На семинаре применим их на практике, подготовим короткую понятную презентацию на основе реальных экономических данных и оценим работы друг друга.

:::note
**После этого семинара вы сможете:**

- самостоятельно выполнять основные операции в редакторе презентаций;
- создавать единый дизайн через образец слайдов;
- вставлять данные Excel в виде связанной диаграммы;
- готовить презентацию к показу и распространению.
:::

## Основные операции

| Операция | В PowerPoint | Совет |
|---|---|---|
| Новая презентация, выбор темы | File → New; Design → Themes | простая тема в 2–3 цвета |
| Образец слайдов | View → Slide Master | логотип, шрифты и цвета настройте здесь один раз |
| Добавление слайда и макет | Home → New Slide → Layout | «Title and Content», «Two Content», «Title Only» |
| Текст и списки | ввод в местозаполнители макета; `Tab` / `Shift + Tab` — уровень | 3–5 пунктов, короткие фразы |
| Таблица | Insert → Table | не более 4–5 строк, выделяйте ключевое значение |
| Диаграмма из Excel | копия в Excel → Paste Special → Paste Link в PowerPoint | при изменении данных диаграмма обновится |
| SmartArt | Insert → SmartArt | процесс, иерархия, цикл |
| Изображения и значки | Insert → Pictures / Icons | значки в едином стиле |
| Анимация | Animations → Appear/Fade | только для поэтапного раскрытия |
| Переходы | Transitions → Fade | один простой переход на всю презентацию |
| Заметки | область Notes под слайдом | что говорить и какие цифры |
| Разделы и порядок | Slide Sorter, Add Section | деление большой презентации на разделы |
| Проверка | Review → Spelling; Check Accessibility | замещающий текст (Alt Text) для изображений |
| Экспорт | File → Export → PDF | для раздаточного материала и архива |
| Совместная работа | Share, комментарии (Comments) | совместное редактирование в OneDrive/Google Drive |

## Практическое задание: «Отчёт малого бизнеса»

На основе таблицы продаж, составленной на семинаре S4 (или данных преподавателя), подготовьте презентацию из **7–8 слайдов**:

1. **Титул**: тема, имя, группа, дата.
2. **Главный вывод** (с одним числом): например, «Продажи за квартал 4,8 млн сумов, доля Ташкента 50%».
3. **Продажи по регионам**: столбчатая диаграмма со связью с Excel.
4. **Доли товаров**: круговая или нормированная столбчатая диаграмма (мало частей).
5. **Динамика во времени**: линейная диаграмма.
6. **Проблема и причины**: SmartArt или список из 3 пунктов.
7. **Предложения**: 2–3 конкретные меры и ожидаемый результат.
8. **Слайд для вопросов**.

Требования: логотип и шрифты в образце слайдов; заголовок каждого слайда — полное предложение; хотя бы одна диаграмма связана с Excel; заметки докладчика на каждом слайде; время выступления — 5 минут; сдайте также PDF-версию.

## Критерии оценивания

| Критерий | Баллы |
|---|---|
| Структура и логика (проблема → доказательства → предложение) | 25 |
| Правильность данных и источники | 20 |
| Диаграммы выбраны правильно и читаемы | 20 |
| Единство дизайна (образец слайдов, шрифты, цвета) | 15 |
| Выступление: соблюдение времени, использование заметок, ответы на вопросы | 20 |

**Взаимная оценка**: каждая группа пишет к презентации другой группы 2 сильные стороны и 1 предложение по улучшению.

:::warning
**Частые ошибки**

- **Оформлять каждый слайд вручную.** Пользуйтесь образцом слайдов — изменение в одном месте.
- **Вставлять диаграмму картинкой.** При обновлении данных её придётся перерисовывать; вставляйте связанную диаграмму.
- **Зачитывать текст со слайда.** Пользуйтесь заметками и смотрите на слушателей.
- **Не репетировать время.** Если 5-минутная презентация растянется на 15 минут, главный вывод так и не прозвучит.
:::

:::tip
Перед сдачей экспортируйте презентацию в PDF и откройте на телефоне: читается ли она на маленьком экране? Если нет — увеличьте шрифты и диаграммы.
:::

## Проверьте себя

:::check
Q: Как вставить диаграмму Excel в PowerPoint, чтобы она обновлялась вместе с данными?
A: Со связью, через Paste Special → Paste Link.
Q: Где один раз настраиваются логотип и шрифты для всех слайдов?
A: В образце слайдов (View → Slide Master).
Q: Зачем к изображениям добавляют замещающий текст (Alt Text)?
A: Для пользователей с нарушениями зрения и программ экранного доступа.
Q: В каком формате удобно экспортировать презентацию для распространения?
A: PDF.
