## Средства просмотра

| Средство | Где | Что даёт |
|---|---|---|
| **Форматирование как таблицы** | Home → Format as Table (`Ctrl + T`) | автоматические фильтры, чередование цвета строк, формулы сами распространяются на новые строки, ссылки по имени столбца |
| **Закрепление строк/столбцов** | View → Freeze Panes | заголовок виден при прокрутке |
| **Группировка** | Data → Group | сворачивание и разворачивание строк или столбцов |
| **Несколько окон** | View → New Window, Arrange All | просмотр разных частей одного файла рядом |

## Средства обработки

| Средство | Содержание |
|---|---|
| **Сортировка** | несколько уровней: например, сначала по региону (А→Я), затем по сумме (по убыванию) |
| **Фильтр** | условия по значениям, тексту, числам и датам («больше 10», «Toshkent», «в этом месяце») |
| **Расширенный фильтр** | сложные условия (И/ИЛИ) в отдельной таблице критериев |
| **Условное форматирование** | цветовые шкалы, гистограммы, значки, правила на основе формул |
| **Проверка данных** (Data Validation) | ввод в ячейку только значений из списка или в пределах — предотвращает ошибки |
| **Удаление дубликатов** | Data → Remove Duplicates |
| **Текст по столбцам** | Data → Text to Columns (например, «Фамилия Имя» → два столбца) |
| **Мгновенное заполнение** (Flash Fill) | автозаполнение по образцу (`Ctrl + E`) |

## Средства обобщения

**Промежуточные итоги** (Data → Subtotal): в отсортированной таблице добавляют сумму или среднее для каждой группы (например, региона).

**Сводная таблица** (Insert → PivotTable) обобщает большую таблицу несколькими движениями мыши:

| Поле | Назначение | Пример |
|---|---|---|
| **Rows** (строки) | группировка | регион |
| **Columns** (столбцы) | вторая группировка | товар или месяц |
| **Values** (значения) | расчёт: Sum, Count, Average, Max | сумма продаж |
| **Filters** (фильтры) | фильтр всей таблицы | год |

Можно показывать значения как «% of Grand Total», группировать даты по месяцам и кварталам, использовать **срезы** (Slicers) для интерактивной фильтрации. На основе сводной таблицы строится **сводная диаграмма** (PivotChart). При изменении исходных данных: PivotTable Analyze → Refresh.

**Анализ «что, если»**:

- **Подбор параметра** (Goal Seek, Data → What-If Analysis): находит одно входное значение для достижения нужного результата. Например, сколько продать, чтобы прибыль составила 50 млн сумов?
- **Диспетчер сценариев**: сохранение и сравнение оптимистичного, базового и пессимистичного вариантов.
- **Таблица данных** (Data Table): таблица результатов при изменении одного или двух параметров.

## Разобранный пример: идея сводной таблицы

Сводная таблица по сути **группирует и обобщает** данные. Программа ниже группирует записи о продажах (регион, товар, сумма) по регионам и выводит для каждого региона сумму, число записей и долю в общей сумме — тот же результат, что в Excel при Rows = регион, Values = сумма и количество записей, в виде «% of Grand Total».

```python
import sys

jami, soni = {}, {}
for satr in sys.stdin.read().split("\n"):
    if not satr.strip():
        continue
    hudud, tovar, summa = satr.split()
    jami[hudud] = jami.get(hudud, 0) + int(summa)     # Values: Sum
    soni[hudud] = soni.get(hudud, 0) + 1              # Values: Count
umumiy = sum(jami.values())
for h in sorted(jami):                                # Rows: регион (по алфавиту)
    print(f"{h}: {jami[h]} ({soni[h]} шт., {100 * jami[h] / umumiy:.1f}%)")
print(f"Итого: {umumiy}")
```
```java
import java.util.Map;
import java.util.Scanner;
import java.util.TreeMap;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Map<String, Long> jami = new TreeMap<>();            // Rows: регион (по алфавиту)
        Map<String, Integer> soni = new TreeMap<>();
        while (in.hasNext()) {
            String hudud = in.next(), tovar = in.next();
            long summa = in.nextLong();
            jami.merge(hudud, summa, Long::sum);              // Values: Sum
            soni.merge(hudud, 1, Integer::sum);               // Values: Count
        }
        long umumiy = 0;
        for (long v : jami.values()) umumiy += v;
        for (String h : jami.keySet()) {
            System.out.println(String.format("%s: %d (%d шт., %.1f%%)", h, jami.get(h), soni.get(h), 100.0 * jami.get(h) / umumiy));
        }
        System.out.println("Итого: " + umumiy);
    }
}
```
```cpp
#include <cstdio>
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<string, long long> jami;                             // Rows: регион (по алфавиту)
    map<string, int> soni;
    string hudud, tovar;
    long long summa;
    while (cin >> hudud >> tovar >> summa) {
        jami[hudud] += summa;                                // Values: Sum
        soni[hudud] += 1;                                    // Values: Count
    }
    long long umumiy = 0;
    for (auto& p : jami) umumiy += p.second;
    for (auto& p : jami) {
        printf("%s: %lld (%d шт., %.1f%%)\n", p.first.c_str(), p.second, soni[p.first], 100.0 * p.second / umumiy);
    }
    printf("Итого: %lld\n", umumiy);
    return 0;
}
```

Buxoro shakar 450000
Samarqand qahva 650000

(Товары — чай, кофе и сахар.) Введите те же данные в Excel, постройте сводную таблицу и сравните результат. Затем добавьте «товар» в поле Columns — получится таблица регион × товар. Программа и сводная таблица делают одну работу, но для тысяч строк и повторяющихся отчётов удобнее автоматизация (программа или Power Query).

## Практические задания

1. Составьте таблицу продаж не менее чем из 30 строк (дата, регион, товар, количество, цена, сумма) и отформатируйте её как таблицу.
2. Закрепите строку заголовка; отсортируйте сначала по региону, затем по сумме.
3. Фильтром покажите продажи только одного региона за последний месяц.
4. Добавьте к столбцу суммы цветовую шкалу и правило для значений больше 1 млн сумов.
5. Добавьте в столбец «регион» раскрывающийся список через Data Validation.
6. Постройте сводную таблицу: Rows — регион, Columns — товар, Values — сумма; покажите доли как «% of Grand Total»; добавьте сводную диаграмму.
7. С помощью Goal Seek: какой должна быть цена одного товара, чтобы общие продажи выросли на 10%?

:::warning
**Частые ошибки**

- **Пустые строки и объединённые ячейки в таблице.** Сортировка, фильтры и сводные таблицы работают неправильно.
- **Разные типы данных в одном столбце.** Если числа и текст смешаны, сумма неверна.
- **Забыть обновить сводную таблицу.** При изменении источника нажимайте Refresh.
- **Выделить при сортировке только один столбец.** Строки «разрываются», данные портятся — выделяйте всю таблицу.
:::

:::tip
Таблица, где в каждом столбце один тип данных, заголовки в первой строке, нет пустых строк и объединённых ячеек, — «чистая». Сводные таблицы и фильтры надёжно работают только с чистой таблицей.
:::
