## Why does this topic matter?

In an economist's daily work several programs work together: analysis in spreadsheets, bookkeeping in an accounting system, payments in a bank-client program, reports in the tax account. A well-chosen software product reduces manual work, prevents errors and gives management information on time; a poorly chosen one wastes money and time. In this lesson we look at the types of software, the main products in the economy and the principles for choosing them.

:::note
**After this lesson you will be able to:**

- divide software into system, application and development types;
- name the software products widely used in the economy and their purposes;
- explain the essence of ERP and CRM systems;
- distinguish licensing models;
- apply criteria for choosing a software product.
:::

## Classification of software

| Type | Purpose | Examples |
|---|---|---|
| **System software** | keeps the computer running | operating systems (S3), drivers, antivirus programs, archivers |
| **Application software** | solves the user's specific tasks | office suites, accounting, ERP, CRM, browsers |
| **Development software** | for creating new programs | programming languages and environments (M8), database tools |

## Main application software in the economy

| Group | Purpose | Examples |
|---|---|---|
| **Office suites** | text, spreadsheets, presentations, mail | Microsoft 365 (Word, Excel, PowerPoint, Outlook), Google Workspace, LibreOffice |
| **Accounting systems** | bookkeeping, payroll, inventory, tax reports | 1C:Accounting (widespread in Uzbekistan), other local and foreign programs |
| **ERP** (enterprise resource planning) | finance, purchasing, production, inventory, sales, HR — in one system | SAP S/4HANA, Oracle, Microsoft Dynamics 365, Odoo, 1C:ERP |
| **CRM** (customer relationship management) | customer database, sales funnel, requests | Salesforce, Bitrix24, amoCRM, HubSpot |
| **Banking systems** | the bank's core system (core banking), bank-client, payment systems | banks' internal systems, "bank-client" for companies |
| **Analysis and statistics** | processing data, regression, forecasting | Excel (M4), SPSS, Stata, EViews, R, Python (pandas) |
| **Business intelligence (BI)** | interactive reports and dashboards | Power BI, Tableau, Looker Studio |
| **Project management** | tasks, deadlines, resources | MS Project, Trello, Jira, Asana |
| **Electronic document workflow** | signing and exchanging documents electronically | electronic invoice systems, inter-agency document workflow systems |

**Why ERP matters**: in separate programs data is entered repeatedly and does not match (sales shows one number, the warehouse another). In an ERP each operation is entered once and immediately affects all departments: a sale → the stock balance → the accounting entry → the financial report. Drawbacks: expensive, long implementation (months), requires redesigning processes.

**What CRM gives**: the history of all contacts with each customer, sales stages, analysis of repeat sales and customer retention.

## Licensing models

| Model | Meaning | Example |
|---|---|---|
| **Commercial (proprietary)** | the right to use is purchased, the code is closed | Windows, MS Office (one-time), SAP |
| **Subscription / SaaS** | a monthly or yearly fee, often in the cloud (M11) | Microsoft 365, Google Workspace, Salesforce |
| **Open source** | the code is open, may be modified and distributed (GPL, MIT and other licences) | Linux, LibreOffice, R, Python, Odoo Community |
| **Freeware** | free to use, but the code is closed | some PDF readers, browsers |
| **Trial, shareware** | limited time or features | trial versions of many commercial programs |

**Using unlicensed software** infringes copyright (fines and liability) and is a security risk: no updates, and "cracked" programs may contain malicious code (see MT9 of the KIA course).

## Choosing a software product

| Criterion | Questions |
|---|---|
| **Functional fit** | does it fit the business processes? Is local legislation (tax, accounting standards) supported? |
| **Price and TCO** | licence or subscription, implementation, customization, training, support (M2) |
| **Integration** | does it exchange data with the bank, tax authority, online cash registers and other systems? |
| **Scalability** | will the program be enough when the company grows? |
| **Supplier** | local support, language, availability of partners, the company's stability |
| **Security and data** | user rights, backups, where the data is stored |

**Implementation stages**: collecting requirements → comparing and choosing options → a trial (pilot) → migrating data → training users → go-live → support and improvement.

:::warning
**Common mistakes**

- **Choosing because "everyone uses it".** Write down your own processes and requirements first.
- **Comparing only licence prices.** Implementation and training often cost more than the licence.
- **Not checking local requirements.** A foreign program may not support Uzbek tax reports.
- **Unlicensed software.** Legal liability and security risk.
- **Not planning data migration.** A new system does not work without the data from the old one.
:::

## Summary

- Software: system (OS, drivers), application (office, accounting, ERP, CRM), development (programming tools).
- In the economy: office suites, accounting (1C), ERP, CRM, banking systems, analysis and BI, project management, electronic document workflow.
- ERP combines all departments in one database; CRM manages customer relationships.
- Licences: commercial, subscription (SaaS), open source, freeware, trial.
- Choosing: functional fit, TCO, integration, scalability, supplier, security.
