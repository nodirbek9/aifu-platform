## Почему эта тема важна?

На лекции M5 мы познакомились с историческими шифрами. Сегодня они ничего не защищают, но на них можно своими руками проверить важнейшие уроки криптографии: если пространство ключей мало — достаточно **полного перебора**; даже если оно велико, шифр всё равно ломается, когда в шифртексте сохраняется **статистика** языка. Современные шифры спроектированы именно против этих двух слабостей.

:::note
**После этого занятия вы сможете:**

- шифровать и расшифровывать шифрами Цезаря и Виженера вручную;
- реализовать их в программе (задания A5 на платформе);
- находить ключ шифра Цезаря частотным анализом;
- определять длину ключа Виженера с помощью индекса совпадений.
:::

## Краткая теория

Заменим буквы числами: A = 0, B = 1, …, Z = 25; все операции — **по модулю 26**.

| Шифр | Шифрование | Пространство ключей | Слабость |
|---|---|---|---|
| **Цезарь** | *C* = (*P* + *k*) mod 26 | 25 ключей | полный перебор, частотный анализ |
| **Атбаш** | *C* = 25 − *P* (A↔Z, B↔Y) | ключа нет | раскрывается сразу, если известен алгоритм |
| **Аффинный** | *C* = (*a*·*P* + *b*) mod 26, НОД(*a*, 26) = 1 | 12 · 26 = 312 | полный перебор, уравнения по двум парам букв |
| **Простая замена** | каждая буква заменяется другой по таблице | 26! ≈ 4 · 10²⁶ | частотный анализ (несмотря на большое пространство ключей!) |
| **Виженер** | *C*ᵢ = (*P*ᵢ + *K*ᵢ mod *m*) mod 26 | 26^*m* | ключ повторяется: метод Казиски, индекс совпадений |

**Шифр Виженера** — несколько шифров Цезаря, применяемых по очереди: каждая буква ключа задаёт свой сдвиг (A = 0, B = 1, …). Когда ключ заканчивается, он повторяется с начала. Для работы вручную используется **таблица Виженера** (tabula recta): строка — буква ключа, столбец — буква открытого текста, на пересечении — буква шифртекста. Три века он считался «невзламываемым шифром» (le chiffre indéchiffrable); в 1863 году Ф. Казиски опубликовал метод его вскрытия.

## Практическая работа

**Шаг 1. Шифрование вручную.** Выполните в тетради и проверьте результат.

- Цезарь, *k* = 3: HUJUM → H+3 = K, U+3 = X, J+3 = M, U+3 = X, M+3 = P → **KXMXP**.
- Виженер, ключ KEY: SALOM. Пишем ключ под текстом с повторением: KEYKE. S(18)+K(10) = 28 mod 26 = 2 → C; A(0)+E(4) = 4 → E; L(11)+Y(24) = 35 mod 26 = 9 → J; O(14)+K(10) = 24 → Y; M(12)+E(4) = 16 → Q → **CEJYQ**.
- Самостоятельно: зашифруйте своё имя шифром Цезаря с *k* = 5; зашифруйте «TOSHKENT» шифром Виженера с ключом LIMON и дайте соседу расшифровать.

**Шаг 2. Программа.** Выполните два задания на платформе: **шифр Цезаря** (отрицательное *k* — расшифрование) и **шифр Виженера** (E — шифрование, D — расшифрование; пробелы и знаки препинания не меняются, индекс ключа сдвигается только на буквах). Обратите внимание на сохранение регистра и на отрицательный остаток по модулю 26.

## Разобранный пример 1: частотный анализ шифра Цезаря

В любом языке буквы встречаются неравномерно: в узбекском латинском тексте самая частая буква — **A** (примерно каждая 6–7-я), затем I, O, L, R. Шифр Цезаря не меняет это распределение, а лишь сдвигает его. Подсчитайте буквы шифртекста и выведите самые частые вместе с ключом *k* в предположении «эта буква на самом деле A».

```python
import sys

matn = sys.stdin.read().upper()
sanoq = [0] * 26
for ch in matn:
    if "A" <= ch <= "Z":
        sanoq[ord(ch) - 65] += 1
jami = sum(sanoq)
print(f"букв: {jami}")
tartib = sorted(range(26), key=lambda i: (-sanoq[i], i))   # от частых к редким, при равенстве по алфавиту
for i in tartib[:4]:
    print(f"{chr(65 + i)} {sanoq[i]} {100 * sanoq[i] / jami:.1f}% k={i}")   # если эта буква — A, то k = i − 0
```
```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int[] sanoq = new int[26];
        while (in.hasNextLine()) {
            for (char ch : in.nextLine().toUpperCase().toCharArray()) {
                if (ch >= 'A' && ch <= 'Z') sanoq[ch - 'A']++;
            }
        }
        int jami = 0;
        for (int s : sanoq) jami += s;
        System.out.println("букв: " + jami);
        List<Integer> tartib = new ArrayList<>();
        for (int i = 0; i < 26; i++) tartib.add(i);
        tartib.sort((a, b) -> sanoq[a] != sanoq[b] ? sanoq[b] - sanoq[a] : a - b);   // от частых к редким, при равенстве по алфавиту
        for (int t = 0; t < 4; t++) {
            int i = tartib.get(t);
            System.out.println(String.format("%c %d %.1f%% k=%d", (char) ('A' + i), sanoq[i], 100.0 * sanoq[i] / jami, i));   // если эта буква — A, то k = i − 0
        }
    }
}
```

## Разобранный пример 2: определение длины ключа Виженера

Шифр Виженера «выравнивает» частоты букв — обычный частотный анализ не работает. Но если длина ключа *m*, то каждая *m*-я буква зашифрована **одним** шифром Цезаря. **Индекс совпадений** (index of coincidence) — вероятность того, что две случайно выбранные буквы одинаковы: IC = Σ *n*ᵢ(*n*ᵢ − 1) / (*N*(*N* − 1)). В естественном тексте IC ≈ 0,07, в случайных буквах ≈ 0,038. В первой строке — наибольшая проверяемая длина *M*, во второй — шифртекст. Для каждого *m* = 1…*M* разбейте текст на *m* столбцов (каждая *m*-я буква), выведите средний IC столбцов и найдите *m* с наибольшим IC.

```python
import sys

satrlar = sys.stdin.read().split("\n")
M = int(satrlar[0])
harflar = [ch for ch in " ".join(satrlar[1:]).upper() if "A" <= ch <= "Z"]
eng_yaxshi, eng_ic = 1, -1.0
for m in range(1, M + 1):
    jami = 0.0
    for r in range(m):
        ustun = harflar[r::m]                     # каждая m-я буква, начиная с буквы r
        n = len(ustun)
        sanoq = [0] * 26
        for ch in ustun:
            sanoq[ord(ch) - 65] += 1
        jami += sum(c * (c - 1) for c in sanoq) / (n * (n - 1))
    ic = jami / m
    if ic > eng_ic:
        eng_yaxshi, eng_ic = m, ic
    print(f"m={m} IC={ic:.4f}")
print(f"вероятная длина ключа: {eng_yaxshi}")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int M = Integer.parseInt(in.nextLine().trim());
        StringBuilder sb = new StringBuilder();
        while (in.hasNextLine()) {
            for (char ch : in.nextLine().toUpperCase().toCharArray()) {
                if (ch >= 'A' && ch <= 'Z') sb.append(ch);
            }
        }
        String harflar = sb.toString();
        int engYaxshi = 1;
        double engIc = -1.0;
        for (int m = 1; m <= M; m++) {
            double jami = 0.0;
            for (int r = 0; r < m; r++) {
                int[] sanoq = new int[26];
                int n = 0;
                for (int i = r; i < harflar.length(); i += m) {   // каждая m-я буква, начиная с буквы r
                    sanoq[harflar.charAt(i) - 'A']++;
                    n++;
                }
                long juftlar = 0;
                for (int c : sanoq) juftlar += (long) c * (c - 1);
                jami += (double) juftlar / ((long) n * (n - 1));
            }
            double ic = jami / m;
            if (ic > engIc) {
                engYaxshi = m;
                engIc = ic;
            }
            System.out.println(String.format("m=%d IC=%.4f", m, ic));
        }
        System.out.println("вероятная длина ключа: " + engYaxshi);
    }
}
```

#include <cstdio>

    string satr;

            long long sanoq[26] = {0};
            long long n = 0;
            for (size_t i = r; i < harflar.size(); i += m) {   // каждая m-я буква, начиная с буквы r

}

Следующий шаг: разбить текст на 5 столбцов и применить к каждому частотный анализ из примера 1 — самая частая буква каждого столбца даёт одну букву ключа. Так вы найдёте ключ (здесь KALIT) и расшифруете текст своей программой Виженера. (Кратные *m* — 10, 15 — тоже дают высокий IC; поэтому выбирают наименьшее «высокое» значение.)

:::warning
**Частые ошибки**

- **Отрицательный остаток.** В Python (−3) % 26 = 23, а в Java и C++ — −3; при расшифровании используйте (*x* % 26 + 26) % 26.
- **Сдвиг индекса ключа и на пробелах.** В задании Виженера ключ продвигается только на буквах.
- **Потеря регистра.** Сохраняйте тип буквы: сдвиги относительно 'a' и 'A' считаются отдельно.
- **Частотный анализ короткого текста.** На 20–30 буквах статистика ненадёжна; проверяйте несколько гипотез.
- **Использование классических шифров для реальных данных.** Они только для обучения; на практике используется AES (A6).
:::

## Итоги

- Цезарь: *C* = (*P* + *k*) mod 26, 25 ключей — легко вскрывается полным перебором и частотным анализом.
- У шифра простой замены большое пространство ключей (26!), но статистика букв сохраняется, и частотный анализ его вскрывает.
- Виженер — шифры Цезаря по очереди по буквам ключа; из-за повторения ключа ломается методом Казиски и индексом совпадений.
- Индекс совпадений: ≈ 0,07 в естественном тексте, ≈ 0,038 в случайных буквах — при верной длине ключа IC столбцов резко растёт.
- Урок: надёжный шифр должен иметь большое пространство ключей и не оставлять в шифртексте статистики языка.

Q: Как шифруется «ABC» шифром Цезаря с ключом k = 3?
A: «DEF».
Q: Почему 26! ключей шифра простой замены не делают его надёжным?
A: Каждая буква всегда заменяется одной и той же буквой, поэтому частоты языка сохраняются и частотный анализ находит ключ без перебора.
Q: Какую слабость даёт повторение ключа в шифре Виженера?
A: Каждая m-я буква зашифрована одним шифром Цезаря — если найти длину ключа, шифр распадается на m шифров Цезаря.
Q: Как индекс совпадений показывает длину ключа?
A: При верной длине каждый столбец — один шифр Цезаря, и IC поднимается до значения естественного языка (≈ 0,07); при неверной он остаётся близким к случайному.
