## Почему эта тема важна?

«Энигма» — самая известная машина в истории криптографии. Во Второй мировой войне вооружённые силы Германии считали её невзламываемой: пространство ключей превышало 10²⁰. Тем не менее польские и британские математики регулярно её читали, и историки считают, что это сократило войну на несколько лет. История «Энигмы» ярко иллюстрирует уроки M5: большого пространства ключей недостаточно; структурные свойства шифра и **ошибки людей** могут его сломать. Кроме того, машины, построенные для взлома «Энигмы», стали одними из предшественников современных компьютеров.

## Устройство «Энигмы»

«Энигма» — электромеханическая **роторная** шифровальная машина (изобретена в 1920-х годах для коммерческого применения, затем принята вооружёнными силами Германии).

| Часть | Назначение |
|---|---|
| **Клавиатура и ламповая панель** | оператор нажимает букву — загорается лампа зашифрованной буквы |
| **Коммутационная панель** (Steckerbrett) | кабелями меняет местами 10 пар букв (например, A↔Q) |
| **Роторы** (обычно 3 из 5) | диски с 26 контактами и проводами внутри, заменяющими буквы |
| **Рефлектор** | возвращает сигнал обратно через роторы |
| **Установка колец** (Ringstellung) | сдвигает проводку ротора относительно его буквенного кольца |

**Путь шифрования**: клавиша → коммутационная панель → правый, средний, левый ротор → рефлектор → левый, средний, правый ротор (в обратном направлении) → коммутационная панель → лампа. При каждом нажатии **правый ротор поворачивается на шаг**, после полного оборота — средний, затем левый (как в часах). Поэтому одна и та же буква каждый раз шифруется по-разному — «Энигма» является **многоалфавитным** шифром замены с очень длинным периодом (сложным преемником шифра Виженера из A5).

**Пространство ключей** (приблизительная оценка для армейской «Энигмы»):

| Часть | Варианты |
|---|---|
| Выбор 3 роторов из 5 с учётом порядка | 5 · 4 · 3 = 60 |
| Начальные положения роторов | 26³ = 17 576 |
| 10 пар на коммутационной панели | ≈ 1,5 · 10¹⁴ |
| Итого | ≈ 1,6 · 10²⁰ (без учёта установки колец) |

Это примерно 67-битный ключ — огромное для того времени число: полный перебор вручную или механически был невозможен.

## Свойства и слабости «Энигмы»

1. **Взаимная обратность**: благодаря рефлектору шифрование и расшифрование — одна и та же операция. Повторное «шифрование» шифртекста при тех же настройках даёт открытый текст — удобно для операторов, но замена всегда состоит из пар.
2. **Ни одна буква не шифруется сама в себя**: сигнал не может вернуться из рефлектора по тому же проводу. Это маленькое свойство стало огромной слабостью: если угадать, где в шифртексте стоит какое-то слово (**crib** — например, «WETTERBERICHT», сводка погоды), оно не может стоять там, где хотя бы одна его буква совпадает с буквой шифртекста.
3. **Ошибки операторов и процедуры**: однотипные сообщения в одно и то же время каждый день (погода, «без происшествий»), двукратное повторение ключа сообщения (до 1940 года), простые ключи (соседние клавиши, инициалы).
4. **Коммутационная панель лишь меняет пары** и не скрывает структуру роторов.

## Взлом «Энигмы»

- **Польша (1932–1939)**: Мариан Реевский с помощью теории перестановок и повторённого ключа сообщения математически восстановил проводку роторов; вместе с Генриком Зыгальским и Ежи Ружицким были созданы машины «бомба» и перфорированные листы. В июле 1939 года результаты были переданы Великобритании и Франции.
- **Блетчли-парк (Великобритания)**: Алан Тьюринг и Гордон Уэлчман разработали электромеханическую **«Бомбу»**, работавшую по crib, — она быстро перебирала настройки роторов и отбрасывала противоречащие crib. К концу войны работали сотни «Бомб»; полученные разведданные назывались «Ultra».
- **Захваченные материалы**: таблицы ключей и машины, взятые с кораблей и подводных лодок, тоже сыграли важную роль.

## Разобранный пример 1: упрощённая «Энигма»

Модель с **одним ротором** и проводкой ротора I настоящей Enigma I (`EKMFLGDQVZNTOWYHXUSPAIBRCJ`) и рефлектором B (`YRUHQSLDPXNGOKMIEBFZCWVJAT`): перед каждой буквой ротор поворачивается на шаг; сигнал проходит ротор → рефлектор → ротор (в обратную сторону); не-буквы не меняются. В первой строке — начальное положение ротора (0–25), во второй — текст.

```python
import sys

ROTOR = "EKMFLGDQVZNTOWYHXUSPAIBRCJ"        # Enigma I, ротор I
REFLEKTOR = "YRUHQSLDPXNGOKMIEBFZCWVJAT"    # рефлектор B

satrlar = sys.stdin.read().split("\n")
holat = int(satrlar[0])
natija = []
for ch in satrlar[1]:
    if not ("A" <= ch <= "Z"):
        natija.append(ch)
        continue
    holat = (holat + 1) % 26                # ротор поворачивается перед каждой буквой
    c = ord(ch) - 65
    c = (ord(ROTOR[(c + holat) % 26]) - 65 - holat) % 26        # через ротор
    c = ord(REFLEKTOR[c]) - 65                                   # рефлектор
    c = (ROTOR.index(chr((c + holat) % 26 + 65)) - holat) % 26  # обратно через ротор
    natija.append(chr(c + 65))
print("".join(natija))
```
```java
import java.util.Scanner;

public class Main {
    static final String ROTOR = "EKMFLGDQVZNTOWYHXUSPAIBRCJ";       // Enigma I, ротор I
    static final String REFLEKTOR = "YRUHQSLDPXNGOKMIEBFZCWVJAT";   // рефлектор B

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int holat = Integer.parseInt(in.nextLine().trim());
        String matn = in.nextLine();
        StringBuilder natija = new StringBuilder();
        for (char ch : matn.toCharArray()) {
            if (ch < 'A' || ch > 'Z') {
                natija.append(ch);
                continue;
            }
            holat = (holat + 1) % 26;                                 // ротор поворачивается перед каждой буквой
            int c = ch - 'A';
            c = Math.floorMod(ROTOR.charAt((c + holat) % 26) - 'A' - holat, 26);        // через ротор
            c = REFLEKTOR.charAt(c) - 'A';                                                // рефлектор
            c = Math.floorMod(ROTOR.indexOf((char) ((c + holat) % 26 + 'A')) - holat, 26);   // обратно через ротор
            natija.append((char) (c + 'A'));
        }
        System.out.println(natija);
    }
}
```
```cpp
#include <iostream>
#include <string>
using namespace std;

const string ROTOR = "EKMFLGDQVZNTOWYHXUSPAIBRCJ";        // Enigma I, ротор I
const string REFLEKTOR = "YRUHQSLDPXNGOKMIEBFZCWVJAT";    // рефлектор B

int mod26(int x) { return (x % 26 + 26) % 26; }

int main() {
    string satr, matn;
    getline(cin, satr);
    int holat = stoi(satr);
    getline(cin, matn);
    if (!matn.empty() && matn.back() == '\r') matn.pop_back();
    string natija;
    for (char ch : matn) {
        if (ch < 'A' || ch > 'Z') {
            natija += ch;
            continue;
        }
        holat = (holat + 1) % 26;                                  // ротор поворачивается перед каждой буквой
        int c = ch - 'A';
        c = mod26(ROTOR[(c + holat) % 26] - 'A' - holat);          // через ротор
        c = REFLEKTOR[c] - 'A';                                    // рефлектор
        c = mod26((int) ROTOR.find((char) ((c + holat) % 26 + 'A')) - holat);   // обратно через ротор
        natija += (char) (c + 'A');
    }
    cout << natija << endl;
    return 0;
}
```

Ввод:

```text
3
SALOM DUNYO
```

Вывод:

```text

```

Теперь введите результат снова с тем же начальным положением (`3` и `GIMHC NMRUA`) — программа вернёт `SALOM DUNYO` («привет, мир» по-узбекски): благодаря рефлектору шифрование и расшифрование — одна операция. Обратите внимание: две буквы O в тексте зашифрованы по-разному — в H и A, так как положение ротора в каждой позиции другое; и ни одна буква не превратилась сама в себя.

## Разобранный пример 2: проверка позиций crib

Пользуясь тем, что ни одна буква не шифруется сама в себя, криптоаналитики Блетчли-парка сдвигали crib вдоль шифртекста и отбрасывали **невозможные** позиции: если в какой-то позиции буква crib равна букве шифртекста, crib там стоять не может. В первой строке — шифртекст, во второй — crib. Выведите все возможные начальные позиции (с 0) и их число.

```python
import sys

satrlar = sys.stdin.read().split("\n")
shifr, crib = satrlar[0].strip(), satrlar[1].strip()
mumkin = []
for i in range(len(shifr) - len(crib) + 1):
    if all(shifr[i + j] != crib[j] for j in range(len(crib))):   # ни одна буква не должна совпасть
        mumkin.append(i)
print("возможно: " + " ".join(map(str, mumkin)))
print(f"{len(mumkin)} / {len(shifr) - len(crib) + 1}")
```
```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String shifr = in.nextLine().trim(), crib = in.nextLine().trim();
        List<String> mumkin = new ArrayList<>();
        int jami = shifr.length() - crib.length() + 1;
        for (int i = 0; i < jami; i++) {
            boolean ok = true;
            for (int j = 0; j < crib.length(); j++) {
                if (shifr.charAt(i + j) == crib.charAt(j)) ok = false;   // ни одна буква не должна совпасть
            }
            if (ok) mumkin.add(String.valueOf(i));
        }
        System.out.println("возможно: " + String.join(" ", mumkin));
        System.out.println(mumkin.size() + " / " + jami);
    }
}
```
```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    string shifr, crib;
    getline(cin, shifr);
    getline(cin, crib);
    while (!shifr.empty() && (shifr.back() == '\r' || shifr.back() == ' ')) shifr.pop_back();
    while (!crib.empty() && (crib.back() == '\r' || crib.back() == ' ')) crib.pop_back();
    vector<int> mumkin;
    int jami = (int) shifr.size() - (int) crib.size() + 1;
    for (int i = 0; i < jami; i++) {
        bool ok = true;
        for (size_t j = 0; j < crib.size(); j++) {
            if (shifr[i + j] == crib[j]) ok = false;                 // ни одна буква не должна совпасть
        }
        if (ok) mumkin.push_back(i);
    }
    cout << "возможно:";
    for (int p : mumkin) cout << " " << p;
    cout << endl << mumkin.size() << " / " << jami << endl;
    return 0;
}

Из 18 позиций 4 сразу отброшены. Чем длиннее crib и чем больше сообщений, тем сильнее фильтр; оставшихся кандидатов «Бомба» проверяла перебором настроек роторов. В современных шифрах (AES) такого «запретного» соответствия между шифртекстом и открытым текстом нет.

## Уроки для современной криптографии

| Опыт «Энигмы» | Современный принцип |
|---|---|
| Машины и роторы захвачены, проводка восстановлена | **принцип Керкгоффса**: стойкость должна зависеть только от ключа (M5) |
| 10²⁰ ключей, но слабые структурные свойства | большое пространство ключей необходимо, но недостаточно |
| Предсказуемые тексты (crib) | шифр должен быть стойким к **атаке с известным открытым текстом** |
| Повтор ключа сообщения, простые ключи | протокол и порядок использования важны так же, как алгоритм; случайные ключи |
| Уверенность «наш шифр не взломать» | открыто проанализированные стандарты, постоянная переоценка |

:::warning
**Частые ошибки**

- **Считать «Энигму» «простым шифром замены».** Ротор поворачивается при каждой букве — это многоалфавитный шифр с очень длинным периодом.
- **Говорить, что её взломал только Тьюринг.** Главный математический прорыв принадлежит польским криптоаналитикам; Блетчли-парк продолжил и расширил их работу.
- **Приравнивать большое пространство ключей к стойкости.** «Энигма» — контрпример.
- **Не проверять исторические факты.** Популярные фильмы упрощают события; в реферате ссылайтесь на исторические исследования и музейные источники.
:::

:::tip
Онлайн-симуляторы «Энигмы» (например, рецепт «Enigma» в CyberChef) дают полную модель с тремя роторами и коммутационной панелью. Сравните с ними модель из примера 1: как изменится результат, если добавить один ротор?

## Итоги

- «Энигма» — роторный электромеханический шифр: коммутационная панель, три ротора, рефлектор; ротор поворачивается при каждой букве.
- Пространство ключей ≈ 1,6 · 10²⁰, но из-за рефлектора ни одна буква не шифруется сама в себя — это открыло путь атаке по crib.
- Первыми её взломали польские математики (Реевский), Блетчли-парк (Тьюринг, Уэлчман) поставил взлом на поток с помощью «Бомбы».
- Ошибки операторов и предсказуемые сообщения значили не меньше слабостей алгоритма.
- Уроки: принцип Керкгоффса, стойкость к атаке с известным открытым текстом, правильный порядок эксплуатации.

## Проверьте себя

:::check
Q: Почему в «Энигме» одна и та же буква каждый раз шифруется по-разному?
A: При каждом нажатии ротор поворачивается, и таблица замены меняется.
Q: Какое свойство «Энигмы» открыло путь атаке по crib?
A: Ни одна буква не шифруется сама в себя — crib не может стоять там, где совпадает с буквой шифртекста.
Q: Как выполняется расшифрование на «Энигме»?
A: Повторным вводом шифртекста при тех же настройках — благодаря рефлектору операция взаимно обратна.
Q: Какой урок о принципе Керкгоффса даёт история «Энигмы»?
A: Машина и её проводка стали известны противнику; стойкость должна опираться только на секретный ключ.
