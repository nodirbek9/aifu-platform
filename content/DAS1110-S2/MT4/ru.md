## Почему это важно

Рекурсия решает задачу через **свою уменьшенную копию**. Некоторые задачи (Ханойские башни, обход деревьев, перебор всех вариантов) очень трудно написать циклом, а рекурсией — в несколько строк. Но чтобы быть уверенным в правильности рекурсивной функции, её надо проектировать **систематически** и отслеживать вызовы. В этой самостоятельной работе вы отработаете этот навык.

:::note
**После этой самостоятельной работы вы сможете:**

- проектировать рекурсивную функцию в три шага: базовый случай, уменьшение, сборка результата;
- составлять таблицу (или дерево) рекурсивных вызовов;
- оценивать глубину рекурсии и число вызовов;
- писать рекурсивное решение на трёх языках и проверять его тестами.
:::

## Краткое повторение темы

Порядок проектирования рекурсивной функции:

1. **Базовый случай** — наименьший случай, ответ на который даётся без рекурсии (`n == 0`, пустая строка, один диск).
2. **Уменьшение** — сведение задачи к одной или нескольким **меньшим** задачам того же вида (`n // 10`, `n - 1`).
3. **Сборка** — получение ответа большой задачи из ответов маленьких.

| Понятие | Смысл |
|---|---|
| Глубина рекурсии | наибольшее число вызовов, одновременно находящихся в стеке |
| Число вызовов | сколько всего раз вызвана функция |
| Порядок вывода | вывод **до** рекурсивного вызова — один порядок, **после** — обратный |

В Python глубина рекурсии по умолчанию ограничена ~1000; в Java и C++ предел зависит от размера стека (обычно от нескольких тысяч до десятков тысяч вызовов).

## Образец: запись цифр в обратном порядке

Дано *n* (0 ≤ *n* ≤ 10¹⁸). Напишите две рекурсивные функции: `teskari(n)` (обратный) выводит цифры *n* начиная с последней в одну строку (`1200` → `0021`), а `raqamlar_soni(n)` (число цифр) возвращает количество цифр. Выведите оба результата на отдельных строках.

```python
def teskari(n):
    print(n % 10, end="")           # сначала последняя цифра
    if n >= 10:
        teskari(n // 10)            # затем остальное


def raqamlar_soni(n):
    if n < 10:                      # базовый случай: одна цифра
        return 1
    return 1 + raqamlar_soni(n // 10)


n = int(input())
teskari(n)
print()
print(raqamlar_soni(n))
```
```java
import java.util.Scanner;

public class Main {
    static void teskari(long n) {
        System.out.print(n % 10);   // сначала последняя цифра
        if (n >= 10) teskari(n / 10);   // затем остальное
    }

    static int raqamlarSoni(long n) {
        if (n < 10) return 1;       // базовый случай: одна цифра
        return 1 + raqamlarSoni(n / 10);
    }

    public static void main(String[] args) {
        long n = new Scanner(System.in).nextLong();
        teskari(n);
        System.out.println();
        System.out.println(raqamlarSoni(n));
    }
}
```
```cpp
#include <iostream>
using namespace std;

void teskari(long long n) {
    cout << n % 10;                 // сначала последняя цифра
    if (n >= 10) teskari(n / 10);   // затем остальное
}

int raqamlarSoni(long long n) {
    if (n < 10) return 1;           // базовый случай: одна цифра
    return 1 + raqamlarSoni(n / 10);
}

int main() {
    long long n;
    cin >> n;
    teskari(n);
    cout << endl;
    cout << raqamlarSoni(n) << endl;
    return 0;
}
```

Таблица вызовов — в самостоятельной работе требуется именно такая таблица (для `raqamlar_soni(1200)`):

| Вызов | Базовый случай? | Возвращает |
|---|---|---|
| `raqamlar_soni(1200)` | нет | 1 + `raqamlar_soni(120)` = 4 |
| `raqamlar_soni(120)` | нет | 1 + `raqamlar_soni(12)` = 3 |
| `raqamlar_soni(12)` | нет | 1 + `raqamlar_soni(1)` = 2 |
| `raqamlar_soni(1)` | да | 1 |

Тесты: `1200` → `0021` и `4`; `7` → `7` и `1`; `0` → `0` и `1`. В `teskari` вывод стоит **до** рекурсивного вызова, поэтому последняя цифра выводится первой. Если перенести `print` после вызова, цифры выйдут в исходном порядке — это тоже полезный опыт. Случай *n* = 0 нужно проверить отдельно: «число цифр числа 0» равно 1, а не 0.

## Задание самостоятельной работы

Решите задание ниже: **Ханойские башни** — переложите *n* дисков с 1-го стержня на 3-й: за раз один диск, больший диск нельзя класть на меньший. Рекурсивная идея: *n* − 1 дисков на вспомогательный стержень, самый большой — на целевой, затем *n* − 1 дисков поверх него. Что сдаётся:

1. **Рекурсивное описание** — параметры функции (число дисков, откуда, куда, вспомогательный), базовый случай и рекурсивный шаг словами.
2. **Программа** — на Python, Java или C++; отправляется в окне задания ниже и должна пройти автоматические тесты.
3. **Дерево вызовов** — для *n* = 3: каждый вызов и выполняемое им перекладывание.
4. **Вывод** — 3–5 предложений: почему число ходов равно 2ⁿ − 1 и сколько времени понадобится при *n* = 64, если делать один ход в секунду.

:::warning
**Критерии оценки и частые ошибки**

- Решение должно быть рекурсивным; программа со списком ходов, записанным вручную или вычисленным только по формуле, не принимается.
- В первой строке выводится число ходов — его надо знать **до** вывода ходов (по формуле или собрав сначала список).
- Не перепутайте стержни в рекурсивных вызовах: *n* − 1 дисков сначала идут на **вспомогательный** стержень.
- Базовый случай — *n* = 0 (ничего не делать) или *n* = 1 (один ход); явно задайте один из них.
:::

:::tip
Сначала выполните ходы для *n* = 1, 2, 3 вручную тремя монетами. Если найденная вручную последовательность совпадает с выводом программы, ей можно доверять и при больших *n*.
:::

## Итоги

- Рекурсивная функция: базовый случай → уменьшение → сборка результата.
- Таблица или дерево вызовов показывает, как работает рекурсия, и помогает находить ошибки.
- Вывод до рекурсивного вызова — один порядок, после — обратный.
- Крайние случаи (*n* = 0, один элемент) в рекурсии требуют особого внимания.
