## Почему это важно

В большой программе код, работающий с массивом, делится на несколько функций: одна читает, другая вычисляет, третья выводит. Правильно передать массив в функцию — навык, нужный каждому программисту: получает ли функция **копию** массива или **сам** массив? Видно ли снаружи изменение внутри функции? В этой самостоятельной работе вы найдёте практические ответы на эти вопросы.

:::note
**После этой самостоятельной работы вы сможете:**

- передавать массив в функцию на трёх языках и правильно определять его длину;
- заранее говорить, что произойдёт, когда функция изменит массив;
- раздельно писать функции, изменяющие массив (процедуры), и вычисляющие функции (возвращающие значение);
- составлять таблицу тестов для функции.
:::

## Краткое повторение темы

| Язык | Объявление функции | Длина | Видно ли изменение внутри функции снаружи? |
|---|---|---|---|
| Python | `def f(a):` | `len(a)` | да — передаётся ссылка на список |
| Java | `static void f(int[] a)` | `a.length` | да — передаётся ссылка на массив |
| C++ (`vector`) | `void f(vector<int>& a)` | `a.size()` | с `&` — да; без `&` — **нет** (копия) |
| C++ (обычный массив) | `void f(int a[], int n)` | отдельный параметр `n` | да — передаётся указатель |

Правила:

1. Если функция **только читает** массив, пишите в C++ `const vector<int>&` — копия не создаётся, и случайно изменить нельзя.
2. Если функция **меняет** массив, пусть об этом говорит её имя (`siljit` — сдвинуть, `saralab_qoy` — отсортировать на месте), и пусть она не возвращает значение.
3. Обычный массив C++ попадает в функцию как указатель и «забывает» свою длину — длину передают отдельно.
4. В Python `a = [...]` внутри функции создаёт **новый** список и не влияет на внешний; а `a[i] = ...` или `a.append(...)` — влияет.

## Образец: сдвиг относительно минимума

В первой строке *n*, во второй — *n* целых чисел. Функция `eng_kichik(a)` (наименьший) возвращает минимум, а процедура `siljit(a)` (сдвинуть) вычитает минимум из каждого элемента, меняя **сам массив**. Основная программа выводит изменённый массив.

```python
def eng_kichik(a):
    natija = a[0]
    for x in a:
        if x < natija:
            natija = x
    return natija


def siljit(a):                      # меняется сам список
    m = eng_kichik(a)
    for i in range(len(a)):
        a[i] -= m


n = int(input())
a = list(map(int, input().split()))
siljit(a)
print(*a)
```
```java
import java.util.Scanner;

public class Main {
    static int engKichik(int[] a) {
        int natija = a[0];
        for (int x : a) if (x < natija) natija = x;
        return natija;
    }

    static void siljit(int[] a) {   // меняется сам массив
        int m = engKichik(a);
        for (int i = 0; i < a.length; i++) a[i] -= m;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = in.nextInt();
        siljit(a);
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) sb.append(' ');
            sb.append(a[i]);
        }
        System.out.println(sb);
    }
}
```
```cpp
#include <iostream>
#include <vector>
using namespace std;

int engKichik(const vector<int>& a) {          // только читает
    int natija = a[0];
    for (int x : a) if (x < natija) natija = x;
    return natija;
}

void siljit(vector<int>& a) {                  // & — меняется сам массив
    int m = engKichik(a);
    for (int& x : a) x -= m;
}

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    siljit(a);
    for (int i = 0; i < n; i++) {
        if (i > 0) cout << ' ';
        cout << a[i];
    }
    cout << endl;
    return 0;
}
```

Таблица тестов — в самостоятельной работе требуется именно такая таблица:

| Ввод | Ожидаемый результат | Что проверяет |
|---|---|---|
| `4` / `7 3 9 3` | `4 0 6 0` | минимум встречается дважды |
| `3` / `-2 -5 0` | `3 0 5` | отрицательные числа |
| `1` / `42` | `0` | один элемент |
| `3` / `5 5 5` | `0 0 0` | все элементы равны |

Если в C++ написать `siljit(vector<int> a)` (без `&`), программа не сообщит об ошибке, но массив не изменится — первый тест выведет `7 3 9 3`. Таблица тестов нужна именно для того, чтобы ловить такие случаи.

## Задание самостоятельной работы

Решите задание ниже: напишите функцию, которая принимает массив как параметр и возвращает **наибольший элемент и его первую позицию** (считая с 1). Что сдаётся:

1. **Описание функции** — имя, параметры и возвращаемое значение (значения); объясните, как возвращаются два результата (кортеж, `record`, параметры-ссылки или массив).
2. **Программа** — на Python, Java или C++; отправляется в окне задания ниже и должна пройти автоматические тесты.
3. **Таблица тестов** — не менее 5 тестов: максимум в начале, в конце, встречается несколько раз, все элементы отрицательные, один элемент.
4. **Вывод** — 3–5 предложений: меняет ли функция массив и почему.

:::warning
**Критерии оценки и частые ошибки**

- Максимум и позицию должна находить **функция**; программа, целиком написанная в `main`, не получает полного балла.
- Если максимум встречается несколько раз, выводится его **первая** позиция: обратите внимание на разницу между `>` и `>=`.
- Позиция считается с 1, а индекс — с 0; не забудьте `+ 1`.
- Начальным значением должен быть первый элемент, а не `0`: все числа могут быть отрицательными.
:::

:::tip
Сначала проверьте функцию на бумаге по таблице тестов: какие значения функция принимает шаг за шагом для каждого теста, — и только потом переходите к коду.
:::

## Итоги

- Список Python и массив Java передаются в функцию по ссылке: изменение внутри видно снаружи.
- Чтобы изменить `vector` в C++, пишут `&`, только для чтения — `const &`; без `&` передаётся копия.
- С обычным массивом C++ длина передаётся отдельным параметром.
- Вычисляющая функция возвращает значение, а изменяющая процедура меняет сам массив.

## Проверьте себя

:::check
Q: Чему равен `a[0]` в массиве вызывающего в Java после вызова `static void f(int[] a) { a[0] = 9; }`?
A: 9 — передана ссылка на массив, и функция изменила этот самый массив.
Q: Изменится ли внешний массив в C++ после вызова `void f(vector<int> a) { a[0] = 9; }`?
A: Нет: без `&` передана копия.
Q: Изменится ли внешний список в Python после вызова `def f(a): a = [0]`?
A: Нет: `a = [0]` создаёт внутри функции новый список и связывает с ним локальное имя.
Q: Почему в C++ с обычным массивом длину передают отдельно?
A: Массив попадает в функцию как указатель и теряет сведения о своей длине.
