## Почему это важно

Рейтинговая таблица упорядочена по баллам, телефонная книга — по фамилиям, интернет-магазин — по цене. Двоичный поиск работает только на отсортированных данных. Поэтому сортировка — одна из самых частых задач, которые выполняют компьютеры.

В первом семестре мы писали сортировку пузырьком. Для 100 элементов она работает спокойно, но 10 000 студентов университета сортирует медленно, а на миллионе записей практически непригодна. На этой лекции научимся сравнивать методы сортировки по **скорости**, писать простые методы и пользоваться стандартной функцией на больших данных.

- сортировать записи по нескольким ключам стандартной функцией сортировки.

## Сложность алгоритма

Скорость алгоритма измеряется не в секундах, а тем, **как растёт число операций при росте размера входа *n***. Это записывают в **O-нотации** («О большое»):

| Сложность | Название | Операций при *n* = 1000 | Пример |
|---|---|---|---|
| *O*(1) | постоянная | 1 | обращение к элементу массива |
| *O*(log *n*) | логарифмическая | ~10 | двоичный поиск |
| *O*(*n*) | линейная | 1 000 | линейный поиск, сумма |
| *O*(*n* log *n*) | | ~10 000 | сортировка слиянием, стандартный `sort` |
| *O*(*n*²) | квадратичная | 1 000 000 | пузырьком, выбором, вставками |

Разница хорошо видна на больших *n*: при *n* = 1 000 000 *O*(*n*²) — это 10¹² операций (несколько часов на компьютере), *O*(*n* log *n*) — 2 · 10⁷ операций (меньше секунды).

## Сортировка выбором

**Сортировка выбором (selection sort)**: находим наименьший элемент неотсортированной части массива и ставим его в начало этой части.

1. Для *i* от 0 до *n* − 2:
2. находим индекс наименьшего элемента на отрезке *i* … *n* − 1;
3. меняем его местами с `a[i]`.

После каждого шага левая часть отсортирована и стоит на своих местах. Сравнений всегда ~*n*²/2, зато обменов не больше *n* − 1 — это полезно, когда запись дорогая.

## Сортировка вставками

**Сортировка вставками (insertion sort)**: как раскладывание карт в руке — каждый новый элемент вставляется на своё место в отсортированную левую часть. Бóльшие элементы сдвигаются на одну позицию вправо.

На почти отсортированном массиве сортировка вставками очень быстрая — около *n* шагов. Поэтому стандартные функции сортировки используют именно её для маленьких кусков.

## Сортировка слиянием и быстрая сортировка

Оба метода основаны на идее **«разделяй и властвуй»** и рекурсивны:

| | Сортировка слиянием (merge sort) | Быстрая сортировка (quick sort) |
|---|---|---|
| Идея | разделить массив пополам, отсортировать каждую половину и слить две отсортированные части | выбрать опорный элемент, меньшие отправить влево, большие — вправо, отсортировать каждую сторону |
| Сложность | всегда *O*(*n* log *n*) | в среднем *O*(*n* log *n*), в худшем *O*(*n*²) |
| Дополнительная память | *O*(*n*) | *O*(log *n*) |
| Устойчивость | устойчива | неустойчива |

Эти алгоритмы подробно пишутся в следующих курсах; на практике используют их готовые проверенные реализации.

## Устойчивая сортировка и сортировка по ключу

**Устойчивая (stable) сортировка** сохраняет взаимный порядок элементов с равными ключами. Например, если студенты стоят по алфавиту и мы устойчиво сортируем их по баллу, студенты с одинаковым баллом останутся в алфавитном порядке.

Стандартные функции:

| Язык | Функция | Устойчива? | Ключ / сравнение |
|---|---|---|---|
| Python | `a.sort()`, `sorted(a)` | да | `key=lambda x: ...`, `reverse=True` |
| Java | `Arrays.sort`, `list.sort` | для объектов да | `Comparator.comparing(...)` |
| C++ | `sort` / `stable_sort` (`<algorithm>`) | `sort` — нет, `stable_sort` — да | функция сравнения (лямбда) |

Сортировка по нескольким ключам: сначала по первому ключу, при равенстве — по второму. Например, балл по **убыванию**, при равенстве — имя по **возрастанию**.

## Разобранный пример 1: сортировка выбором и число шагов

В первой строке *n*, во второй — *n* чисел. Отсортируйте их выбором; выведите отсортированный массив и число выполненных обменов (элемент сам с собой не меняется).

```python
n = int(input())
a = list(map(int, input().split()))

almashtirish = 0
for i in range(n - 1):
    eng_kichik = i
    for j in range(i + 1, n):
        if a[j] < a[eng_kichik]:
            eng_kichik = j
    if eng_kichik != i:
        a[i], a[eng_kichik] = a[eng_kichik], a[i]
        almashtirish += 1

print(*a)
print(almashtirish)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = in.nextInt();

        int almashtirish = 0;
        for (int i = 0; i < n - 1; i++) {
            int engKichik = i;
            for (int j = i + 1; j < n; j++) {
                if (a[j] < a[engKichik]) engKichik = j;
            }
            if (engKichik != i) {
                int t = a[i];
                a[i] = a[engKichik];
                a[engKichik] = t;
                almashtirish++;
            }
        }

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) sb.append(' ');
            sb.append(a[i]);
        }
        System.out.println(sb);
        System.out.println(almashtirish);
    }
}
```
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    int almashtirish = 0;
    for (int i = 0; i < n - 1; i++) {
        int engKichik = i;
        for (int j = i + 1; j < n; j++) {
            if (a[j] < a[engKichik]) engKichik = j;
        }
        if (engKichik != i) {
            swap(a[i], a[engKichik]);
            almashtirish++;
        }
    }

    for (int i = 0; i < n; i++) {
        if (i > 0) cout << ' ';
        cout << a[i];
    }
    cout << endl << almashtirish << endl;
    return 0;
}
```

При вводе `5` и `29 10 14 37 13` (*eng_kichik* — наименьший, *almashtirish* — обмены):

| *i* | Наименьший | Массив после шага |
|---|---|---|
| 0 | 10 | 10 29 14 37 13 |
| 1 | 13 | 10 13 14 37 29 |
| 2 | 14 (на месте) | 10 13 14 37 29 |
| 3 | 29 | 10 13 14 29 37 |

Выводится: `10 13 14 29 37` и `3` — на одном из 4 шагов элемент уже стоял на месте. В C++ `swap` — готовая функция обмена из `<utility>`.

## Разобранный пример 2: сортировка вставками

В первой строке *n*, во второй — *n* чисел. Отсортируйте их вставками.

```python
n = int(input())
a = list(map(int, input().split()))

for i in range(1, n):
    joriy = a[i]
    j = i - 1
    while j >= 0 and a[j] > joriy:
        a[j + 1] = a[j]          # сдвигаем больший элемент вправо
        j -= 1
    a[j + 1] = joriy             # ставим на освободившееся место

print(*a)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = in.nextInt();

        for (int i = 1; i < n; i++) {
            int joriy = a[i];
            int j = i - 1;
            while (j >= 0 && a[j] > joriy) {
                a[j + 1] = a[j];         // сдвигаем больший элемент вправо
                j--;
            }
            a[j + 1] = joriy;            // ставим на освободившееся место
        }

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) sb.append(' ');
            sb.append(a[i]);
        }
        System.out.println(sb);
    }
}
```
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    for (int i = 1; i < n; i++) {
        int joriy = a[i];
        int j = i - 1;
        while (j >= 0 && a[j] > joriy) {
            a[j + 1] = a[j];         // сдвигаем больший элемент вправо
            j--;
        }
        a[j + 1] = joriy;            // ставим на освободившееся место
    }

    for (int i = 0; i < n; i++) {
        if (i > 0) cout << ' ';
        cout << a[i];
    }
    cout << endl;
    return 0;
}
```

При вводе `6` и `5 2 4 6 1 3` отсортированная левая часть растёт на каждом шаге на один элемент (*joriy* — текущий):

| *i* | *joriy* | Массив после шага |
|---|---|---|
| 1 | 2 | **2 5** 4 6 1 3 |
| 2 | 4 | **2 4 5** 6 1 3 |
| 3 | 6 | **2 4 5 6** 1 3 |
| 4 | 1 | **1 2 4 5 6** 3 |
| 5 | 3 | **1 2 3 4 5 6** |

Выводится: `1 2 3 4 5 6`. В условии `while` первым стоит `j >= 0`: благодаря короткому замыканию обращения к `a[-1]` не происходит.

## Разобранный пример 3: рейтинг студентов

В первой строке *n*, в следующих *n* строках — имя студента и балл через пробел. Выведите студентов по убыванию балла, при равном балле — по алфавиту.

```python
n = int(input())
talabalar = []
for _ in range(n):
    ism, ball = input().split()
    talabalar.append((ism, int(ball)))

talabalar.sort(key=lambda t: (-t[1], t[0]))

for ism, ball in talabalar:
    print(ism, ball)
```
```java
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;
import java.util.Scanner;

public class Main {
    record Talaba(String ism, int ball) {}

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        List<Talaba> talabalar = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            talabalar.add(new Talaba(in.next(), in.nextInt()));
        }

        talabalar.sort(Comparator.comparingInt(Talaba::ball).reversed()
                .thenComparing(Talaba::ism));

        for (Talaba t : talabalar) {
            System.out.println(t.ism() + " " + t.ball());
        }
    }
}
```
```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

struct Talaba {
    string ism;
    int ball;
};

int main() {
    int n;
    cin >> n;
    vector<Talaba> talabalar(n);
    for (auto& t : talabalar) cin >> t.ism >> t.ball;

    sort(talabalar.begin(), talabalar.end(), [](const Talaba& x, const Talaba& y) {
        if (x.ball != y.ball) return x.ball > y.ball;   // балл: по убыванию
        return x.ism < y.ism;                           // имя: по алфавиту
    });

    for (const auto& t : talabalar) {
        cout << t.ism << " " << t.ball << endl;
    }
    return 0;
}
```

Ввод:

```text
5
Malika 88
Aziz 92
Bekzod 88
Dilnoza 75
Anvar 92
```

Вывод:

```text
Anvar 92
Aziz 92
Bekzod 88
Malika 88
Dilnoza 75
```

В Python ключ — пара `(-ball, ism)`: знак минус обращает порядок баллов, а имя остаётся в обычном порядке. В Java цепочка `Comparator`, в C++ функция сравнения выражают то же правило: «стоит ли *x* раньше *y*?». Эти стандартные функции работают за *O*(*n* log *n*).

:::warning
**Частые ошибки**

- **Сортировка *O*(*n*²) на больших данных.** Для 100 000 элементов сортировка пузырьком превысит лимит времени; используйте стандартный `sort`.
- **`<=` в функции сравнения C++.** Сравнение должно быть «строго меньше»; `<=` ведёт к неопределённому поведению.
- **Не сохранённый результат `sorted(a)` в Python.** `sorted` возвращает новый список; `a.sort()` сортирует на месте и возвращает `None`.
- **Расчёт на устойчивость.** `sort` в C++ неустойчив; если порядок важен — `stable_sort` или полный ключ.
:::

:::tip
Проверяя алгоритм сортировки, обязательно попробуйте три особых входа: уже отсортированный массив, отсортированный в обратном порядке и массив из одинаковых элементов.
:::

## Итоги

- Скорость алгоритма оценивают по тому, как растёт число операций с ростом *n*: разница *O*(*n*²) и *O*(*n* log *n*) на больших *n* огромна.
- Сортировка выбором — найти наименьший и поставить в начало; вставками — вставить каждый элемент в отсортированную часть; обе *O*(*n*²).
- Сортировка слиянием и быстрая сортировка — алгоритмы *O*(*n* log *n*) на принципе «разделяй и властвуй».
- Устойчивая сортировка сохраняет порядок равных элементов.
- На практике используют стандартный `sort`; ключом или функцией сравнения задаётся любой порядок.

Q: Во сколько раз вырастет время работы алгоритма *O*(*n*²), если *n* увеличить в 10 раз?

Q: Сколько обменов выполнит сортировка выбором для массива `4 3 2 1`?
A: 2: 4 ↔ 1, затем 3 ↔ 2; на остальных шагах элементы стоят на месте.
Q: В каком случае сортировка вставками работает очень быстро?
A: Если массив почти отсортирован: каждый элемент близок к своему месту, сдвигов мало — около *n* шагов.
Q: Что такое устойчивая сортировка?
A: Сортировка, сохраняющая исходный взаимный порядок элементов с равными ключами.
Q: Как в Python отсортировать список по баллу по убыванию и по имени по возрастанию?
A: `a.sort(key=lambda t: (-t.ball, t.ism))` (или для пар `(-t[1], t[0])`).
