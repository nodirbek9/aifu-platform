## Почему это важно

Найти книгу в каталоге библиотеки, имя в списке контактов, оценку студента в таблице — всё это **поиск**. После того как элемент найден, с ним обычно что-то делают: удаляют, добавляют рядом новый или сдвигают элементы.

В первом семестре мы видели простую форму линейного и двоичного поиска: «есть ли элемент и где?». На практике вопросы сложнее: где *последнее* вхождение, *сколько* их, какой первый элемент больше *x*? На этом занятии изучим методы, отвечающие на такие вопросы, и основные операции, изменяющие массив.

:::note
**После этого занятия вы сможете:**

- находить первое, последнее и все вхождения линейным поиском;
- находить нижнюю и верхнюю границу в отсортированном массиве двоичным поиском;
- пользоваться стандартными функциями поиска Python, Java и C++;
- удалять элемент из массива и вставлять элемент сдвигом элементов;
- циклически сдвигать массив.
:::

## Виды линейного поиска

Линейный поиск просматривает массив от начала до конца — *O*(*n*). Он работает и на **неотсортированном** массиве. В зависимости от вопроса цикл немного меняется:

| Вопрос | Способ |
|---|---|
| Первое вхождение | остановить цикл сразу после нахождения (`break`) |
| Последнее вхождение | искать с конца или не останавливаться и запоминать последнее найденное |
| Все вхождения / их число | не останавливаться, записывать или считать каждое найденное |
| По условию (например, первое отрицательное) | любое условие вместо `a[i] == x` |

Заранее определите результат «не найдено»: для индекса обычно берут `-1`.

## Границы в отсортированном массиве

В отсортированном массиве двоичный поиск работает за *O*(log *n*) шагов. Кроме «есть ли элемент?», он отвечает на два важных вопроса:

- **нижняя граница** (lower bound) — **первый** индекс, где `a[i] >= x`;
- **верхняя граница** (upper bound) — **первый** индекс, где `a[i] > x`.

Если такого элемента нет, ответ — *n* (конец массива). С их помощью легко найти, **сколько раз** встречается *x*: `верхняя − нижняя`. Например, для `1 2 2 2 5 7` и *x* = 2 нижняя граница 1, верхняя 4, вхождений 3.

Общая схема поиска нижней границы — ответ всегда лежит в отрезке `[chap, ong]` (левая, правая):

```text
chap = 0, ong = n
пока chap < ong:
    orta = (chap + ong) / 2
    если a[orta] < x:  chap = orta + 1
    иначе:             ong = orta
ответ: chap
```

Для верхней границы меняется только условие — на `a[orta] <= x`.

## Стандартные функции поиска

| Язык | Линейный | Двоичный (в отсортированном массиве) |
|---|---|---|
| Python | `x in a`, `a.index(x)`, `a.count(x)` | `bisect_left(a, x)`, `bisect_right(a, x)` (модуль `bisect`) |
| Java | цикл или `list.indexOf(x)` | `Arrays.binarySearch(a, x)` — индекс или отрицательное число |
| C++ | `find(a.begin(), a.end(), x)` | `lower_bound`, `upper_bound`, `binary_search` (`<algorithm>`) |

В Python `bisect_left` — нижняя граница, `bisect_right` — верхняя. `Arrays.binarySearch` в Java не гарантирует, **какой** из повторяющихся элементов будет найден, поэтому, если нужны границы, их пишут самостоятельно.

## Операции над элементами

Массив лежит в памяти непрерывно, поэтому удаление или вставка в середину выполняется **сдвигом элементов**:

- **удаление элемента на позиции *k***: сдвинуть `a[k+1]`, `a[k+2]`, … на одну позицию влево и уменьшить длину на единицу;
- **вставка элемента на позицию *k***: начиная с конца, сдвинуть элементы до `a[k]` на одну позицию вправо, затем `a[k] = x`;
- **циклический сдвиг** (на *k* шагов вправо): каждый `a[i]` попадает на позицию `(i + k) mod n` нового массива.

Эти операции занимают *O*(*n*) времени. В Python `a.pop(k)`, `a.insert(k, x)`, в C++ `vector::erase` и `vector::insert` выполняют такой же сдвиг внутри.

## Разобранный пример 1: удаление всех вхождений

В первой строке *n* и *x*, во второй — *n* чисел. Удалите все элементы, равные *x*: выведите оставшиеся элементы в порядке ввода, а на следующей строке — число удалённых. Если массив стал пустым, в первой строке выведите `-`.

```python
n, x = map(int, input().split())
a = list(map(int, input().split()))

k = 0                       # новая длина
for i in range(n):
    if a[i] != x:
        a[k] = a[i]         # переносим оставляемый элемент вперёд
        k += 1

print(*a[:k] if k > 0 else "-")
print(n - k)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt(), x = in.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = in.nextInt();

        int k = 0;                  // новая длина
        for (int i = 0; i < n; i++) {
            if (a[i] != x) {
                a[k] = a[i];        // переносим оставляемый элемент вперёд
                k++;
            }
        }

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < k; i++) {
            if (i > 0) sb.append(' ');
            sb.append(a[i]);
        }
        System.out.println(k > 0 ? sb : "-");
        System.out.println(n - k);
    }
}
```
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, x;
    cin >> n >> x;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    int k = 0;                  // новая длина
    for (int i = 0; i < n; i++) {
        if (a[i] != x) {
            a[k] = a[i];        // переносим оставляемый элемент вперёд
            k++;
        }
    }

    if (k == 0) cout << "-";
    for (int i = 0; i < k; i++) {
        if (i > 0) cout << ' ';
        cout << a[i];
    }
    cout << endl << n - k << endl;
    return 0;
}
```

При вводе `7 3` и `3 1 3 4 3 5 3` выводится: `1 4 5` и `4`. Удалять каждый элемент отдельно со сдвигом остальных — это *O*(*n*²); здесь же «два указателя» — `i` читает, `k` пишет — просматривают массив один раз, *O*(*n*).

## Разобранный пример 2: число вхождений в отсортированном массиве

В первой строке *n*, во второй — *n* чисел по возрастанию, в третьей — *q*, затем *q* запросов *x*. Для каждого запроса выведите, сколько раз *x* встречается в массиве.

```python
from bisect import bisect_left, bisect_right

n = int(input())
a = list(map(int, input().split()))
q = int(input())
for _ in range(q):
    x = int(input())
    print(bisect_right(a, x) - bisect_left(a, x))
```
```java
import java.util.Scanner;

public class Main {
    // первый индекс, где a[i] >= x (qatiy = false) или a[i] > x (qatiy = true)
    static int chegara(int[] a, int x, boolean qatiy) {
        int chap = 0, ong = a.length;
        while (chap < ong) {
            int orta = (chap + ong) / 2;
            if (a[orta] < x || (qatiy && a[orta] == x)) chap = orta + 1;
            else ong = orta;
        }
        return chap;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = in.nextInt();
        int q = in.nextInt();
        StringBuilder sb = new StringBuilder();
        for (int k = 0; k < q; k++) {
            int x = in.nextInt();
            sb.append(chegara(a, x, true) - chegara(a, x, false)).append('\n');
        }
        System.out.print(sb);
    }
}
```
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    int q;
    cin >> q;
    while (q--) {
        int x;
        cin >> x;
        auto quyi = lower_bound(a.begin(), a.end(), x);
        auto yuqori = upper_bound(a.begin(), a.end(), x);
        cout << (yuqori - quyi) << '\n';
    }
    return 0;
}
```

Ввод:

```text
6
1 2 2 2 5 7
4
2
5
3
8
```

Вывод:

```text
3
1
0
0
```

Для *x* = 3 обе границы равны 4 (первый элемент `>= 3` — это 5), разность 0. Для *x* = 8 обе равны 6 — конец массива. Каждый запрос занимает *O*(log *n*), поэтому даже 10⁵ запросов выполняются быстро. В версии на Java одна функция находит обе границы (*chegara* — граница): параметр `qatiy` («строго») выбирает между `<=` и `<`.

## Разобранный пример 3: циклический сдвиг

В первой строке *n* и *k*, во второй — *n* чисел. Циклически сдвиньте массив на *k* шагов вправо: последние элементы переходят в начало.

```python
n, k = map(int, input().split())
a = list(map(int, input().split()))

k %= n
b = [0] * n
for i in range(n):
    b[(i + k) % n] = a[i]

print(*b)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        long k = in.nextLong();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = in.nextInt();

        int s = (int) (k % n);
        int[] b = new int[n];
        for (int i = 0; i < n; i++) b[(i + s) % n] = a[i];

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) sb.append(' ');
            sb.append(b[i]);
        }
        System.out.println(sb);
    }
}
```
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    long long k;
    cin >> n >> k;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    int s = k % n;
    vector<int> b(n);
    for (int i = 0; i < n; i++) b[(i + s) % n] = a[i];

    for (int i = 0; i < n; i++) {
        if (i > 0) cout << ' ';
        cout << b[i];
    }
    cout << endl;
    return 0;
}
```

При вводе `5 2` и `1 2 3 4 5` выводится: `4 5 1 2 3`. Ввод `5 7` даёт тот же результат: сдвиг на 7 равен сдвигу на 2, ведь через *n* = 5 шагов массив возвращается в исходное состояние, — поэтому сначала берётся `k % n`. Так как *k* может быть очень большим, в Java и C++ он читается как `long`.

:::warning
**Частые ошибки**

- **Двоичный поиск в неотсортированном массиве.** Результат случаен; сначала отсортируйте или используйте линейный поиск.
- **Бесконечный цикл в границах.** `while (chap <= ong)` вместе с `ong = orta` никогда не завершится; сохраняйте `chap < ong` из схемы.
- **Удаление из списка Python во время обхода.** `for v in a: a.remove(v)` пропускает элементы; создайте новый список или используйте два указателя.
- **Забытый `k % n` при сдвиге.** При большом *k* цикл крутится впустую или индекс выходит за границы.
:::

:::tip
Написав двоичный поиск, проверьте его на трёх крайних случаях: *x* меньше всех элементов, больше всех и повторяется несколько раз.
:::

## Итоги

- Линейный поиск — *O*(*n*), работает на любом массиве; в зависимости от вопроса находит первое, последнее или все вхождения.
- В отсортированном массиве нижняя (`>= x`) и верхняя (`> x`) границы находятся двоичным поиском за *O*(log *n*); их разность — число вхождений.
- `bisect` в Python и `lower_bound`/`upper_bound` в C++ дают готовые границы.
- Удаление и вставка в середину массива выполняются сдвигом элементов, *O*(*n*).
- При циклическом сдвиге элемент попадает на позицию `(i + k) mod n`.

## Проверьте себя

:::check
Q: В массиве `4 1 4 2 4` на каком индексе (с 0) последнее вхождение 4?
A: На индексе 4 (последний элемент).
Q: Чему равна нижняя граница для *x* = 4 в массиве `1 3 3 6 9`?
A: 3: первый элемент `>= 4` — это 6, его индекс 3.
Q: Как найти число вхождений *x* в отсортированном массиве?
A: Вычесть нижнюю границу из верхней: `upper_bound − lower_bound`.
Q: Если удалить один элемент из начала массива из 1000 элементов, сколько элементов сдвинется?
A: 999 — все оставшиеся элементы сдвинутся на одну позицию влево.
Q: Что получится при циклическом сдвиге массива `1 2 3 4` на 1 шаг вправо?
A: `4 1 2 3`.
