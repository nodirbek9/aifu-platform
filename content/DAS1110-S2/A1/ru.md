## Почему это важно

Расписание — это дни и пары, ведомость экзамена — студенты и предметы, изображение — строки и столбцы пикселей. Такие данные естественно имеют вид **таблицы** и хранятся в программе в **двумерном массиве** (матрице).

В первом семестре мы изучили одномерные массивы, а на прошлой лекции — методы сортировки. На этом практическом занятии объединим их: прочитаем матрицу, посчитаем по строкам и столбцам и отсортируем строки.

:::note

- транспонировать матрицу;
- объяснять разницу между статическим массивом и массивом, размер которого задаётся при запуске;
- сортировать строки матрицы по заданному критерию.
:::

## Двумерный массив

Двумерный массив — это **массив массивов**: каждый элемент сам является массивом (строкой). `a[i][j]` — элемент в строке *i*, столбце *j*. Оба индекса начинаются с 0.

| Язык | Объявление (*n* × *m*, заполнено нулями) | Элемент |
|---|---|---|
| Python | `a = [[0] * m for _ in range(n)]` | `a[i][j]` |
| Java | `int[][] a = new int[n][m];` | `a[i][j]` |
| C++ (статический) | `int a[100][100];` | `a[i][j]` |
| C++ (размер при запуске) | `vector<vector<int>> a(n, vector<int>(m));` | `a[i][j]` |

В Python нельзя писать `[[0] * m] * n`: так создаётся *n* ссылок на одну строку, и изменение одного элемента меняет весь столбец.

## Статический массив

**Статический массив** — массив, размер которого известен на этапе компиляции. В C++ `int a[100][100];` выделяет память под 100 · 100 значений `int`, даже если в задаче нужна матрица 3 × 4. Поэтому:

- размер должен быть не меньше наибольшей границы из условия (`n, m ≤ 100` — значит `[100][100]`);
- фактические размеры хранятся в отдельных переменных `n` и `m`;
- большой статический массив лучше объявлять **глобально**, а не внутри функции: стек функции мал (обычно 1–8 МБ).

В Java и Python массив создаётся при выполнении (`new int[n][m]`), поэтому его размер можно взять из прочитанных `n` и `m`.

## Обход по строкам и по столбцам

Два вложенных цикла: внешний по строкам, внутренний по столбцам — **обход по строкам**. Если внешний цикл по столбцам, а внутренний по строкам — **обход по столбцам**.

```text
по строкам:   для i = 0..n-1: для j = 0..m-1: a[i][j]
по столбцам:  для j = 0..m-1: для i = 0..n-1: a[i][j]
```

Для суммы строки сумма обнуляется в начале каждой строки, для суммы столбца — в начале каждого столбца. **Транспонирование** превращает строки в столбцы: `t[j][i] = a[i][j]`, результат имеет размер *m* × *n*.

## Сортировка в матрице

Задачи сортировки с матрицей бывают разные:

| Задача | Что сортируется | Как |
|---|---|---|
| Отсортировать каждую строку | элементы внутри строки | сортировать каждую `a[i]` как отдельный массив |
| Отсортировать строки | строки целиком | менять строки местами по ключу (например, по сумме строки) |
| Отсортировать столбец | элементы столбца | скопировать столбец в отдельный массив, отсортировать, записать обратно |

При сортировке строк целиком порядок внутри строки не меняется — местами меняются только строки.

## Разобранный пример 1: суммы строк и максимумы столбцов

В первой строке *n* и *m*, затем *n* строк по *m* целых чисел. Выведите сумму каждой строки, затем наибольший элемент каждого столбца.

```python
n, m = map(int, input().split())
a = [list(map(int, input().split())) for _ in range(n)]

for i in range(n):
    print(sum(a[i]))

ustun_max = []
for j in range(m):
    eng_katta = a[0][j]
    for i in range(1, n):
        if a[i][j] > eng_katta:
            eng_katta = a[i][j]
    ustun_max.append(eng_katta)
print(*ustun_max)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt(), m = in.nextInt();
        int[][] a = new int[n][m];
        for (int i = 0; i < n; i++)
            for (int j = 0; j < m; j++)
                a[i][j] = in.nextInt();

        for (int i = 0; i < n; i++) {
            long yigindi = 0;
            for (int j = 0; j < m; j++) yigindi += a[i][j];
            System.out.println(yigindi);
        }

        StringBuilder sb = new StringBuilder();
        for (int j = 0; j < m; j++) {
            int engKatta = a[0][j];
            for (int i = 1; i < n; i++) {
                if (a[i][j] > engKatta) engKatta = a[i][j];
            }
            if (j > 0) sb.append(' ');
            sb.append(engKatta);
        }
        System.out.println(sb);
    }
}
```
```cpp
#include <iostream>
using namespace std;

int a[100][100];   // статический массив: по наибольшему размеру

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            cin >> a[i][j];

    for (int i = 0; i < n; i++) {
        long long yigindi = 0;
        for (int j = 0; j < m; j++) yigindi += a[i][j];
        cout << yigindi << endl;
    }

    for (int j = 0; j < m; j++) {
        int engKatta = a[0][j];
        for (int i = 1; i < n; i++) {
            if (a[i][j] > engKatta) engKatta = a[i][j];
        }
        if (j > 0) cout << ' ';
        cout << engKatta;
    }
    cout << endl;
    return 0;
}
```

Ввод:

```text
3 4
5 1 8 2
7 3 0 4
1 9 6 2
```

Вывод:

```text
16
14
18
7 9 8 4
```

Для максимума столбца внешний цикл идёт по `j` — это обход по столбцам. Начальное значение — `a[0][j]`, а не `0`: иначе для столбца из отрицательных чисел ответ будет неверным (*yigindi* — сумма, *eng_katta* — наибольший).

## Разобранный пример 2: транспонирование

В первой строке *n* и *m*, затем матрица *n* × *m*. Выведите транспонированную матрицу (*m* × *n*).

```python
n, m = map(int, input().split())
a = [list(map(int, input().split())) for _ in range(n)]

t = [[0] * n for _ in range(m)]
for i in range(n):
    for j in range(m):
        t[j][i] = a[i][j]

for satr in t:
    print(*satr)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt(), m = in.nextInt();
        int[][] a = new int[n][m];
        for (int i = 0; i < n; i++)
            for (int j = 0; j < m; j++)
                a[i][j] = in.nextInt();

        int[][] t = new int[m][n];
        for (int i = 0; i < n; i++)
            for (int j = 0; j < m; j++)
                t[j][i] = a[i][j];

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (j > 0) sb.append(' ');
                sb.append(t[i][j]);
            }
            sb.append('\n');
        }
        System.out.print(sb);
    }
}
```
```cpp
#include <iostream>
using namespace std;

int a[100][100], t[100][100];

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            cin >> a[i][j];

    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            t[j][i] = a[i][j];

    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (j > 0) cout << ' ';
            cout << t[i][j];
        }
        cout << endl;
    }
    return 0;
}
```

При вводе `2 3` и `1 2 3` / `4 5 6` выводится: `1 4`, `2 5`, `3 6`. Массив-результат `t` имеет размер *m* × *n* — число строк и столбцов поменялось (*satr* — строка).

## Разобранный пример 3: сортировка строк по сумме

В первой строке *n* и *m*, затем матрица *n* × *m*. Расположите строки по возрастанию суммы; строки с равной суммой остаются в порядке ввода. Элементы внутри строки не меняются.

```python
n, m = map(int, input().split())
a = [list(map(int, input().split())) for _ in range(n)]

a.sort(key=sum)          # устойчиво: равные суммы сохраняют порядок

for satr in a:
    print(*satr)
```
```java
import java.util.Arrays;
import java.util.Comparator;
import java.util.Scanner;

public class Main {
    static long yigindi(int[] satr) {
        long s = 0;
        for (int x : satr) s += x;
        return s;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt(), m = in.nextInt();
        int[][] a = new int[n][m];
        for (int i = 0; i < n; i++)
            for (int j = 0; j < m; j++)
                a[i][j] = in.nextInt();

        Arrays.sort(a, Comparator.comparingLong(Main::yigindi));   // для объектов устойчиво

        StringBuilder sb = new StringBuilder();
        for (int[] satr : a) {
            for (int j = 0; j < m; j++) {
                if (j > 0) sb.append(' ');
                sb.append(satr[j]);
            }
            sb.append('\n');
        }
        System.out.print(sb);
    }
}
```
```cpp
#include <algorithm>
#include <iostream>
#include <numeric>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> a(n, vector<int>(m));
    for (auto& satr : a)
        for (auto& x : satr) cin >> x;

    stable_sort(a.begin(), a.end(), [](const vector<int>& x, const vector<int>& y) {
        return accumulate(x.begin(), x.end(), 0LL) < accumulate(y.begin(), y.end(), 0LL);
    });

    for (const auto& satr : a) {
        for (int j = 0; j < m; j++) {
            if (j > 0) cout << ' ';
            cout << satr[j];
        }
        cout << endl;
    }
    return 0;
}
```

Ввод:

```text
4 3
5 5 5
1 2 3
9 0 0
3 2 1
```

Вывод:

```text
1 2 3
3 2 1
9 0 0
5 5 5
```

Суммы: 15, 6, 9, 6. У `1 2 3` и `3 2 1` суммы равны (6), поэтому они остаются в порядке ввода — это **устойчивая** сортировка. Поэтому в C++ использован `stable_sort`, а не `sort`; строки — это `vector`, и их можно менять местами целиком (строки статического `int a[100][100]` функцией `sort` переставить нельзя).

:::warning
**Частые ошибки**

- **`[[0] * m] * n` в Python.** Все строки становятся одним списком; пишите `[[0] * m for _ in range(n)]`.
- **Перепутанные индексы.** `a[j][i]` выходит за границы при *n* ≠ *m*; всегда `a[строка][столбец]`.
- **Большой статический массив внутри `main`.** `int a[1000][1000]` переполняет стек, и программа падает при запуске; объявите его глобально.
- **Максимум, начатый с `0`.** Неверно для отрицательных чисел; начинайте с первого элемента.
:::

:::tip
Проверяйте программу с матрицей на маленьком, но неквадратном примере (например, 2 × 3): в квадратной матрице путаница `i` и `j` может остаться незамеченной.
:::

## Итоги

- Двумерный массив — массив массивов; `a[i][j]` — строка *i*, столбец *j*.
- Статический массив объявляется по наибольшему размеру, фактический размер хранится в `n`, `m`.
- Внешний цикл по строкам — обход по строкам; по столбцам — обход по столбцам.
- Транспонирование: `t[j][i] = a[i][j]`, размер *m* × *n*.
- Можно сортировать каждую строку как отдельный массив или сортировать строки целиком по ключу.

## Проверьте себя

:::check
Q: Какой элемент `a[2][4]` в матрице 3 × 5?
A: Элемент в третьей строке, пятом столбце — последний элемент последней строки.
Q: Почему `[[0] * 3] * 2` в Python опасно?
A: Обе строки ссылаются на один список: после `a[0][0] = 1` и `a[1][0]` станет 1.
Q: Какого размера будет результат транспонирования матрицы 2 × 5?
A: 5 × 2.
Q: Что написать в Python, чтобы отсортировать каждую строку по возрастанию?
A: `for satr in a: satr.sort()` — каждая строка сортируется как отдельный список.
Q: Меняется ли порядок внутри строки при сортировке строк по сумме?
A: Нет, строки меняются местами целиком.
