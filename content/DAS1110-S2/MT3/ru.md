## Почему это важно

Во многих задачах размер массива-результата заранее неизвестен: «запишите элементы больше заданного числа в отдельный массив», «объедините два массива в один». Такой массив создаётся **во время работы программы** нужного размера. В этой самостоятельной работе вы потренируетесь создавать динамический массив правильного размера, обходить его указателем и возвращать из функции.

:::note
**После этой самостоятельной работы вы сможете:**

- заранее вычислять размер массива-результата и создавать его ровно такого размера;
- правильно освобождать в C++ память, выделенную через `new[]`, с помощью `delete[]`;
- обходить массив указателем;
- возвращать из функции новый динамический массив и его длину.
:::

## Краткое повторение темы

Когда размер результата неизвестен, есть два пути:

| Способ | Идея | Когда |
|---|---|---|
| **Два прохода** | 1-й проход: посчитать, сколько нужно элементов; выделить; 2-й проход: заполнить | обычный массив (`new int[k]`, `new int[k]` в Java) |
| **Растущий массив** | начать с пустого массива и добавлять каждый элемент в конец | `list`, `ArrayList`, `vector` |

| Язык | Создание динамического массива | Освобождение | Возврат из функции |
|---|---|---|---|
| Python | `[0] * k` или `append` | автоматически | `return список` |
| Java | `new int[k]` | автоматически | `return массив;` (длина — в `length`) |
| C++ (`new`) | `int* p = new int[k];` | `delete[] p;` | указатель **и** длина (например, через параметр-ссылку) |
| C++ (`vector`) | `vector<int> v(k);` | автоматически | `return v;` |

В C++, если функция возвращает массив, выделенный через `new`, освободить его через `delete[]` должен **вызывающий** — это соглашение записывается в описании функции. Обход указателем: `for (int* p = a; p != a + n; ++p)` — `*p` текущий элемент.

## Образец: отфильтрованный динамический массив

В первой строке *n*, во второй — *n* целых чисел, в третьей — *x*. Функция `kattalar(a, n, x)` (бо́льшие) должна создать и вернуть **новый** массив из элементов больше *x* (в исходном порядке). Выведите длину нового массива и его элементы (если он пуст — `-`).

```python
def kattalar(a, x):
    natija = []                          # растущий список
    for v in a:
        if v > x:
            natija.append(v)
    return natija


n = int(input())
a = list(map(int, input().split()))
x = int(input())
b = kattalar(a, x)
print(len(b))
print(*b if b else "-")
```
```java
import java.util.Scanner;

public class Main {
    static int[] kattalar(int[] a, int x) {
        int k = 0;
        for (int v : a) if (v > x) k++;  // 1-й проход: подсчёт
        int[] natija = new int[k];       // ровно нужного размера
        int j = 0;
        for (int v : a) if (v > x) natija[j++] = v;   // 2-й проход: заполнение
        return natija;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = in.nextInt();
        int x = in.nextInt();

        int[] b = kattalar(a, x);
        System.out.println(b.length);
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < b.length; i++) {
            if (i > 0) sb.append(' ');
            sb.append(b[i]);
        }
        System.out.println(b.length > 0 ? sb.toString() : "-");
    }
}
```
```cpp
#include <iostream>
using namespace std;

// Возвращает новый массив; вызывающий освобождает его через delete[].
int* kattalar(const int* a, int n, int x, int& k) {
    k = 0;
    for (const int* p = a; p != a + n; ++p)       // 1-й проход: подсчёт
        if (*p > x) k++;
    int* natija = new int[k];                     // ровно нужного размера
    int* q = natija;
    for (const int* p = a; p != a + n; ++p)       // 2-й проход: заполнение
        if (*p > x) *q++ = *p;
    return natija;
}

int main() {
    int n;
    cin >> n;
    int* a = new int[n];
    for (int i = 0; i < n; i++) cin >> a[i];
    int x;
    cin >> x;

    int k;
    int* b = kattalar(a, n, x, k);
    cout << k << endl;
    if (k == 0) cout << "-";
    for (int i = 0; i < k; i++) {
        if (i > 0) cout << ' ';
        cout << b[i];
    }
    cout << endl;

    delete[] b;                                   // память, выделенная kattalar()
    delete[] a;
    return 0;
}
```

Таблица тестов:

| Ввод | Ожидаемый результат | Что проверяет |
|---|---|---|
| `6` / `4 9 1 7 3 9` / `4` | `3`, `9 7 9` | обычный случай, повторяющиеся элементы |
| `3` / `1 2 3` / `5` | `0`, `-` | пустой результат |
| `3` / `-1 -5 -3` / `-4` | `2`, `-1 -3` | отрицательные числа |
| `2` / `4 4` / `4` | `0`, `-` | элементы, равные *x*, не берутся |

В версии на C++ `*q++ = *p` означает «записать туда, куда указывает *q*, затем сдвинуть *q* на следующий элемент». Память выделялась в двух местах (`a` и внутри `kattalar`) — значит, в конце обязательно два `delete[]`.

## Задание самостоятельной работы

Решите задание ниже: **слейте два массива, упорядоченных по возрастанию, в один отсортированный** (merge). Не используйте готовую функцию сортировки: метод двух указателей работает за *O*(*n* + *m*) — на каждом шаге в результат записывается меньший из текущих элементов двух массивов. Что сдаётся:

1. **Алгоритм** — словами или блок-схемой: как сдвигаются указатели и что делать, когда один из массивов закончился.
2. **Программа** — массив-результат создаётся динамически ровно на *n* + *m* элементов; на Python, Java или C++; отправляется в окне задания ниже и должна пройти автоматические тесты.
3. **Таблица тестов** — не менее 5 тестов: один массив целиком меньше другого, элементы вперемешку, равные элементы, один из массивов из одного элемента, массивы разной длины.
4. **Вывод** — 3–5 предложений: почему этот способ быстрее `sort` и сколько дополнительной памяти он требует.

:::warning
**Критерии оценки и частые ошибки**

- Использование функций вроде `sort`, `sorted`, `Arrays.sort` означает, что задание не выполнено.
- Когда один массив закончился, не забудьте скопировать в результат **оставшиеся** элементы другого.
- Если в C++ используется `new[]`, каждому нужен соответствующий `delete[]`.
- Равные элементы оба попадают в результат — ни один не должен потеряться.
:::

## Итоги

- Если размер результата неизвестен: два прохода (подсчёт → выделение → заполнение) или растущий массив.
- В C++ память, выделенная через `new[]`, освобождается через `delete[]`; массив, возвращённый функцией, освобождает вызывающий.
- Обход указателем: `p != a + n`, `*p` — текущий элемент, `++p` — следующий.
- В Java и Python массив хранит свою длину, а указатель C++ — нет, поэтому длину возвращают отдельно.

## Проверьте себя

:::check
Q: Зачем нужен первый проход в методе «двух проходов»?
A: Чтобы узнать, сколько элементов будет в массиве-результате, и создать его ровно такого размера.
Q: Кто должен освободить память в C++ после `int* b = kattalar(...)`?
A: Вызывающий — через `delete[] b;`, потому что массив выделен через `new[]` внутри функции.
Q: Что делает `*q++ = *p`?
A: Записывает значение, на которое указывает `p`, туда, куда указывает `q`, затем сдвигает `q` на следующий элемент.
Q: Почему функция C++ должна вместе с указателем возвращать и длину?
A: Указатель не хранит сведений о длине массива.
