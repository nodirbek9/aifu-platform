## Почему это важно

Операции над матрицами — сложение, умножение, транспонирование, поворот — основа инженерных расчётов, компьютерной графики и искусственного интеллекта. Если каждую операцию написать отдельной функцией, их можно соединять, строя сложные вычисления: `kopaytir(transponirla(A), B)` (умножить, транспонировать). Для этого нужно уметь передавать матрицу в функцию и возвращать из функции новую матрицу.

:::note
**После этой самостоятельной работы вы сможете:**

- передавать матрицу в функцию на трёх языках и определять её размеры внутри функции;
- возвращать из функции новую матрицу;
- раздельно писать функции чтения, вывода и вычислений с матрицей;
- составлять таблицу тестов для матричной функции.
:::

## Краткое повторение темы

| Язык | Параметр | Число строк | Число столбцов | Возврат новой матрицы |
|---|---|---|---|---|
| Python | `def f(m):` | `len(m)` | `len(m[0])` | `return [[0] * p for _ in range(n)]` |
| Java | `static int f(int[][] m)` | `m.length` | `m[0].length` | `return new int[n][p];` |
| C++ | `int f(const vector<vector<int>>& m)` | `m.size()` | `m[0].size()` | `return vector<vector<int>>(n, vector<int>(p));` |
| C++ (статическая) | `int f(int m[][100], int n, int k)` | параметр `n` | параметр `k` | вернуть нельзя — результат через параметр |

Замечания:

1. В C++ при передаче статической матрицы **второе** измерение обязательно (`int m[][100]`): компилятору нужна длина строки, чтобы вычислить адрес `m[i][j]`. Поэтому `vector` удобнее.
2. Если функция только читает матрицу, пишите в C++ `const &` — копия большой матрицы не создаётся.
3. Возврат `vector` из функции в C++ быстр: компилятор «перемещает» его, а не копирует.
4. Чтение и вывод матрицы тоже делайте отдельными функциями — они снова понадобятся в каждой матричной задаче.

## Образец: след и симметричность

В первой строке *n*, затем квадратная матрица *n* × *n*. Функция `iz(m)` (след) находит сумму элементов главной диагонали, а `simmetrikmi(m)` (симметрична ли) — равна ли матрица транспонированной (каждое `m[i][j] == m[j][i]`). Выведите след и `да` или `нет`.

```python
def oqi(n):
    return [list(map(int, input().split())) for _ in range(n)]


def iz(m):
    return sum(m[i][i] for i in range(len(m)))


def simmetrikmi(m):
    n = len(m)
    for i in range(n):
        for j in range(i + 1, n):           # только половина над диагональю
            if m[i][j] != m[j][i]:
                return False
    return True


n = int(input())
m = oqi(n)
print(iz(m))
print("да" if simmetrikmi(m) else "нет")
```
```java
import java.util.Scanner;

public class Main {
    static int[][] oqi(Scanner in, int n) {
        int[][] m = new int[n][n];
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                m[i][j] = in.nextInt();
        return m;
    }

    static long iz(int[][] m) {
        long s = 0;
        for (int i = 0; i < m.length; i++) s += m[i][i];
        return s;
    }

    static boolean simmetrikmi(int[][] m) {
        int n = m.length;
        for (int i = 0; i < n; i++)
            for (int j = i + 1; j < n; j++)     // только половина над диагональю
                if (m[i][j] != m[j][i]) return false;
        return true;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[][] m = oqi(in, n);
        System.out.println(iz(m));
        System.out.println(simmetrikmi(m) ? "да" : "нет");
    }
}
```
```cpp
#include <iostream>
#include <vector>
using namespace std;

using Matritsa = vector<vector<int>>;          // короткое имя

Matritsa oqi(int n) {
    Matritsa m(n, vector<int>(n));
    for (auto& satr : m)
        for (int& x : satr) cin >> x;
    return m;
}

long long iz(const Matritsa& m) {
    long long s = 0;
    for (size_t i = 0; i < m.size(); i++) s += m[i][i];
    return s;
}

bool simmetrikmi(const Matritsa& m) {
    size_t n = m.size();
    for (size_t i = 0; i < n; i++)
        for (size_t j = i + 1; j < n; j++)      // только половина над диагональю
            if (m[i][j] != m[j][i]) return false;
    return true;
}

int main() {
    int n;
    cin >> n;
    Matritsa m = oqi(n);
    cout << iz(m) << endl;
    cout << (simmetrikmi(m) ? "да" : "нет") << endl;
    return 0;
}
```

Таблица тестов:

| Ввод | Ожидаемый результат | Что проверяет |
|---|---|---|
| `3` / `1 2 3` / `2 5 4` / `3 4 9` | `15`, `да` | симметричная матрица |
| `2` / `1 2` / `3 4` | `5`, `нет` | несимметричная |
| `1` / `-7` | `-7`, `да` | матрица 1 × 1 |
| `2` / `0 0` / `0 0` | `0`, `да` | нулевая матрица |

`simmetrikmi` начинает внутренний цикл с `j = i + 1`: незачем сравнивать диагональные элементы с собой и проверять каждую пару дважды (*oqi* — прочитать). `using Matritsa = ...` в C++ даёт длинному типу короткое имя и облегчает чтение описаний функций.

## Задание самостоятельной работы

Решите задание ниже: напишите функцию, которая принимает матрицы *A* (*n* × *m*) и *B* (*m* × *p*) и возвращает **C = A · B**: `C[i][j]` — сумма произведений элементов *i*-й строки *A* и *j*-го столбца *B*. Что сдаётся:

1. **Описание функций** — не менее трёх функций: чтение матрицы, умножение, вывод; параметры и возвращаемое значение каждой.
2. **Программа** — на Python, Java или C++; отправляется в окне задания ниже и должна пройти автоматические тесты.
3. **Таблица тестов** — не менее 4 тестов: квадратные матрицы, прямоугольные матрицы (например, 2 × 3 и 3 × 1), умножение на единичную матрицу, отрицательные элементы; каждый результат вычислен вручную.
4. **Вывод** — 3–5 предложений: сколько операций требует умножение (через *n*, *m*, *p*) и почему число столбцов *A* должно равняться числу строк *B*.

:::warning
**Критерии оценки и частые ошибки**

- Умножение должно быть отдельной **функцией**, возвращающей новую матрицу.
- Размер результата *n* × *p*: внутренний цикл идёт до *m* — не перепутайте индексы.
- Сумма `C[i][j]` для каждой клетки начинается с нуля.
- Элементы до 1000, а *m* до 50: сумма помещается в `int`, но покажите проверку границы в выводе.
:::

:::tip
Тестируйте на прямоугольных матрицах: на квадратных путаница `n`, `m` и `p` может остаться незамеченной.
:::

## Итоги

- Матрица передаётся в функцию как массив массивов; размеры определяются через `len(m)`, `len(m[0])` (или `length`, `size()`).
- В C++ `const vector<vector<int>>&` — передача без копирования и изменения; у статической матрицы указывается второе измерение.
- Возврат новой матрицы из функции во всех трёх языках — обычный `return`.
- Если чтение, вычисления и вывод — в отдельных функциях, их можно использовать и в других задачах.

## Проверьте себя

:::check
Q: Как в Java найти число столбцов матрицы `int[][] m`?
A: `m[0].length` (если матрица не пуста).
Q: Почему в C++ не компилируется `void f(int m[][])`?
A: Не указано второе измерение; компилятору нужна длина строки для вычисления адреса `m[i][j]`.
Q: Какого размера будет результат умножения матрицы 2 × 3 на матрицу 3 × 4?
A: 2 × 4.
Q: Почему `simmetrikmi` начинает внутренний цикл с `j = i + 1`?
A: Диагональные элементы равны сами себе, а каждую пару `(i, j)`–`(j, i)` достаточно проверить один раз.
