## Почему это важно

В первом семестре мы познакомились со стеком и кучей, указателями, `new` и `delete`. Недостаток статического массива в том, что его размер задаётся при компиляции: `int a[100][100]` всегда занимает 40 КБ, а для матрицы 1000 × 1000 его не хватит. Динамическая память решает эту проблему — массив создаётся **во время работы программы** нужного размера.

На этом практическом занятии тренируем три вида динамических массивов: прямоугольную матрицу, массив со строками разной длины и матрицу в одном непрерывном блоке памяти.

:::note
**После этого занятия вы сможете:**

- объяснять арифметику указателей (`p + i`, `*(p + i)`, `p++`);
- создавать в C++ динамическую матрицу через `new` и правильно освобождать её через `delete[]`;
- создавать массив со строками разной длины («рваный» массив);
- хранить матрицу в одномерном массиве с индексом `i * m + j`;
- строить те же структуры в Java и Python.
:::

## Арифметика указателей

В C++ имя массива работает как указатель на его первый элемент. Если прибавить к указателю целое число, он сдвинется вперёд **на столько элементов** (не байтов):

| Выражение | Смысл |
|---|---|
| `p` | адрес первого элемента |
| `p + i` | адрес *i*-го элемента |
| `*(p + i)` | значение *i*-го элемента — то же, что `p[i]` |
| `p++` | переход к следующему элементу |
| `q - p` | число элементов между двумя указателями |

Для `p + i` компилятор сам вычисляет `i * sizeof(int)` байтов. В Java и Python арифметики указателей нет — там используются только индексы, а выход за границы сразу даёт ошибку.

## Динамическая матрица

В C++ динамическая матрица *n* × *m* создаётся в два этапа: сначала массив из *n* **указателей на строки**, затем *m* элементов для каждой строки:

```text
int** a = new int*[n];             // указатели на строки
для каждого i: a[i] = new int[m];  // каждая строка
...
для каждого i: delete[] a[i];      // освобождение — в обратном порядке
delete[] a;
```

Каждому `new[]` должен соответствовать ровно один `delete[]`, иначе возникает **утечка памяти**. Поэтому на практике обычно используют `vector<vector<int>>` — он сам освобождает память. Но понимать `new`/`delete` важно: именно этот процесс скрыт внутри `vector`.

| Язык | Динамическая матрица *n* × *m* | Освобождение |
|---|---|---|
| C++ | `new int*[n]` + `new int[m]` для каждой строки | `delete[]` — каждой строки и массива указателей |
| C++ (рекомендуется) | `vector<vector<int>> a(n, vector<int>(m))` | автоматически |
| Java | `int[][] a = new int[n][m]` | сборщик мусора |
| Python | `[[0] * m for _ in range(n)]` | сборщик мусора |

## «Рваный» массив

Поскольку строки создаются по отдельности, их длина может быть **разной** — такой массив называют «рваным» (jagged). Например, в треугольнике Паскаля в *i*-й строке *i* + 1 элементов; в прямоугольной матрице почти половина места пустовала бы.

| Язык | «Рваный» массив |
|---|---|
| C++ | `a[i] = new int[i + 1];` или `vector<vector<int>>` |
| Java | `int[][] a = new int[n][];` и `a[i] = new int[i + 1];` |
| Python | список списков — каждый внутренний список любой длины |

## Хранение матрицы в одномерном массиве

Матрицу можно хранить и в одном непрерывном массиве: элемент строки *i*, столбца *j* находится на позиции `i * m + j` (строки идут подряд). Преимущества:

- один `new` и один `delete[]` — меньше шансов ошибиться;
- элементы лежат в памяти рядом — быстрее благодаря кешу процессора;
- всю матрицу можно передать в функцию как обычный массив.

Библиотеки графики, обработки изображений и научных вычислений используют именно этот способ.

## Разобранный пример 1: спиральная матрица

Даны *n* и *m*. Заполните динамическую матрицу *n* × *m* числами от 1 до *n* · *m* по спирали по часовой стрелке и выведите её (каждое число шириной 3 символа).

```python
n, m = map(int, input().split())
a = [[0] * m for _ in range(n)]

yuqori, past, chap, ong = 0, n - 1, 0, m - 1
k = 1
while yuqori <= past and chap <= ong:
    for j in range(chap, ong + 1):              # верхняя строка: слева направо
        a[yuqori][j] = k; k += 1
    yuqori += 1
    for i in range(yuqori, past + 1):           # правый столбец: сверху вниз
        a[i][ong] = k; k += 1
    ong -= 1
    if yuqori <= past:
        for j in range(ong, chap - 1, -1):      # нижняя строка: справа налево
            a[past][j] = k; k += 1
        past -= 1
    if chap <= ong:
        for i in range(past, yuqori - 1, -1):   # левый столбец: снизу вверх
            a[i][chap] = k; k += 1
        chap += 1

for satr in a:
    print("".join(f"{x:3d}" for x in satr))
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt(), m = in.nextInt();
        int[][] a = new int[n][m];

        int yuqori = 0, past = n - 1, chap = 0, ong = m - 1, k = 1;
        while (yuqori <= past && chap <= ong) {
            for (int j = chap; j <= ong; j++) a[yuqori][j] = k++;      // верхняя строка: слева направо
            yuqori++;
            for (int i = yuqori; i <= past; i++) a[i][ong] = k++;      // правый столбец: сверху вниз
            ong--;
            if (yuqori <= past) {
                for (int j = ong; j >= chap; j--) a[past][j] = k++;    // нижняя строка: справа налево
                past--;
            }
            if (chap <= ong) {
                for (int i = past; i >= yuqori; i--) a[i][chap] = k++; // левый столбец: снизу вверх
                chap++;
            }
        }

        StringBuilder sb = new StringBuilder();
        for (int[] satr : a) {
            for (int x : satr) sb.append(String.format("%3d", x));
            sb.append('\n');
        }
        System.out.print(sb);
    }
}
```
```cpp
#include <cstdio>
#include <iostream>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    int** a = new int*[n];                      // указатели на строки
    for (int i = 0; i < n; i++) a[i] = new int[m];

    int yuqori = 0, past = n - 1, chap = 0, ong = m - 1, k = 1;
    while (yuqori <= past && chap <= ong) {
        for (int j = chap; j <= ong; j++) a[yuqori][j] = k++;      // верхняя строка: слева направо
        yuqori++;
        for (int i = yuqori; i <= past; i++) a[i][ong] = k++;      // правый столбец: сверху вниз
        ong--;
        if (yuqori <= past) {
            for (int j = ong; j >= chap; j--) a[past][j] = k++;    // нижняя строка: справа налево
            past--;
        }
        if (chap <= ong) {
            for (int i = past; i >= yuqori; i--) a[i][chap] = k++; // левый столбец: снизу вверх
            chap++;
        }
    }

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) printf("%3d", a[i][j]);
        printf("\n");
    }

    for (int i = 0; i < n; i++) delete[] a[i];  // освобождаем каждую строку
    delete[] a;                                 // затем массив указателей
    return 0;
}
```

При вводе `3 4` выводится:

```text
  1  2  3  4
 10 11 12  5
  9  8  7  6
```

Четыре границы (`yuqori`, `past`, `chap`, `ong` — верх, низ, лево, право) после каждого витка сдвигаются внутрь. Два внутренних `if` нужны, чтобы в прямоугольной (не квадратной) матрице оставшаяся одна строка или один столбец не заполнялись дважды. В конце версии на C++ память освобождается **в обратном порядке**: сначала строки, затем массив указателей — иначе адреса строк будут потеряны.

## Разобранный пример 2: треугольник Паскаля («рваный» массив)

Дано *n* (1 ≤ *n* ≤ 30). Выведите первые *n* строк треугольника Паскаля: по краям каждой строки — 1, а внутренний элемент равен сумме двух соседних элементов над ним.

```python
n = int(input())
uchburchak = []
for i in range(n):
    satr = [1] * (i + 1)                       # в i-й строке i+1 элементов
    for j in range(1, i):
        satr[j] = uchburchak[i - 1][j - 1] + uchburchak[i - 1][j]
    uchburchak.append(satr)

for satr in uchburchak:
    print(*satr)
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        int n = new Scanner(System.in).nextInt();
        long[][] uchburchak = new long[n][];            // строки ещё не созданы
        for (int i = 0; i < n; i++) {
            uchburchak[i] = new long[i + 1];            // в i-й строке i+1 элементов
            uchburchak[i][0] = uchburchak[i][i] = 1;
            for (int j = 1; j < i; j++) {
                uchburchak[i][j] = uchburchak[i - 1][j - 1] + uchburchak[i - 1][j];
            }
        }

        StringBuilder sb = new StringBuilder();
        for (long[] satr : uchburchak) {
            for (int j = 0; j < satr.length; j++) {
                if (j > 0) sb.append(' ');
                sb.append(satr[j]);
            }
            sb.append('\n');
        }
        System.out.print(sb);
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    long long** uchburchak = new long long*[n];
    for (int i = 0; i < n; i++) {
        uchburchak[i] = new long long[i + 1];       // в i-й строке i+1 элементов
        uchburchak[i][0] = uchburchak[i][i] = 1;
        for (int j = 1; j < i; j++) {
            uchburchak[i][j] = uchburchak[i - 1][j - 1] + uchburchak[i - 1][j];
        }
    }

    for (int i = 0; i < n; i++) {
        for (int j = 0; j <= i; j++) {
            if (j > 0) cout << ' ';
            cout << uchburchak[i][j];
        }
        cout << endl;
    }

    for (int i = 0; i < n; i++) delete[] uchburchak[i];
    delete[] uchburchak;
    return 0;
}
```

При вводе `5` выводится:

```text
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```

Каждая строка создана ровно нужной длины: при *n* = 30 это 465 элементов, а прямоугольная матрица 30 × 30 заняла бы 900 мест. В Java `new long[n][]` — второе измерение не указано, строки создаются позже по отдельности. Присваивание краёв `[i][0] = [i][i] = 1` в первой строке (*i* = 0) дважды пишет в один элемент — это не ошибка. Значения растут быстро (в 30-й строке до 77 558 760, а в 35-й превышают предел `int`), поэтому выбран `long` (*uchburchak* — треугольник).

## Разобранный пример 3: поворот матрицы в одномерном массиве

В первой строке *n* и *m*, затем матрица *n* × *m*. Храните матрицу в одном одномерном массиве, поверните её на 90° по часовой стрелке в результат (*m* × *n*), тоже одномерный, и выведите.

```python
n, m = map(int, input().split())
a = []
for _ in range(n):
    a.extend(map(int, input().split()))         # строки подряд: a[i*m + j]

b = [0] * (n * m)                               # результат: m строк, n столбцов
for i in range(n):
    for j in range(m):
        b[j * n + (n - 1 - i)] = a[i * m + j]

for i in range(m):
    print(*b[i * n:(i + 1) * n])
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt(), m = in.nextInt();
        int[] a = new int[n * m];                       // строки подряд: a[i*m + j]
        for (int k = 0; k < n * m; k++) a[k] = in.nextInt();

        int[] b = new int[n * m];                       // результат: m строк, n столбцов
        for (int i = 0; i < n; i++)
            for (int j = 0; j < m; j++)
                b[j * n + (n - 1 - i)] = a[i * m + j];

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (j > 0) sb.append(' ');
                sb.append(b[i * n + j]);
            }
            sb.append('\n');
        }
        System.out.print(sb);
    }
}
```
```cpp
#include <iostream>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    int* a = new int[n * m];                    // один непрерывный блок
    for (int* p = a; p < a + n * m; p++) cin >> *p;   // чтение через указатель

    int* b = new int[n * m];                    // результат: m строк, n столбцов
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            *(b + j * n + (n - 1 - i)) = *(a + i * m + j);

    for (int i = 0; i < m; i++) {
        const int* satr = b + i * n;            // начало i-й строки
        for (int j = 0; j < n; j++) {
            if (j > 0) cout << ' ';
            cout << satr[j];
        }
        cout << endl;
    }

    delete[] a;                                 // один new — один delete
    delete[] b;
    return 0;
}
```

Ввод:

```text
2 3
1 2 3
4 5 6
```

Вывод:

```text
4 1
5 2
6 3
```

При повороте *i*-я строка становится (*n* − 1 − *i*)-м столбцом результата: первая строка `1 2 3` попала в последний столбец. В версии на C++ арифметика указателей видна полностью: `for (int* p = a; p < a + n * m; p++)` обходит массив без индексов, а `b + i * n` даёт начало *i*-й строки, которая используется как обычный массив `satr[j]`. На каждую матрицу хватает одного `new` и одного `delete[]`.

:::warning
**Частые ошибки**

- **Путаница `delete` и `delete[]`.** Массив, созданный через `new[]`, освобождается только `delete[]`.
- **Удаление массива указателей первым.** Обращение к `a[i]` после `delete[] a;` — неопределённое поведение; сначала освобождайте строки.
- **`i * n + j` при одномерном хранении.** Длина строки — число столбцов *m*; должно быть `i * m + j` (при *n* = *m* ошибка сразу не видна).
- **Выход указателя за конец массива.** `p <= a + n` — на один элемент больше; условие `p < a + n`.
:::

:::tip
Работая в C++ с `new`/`delete`, сразу после каждого `new` пишите соответствующий `delete`, а затем заполняйте код между ними. В реальных проектах используйте `vector` и `unique_ptr` — они сами освобождают память.
:::

## Итоги

- Прибавление *i* к указателю сдвигает его на *i* элементов вперёд; `*(p + i)` — это `p[i]`.
- Динамическая матрица в C++: массив указателей + каждая строка; освобождение — в обратном порядке.
- Если строки создаются по отдельности, они могут быть разной длины — «рваный» массив экономит память.
- Хранение матрицы в одномерном массиве на позиции `i * m + j` — одно выделение, более быстрый доступ.
- В Java и Python память освобождается автоматически; в C++ на практике предпочтителен `vector`.

## Проверьте себя

:::check
Q: Если `int* p = a;`, чему равно `*(p + 3)`?
A: `a[3]` — четвёртому элементу массива.
Q: Как освободить в C++ матрицу, созданную через `new int*[n]` и `new int[m]` для каждой строки?
A: Сначала `delete[] a[i]` для каждой `a[i]`, затем `delete[] a`.
Q: Что создаёт в Java `new int[5][]`?
A: Массив из 5 ссылок на строки (`null`); каждая строка затем создаётся отдельно через `new int[...]`.
Q: Если матрица 4 × 6 хранится в одномерном массиве, на каком индексе элемент `[2][3]`?
A: На индексе 2 · 6 + 3 = 15.
Q: В чём преимущество «рваного» массива?
A: Каждая строка ровно нужной длины, и память не тратится впустую.
