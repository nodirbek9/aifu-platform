## Почему это важно

Для компьютера каждый символ — это число. `A` — 65, `a` — 97, `0` — 48, пробел — 32. В первом семестре мы познакомились с символьным типом и таблицей ASCII. Знание **устройства** этой таблицы делает многие задачи очень простыми: буквы и цифры идут в таблице подряд, поэтому над символами можно выполнять обычную арифметику.

На этом практическом занятии тренируем работу с кодами символов: меняем регистр буквы, превращаем строку цифр в число и считаем, сколько раз встречается каждая буква, — всё без готовых функций, только через коды.

:::note
**После этого занятия вы сможете:**

- называть основные диапазоны таблицы ASCII (цифры, заглавные и строчные буквы);
- переходить от символа к коду и обратно на трёх языках;
- менять регистр буквы через разность кодов (32);
- превращать строку цифр в число без готовой функции;
- считать частоты букв в массиве с индексом `код − 'a'`.
:::

## Устройство таблицы ASCII

ASCII — 128 символов с кодами от 0 до 127. Самые нужные диапазоны:

| Символы | Коды | Как запомнить |
|---|---|---|
| управляющие символы (`\n` = 10, `\t` = 9) | 0–31 | не печатаются |
| пробел | 32 | |
| `0` … `9` | 48–57 | `'0'` + цифра |
| `A` … `Z` | 65–90 | `'A'` + номер буквы |
| `a` … `z` | 97–122 | `'a'` + номер буквы |

Важные свойства:

- значение символа-цифры: `c - '0'` (например, `'7' - '0'` = 7);
- номер буквы в алфавите: `c - 'a'` (например, `'d' - 'a'` = 3);
- коды заглавной и строчной букв различаются на **32**: `'a' - 'A'` = 32.

Символы с кодами больше 128 (узбекский `ʻ`, кириллица, `€`) в ASCII не входят — они есть в Unicode и записываются в UTF-8 несколькими байтами. Поэтому способы этого занятия верны только для букв ASCII.

## Переход между символом и кодом

| Действие | Python | Java | C++ |
|---|---|---|---|
| символ → код | `ord(c)` | `(int) c` | `(int) c` |
| код → символ | `chr(k)` | `(char) k` | `(char) k` |
| значение цифры | `ord(c) - ord('0')` | `c - '0'` | `c - '0'` |
| буква ли это? | `'a' <= c <= 'z'` | `c >= 'a' && c <= 'z'` | `c >= 'a' && c <= 'z'` |

В Java и C++ `char` — целочисленный тип, поэтому `c - '0'` работает напрямую. В Python символ — строка длины 1, а не число: для арифметики нужны `ord` и `chr`. В Java результат `char + int` имеет тип `int` — если нужен символ, его возвращают через `(char)`.

## Разобранный пример 1: смена регистра

Дана одна строка (символы ASCII). Замените каждую строчную букву заглавной, а заглавную — строчной; остальные символы не меняются. Не используйте готовые функции `upper`/`lower` — только коды.

```python
satr = input()
natija = []
for c in satr:
    k = ord(c)
    if 97 <= k <= 122:              # 'a'..'z'
        natija.append(chr(k - 32))
    elif 65 <= k <= 90:             # 'A'..'Z'
        natija.append(chr(k + 32))
    else:
        natija.append(c)
print("".join(natija))
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        String satr = new Scanner(System.in).nextLine();
        StringBuilder natija = new StringBuilder();
        for (char c : satr.toCharArray()) {
            if (c >= 'a' && c <= 'z') natija.append((char) (c - 32));
            else if (c >= 'A' && c <= 'Z') natija.append((char) (c + 32));
            else natija.append(c);
        }
        System.out.println(natija);
    }
}
```
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string satr;
    getline(cin, satr);
    for (char& c : satr) {                     // & — меняем саму строку
        if (c >= 'a' && c <= 'z') c = c - 32;
        else if (c >= 'A' && c <= 'Z') c = c + 32;
    }
    cout << satr << endl;
    return 0;
}
```

При вводе `Salom, Dunyo! 2024` выводится `sALOM, dUNYO! 2024`. В Python вместо `97` и `122` можно писать `ord('a')` и `ord('z')` — коды запоминать не обязательно. В C++ символы строки меняются напрямую; в Java и Python строки неизменяемы, поэтому собирается новая строка (*satr* — строка, *natija* — результат).

## Разобранный пример 2: превращение строки цифр в число

В одной строке записано целое число со знаком (может начинаться с `-`, длина до 18 цифр). Превратите его в число без готовых функций вроде `int()`, `parseInt`, `stoi` и выведите само число и сумму его цифр. Если в строке встречается что-то кроме цифр, выведите `Ошибка`.

```python
satr = input().strip()
manfiy = satr.startswith("-")
if manfiy:
    satr = satr[1:]

son = 0
yigindi = 0
togri = len(satr) > 0
for c in satr:
    if not ("0" <= c <= "9"):
        togri = False
        break
    raqam = ord(c) - ord("0")
    son = son * 10 + raqam                  # схема Горнера
    yigindi += raqam

if togri:
    print(-son if manfiy else son, yigindi)
else:
    print("Ошибка")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        String satr = new Scanner(System.in).nextLine().trim();
        boolean manfiy = satr.startsWith("-");
        if (manfiy) satr = satr.substring(1);

        long son = 0;
        int yigindi = 0;
        boolean togri = satr.length() > 0;
        for (char c : satr.toCharArray()) {
            if (c < '0' || c > '9') {
                togri = false;
                break;
            }
            int raqam = c - '0';
            son = son * 10 + raqam;                 // схема Горнера
            yigindi += raqam;
        }

        if (togri) System.out.println((manfiy ? -son : son) + " " + yigindi);
        else System.out.println("Ошибка");
    }
}
```
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string satr;
    cin >> satr;
    bool manfiy = !satr.empty() && satr[0] == '-';
    if (manfiy) satr = satr.substr(1);

    long long son = 0;
    int yigindi = 0;
    bool togri = !satr.empty();
    for (char c : satr) {
        if (c < '0' || c > '9') {
            togri = false;
            break;
        }
        int raqam = c - '0';
        son = son * 10 + raqam;                     // схема Горнера
        yigindi += raqam;
    }

    if (togri) cout << (manfiy ? -son : son) << " " << yigindi << endl;
    else cout << "Ошибка" << endl;
    return 0;
}
```

Для `-4071` выводится `-4071 12`; для `12a5` — `Ошибка`. `son = son * 10 + raqam` — **схема Горнера**: для `"407"` получаем 0 → 4 → 40 → 407. Именно этот процесс выполняется внутри готовых функций вроде `int()` (*son* — число, *raqam* — цифра, *manfiy* — отрицательное, *togri* — корректно). Строка из одного `-` тоже даёт `Ошибка`: после него нет цифр.

## Разобранный пример 3: частоты букв

Дана одна строка текста. Без учёта регистра посчитайте, сколько раз встречается каждая латинская буква, и выведите встретившиеся буквы в алфавитном порядке в виде гистограммы: буква, количество и столько же звёздочек.

```python
satr = input()
soni = [0] * 26                             # soni[0] — 'a', soni[25] — 'z'
for c in satr:
    if "A" <= c <= "Z":
        c = chr(ord(c) + 32)                # в строчную
    if "a" <= c <= "z":
        soni[ord(c) - ord("a")] += 1

for i in range(26):
    if soni[i] > 0:
        print(chr(ord("a") + i), soni[i], "*" * soni[i])
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        String satr = new Scanner(System.in).nextLine();
        int[] soni = new int[26];                       // soni[0] — 'a', soni[25] — 'z'
        for (char c : satr.toCharArray()) {
            if (c >= 'A' && c <= 'Z') c = (char) (c + 32);   // в строчную
            if (c >= 'a' && c <= 'z') soni[c - 'a']++;
        }

        for (int i = 0; i < 26; i++) {
            if (soni[i] > 0) {
                System.out.println((char) ('a' + i) + " " + soni[i] + " " + "*".repeat(soni[i]));
            }
        }
    }
}
```
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string satr;
    getline(cin, satr);
    int soni[26] = {0};                             // soni[0] — 'a', soni[25] — 'z'
    for (char c : satr) {
        if (c >= 'A' && c <= 'Z') c = c + 32;       // в строчную
        if (c >= 'a' && c <= 'z') soni[c - 'a']++;
    }

    for (int i = 0; i < 26; i++) {
        if (soni[i] > 0) {
            cout << (char) ('a' + i) << " " << soni[i] << " " << string(soni[i], '*') << endl;
        }
    }
    return 0;
}
```

Ввод:

```text
Banan va Ananas!
```

Вывод:

```text
a 6 ******
b 1 *
n 4 ****
s 1 *
v 1 *
```

Вместо словаря (`dict`, `Map`) использован массив из 26 элементов: код буквы `c - 'a'` сразу служит индексом, и буквы автоматически выводятся по алфавиту. В Java важно `(char) ('a' + i)`: `'a' + i` — это `int`, без приведения выведется число. Этот способ широко применяется в криптографии (взлом шифра Цезаря), анализе текста и сжатии.

:::warning
**Частые ошибки**

- **`char + int` в Java принят за символ.** `'a' + 1` — число 98; для символа — `(char) ('a' + 1)`.
- **Вычитание числа из символа в Python.** `c - '0'` даёт ошибку; пишите `ord(c) - ord('0')`.
- **Символ-цифра принят за само число.** Код `'7'` — 55, а значение — 7; не забывайте `c - '0'`.
- **Способ ASCII для узбекских букв.** Символы вроде `ʻ` или `ш` больше 127; для них `c - 'a'` выходит за границы массива — сначала проверяйте `'a' <= c <= 'z'`.
:::

:::tip
Коды запоминать не нужно: пишите символьные литералы вроде `'A'`, `'a'`, `'0'` — компилятор сам превратит их в коды, а программа станет понятнее.
:::

## Итоги

- В ASCII цифры (48–57), заглавные буквы (65–90) и строчные буквы (97–122) идут подряд.
- Символ → код: `ord` / `(int)`; код → символ: `chr` / `(char)`.
- Значение цифры — `c - '0'`, номер буквы — `c - 'a'`, разница регистров — 32.
- Строка цифр превращается в число по схеме Горнера: `son = son * 10 + raqam`.
- Для частот букв удобен массив из 26 элементов с индексом `c - 'a'`.

## Проверьте себя

:::check
Q: Чему равно `'5' - '0'`?
A: 5: код `'5'` — 53, код `'0'` — 48.
Q: Как через код превратить `'G'` в строчную букву?
A: Прибавить к коду 32: `(char) ('G' + 32)` = `'g'`.
Q: Что выведет в Java `System.out.println('a' + 1);`?
A: 98 — сумма `char` и `int` имеет тип `int`.
Q: По каким шагам схема Горнера превращает строку `"305"` в число?
A: 0 → 3 → 30 → 305.
Q: Почему перед `soni[c - 'a']` нужно проверять, что символ — буква?
A: Для других символов `c - 'a'` отрицательно или больше 25 и выходит за границы массива.
