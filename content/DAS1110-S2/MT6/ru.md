## Почему это важно

Большая часть программ обработки текста работает по одной схеме: строка **разбивается на слова**, каждое слово обрабатывается отдельно, и результат **собирается обратно**. Поисковые системы, проверка орфографии, форматирование заголовков — всё устроено так. В этой самостоятельной работе вы потренируетесь самостоятельно применять эту схему на трёх языках.

:::note
**После этой самостоятельной работы вы сможете:**

- правильно разбивать строку на слова, несмотря на лишние пробелы;
- собирать список слов обратно с нужным разделителем;
- менять отдельные символы внутри слова (например, первую букву);
- составлять таблицу тестов для строковой задачи с крайними случаями.
:::

## Краткое повторение темы

Схема «разбить — обработать — собрать» на трёх языках:

| Этап | Python | Java | C++ |
|---|---|---|---|
| Разбиение | `s.split()` — по любому числу пробелов | `s.trim().split("\\s+")` | `istringstream` и `>>` |
| Работа со словом | `soz.upper()`, `soz[0]`, `soz[1:]` | `soz.toUpperCase()`, `soz.charAt(0)`, `soz.substring(1)` | `toupper(soz[0])`, `soz.substr(1)` |
| Сборка | `" ".join(sozlar)` | `String.join(" ", sozlar)` | цикл и `+=` |

Важные тонкости:

1. В Python `s.split()` (без аргумента) отбрасывает пробелы в начале, в конце и повторяющиеся; а `s.split(" ")` даёт **пустые слова**.
2. В Java `split("\\s+")` возвращает пустую строку первым элементом, если строка начинается с пробела, — поэтому сначала `trim()`.
3. В C++ оператор `>>` сам пропускает пробелы — это самый простой способ разбиения на слова.

## Образец: обратный порядок слов

Дана одна строка текста (между словами может быть несколько пробелов, в начале и конце — пробелы). Выведите слова в обратном порядке через одиночные пробелы; в следующей строке выведите самое длинное слово (если таких несколько — первое).

```python
def sozlarga_ajrat(satr):
    return satr.split()                 # лишние пробелы отбрасываются


def eng_uzun(sozlar):
    natija = sozlar[0]
    for soz in sozlar:
        if len(soz) > len(natija):      # строгое > — остаётся первое
            natija = soz
    return natija


sozlar = sozlarga_ajrat(input())
print(" ".join(reversed(sozlar)))
print(eng_uzun(sozlar))
```
```java
import java.util.Scanner;

public class Main {
    static String[] sozlargaAjrat(String satr) {
        return satr.trim().split("\\s+");    // trim — чтобы первым не было пустое слово
    }

    static String engUzun(String[] sozlar) {
        String natija = sozlar[0];
        for (String soz : sozlar) {
            if (soz.length() > natija.length()) natija = soz;   // строгое > — остаётся первое
        }
        return natija;
    }

    public static void main(String[] args) {
        String[] sozlar = sozlargaAjrat(new Scanner(System.in).nextLine());
        StringBuilder sb = new StringBuilder();
        for (int i = sozlar.length - 1; i >= 0; i--) {
            sb.append(sozlar[i]);
            if (i > 0) sb.append(' ');
        }
        System.out.println(sb);
        System.out.println(engUzun(sozlar));
    }
}
```
```cpp
#include <iostream>
#include <sstream>
#include <string>
#include <vector>
using namespace std;

vector<string> sozlargaAjrat(const string& satr) {
    istringstream oqim(satr);
    vector<string> sozlar;
    string soz;
    while (oqim >> soz) sozlar.push_back(soz);     // >> сам пропускает пробелы
    return sozlar;
}

string engUzun(const vector<string>& sozlar) {
    string natija = sozlar[0];
    for (const string& soz : sozlar) {
        if (soz.size() > natija.size()) natija = soz;   // строгое > — остаётся первое
    }
    return natija;
}

int main() {
    string satr;
    getline(cin, satr);
    vector<string> sozlar = sozlargaAjrat(satr);
    for (int i = (int) sozlar.size() - 1; i >= 0; i--) {
        cout << sozlar[i];
        if (i > 0) cout << ' ';
    }
    cout << endl << engUzun(sozlar) << endl;
    return 0;
}
```

Таблица тестов:

| Ввод | Ожидаемый результат | Что проверяет |
|---|---|---|
| `bugun   havo  juda yaxshi` | `yaxshi juda havo bugun`, `yaxshi` | повторяющиеся пробелы |
| `␣␣salom dunyo␣` | `dunyo salom`, `salom` | пробелы в начале и конце; равная длина — первое |
| `yolgiz` | `yolgiz`, `yolgiz` | одно слово |

(`␣` обозначает пробел.) Во всех трёх языках задача разбита на три независимые части: разбиение (*sozlarga_ajrat*), поиск самого длинного (*eng_uzun*) и сборка в обратном порядке. Каждую часть можно проверить отдельно.

## Задание самостоятельной работы

Решите задание ниже: начните **каждое слово с заглавной буквы**, а остальные буквы сделайте строчными; между словами оставьте один пробел (`  dASturLASH   tili ` → `Dasturlash Tili`). Что сдаётся:

1. **Описание функций** — не менее двух функций: форматирование одного слова и форматирование всей строки.
2. **Программа** — на Python, Java или C++; отправляется в окне задания ниже и должна пройти автоматические тесты.
3. **Таблица тестов** — не менее 5 тестов: обычный случай, повторяющиеся и крайние пробелы, однобуквенные слова, слова целиком заглавными, одно слово.
4. **Вывод** — 3–5 предложений: какие функции вашего языка вы использовали и какой крайний случай дал больше всего ошибок.

:::warning
**Критерии оценки и частые ошибки**

- Не используйте готовый `str.title()` в Python — он ставит заглавную букву и после апострофов и цифр, а цель задания — написать форматирование самому.
- Для однобуквенного слова (`a`) `soz[1:]` / `substring(1)` даёт пустую строку — это не ошибка, но проверьте.
- В конце результата не должно оставаться лишнего пробела.
- Хотя бы одно слово гарантировано, но строка может начинаться с пробела.
:::

:::tip
Сначала напишите функцию форматирования одного слова и проверьте её отдельно на нескольких словах (`dASTUR`, `a`, `Ok`). Когда она заработает, функция для всей строки сведётся к «разбить — применить к каждому — собрать».
:::

## Итоги

- Основная схема обработки текста: разбить на слова → обработать каждое слово → собрать обратно.
- Лишние пробелы: Python `split()`, Java `trim().split("\\s+")`, C++ `>>`.
- Символы внутри слова меняются через индексы и подстроки.
- Разбиение задачи на маленькие функции позволяет проверить каждую часть отдельно.

## Проверьте себя

:::check
Q: Чем различаются результаты `"  a  b ".split()` и `"  a  b ".split(" ")` в Python?
A: Первый — `["a", "b"]`, второй содержит пустые строки: `["", "", "a", "", "b", ""]`.
Q: Почему в Java перед `split("\\s+")` вызывают `trim()`?
A: Если строка начинается с пробела, `split` возвращает пустую строку первым элементом.
Q: Какой самый простой способ разбить строку на слова в C++?
A: Создать `istringstream` и читать из него по словам через `>>`.
Q: Какое сравнение сохраняет первое из нескольких слов одинаковой длины?
A: Строгое `>`: следующее слово той же длины не заменяет результат.
