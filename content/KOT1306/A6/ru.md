## Почему это важно

В многоэтажном доме у каждой квартиры свой роутер, и большинство из них работает на одном и том же канале 2,4 ГГц — в итоге Wi-Fi «есть, но не работает». Другая опасность: роутер с заводским паролем и старым шифрованием открывает сеть посторонним. На этом занятии научимся правильно настраивать беспроводную сеть — канал, ширину и безопасность — и рассчитывать качество сигнала.

:::note
**После этого занятия вы сможете:**

- объяснять различие диапазонов 2,4, 5 и 6 ГГц и почему в 2,4 ГГц рекомендуются только каналы 1, 6, 11;
- выбирать наименее загруженный канал по списку соседних сетей;
- оценивать уровень сигнала в дБм и рассчитывать влияние расстояния и частоты;
- сравнивать протоколы безопасности и безопасно настраивать домашний или офисный роутер.
:::

## Диапазоны и каналы

| Диапазон | Каналы | Преимущество | Недостаток |
|---|---|---|---|
| **2,4 ГГц** | 1–13 (через 5 МГц, ширина каждого 20 МГц) | хорошо проходит сквозь стены, далеко достаёт | всего 3 непересекающихся канала, помехи от микроволновок и Bluetooth |
| **5 ГГц** | 36–165 (шаг 20 МГц, 20+ непересекающихся каналов) | много каналов, высокая скорость | хуже проходит сквозь стены, дальность меньше |
| **6 ГГц** (Wi-Fi 6E/7) | 59 каналов по 20 МГц | чистый диапазон, только новые устройства | самая малая дальность |

В 2,4 ГГц центр канала *c* = 2407 + 5·*c* МГц. Так как ширина канала 20 МГц, каналы, центры которых отличаются меньше чем на 20 МГц (то есть номера отличаются меньше чем на 4), **перекрываются** и мешают друг другу. Поэтому непересекающаяся тройка — **1, 6, 11**.

**Ширина канала**: 20 МГц — самая стабильная; 40 МГц — вдвое быстрее, но в 2,4 ГГц занимает почти весь диапазон; в 5 ГГц ширины 80 и 160 МГц дают высокие скорости Wi-Fi 5/6.

## Уровень сигнала

Уровень сигнала Wi-Fi измеряется в **дБм** (децибелы относительно 1 милливатта): 0 дБм = 1 мВт, 20 дБм = 100 мВт, −70 дБм = 0,0000001 мВт. Значение отрицательное, и чем ближе к 0, тем сильнее сигнал.

| Принимаемый сигнал | Качество |
|---|---|
| −50 дБм и выше | отлично |
| −67 … −50 дБм | хорошо (видеозвонки, стриминг) |
| −80 … −67 дБм | слабо (страницы открываются, медленно) |
| ниже −80 дБм | практически не работает |

Затухание в свободном пространстве (**FSPL**, free-space path loss): FSPL(дБ) = 20·lg(*d*, км) + 20·lg(*f*, МГц) + 32,44. При удвоении расстояния теряется 6 дБ; при росте частоты с 2,4 до 5 ГГц — примерно на 6,5 дБ больше. Стены «съедают» ещё 3–15 дБ.

## Безопасность

| Протокол | Год | Шифрование | Состояние |
|---|---|---|---|
| **WEP** | 1997 | RC4 | взламывается за минуты — **не используйте** |
| **WPA** | 2003 | TKIP | устарел |
| **WPA2** | 2004 | AES-CCMP | текущий минимум; с надёжным паролем |
| **WPA3** | 2018 | AES, обмен ключами SAE | лучший выбор; устойчив к подбору пароля |

Дополнительные правила: отключите **WPS** (8-значный PIN быстро взламывается); смените **пароль администратора** роутера; обновляйте прошивку; создайте отдельную **гостевую сеть**. Скрытие SSID и фильтрация по MAC — не настоящая защита: сниффером видны и SSID, и разрешённые MAC.

## Практическая работа: настройка точки доступа

1. Подключитесь к роутеру или точке доступа кабелем и откройте в браузере страницу управления (обычно `192.168.0.1` или `192.168.1.1`). В Packet Tracer — вкладка **Config → Wireless** устройства **WRT300N** или **AccessPoint-PT**.
2. Смените пароль администратора.
3. Задайте **SSID** (без личных данных, например `AIFU-Lab-3`).
4. Безопасность: **WPA2-Personal (AES)** или **WPA3-Personal**, пароль не короче 12 символов.
5. Посмотрите соседние сети: в Windows

```text
netsh wlan show networks mode=bssid
```

   — выводятся SSID, сигнал (%), канал и стандарт каждой сети. Выберите наименее загруженный канал программой первого примера ниже.
6. Для 2,4 ГГц установите ширину канала 20 МГц; для 5 ГГц — 40 или 80 МГц.
7. Подключите ноутбук и проверьте сигнал, канал и скорость командой `netsh wlan show interfaces`.

## Разобранный пример 1: выбор канала 2,4 ГГц

В первой строке — число соседних сетей *n*, во второй — их каналы (1–13). Для каждого из непересекающихся каналов 1, 6 и 11 выведите число соседей, перекрывающихся с ним (номера каналов отличаются меньше чем на 4), и порекомендуйте наименее загруженный канал (при равенстве — меньший).

```python
n = int(input())
qoshnilar = list(map(int, input().split()))
eng_yaxshi, eng_kam = 0, n + 1
for kanal in (1, 6, 11):
    band = sum(1 for q in qoshnilar if abs(q - kanal) < 4)   # перекрытие 20 МГц
    print("канал " + str(kanal) + ": " + str(band))
    if band < eng_kam:
        eng_yaxshi, eng_kam = kanal, band
print("рекомендуется: " + str(eng_yaxshi))
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] qoshnilar = new int[n];
        for (int i = 0; i < n; i++) qoshnilar[i] = in.nextInt();
        int engYaxshi = 0, engKam = n + 1;
        for (int kanal : new int[] {1, 6, 11}) {
            int band = 0;
            for (int q : qoshnilar) {
                if (Math.abs(q - kanal) < 4) band++;                // перекрытие 20 МГц
            }
            System.out.println("канал " + kanal + ": " + band);
            if (band < engKam) {
                engYaxshi = kanal;
                engKam = band;
            }
        }
        System.out.println("рекомендуется: " + engYaxshi);
    }
}
```
```cpp
#include <cstdlib>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> qoshnilar(n);
    for (int& q : qoshnilar) cin >> q;
    int engYaxshi = 0, engKam = n + 1;
    for (int kanal : {1, 6, 11}) {
        int band = 0;
        for (int q : qoshnilar) {
            if (abs(q - kanal) < 4) band++;                         // перекрытие 20 МГц
        }
        cout << "канал " << kanal << ": " << band << endl;
        if (band < engKam) {
            engYaxshi = kanal;
            engKam = band;
        }
    }
    cout << "рекомендуется: " << engYaxshi << endl;
    return 0;
}
```

Ввод:

```text
6
1 1 6 3 4 13
```

Вывод:

```text
канал 1: 4
канал 6: 3
канал 11: 1
рекомендуется: 11
```

Обратите внимание: соседи на каналах 3 и 4 (неправильно настроенные роутеры) мешают одновременно и каналу 1, и каналу 6 — вот почему плохо выбирать канал, отличный от 1, 6, 11.

## Разобранный пример 2: уровень сигнала в зависимости от расстояния

В каждой строке — мощность передатчика *P* (дБм), частота *f* (МГц) и расстояние *d* (м). Выведите затухание в свободном пространстве, принимаемый сигнал (дБм, один знак) и оценку качества. Ввод читается до конца файла.

```python
import math
import sys

for satr in sys.stdin:
    if not satr.strip():
        continue
    p, f, d = map(int, satr.split())
    fspl = 20 * math.log10(d / 1000) + 20 * math.log10(f) + 32.44   # d в км
    signal = p - fspl
    if signal >= -50:
        baho = "отлично"
    elif signal >= -67:
        baho = "хорошо"
    elif signal >= -80:
        baho = "слабо"
    else:
        baho = "не работает"
    print(f"{fspl:.1f} {signal:.1f} {baho}")
```
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        while (in.hasNextInt()) {
            int p = in.nextInt();
            int f = in.nextInt();
            int d = in.nextInt();
            double fspl = 20 * Math.log10(d / 1000.0) + 20 * Math.log10(f) + 32.44;   // d в км
            double signal = p - fspl;
            String baho;
            if (signal >= -50) {
                baho = "отлично";
            } else if (signal >= -67) {
                baho = "хорошо";
            } else if (signal >= -80) {
                baho = "слабо";
            } else {
                baho = "не работает";
            }
            System.out.println(String.format("%.1f %.1f ", fspl, signal) + baho);
        }
    }
}
```
```cpp
#include <cmath>
#include <cstdio>
#include <iostream>
#include <string>
using namespace std;

int main() {
    int p, f, d;
    while (cin >> p >> f >> d) {
        double fspl = 20 * log10(d / 1000.0) + 20 * log10((double) f) + 32.44;   // d в км
        double signal = p - fspl;
        string baho;
        if (signal >= -50) {
            baho = "отлично";
        } else if (signal >= -67) {
            baho = "хорошо";
        } else if (signal >= -80) {
            baho = "слабо";
        } else {
            baho = "не работает";
        }
        printf("%.1f %.1f %s\n", fspl, signal, baho.c_str());
    }
    return 0;
}
```

Ввод:

```text

20 2437 50
20 5180 50
20 5180 200
17 2412 1000
```

Вывод:

```text

74.2 -54.2 хорошо
80.7 -60.7 хорошо
92.7 -72.7 слабо

```

На одних и тех же 50 м сигнал 5 ГГц на ~6,5 дБ слабее, чем 2,4 ГГц. Это расчёт для открытого пространства — каждая стена в квартире ещё снижает значение, поэтому реальная дальность в помещении гораздо меньше.

:::warning
**Частые ошибки**

- **Выбирать в 2,4 ГГц канал 3, 4 или 9.** Такой канал одновременно мешает двум «чистым» каналам и получает от них помехи.
- **Ширина 40 МГц в 2,4 ГГц.** Она занимает 9 из 13 каналов и ведёт к постоянным столкновениям с соседями.
- **Считать защитой скрытие SSID или фильтрацию по MAC.** Оба легко обходятся сниффером; настоящая защита — WPA2/WPA3 и надёжный пароль.
- **Сравнивать значения дБм как обычные числа.** Сигнал −60 дБм в 10 раз сильнее −70 дБм; разница 3 дБ — мощность вдвое.
:::

:::tip
Установите на телефон приложение-анализатор Wi-Fi и посмотрите, на каких каналах работают соседние сети у вас дома или в общежитии. Запишите уровень сигнала в 1, 5 и 10 метрах от роутера (за стеной) и сравните с результатом второго примера.
:::

## Итоги

- 2,4 ГГц достаёт далеко, но каналов мало (непересекающиеся — 1, 6, 11); 5 и 6 ГГц быстрее и чище, но дальность меньше.
- Уровень сигнала в дБм: −50 и выше — отлично, ниже −80 — не работает; затухание в свободном пространстве растёт логарифмически с расстоянием и частотой.
- Безопасность: WPA2 (AES) — минимум, WPA3 — лучший; WEP и WPS опасны.
- Настройка: пароль администратора, SSID, WPA2/WPA3 и надёжный пароль, выбор канала по соседям, подходящая ширина канала.

:::check
Q: Почему в 2,4 ГГц рекомендуются только каналы 1, 6 и 11?
A: Центры каналов отстоят на 5 МГц, а ширина канала 20 МГц — не перекрывается друг с другом только эта тройка.
Q: Какой сигнал сильнее, −55 дБм или −75 дБм, и во сколько раз?
A: −55 дБм; разница 20 дБ — мощность в 100 раз больше.
Q: Какой протокол безопасности выбрать для домашнего роутера?
A: WPA3-Personal, а если его нет — WPA2-Personal (AES), с надёжным паролем.
Q: Почему рекомендуется отключать WPS?
A: Его 8-значный PIN уязвим к атаке перебором.
Q: На сколько растёт затухание в свободном пространстве при удвоении расстояния?
A: Примерно на 6 дБ (20·lg 2 ≈ 6).
