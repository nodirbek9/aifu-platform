## Почему это важно

Соединить два компьютера одним кабелем легко. Но как построить сеть университета из 500 компьютеров, 20 принтеров и 10 серверов, чтобы она работала быстро, не останавливалась при обрыве одного кабеля и легко расширялась? Ответ дают **топология** (как соединены устройства), **архитектура** (как сеть делится на уровни) и **устройства** (что стоит в каждом узле).

## Принципы построения сетей

| Принцип | Смысл |
|---|---|
| **Стандартизация** | устройства разных производителей работают вместе по общим стандартам (IEEE 802, TCP/IP) |
| **Многоуровневость** (модульность) | сложная задача делится на уровни; каждый уровень взаимодействует только с соседними |
| **Избыточность** | резервные линии и устройства в важных местах — при отказе одного работает другое |
| **Масштабируемость** | возможность расширять сеть без полной перестройки |
| **Иерархия** | уровни ядра (core), распределения (distribution) и доступа (access) |

## Топологии

**Физическая топология** — как на самом деле соединены кабели и устройства. **Логическая топология** — каким путём движется сигнал или данные. Например, сеть на концентраторе физически — звезда, а логически — шина: концентратор рассылает сигнал во все порты.

| Топология | Устройство | Число линий (*n* узлов) | Преимущество | Недостаток |
|---|---|---|---|---|
| **Шина** (bus) | все узлы подключены к одному общему кабелю | 1 общий кабель | дёшево, просто | обрыв кабеля — вся сеть не работает; коллизии |
| **Звезда** (star) | каждый узел подключён к центральному устройству | *n* | обрыв кабеля затрагивает лишь один узел; легко расширять | отказ центрального устройства останавливает всё |
| **Кольцо** (ring) | каждый узел соединён с двумя соседями, образуя замкнутое кольцо | *n* | без коллизий (при маркерном доступе) | один обрыв (в простом кольце) нарушает сеть |
| **Полносвязная** (full mesh) | каждый узел соединён со всеми остальными | *n*(*n* − 1)/2 | самая надёжная | очень дорого; число линий растёт квадратично |
| **Дерево** (tree) | иерархическое соединение звёзд | *n* − 1 | удобна для больших сетей | отказ устройства верхнего уровня отрезает всю ветвь |
| **Гибридная** | смесь топологий | — | гибкость | сложное проектирование |

Современные LAN почти всегда — **коммутируемая звезда** или **дерево**; WAN и сети провайдеров ради надёжности — **частично связанные** (partial mesh).

## Архитектура сети

**Архитектура сети** — общее описание её структуры, протоколов и устройств: на какие уровни она делится (OSI, TCP/IP), какие протоколы используются и какую роль играют узлы. Основные архитектурные модели:

- **клиент–сервер** — сервисы на выделенных серверах;
- **одноранговая** — узлы равноправны;
- **трёхуровневая иерархическая модель** (Cisco) — уровень доступа (коммутаторы, к которым подключены компьютеры пользователей), уровень распределения (маршрутизация между зданиями и этажами), ядро (быстрая магистраль).

## Сетевые устройства

| Устройство | Назначение | Уровень OSI | Главная особенность |
|---|---|---|---|
| **Сетевой адаптер** (NIC) | подключает компьютер к сети | 1–2 | имеет собственный MAC-адрес |
| **Повторитель** (repeater) | усиливает ослабленный сигнал | 1 | не понимает содержания данных |
| **Концентратор** (hub) | многопортовый повторитель | 1 | отправляет кадр **во все** порты |
| **Мост** (bridge) | соединяет два сегмента | 2 | пропускает или блокирует кадр по MAC-адресу |
| **Коммутатор** (switch) | многопортовый мост | 2 | отправляет кадр только в **нужный** порт |
| **Маршрутизатор** (router) | соединяет разные сети | 3 | выбирает лучший путь по IP-адресу |
| **Шлюз** (gateway) | соединяет разные протоколы | 4–7 | преобразует протоколы друг в друга |
| **Беспроводная точка доступа** | подключает Wi-Fi-устройства к проводной сети | 1–2 | мост между радио и Ethernet |

## Разобранный пример 1: число линий для топологии

В первой строке *k*, в следующих *k* строках — название топологии (`shina` — шина, `yulduz` — звезда, `halqa` — кольцо, `toliq` — полносвязная, `daraxt` — дерево) и число узлов *n*. Для каждой выведите нужное число линий связи (кабелей): у шины один общий кабель, у звезды *n* (к центральному устройству), у кольца *n*, у полносвязной *n*(*n* − 1)/2, у дерева *n* − 1.

```python
def liniyalar(tur, n):
    if tur == "shina":
        return 1                        # один общий кабель
    if tur in ("yulduz", "halqa"):
        return n
    if tur == "toliq":
        return n * (n - 1) // 2         # каждая пара — отдельная линия
    return n - 1                        # дерево


k = int(input())
for _ in range(k):
    tur, n = input().split()
    print(tur, liniyalar(tur, int(n)))
```
```java
import java.util.Scanner;

public class Main {
    static long liniyalar(String tur, long n) {
        switch (tur) {
            case "shina": return 1;                 // один общий кабель
            case "yulduz": case "halqa": return n;
            case "toliq": return n * (n - 1) / 2;   // каждая пара — отдельная линия
            default: return n - 1;                  // дерево
        }
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int k = in.nextInt();
        for (int i = 0; i < k; i++) {
            String tur = in.next();
            long n = in.nextLong();
            System.out.println(tur + " " + liniyalar(tur, n));
        }
    }
}
```
```cpp
#include <iostream>
#include <string>
using namespace std;

long long liniyalar(const string& tur, long long n) {
    if (tur == "shina") return 1;                   // один общий кабель
    if (tur == "yulduz" || tur == "halqa") return n;
    if (tur == "toliq") return n * (n - 1) / 2;     // каждая пара — отдельная линия
    return n - 1;                                   // дерево
}

int main() {
    int k;
    cin >> k;
    for (int i = 0; i < k; i++) {
        string tur;
        long long n;
        cin >> tur >> n;
        cout << tur << " " << liniyalar(tur, n) << endl;
    }
    return 0;
}
```

Ввод:

```text
4
yulduz 30
halqa 30
toliq 30
toliq 300
```

Вывод:

```text
yulduz 30
halqa 30
toliq 435
toliq 44850
```

Для 30 компьютеров звезде нужно 30 кабелей, полносвязной — 435; для 300 компьютеров — 44 850 (*liniyalar* — линии, *tur* — вид). Поэтому полносвязная топология используется лишь между немногими важными узлами (например, маршрутизаторами ядра).

## Разобранный пример 2: определение топологии по графу

В первой строке число узлов *n* и соединений *m*, в следующих *m* строках — соединения `u v` (каждая пара один раз). Определите топологию: `yulduz` (один центр связан со всеми, остальные — только с центром), `halqa` (у всех узлов по 2 соседа, граф связный), `toliq` (каждый узел связан со всеми), `chiziq` — линия (два крайних узла с 1 соседом, остальные с 2, связный), иначе `aralash` — смешанная. Считайте *n* ≥ 4.

```python
from collections import deque

n, m = map(int, input().split())
qoshni = [[] for _ in range(n + 1)]
for _ in range(m):
    u, v = map(int, input().split())
    qoshni[u].append(v)
    qoshni[v].append(u)

daraja = [len(qoshni[i]) for i in range(1, n + 1)]

korilgan = {1}                              # проверяем связность поиском в ширину
navbat = deque([1])
while navbat:
    v = navbat.popleft()
    for u in qoshni[v]:
        if u not in korilgan:
            korilgan.add(u)
            navbat.append(u)
boglamli = len(korilgan) == n

if all(d == n - 1 for d in daraja):
    print("toliq")
elif daraja.count(n - 1) == 1 and daraja.count(1) == n - 1:
    print("yulduz")
elif boglamli and all(d == 2 for d in daraja):
    print("halqa")
elif boglamli and daraja.count(1) == 2 and daraja.count(2) == n - 2:
    print("chiziq")
else:
    print("aralash")
```
```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt(), m = in.nextInt();
        List<List<Integer>> qoshni = new ArrayList<>();
        for (int i = 0; i <= n; i++) qoshni.add(new ArrayList<>());
        for (int k = 0; k < m; k++) {
            int u = in.nextInt(), v = in.nextInt();
            qoshni.get(u).add(v);
            qoshni.get(v).add(u);
        }

        boolean[] korilgan = new boolean[n + 1];        // проверяем связность поиском в ширину
        ArrayDeque<Integer> navbat = new ArrayDeque<>();
        korilgan[1] = true;
        navbat.add(1);
        int soni = 1;
        while (!navbat.isEmpty()) {
            int v = navbat.poll();
            for (int u : qoshni.get(v)) {
                if (!korilgan[u]) {
                    korilgan[u] = true;
                    soni++;
                    navbat.add(u);
                }
            }
        }
        boolean boglamli = soni == n;

        int markazlar = 0, birlar = 0, ikkilar = 0;
        for (int i = 1; i <= n; i++) {
            int d = qoshni.get(i).size();
            if (d == n - 1) markazlar++;
            if (d == 1) birlar++;
            if (d == 2) ikkilar++;
        }

        if (markazlar == n) System.out.println("toliq");
        else if (markazlar == 1 && birlar == n - 1) System.out.println("yulduz");
        else if (boglamli && ikkilar == n) System.out.println("halqa");
        else if (boglamli && birlar == 2 && ikkilar == n - 2) System.out.println("chiziq");
        else System.out.println("aralash");
    }
}
```
```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> qoshni(n + 1);
    for (int k = 0; k < m; k++) {
        int u, v;
        cin >> u >> v;
        qoshni[u].push_back(v);
        qoshni[v].push_back(u);
    }

    vector<bool> korilgan(n + 1, false);                // проверяем связность поиском в ширину
    queue<int> navbat;
    korilgan[1] = true;
    navbat.push(1);
    int soni = 1;
    while (!navbat.empty()) {
        int v = navbat.front();
        navbat.pop();
        for (int u : qoshni[v]) {
            if (!korilgan[u]) {
                korilgan[u] = true;
                soni++;
                navbat.push(u);
            }
        }
    }
    bool boglamli = soni == n;

    int markazlar = 0, birlar = 0, ikkilar = 0;
    for (int i = 1; i <= n; i++) {
        int d = qoshni[i].size();
        if (d == n - 1) markazlar++;
        if (d == 1) birlar++;
        if (d == 2) ikkilar++;
    }

    if (markazlar == n) cout << "toliq" << endl;
    else if (markazlar == 1 && birlar == n - 1) cout << "yulduz" << endl;
    else if (boglamli && ikkilar == n) cout << "halqa" << endl;
    else if (boglamli && birlar == 2 && ikkilar == n - 2) cout << "chiziq" << endl;
    else cout << "aralash" << endl;
    return 0;
}
```

| Ввод (*n*, соединения) | Результат |
|---|---|
| 5: 1-2, 1-3, 1-4, 1-5 | `yulduz` |
| 4: 1-2, 2-3, 3-4, 4-1 | `halqa` |
| 4: 1-2, 2-3, 3-4 | `chiziq` |
| 4: все 6 пар | `toliq` |
| 5: 1-2, 2-3, 3-1, 3-4, 4-5 | `aralash` |

Для определения топологии хватает двух признаков: **степени** каждого узла (сколько у него соседей) и **связности** графа. У двух отдельных колец тоже все узлы степени 2, поэтому для кольца и линии связность проверяется поиском в ширину (*qoshni* — соседи, *daraja* — степень, *boglamli* — связный). Такой анализ используется в системах мониторинга сети: они собирают соединения устройств (например, через LLDP) и автоматически рисуют карту сети.

:::warning
**Частые ошибки**

- **Путать физическую и логическую топологию.** Звезда на концентраторе логически работает как шина: все компьютеры конкурируют за один «общий канал».
- **Считать концентратор и коммутатор одним устройством.** Концентратор шлёт кадр во все порты, коммутатор — только в нужный.
- **Забывать о «единой точке отказа» звезды.** При отказе центрального коммутатора останавливается весь сегмент — в важных сетях ставят резервный коммутатор.
- **Использовать маршрутизатор вместо коммутатора.** Маршрутизатор соединяет разные сети (по IP); соединять устройства внутри одной LAN — задача коммутатора.
:::

:::tip
Нарисуйте на бумаге сеть вашего университета или дома: какое устройство где стоит и как подключено. Затем отметьте, какие пользователи останутся без связи при отказе каждого устройства, — это покажет слабые места сети.
:::

## Итоги

- Принципы построения сетей: стандартизация, многоуровневость, избыточность, масштабируемость, иерархия.
- Основные топологии: шина, звезда, кольцо, полносвязная, дерево, гибридная; физическая и логическая топологии могут различаться.
- Полносвязной топологии нужно *n*(*n* − 1)/2 линий — самая надёжная, но самая дорогая.
- Устройства по уровням: повторитель и концентратор (1), мост и коммутатор (2), маршрутизатор (3), шлюз (4–7).

## Проверьте себя

:::check
Q: Сколько линий в полносвязной сети из 10 узлов?
A: 10 · 9 / 2 = 45.
Q: Каков главный недостаток топологии «звезда»?
A: Центральное устройство — единая точка отказа: при его поломке не работает вся сеть.
Q: По чему коммутатор решает, куда отправить кадр?
A: По MAC-адресу получателя (с помощью своей MAC-таблицы).
Q: Какое устройство соединяет разные IP-сети?
A: Маршрутизатор.
Q: Какая топология у сети на концентраторе физически и логически?
A: Физически — звезда, логически — шина.
